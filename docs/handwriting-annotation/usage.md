# 手写笔记与文件批注使用说明

## 入口

- 资源库桌面/移动创建菜单选择“手写笔记”，创建固定分页的 `.dsink` 文件。
- 资源菜单选择“手写批注”，将受支持来源转换为固定页图并打开关联批注文档。
- 已有 `.dsink` 可从资源库、Workbench 文件预览或直接 DSTU 文件编辑入口打开，均使用同一编辑器。

## 编辑与恢复

支持笔、荧光笔、颜色/笔宽、整笔橡皮、撤销/重做、多页导航/追加、改名、缩放/平移；触摸绘制需要显式开启，笔输入使用浏览器支持的压感。

收笔后先持久化本地恢复草稿，再按服务端 revision 保存当前页。保存失败保留可恢复草稿；版本冲突不静默覆盖远端。IndexedDB 写入失败会显示独立存储错误，不能当成草稿已保留。隐藏页面/卸载会尝试完成当前笔并持久草稿。冲突时请先保留草稿再选择远端重载；不要假设失败操作已提交。

## 支持矩阵

| 输入/输出 | 当前边界 |
| --- | --- |
| 空白笔记 | 固定分页，A4默认比例；空白/横线/方格 |
| PDF | 固定PNG逐页转换，保持页序、CropBox和旋转；已有文本高亮以独立只读层合成 |
| PNG/JPEG/WebP/GIF | 本地解码为固定页；以VFS受支持MIME/扩展名一致性为准；GIF为静态固定页面 |
| DOCX/PPTX | 本地预览逐完整页面/slide固化，等待字体/图片/图表；不承诺原生Office高保真 |
| XLS/XLSX/旧DOC/PPT/加密Office | 不支持，不自动启动外部转换器或云服务 |
| PNG导出 | 当前页；共享renderer也支持受控选区导出 |
| PDF导出 | 选页/页序保持，逐页嵌图的扁平栅格PDF，不含可编辑笔迹对象 |

源文件不覆盖，可编辑笔迹保存在独立 `.dsink`。来源变化返回 `SOURCE_CHANGED`，不会将旧笔迹自动套入重排后的新文件。来源被永久删除后，Ink自己持有的固定背景仍保留；原来源的文本高亮不再从已删除资源读取。

## 问 AI

编辑器“问 AI”会先完成当前笔、flush/CAS保存，再生成固定版本PNG并加入Chat图片上下文；不会自动发送消息或调用模型。请在目标对话中确认附件后发送。

Chat启用 `ink-tools` 后提供六个工具：

- `builtin-ink_prepare`：准备/复用来源批注文档。
- `builtin-ink_create`：创建空白笔记。
- `builtin-ink_get`：只读有限文档/页/操作摘要，不返回笔迹点数组。
- `builtin-ink_render`：生成含笔迹与来源高亮的真实页图，并经可信本地图片引用交给模型。
- `builtin-ink_apply_ops`：单批1–100项文本、形状或页面操作；几何定位绑定当前render与revision。
- `builtin-ink_export`：生成独立PNG或扁平PDF产物。

仅识别/解释默认只读。更新/删除既有对象必须通过精确的一次性审批，不能靠全局bypass降级。编辑器草稿无法安全协调时返回 `EDITOR_BUSY`；文本模型看图返回 `VISION_MODEL_REQUIRED`；图像未送达返回 `IMAGE_DELIVERY_FAILED`，不能把普通工具文本当作看过图片。

工具卡可打开文档与导出/快照产物。AI事务撤销按对象校验，不回滚整本文件，也不删除后来无关人类笔迹。跨调用精确重试不复制撤销authority：新工具卡会如实禁用未绑定的撤销入口，并在输出中链接原可信回执。

## 数据与限制

文档、页、背景和产物均在现有VFS/DSTU/blob中；原始笔迹JSON不进入通用正文、OCR或RAG。历史模型图片是不可变快照，不随之后编辑漂移。图像预算与检索共享，最多4图、单4MiB/长边2048、总16MiB；较旧历史图片可能被明确标为本次未送达。

新增六工具严格schema在现有渐进披露架构下单列3000估算schema-token预算；旧工具组原有预算不变。Office/页数/像素/ZIP/导出均有硬限制，超限会明确失败。

当前视觉模型已获授权，以自建夹具完成11/20次实际请求，识别／AI批注／可信撤销和历史恢复见 [本轮结果](verification/closure-results.md)，没有个人资料外发。不据此承诺任意手写准确率。Android内模型未实际调用；真机压感、手掌误触、延迟／内存仍待设备验证，浏览器和模拟器不能替代。
