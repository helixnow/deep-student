# 收尾续作 #9：遮挡、偏好写入与错误码 i18n

## 范围

本次只补充 `zh-CN` / `en-US` 翻译资源，不修改 Rust。覆盖：

- 图像遮挡预览的徽标、草稿提示、图片替代文本、降级提示和揭示区域 ARIA 文案；
- 偏好记忆写入成功、写入失败、损坏存储降级和关闭状态；
- transform script 新增的环境/初始化失败，以及字段膨胀、字段过长、标签过长、
  标签数量超限四类逐卡拒绝码；
- `max_cards_clamped` 结构化 warning 及偏好存储降级 warning。

## Key 布局

- `anki:agent.occlusion.*`：遮挡组件和卡片内预览文案；
- `anki:agent.preferenceMemory.*`：偏好读取与写入状态；
- `anki:agent.transform.script.*` / `scriptReject.*`：脚本整批失败和逐卡拒绝文案；
- `chatV2:blocks.ankiCards.occlusion.*`：聊天预览块文案；
- `chatV2:blocks.ankiCards.warnings.*`：后端结构化 warning 的用户可见文案。

中英文以相同路径成对新增，插值变量也保持一致：
`{{index}}`、`{{label}}`、`{{added}}`、`{{reinforced}}`、
`{{requested}}`、`{{applied}}`。
