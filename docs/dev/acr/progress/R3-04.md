## 问题→根因→修法

### 1. apply 抛异常误标 cancelled
- **问题**：`handleApplyOps` catch 里调用 `driver.abort()` 并把其回执当作结果 → 异常路径常变成 `cancelled`，LLM 可能按取消语义续跑。
- **根因**：把「停驱动」与「终态回执」绑在同一返回值上。
- **修法**：catch 内 best-effort `abort`，回执固定 `failedReceipt(... apply 异常 ...)`；`finally` 仍 `clearActiveRun` 清 presence/租约。
