1. **参数整形**：LLM/skill 侧 snake_case（STANDARDS §3）；桥协议 camelCase（DESIGN §2.3）。`normalize_bridge_args` 提升别名，camelCase 已存在时优先。
2. **闸门语义**：未照抄 browser 的 `is_truthy`；仅 `background`/`follow` 开（与任务卡/DESIGN §6 三态一致）。
3. **桥内超时**：list_windows/query_state=5s；open_app/app_command/close_window=15s。外层 registry 统一 180s（覆盖 app_command 与未来 apply 类）。
4. **桥错误统一码**：`Err` 与 `ok:false` 均映射 `WORKBENCH_UNAVAILABLE`；业务回执（`ok:true` + data.status）原样返回。
5. **并发**：`ToolConcurrency::Serial`（共享舞台/租约）。
6. **依赖**：`tools/mod.rs` 已由 R1-01 预留 `mod workbench_executor` + `pub use WorkbenchToolExecutor`，本卡直接使用，无悬空依赖。
