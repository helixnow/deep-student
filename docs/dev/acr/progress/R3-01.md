## 关键修复清单（问题 → 根因 → 修法）

### 1. S-SUG-04 — hot 笔记追加未暂停

| | |
|--|--|
| **问题** | 光标在目标节内时 `note_append` 立即打字机，无「暂停等待」 |
| **根因** | `noteDriver.probe` 恒返回 `clean`；apply 无 hot 等待路径（R2-03 遗留） |
| **修法** | `captureSelection` 有选区 → probe `hot`；追加类 `waitWhileNoteHot` → `pauseRun` + 轮询至光标离开 → `resumeRun`；`bindNoteHotPauseHooks` 解循环依赖 |

### 2. S-REV-01 — 工具卡撤销入口不可达

| | |
|--|--|
| **问题** | 演出完成后 chat 卡无可用「撤销」（场景期望点工具卡撤销） |
| **根因** | 产出 `mode=frontend` AcrReceipt 的是 `note_*` / `mindmap_edit_nodes`，块类型为 `mcp_tool`；`workbench_ops` 撤销 chrome 只挂在导航工具上 |
| **修法** | 前端 `isWorkbenchOpsToolName` + toolCall remap；Rust `context`/`pipeline` 持久化同名单 → `workbench_ops`（恢复路径亦 remap） |

### 3. S-REV-02 — AgentStrip 撤销死态

| | |
|--|--|
| **问题** | run 结束后 Strip 立即消失，无法点撤销 |
| **根因** | `handleApplyOps` finally 同步 `clearByRun`，done 窗口期为 0 |
| **修法** | completed/partial 后 presence 保留 4s；Strip `canRevert = (done\|aborted) && ledger.hasRun`；`revertRun` 成功后清 presence |
