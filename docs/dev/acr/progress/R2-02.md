## 设计决策与偏差

### 1. destructive+dirty suggestion：**否决升级预览（定稿）**
- **评估**：笔记侧有 `AIDiffPanel` + `canvas:ai-edit-request` 现成路径；导图无等价树 diff UI，新建预览面板成本高且易与单例 store / 大纲双模不同步。
- **定稿**：维持 R1-11 / S-SUG-03 v1——`mode=suggestion` + `suggestionPending` + 中文 message，**不改文档**；LLM 应等待空闲或走后端。
- **升级条件（留给 R3+）**：若产品要求可接受树 diff，再单独立项；本轮不半吊子实现。

### 2. 视口节流
- `VIEWPORT_FOLLOW_EVERY = 4`（DESIGN §4.3「3–5」中值）。
- normal/demo：第 1 次成功 + 每 4 次 `setFocusedNodeId`（触发 canvas `ensureNodeVisible`，非 fitView）；收尾保证焦点在最后实体；`requestAgentFitView()` 一次。
- fast/instant：循环内不跟随，收尾一次焦点，**不** fitView。
- `agentAddNode` 去掉内部 `focusedNodeId` 赋值，避免冲掉节流。

### 3. 双窗防御
- 单例 store：`mindmapId !== resourceId` → probe `closed`；apply `failed` + message 指引回落后端；不 mutate。
- StageManager 租约互斥仍由 R2-06 负责；本卡保证错误 target 不会写错图。
