## 设计决策与偏差
1. **域事件 `source`**：AI 工具路径用 `"ai"`（与既有 `todo://changed` 一致）；`fsrs_enqueue_cards` / `fsrs_rate` 为用户 invoke，用 `"user"`。DESIGN §5.6 写的是 `'agent'|'user'`，本轮与存量 `"ai"` 对齐，R2 可统一别名。
2. **`runId`**：工具侧用 `ctx.block_id`（todo/qbank）或 `params.anki_block_id`（chatanki）；cmd 侧无 toolCallId，省略 `runId`。
3. **todo OCC 错误**：repo 返回 `VfsError::Other("TODO_CONFLICT: ...")`，经 `e.to_string()` 透出，便于前端 `includes('TODO_CONFLICT')`；未改 `VfsError::Conflict` Display 格式（避免牵动 note 等）。
4. **`todo_toggle_item`**：新增可选参数名 `expectedUpdatedAt`（`#[allow(non_snake_case)]`），与既有 `itemId` camelCase invoke 约定一致；缺省 None 兼容存量。
5. **reorder OCC**：校验的是 **list** 的 `updated_at`（批量操作无单一 item 版本）。
6. **qbank OCC**：`UpdateQuestionParams` 无 `updated_at` 字段；写路径经 QuestionBankService + preview_json 双轨，改动面 >3 文件，本轮不实现。
