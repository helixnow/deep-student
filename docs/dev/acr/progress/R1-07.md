## 设计决策与偏差
1. **进度节流**：按 correlationId 维护 200ms 窗口；首条立即 emit；窗口内尾随合并，`step = max(prev, next)`，其余字段取最后一次调用。
2. **响应双 emit**：`acr:bridge-response:{corr}`（Rust oneshot）+ 广播 `acr:bridge-response`（诊断，best-effort），对齐 mcp 桥模式。
3. **非 Tauri / jsdom**：`setupAgentBridge` 始终动态 `import('@tauri-apps/api/event')`（测试 mock）；import 失败仅 warn，不抛死。
4. **probe 找窗**：有 `resourceId` 时要求 `instanceKey` 精确匹配；无则取同 `typeId` 中 `lastFocusedAt` 最大者（覆盖单例）。
5. **driver.probe**：仅当返回 `dirty`/`hot` 时采纳；返回 `clean` 等继续走 `isContentDirty`，避免 driver 短路掉注册表脏态。
6. **pacing reduced-motion**：强制 `instant:true`，但 `profile.name` 保留调用方档位名，便于上层日志区分。
7. **他人文件**：`stageManager` 仍为 R0.5/R1-06 并行态；本卡仅经 `StageManagerApi` 调用，其桩错误不在本卡修复范围。
