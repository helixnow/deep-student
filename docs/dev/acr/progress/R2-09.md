## 设计决策与偏差
1. **关窗 abort**：`handleCloseWindow` 先 abort，再 `workbenchBus.closeWindow`；外部 `store.closeWindow`（含 resourceSync）经 `useWindowStore.subscribe` 检测 id 消失后 abort。不在 abort 路径 `clearActiveRun`，等 apply `finally` 统一清理。
2. **follow 唤醒**：`focusWindow` 不改 lifecycle，故乐观 `setLifecycles(..., focused)` + `requestWakePrefetch`，对齐 WindowBody 点击唤醒。
3. **直落 pacing**：`shouldInstantDrop` 覆盖 minimized / background / frozen；与 R2-07 演出槽上限（`applyStagingGates`）并存——本卡只保证生命周期档位强制 fast。
4. **background 档 frozen**：仍依赖 Rust probe 回落；若误入 `apply_ops` 则直落 + prefetch，不抢焦点。
