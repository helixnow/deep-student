## 设计决策与偏差
1. **mindmap AgentOp 映射**：`type`→`kind`；`node_id`/`parent_id`/`new_parent_id`→`anchor`；`patch`/`data`/`index`→`payload`。`delete_node`/`move_node` 标 `destructive=true`。label 例：「添加节点「X」」「更新节点「Y」」「删除节点 id」「移动节点 a → b」。
2. **apply_ops 超时**：按 R1-03 同档 60s（非 DESIGN §6 动态预算）；probe 3s。
3. **操作类工具范围**：任务卡举例 click/type/navigate；实现另含 `open`/`scroll`/`back`（会改会话/视口）。`snapshot`/`close` 不 claim。`browser_open` 无 session 时跳过 ensure，开窗成功后再 `set_agent_control`。
4. **用户接管冷却**：`USER_TAKEOVER_BLOCK_SECS=15`；冷却期内操作类工具返回 `USER_TAKEOVER`（retryable）。Agent `set_control_mode(Agent)` 清除闩锁——与「用户导航后短时拒绝 agent 抢回」一致；冷却过后或显式 claim 可续控。
5. **`cmd/browser.rs`**：既有 `browser_take_over` → `service.take_over()` 已闭环，本卡无增量。
6. **回落平面字段**：对齐 R1-03，后端结果补 `mode/plane/delegated/message`，避免 LLM 静默重试委托。
