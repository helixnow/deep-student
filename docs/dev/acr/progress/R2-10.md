## 设计决策与偏差
1. **ControlMode 权威**：Rust emit `browser:control-mode-changed`；前端经 `eventHub.hubListen` 单订阅写镜像。chrome 挂载时 `ensureBrowserControlModeSync`。
2. **用户接管 vs agent navigate**：地址栏/back/forward 默认 `forceUserControl:true`（打闩锁）；workbench `app_command` navigate 显式 `false`，避免 agent 自锁。
3. **ActivationResult**：`workbenchBus.activate` 布尔仍表示「窗已命中并送达」；业务拒绝（STRICT_MODE 等）经 `consumeLastActivationResult()` 给 StageManager，避免 UI 侧把「拒绝 pause」当成「窗不存在」。
4. **app_command fallbackLaunch**：仅 single 或带 instanceKey 的 multi；无 key 的 exam 不瞎开空壳。
5. **scrollToHeading 长尾**：translation/essay/image 无大纲 API → `UNSUPPORTED_ACTION` + hint；textbook/file 复用既有 `pdf-ref:focus`（需 `payload.page`）。
6. **R1 跨界清算（本区）**：exam focusQuestion、content scroll 真实现/可行动回执、browser 镜像一致性、pomodoro strict 回执。其余跨界（disposeAllDrivers→R2-06、ankiCardsBlock→R2-04、ERRORS.md→R2-01 等）不属本卡写权，未改。
