## 设计决策与偏差

1. **title 兜底**：`win.title` 非空优先；否则 `i18n.t(appRegistry.nameKey, typeId)`；再否则 `typeId`。与 Dock/WindowShell 一致。
2. **lifecycle 兜底**：`lifecycles[id]` 优先；缺失时按 minimized / focusStack 栈顶派生（scheduler 未跑时仍可用）。
3. **query_state driver 扩展**：未改冻结 `CollabDriver`；用 `QueryStateCapableDriver` 鸭子探测可选 `queryState`，合并进摘要对象。
4. **open_app / app_command 的 payload**：schema 用 `additionalProperties: true` 的 object（各应用载荷异构）；约束写在 description 字典里，避免假严格 schema 拒合法载荷。
5. **导出 `buildWindowSummaries`**：便于单测直接断言，不依赖 StageManager 桩实现细节。
