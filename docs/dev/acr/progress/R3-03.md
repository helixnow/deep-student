## 问题→根因→修法

1. **列表 pacing 与 DESIGN §4.3 不符**  
   根因：todo/finder/fsrs/qbank 用 `tick()` 默认 cost=1 → 跟导图同为 300/600ms。  
   修法：`LIST_INTERVAL_MS` + `listTickCost`（normal 0.5→150ms，demo 0.5→300ms）；不改冻结 `PacingProfile`。

2. **暂停覆盖步骤 label**  
   根因：`onPauseChange` / `pauseRun` 把 presence.label 写成「已暂停」。  
   修法：只改 status；Strip 用 `pausedLabel` 模板；进度文案走 i18n。

3. **flash reduced-motion 属性可能悬挂**  
   根因：CSS `animation:none` 无 `animationend`，仅靠 800–1000ms 兜底偏长。  
   修法：检测 reduce → 400ms 静态清理；默认 scroll `auto`。

4. **光环/状态点唯颜色区分**  
   根因：acting/paused 仅靠主题色 vs 琥珀。  
   修法：acting 实线圆点；paused 虚线描边 + 方点；forced-colors 映射 Highlight/GrayText。

5. **无 aria-live 生命周期通告**  
   根因：Strip 仅有视觉文案。  
   修法：`announceWorkbench` 通告开始/暂停/完成/停止；按钮 `aria-label` + 原生 button 键盘可达。
