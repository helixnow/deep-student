## 设计决策与偏差
1. **flag 无依赖**：`tools.browser_agent` 依赖 `ui.workbench_browser`（公网面更大）；`tools.workbench_agent` 操控的是本地桌面子应用，运行时另有 `desktop.workbenchMode` / `workbenchBus` 闸（DESIGN §6），故不挂 feature-flag 依赖。
2. **debug 默认策略**：跟随 `tools.browser_agent` 写法——一律 `.disable()`；**不**采用 `ui.workbench_browser` 的 `#[cfg(debug_assertions)] enable` 分支。生产与 debug 均默认关，需显式开 flag。
3. **控件**：本文件已有 `SegmentedControl`（性能档 / 网络范围），三档枚举沿用分段控件，不用另引 Select。
4. **父闸 UX**：与浏览器子设置一致，未开学习桌面时控件 `disabled`，描述回落 `browserEnabled.needWorkbench`。
5. **事件**：变更经既有 `persist()` → `save_setting` + `dispatchSettingsChanged(key, value)`，key 为 `desktop.workbenchAgentControl` / `desktop.workbenchAgentPacing`。
