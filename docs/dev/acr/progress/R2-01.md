## 设计决策与偏差
1. **runId**：在 `executor.rs` + `tool_loop` 注入 `tool_call_id`，桥与域事件统一 `ctx.run_id()`；缺省回退 `block_id` 兼容旧构造。
2. **闸门**：feature flag 关与设置 off 同为 `GateMode::Off`（只读允许）；写拒绝码用 `WORKBENCH_DISABLED`（不再一律 UNAVAILABLE）。
3. **取消**：桥返回 `CANCELLED:...`；canvas/mindmap 命中后返回 cancelled 回执，**不**回落后端，避免双写。
4. **qbank OCC**：仅 `UpdateQuestionParams.expected_updated_at` + repo 校验；存量 `..Default::default()` 自动兼容；preview_json 双轨无版本字段，不在本轮硬加。
5. **错误透传**：桥 `ok:false` 若含已知码则保留（如前端 `WINDOW_BUSY`），未知归 `WORKBENCH_UNAVAILABLE`。
6. **超时表**：registry `workbench_*` 180s 已在 R1-02，本轮未改。
