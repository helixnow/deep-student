## 设计决策与偏差
1. **runId 来源**：`ExecutionContext` 无独立 `tool_call_id` 字段；pipeline 里 `block_id` 与 `tool_call.id` 是不同 id。本卡在名下文件内只能注入 `runId = ctx.block_id`。若验收要求严格 `runId === toolCallId`，需跨界给 `ExecutionContext` 增字段（见下）。
2. **emit_chunk 第四参**：按 DESIGN / 任务卡伪代码传 `None`（真实签名为 `Option<&str>`）。
3. **ListenerGuard**：扩展为持有 `Vec<EventId>`（响应 + 进度两个 listen），drop 时全部 unlisten，对齐 mcp-bridge RAII 意图。
4. **进度解析**：优先反序列化为 `AcrProgress`；失败则从原始 JSON 取 `message`，避免前端字段漂移导致静默丢进度；chunk 追加 `\n` 便于工具卡按行渲染。
5. **`workbench_executor` 模块**：按卡预留 `pub mod` + `pub use WorkbenchToolExecutor`；文件由 R1-02 并行创建（当前工作区已存在该文件）。
6. **events.rs**：无需新增 event_types；进度走既有 `TOOL_CALL` chunk。
