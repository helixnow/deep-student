## 已完成

- **eventHub**：同一事件名任意多订阅者只建一个 Tauri listener；`hubListenKeyed(event, key, handler)` 按 payload 业务键路由（默认探测 sessionId/session_id/resourceId/resource_id/documentId/document_id/id，`setHubKeyExtractor` 可按事件名定制——P7/P8 嵌套 payload 事件用这个）；处理了 listen Promise 挂起期间订阅者全部离开的竞态；`resetEventHub()` 供卸载/测试；`getEventHubDiagnostics()` 供 DevPanel（P10 可选消费）。
- **projection**：diff 式管理，出现→`workbenchBus.project()`（幂等复用已有窗），消失→直接 store.closeWindow（不走 canClose——业务实例已结束）；keepShell 保壳；projectWindows=false 为 badge-only 源；workbench 未启用期间静默累积状态，`resyncProjections()` 补投。
- **系统应用群**（全部 single；nameKey 统一 `workbench:apps.<typeId>`）：
  - todo：TodoContentView + 窗口内自带 TodoShellSidebar（legacy 下该侧栏在 App 壳导航槽位）；`launchPayload.todoListId` 支持定位列表；
  - skills / templates：页面自含布局零适配（templates 的 `useDesktopShellSidebarPortal` 无 portal 目标时自动回退内部侧栏）；
  - taskDashboard：`onNavigateToChat`→`bus.launch({typeId:'chat', instanceKey: sessionId})`，`onOpenTemplateManagement`→launch templates；badgeSource=活跃制卡任务数；
  - settings：Settings + 窗口内自带 SettingsShellSidebar；onBack→requestClose；tab 状态是全局 useSettingsShellStore（single 无冲突）；
  - pomodoro：PomodoroPanel 包装，投射目标，标题跟随当前专注任务，badgeSource=运行中 dot。
  - **适配点**：TodoShellSidebar / SettingsSidebar 的 slot 形态自带 `paddingTop: calc(var(--shell-titlebar-height)+var(--shell-layout-gap))`，包装器在容器上把这两个 CSS 变量局部清零。
- **sandbox**：SandboxWorkbenchSurface（embedded=false 保留空态引导），onClose→requestClose，关窗不清会话数据。

## 遗留问题

1. **番茄钟窗口投射的策略**：当前"专注开始→自动弹出 pomodoro 窗口"。若人工验收觉得打扰，把 `projections.ts` 里 pomodoro 源加 `projectWindows: false` 即变 badge-only（一行改动）。
2. 番茄钟任务切换（active 状态不变、title 变）不更新已投射窗口的投射源 title；但 PomodoroAppWindow 自身订阅 store 用 onTitleChange 跟随，实际无感。
3. Settings / TaskDashboardPage / TemplateManagementPage 等重页面均为 React.lazy 按需加载，但页面内部各自有全局事件监听（如 systemSettingsChanged），多为幂等添加/移除，未逐一审计 frozen→唤醒重建路径；建议 P11 验收时对 settings 窗做一次 冻结→唤醒 人工检查。
4. TaskDashboardPage 自带 5s/30s 智能轮询且依赖 `useViewVisibility('task-dashboard')`（legacy 视图可见性），在 workbench 窗口里恒判 " 不可见/可见 " 取决于该 hook 的默认行为，轮询频率可能偏保守或偏勤——功能正确，只是频率非最优。
5. p9 测试放在 `tests/vitest/workbench/p9-*.{ts,tsx}`（core/__tests__ 归 P1 所有，不可写入）；文件名带 p9 前缀避免与他人冲突。
6. `tests/vitest/workbench` 目录下 P3（window-titlebar）、P6（use-workbench-shortcuts）各有 1 个失败 case，属对应代理文件，与本代理改动无关（本代理只新增文件 + index.ts 追加导出）。
