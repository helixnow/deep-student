## 决策

- 退场不立刻 `return null`：与 WindowSwitcher / ShortcutCheatsheet 同模式，保留 DOM 播 `wb-kf-pop-out`，避免 TitleBar 宽限期关闭时硬切。
- Glyph 几何用 CSS 定位类（`cell-left` / `cell-tl`…）而非内联 style，便于 hover spring 与 reduced-motion 统一归零。
- z-index 选 `--wb-z-dock-flyout`（9200）：菜单挂在标题栏内，需压过窗口内容；与 Dock 飞出同刻度，低于 desktop-menu(9600)。
- TitleBar 测试「离开后关闭」改为：宽限期后 `data-phase=closing`，再推进退场兜底才 `queryByRole('menu') === null`。
