### 1. 缓动曲线（CSS 变量，挂 `:root`）

| 变量 | 用途 | 值（参考） |
|---|---|---|
| `--wb-ease` | 通用状态过渡（既有，保留） | `cubic-bezier(0.32, 0.72, 0.28, 1)` |
| `--wb-ease-out` | 通用减速出场（既有，保留） | `cubic-bezier(0.16, 1, 0.3, 1)` |
| `--wb-ease-spring` | **标准弹出**：开窗 / 平铺落位 / 弹层，约 3% 过冲 | `cubic-bezier(0.32, 1.25, 0.36, 1)` |
| `--wb-ease-spring-soft` | 柔和 spring：焦点切换、俯瞰 FLIP，微过冲 | `cubic-bezier(0.3, 1.12, 0.36, 1)` |
| `--wb-ease-overshoot` | **明显回弹**：tooltip / 菜单 / Dock autohide 展开 | `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| `--wb-ease-swift` | **快速淡入**：hover 高亮、指示点、badge | `cubic-bezier(0.3, 0.9, 0.35, 1)` |
| `--wb-ease-in` | 加速退场：关窗前段、淡出 | `cubic-bezier(0.5, 0.05, 0.8, 0.4)` |
| `--wb-ease-genie` | **genie 吸入**：最小化向 Dock 收敛（带蓄力起步） | `cubic-bezier(0.55, -0.08, 0.68, 0.28)` |
| `--wb-ease-magnify` | **magnification 跟踪**：Dock 邻近放大、指针跟随类 | `cubic-bezier(0.2, 0.6, 0.25, 1)` |

### 4. 命名 keyframes（motion.css 内定义，直接 `animation: <名> ...` 引用）

| keyframes | 效果（全部仅 transform/opacity） | 建议搭配 |
|---|---|---|
| `wb-kf-fade-in` / `wb-kf-fade-out` | 纯 opacity 淡入/淡出 | quick + swift |
| `wb-kf-pop-in` | 标准弹出：scale .96→1.015→1 + fade | standard + spring |
| `wb-kf-pop-out` | 消散：scale→.97 + fade out | quick + in |
| `wb-kf-overshoot-in` | 弹层入场：scale .92→1.03→1 + fade | standard + overshoot |
| `wb-kf-rise-in` / `wb-kf-sink-out` | 上浮 8px 入场 / 下沉退场（Dock 弹层、tooltip） | quick~standard |
| `wb-kf-genie-min` | 向 `--wb-minimize-origin-x/y` 收敛的吸入（非对称 scale + fade） | genie 时长曲线 |
| `wb-kf-genie-restore` | genie 反向还原 | genie 时长 + spring |
| `wb-kf-bounce` | Dock launch bounce：translateY 两跳衰减 | bounce 时长，可 `animation-iteration-count` |

### 8. 材质切档平滑

- 切档时 `materialTier.ts` 会在 `<html>` 上短暂加 `data-wb-material-switching` 属性
  （~300ms），token 层对玻璃类做 background-color/box-shadow 交叉淡化，不硬切。
- 目标档为 minimal 或系统 `prefers-reduced-motion` 时自动硬切（时长 token 归零）。
- **其他代理无需感知**；若你新建的玻璃面想参与切档淡化，给根元素加类 `wb-glass`
  或在自己 CSS 里追加 `html[data-wb-material-switching] .wb-你的类 { transition: ... }`。

## 二、视觉与交互决策（供人工复核）

1. **grain 并入 sheen 栈**而非独立类：冻结的 workbench.css 只消费
   `background-image: var(--wb-glass-sheen)`，并入后 Dock/标题栏/玻璃卡零改动即得微噪点；
   opacity 0.045（128px 平铺、feColorMatrix 去饱和），运行时请在 WebView2 实际核验颗粒度。
2. **blur 的 none↔blur() 不可插值**（离散属性），切档"淡入"实为 background/box-shadow
   交叉淡化掩蔽 blur 的瞬时切换——静态推敲可接受，运行时如仍觉突兀，O20 可考虑
   把 reduced 档 blur 改为 `blur(0px)`（可插值但常驻合成层开销，当年 P4 刻意用 none）。
3. genie 用**非对称 scale**（横向先于纵向收窄）近似形变，纯 transform 实现（无 clip-path
   动画），忠实于"仅 transform/opacity"铁律；真 genie 曲面弯曲在该约束下不可达。
4. z 刻度 9000-9900 段留了百位间隙（dock 9000 → flyout 9200），供 O20 reconcile 时插层。
5. 标准弹出过冲刻意压在 ~3%（`0.32,1.25,0.36,1`）：窗口级元素过冲太大显得轻浮；
   小件（tooltip/菜单）才用 `--wb-ease-overshoot`（1.56）。
