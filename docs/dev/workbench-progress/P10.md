## 设计决策（供其他代理参考）

### 设置 key 约定（全部走 `get_setting`/`save_setting` invoke）

| key | 值格式 | 默认 |
|---|---|---|
| `desktop.workbenchMode` | `'true'/'false'` | `false` |
| `desktop.workbenchMaterialTier` | `'auto'\|'full'\|'reduced'\|'minimal'` | `auto` |
| `desktop.workbenchWallpaper` | JSON `{"kind":"theme"\|"image","value":string}` | `{"kind":"theme","value":"aurora"}` |
| `desktop.workbenchTileMargins` | JSON `{"enabled":boolean,"px":number}`（px 0–32） | `{"enabled":true,"px":8}` |
| `desktop.workbenchDockAutohide` | `'true'/'false'` | `false` |
| `desktop.workbenchDevPanel` | `'true'/'false'` | `false` |

### 事件约定

- 总开关变化：`workbenchBus.setEnabled(v)` + `window.dispatchEvent(new CustomEvent('workbench:mode-changed', { detail: { enabled } }))`
- 其余任何 workbench 设置变化：`CustomEvent('workbench:settings-changed', { detail: { key, value } })`（value 为解析后的 JS 值，如 tileMargins 为对象）
- DevPanel 监听 `CustomEvent('workbench:snapshot-saved', { detail: { at: number } })` 显示快照最后保存时间

### 对齐并行代理的集成点

- materialTier 分段控件直接调 P4 `setMaterialTier()`（`core/materialTier.ts`，支持 'auto'）；
- 壁纸预设复用 P4 `WALLPAPER_PRESETS`（aurora / horizon / graphite）与 `WallpaperConfig` 类型；
- DevPanel 预算取 P1 `getMemoryBudget()`（含 macOS 9 点降档与 override）；
- i18n key 已按各代理源码实际引用全量补齐（`apps.*`、`dock.*`、`window.*`、`tile.*`、`expose.*`、`switcher.*`、`emptyDesktop.*`、`wallpaper.*`、`content.*`、`shortcuts.*`），parity 测试含「消费 key 抽查」防回归。
