## 视觉与交互决策（供人工复核）

1. **拖拽抬升**：`wb-shell-dragging` → `box-shadow: inset rim + var(--wb-shadow-lifted)`；
   微缩放 `scale(1.002)` 由 JS 合成进 `translate3d`（避免与定位 transform 冲突）；
   `prefers-reduced-motion` 下关闭 scale。
2. **缩放不抬升**：仅挂 `wb-shell-resizing`（macOS 行为），过程写 `left/top/width/height`。
3. **will-change**：CSS 中和基线常驻 `will-change: transform` 为 `auto`；手势期 inline
   `will-change: transform`，结束移除。
4. **光标**：拖拽 `grabbing`；缩放按边/角 `ns|ew|nwse|nesw-resize`（O19 栈式锁）。
5. **角柄命中**：12×12px（边仍 6px）。
