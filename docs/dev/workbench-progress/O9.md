## 已完成（实现细节）

1. **瞬态相位 → CSS 类映射**（挂在壳 `[data-wb-window-id]`，不改 WindowShell）：
   - `opening` → `wb-lifec-pop-in`（`wb-kf-pop-in` + standard/spring）→ 清标记
   - `restoring` → 注入 Dock origin + `wb-lifec-genie-restore` → 清标记
   - `minimizing` → 注入 Dock origin + `wb-lifec-genie-min` → **再** `minimizeWindow(true)`
   - `closing` → `wb-lifec-pop-out` → **再** `closeWindow`
   - 每相有超时兜底（opening 400 / closing 320 / genie 600ms），0ms 动画仍收尾。
2. **Dock 坐标**：`injectMinimizeOrigin` 用 `getDockIconCenter` 换算相对壳的百分比；无坐标回退 `50%` / `130%`。
3. **最小化时序方案（侵入最小）**：
   - store 的 `minimizeWindow` 同步 `minimized=true` + 清 transient，WindowShell 立刻 `visibility:hidden`，无法「先播再藏」。
   - **不改 store**：导出 `requestMinimizeAnimated(id)` —— 只 `setWindowTransient(id, 'minimizing')`；hook 播完再提交。
   - 同理 `requestCloseAnimated`（含 canClose）供关窗动画。
   - WindowBody 内 `requestClose` 已改走 `requestCloseAnimated`。
4. **Frozen**：占位仍 `data-wb-frozen-placeholder`；内层 `wb-body-frozen-card wb-glass`；图标取 `appRegistry.icon`，缺省 MoonStars；唤醒后 body 挂 `wb-body-wake-in`。
5. **Crash**：`data-wb-crash-card` + `wb-body-crash` 玻璃卡，重载按钮语义不变。

## 视觉与交互决策（供人工复核）

| 决策 | 取值/理由 |
|---|---|
| 最小化延迟提交 | hook 层 `requestMinimizeAnimated`，避免改 windowStore / WindowShell |
| genie origin | 视口中心 → 相对壳百分比 CSS 变量；无 Dock 数据向下方 130% 收敛 |
| 开窗 | 消费 store 自动 `opening` + pop-in；与壳上遗留 `wb-anim-open` 可能叠播（见 reconcile） |
| frozen 唤醒 | 内容淡入类而非延迟 remount；子树仍即时重建（契约不变） |
| 崩溃卡 | 与 frozen 同玻璃语言，摘要保留 error.message |
