## 需 O20 reconcile 事项

1. **workbench.css 契约类 `.wb-expose-backdrop` 仍写死 `z-index: 8000`**：
   O7 用内联 `var(--wb-z-expose-backdrop)`（=5）覆盖，保持「低于窗口层」既有裁决。
   O20 可把契约类 z 改为 token，去掉内联。
2. **`--wb-z-overlay: 9500` 低于旧硬编码 2147483000**：若其它 overlay（O8 switcher
   9600）层序依赖旧天文数字，O20 统一校验；本组件已按 token 刻度。
3. **关窗后真实窗口 DOM 由 WindowShell 卸载**：O7 只清 transform 标记；若 O9 关窗
   消散动画与 expose dissolve 叠用，需 O20 协调时序。
4. **帧率 10+ 窗**：本轮未做 perf 采样；FLIP 仅 transform，理论可 60fps，
   O15/O10 可挂 perfMonitor 复核。
5. **他人并行 tsc 错误**（与 O7 无关）：`WindowShell.tsx` 报 `Cannot find name
   'dragging'`——属 O9/接线名下，O20 门禁时复核。
