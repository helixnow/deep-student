## 遗留问题

1. **默认指针实现是临时兜底**：`useDefaultWindowPointer` 不做吸附命中（onSnapZoneChange 恒为 null）、不做 snapZones 边缘检测；P2 的 `useWindowPointer` + `hitTestSnapZone` 交付后应整体替换（接口即 `WindowShellPointerHook`）。
2. Esc 取消拖动时如果拖动起点是平铺/最大化态（拖动开始已转 floating），取消只回到转换后的 floating frame，不回平铺态——真实恢复语义由 P2 引擎细化。
3. `snapZoneToDisplayMode` 为 WindowShell 内本地映射；P2 在 `tiling.ts` 导出 `zoneToDisplayMode` 后可切换（签名一致）。
4. 最小化动画：目前 minimized 即时 `visibility:hidden` + 挂 `wb-anim-minimize` 类；「先播 220ms 动画再隐藏 + transform-origin 指向 Dock」的编排需 P4 动画类 + P11 Dock 方位变量注入后再接。
5. 跑全目录 `tests/vitest/workbench` 时另有两处失败均非 P3 文件：`p6-use-workbench-shortcuts.test.tsx`（P6）、`workbenchSettingsSection.test.tsx`（因 `src/features/learning-hub/icons/ResourceIcons.tsx` 语法错误，属并行代理编辑中）。P3 五个文件单独运行 44/44 全绿。

## 需要接线代理（P11）处理的事项

1. P2 交付后把 `WindowShell` 的 `usePointer` 接成 P2 `useWindowPointer` 的适配器（或直接替换 `useDefaultWindowPointer` 实现）；适配器只需返回 `{ onMovePointerDown, onResizePointerDown }` 并消费 `WindowShellPointerArgs.callbacks`（冻结契约）。
2. `WindowShell` 的 `onSnapZoneChange(windowId, zone)` prop → Desktop 层驱动 P2 `SnapPreview` 渲染。
3. `tileMargin` prop（默认 8，0=关闭）接 settings `tileMargins` 设置项。
4. 左右平铺 ratio：WindowShell 通过扫描 `tilingRatios` 键（`${leftId}:${rightId}`）取比例；P2 的 `useTilingDivider` 写入同一 store 字段即可自动生效。
5. WindowBody 唤醒时做了「乐观解冻」（setLifecycles 该窗为 focused）后调 `recomputeLifecycles()`；P1 完整版 scheduler 接管后此写入会被下一次全量重算覆盖，无需改动，但请知悉。
6. Desktop 装配建议：`<WindowShell windowId={id} />` 默认内含 `<WindowBody>`，无需额外包装；如需自定内容（如 Expose 包装层）可用 children 覆盖。
