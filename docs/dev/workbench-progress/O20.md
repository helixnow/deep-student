## 五、剩余已知遗留（历史 + 本轮）

4. **本轮 R1–R8**：动画路径统一、Cheatsheet/Drop 装配、z-token 补表、content 时长 token 化、expose 契约 z 分叉。
5. **COORDINATION 编码**：部分历史段落曾出现乱码；以各 `O*.md` UTF-8 正文为准。
