| key | 兜底文案 |
|---|---|
| `workbench:cheatsheet.title` | 键盘快捷键 |
| `workbench:cheatsheet.close` | 关闭 |
| `workbench:cheatsheet.hint` | 按 ? 或 Esc 关闭 · 长按 Ctrl+Alt 随时查看 |

| key | 兜底 |
|---|---|
| `workbench:cheatsheet.groups.layout` | 平铺与布局 |
| `workbench:cheatsheet.groups.movement` | 移动与贴边 |
| `workbench:cheatsheet.groups.navigation` | 切换与导航 |
| `workbench:cheatsheet.groups.management` | 窗口管理 |
| `workbench:cheatsheet.groups.help` | 帮助 |
