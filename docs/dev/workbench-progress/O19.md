## 一、已完成

1. **手势层**（`useWorkbenchGestures.ts`）：wheel 无原生会话概念，按 endDelayMs（默认 160ms）
   静默期合成 start/update/end；pinch 走 ctrl+wheel（Chromium/WebView2 的触控板捏合上报形态，
   `exp(-deltaY*0.01)` 累计，钳 0.05–20）与 WebKit GestureEvent 双路归一；swipe 仅对
   deltaMode=0（像素级 = 触控板）序列启动，24px 阈值锁主轴；全部回调 rAF 合帧、0 React state；
   卸载时进行中会话先正常 end 再释放。附 `normalizeWheelDelta`（行/页 → px）与
   `useWheelStep`（±1 步进，默认 80px/步，300ms 静默清余量，默认 preventDefault——Dock 上滚轮不滚页面）。
2. **拖放层**（`useDesktopDrop.ts`）：dragenter/leave 深度计数消除子元素抖动；over/denied
   两态直写 target（`data-wb-drop-state` + `wb-cursor-drop-over/denied` 类）；accept 谓词仅凭
   types 摘要（浏览器安全模型下 drop 前读不到文件）；drop 解析优先级 资源 JSON > files > text；
   window 级 dragend 兜底复位；落点给相对/视口双坐标。拖源辅助与解析器同构。
3. **无障碍层**（`useWorkbenchA11y.ts`）：窗口 aria 属性唯一生成器（非模态 dialog +
   roledescription + 最小化 aria-hidden + tabIndex -1）；aria-live 公告采用**双缓冲交替写入**
   （同文案连续公告也会被 AT 重播），单例直写 body、hook 引用计数回收、非 React 上下文可调；
   通用 roving tabindex（focusin 同步 + 方向键/Home/End/wrap）；焦点归还；
   forced-colors/prefers-contrast/reduced-motion 订阅（useSyncExternalStore）。
4. **样式层**（`a11y-cursor.css`）：16 个 `wb-cursor-*` 工具类；14 种 `:root[data-wb-cursor]`
   全局锁选择器（!important，会话期压过元素级 cursor）；`wb-focus-ring / -inset / within` 三变体
   （:focus-visible 驱动，token `--wb-focus-*` 可被 O1 覆写，:where 降特异性）；
   `wb-focus-sr-only` + `wb-focus-reveal` skip-link；拖放高亮只用 outline/background 零布局影响。
5. **规范文档**：`docs/dev/workbench-a11y-checklist.md`（交各代理与 O20）。

## 二、视觉与交互决策（供人工复核）

- 焦点环颜色对齐 `--wb-snap-stroke`（吸附预览主题色），宽 2px、offset 2px；
  prefers-contrast: more 时自动加粗到 3px 全不透明；forced-colors 映射 Highlight。
- 拖放 over 态 = 2px 主题色虚线 outline（-2px 内收）+ `--wb-snap-fill` 底色；denied 态 =
  destructive 色虚线 + not-allowed 光标。有意与吸附预览同语言（都是「落点」语义）。
- 光标遵循 macOS 惯例：Dock/按钮保持 default（不用 pointer）；拖拽把手 grab/grabbing；
  会话期全局锁防闪回。
- pinch 灵敏度 0.01（Chromium 社区惯例值）；swipe 方向语义 = 自然滚动（deltaX>0 → 'left'）。
- 公告默认 polite，仅崩溃类 assertive（role=alert），防轰炸。
