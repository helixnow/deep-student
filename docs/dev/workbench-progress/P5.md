## 遗留问题

1. **Dock 端俯瞰入口未加**：设计 §6.3 提到俯瞰可由“Dock 端点触发”，Expose 归 P6；如需 Dock 端入口，P11 接线时可在 Dock 两端加一个固定按钮（当前未实现，等 P6 的触发 API）。
2. **DockWindowList 无缩略预览**：设计提到“标题 + 缩略预览”，当前只有标题 + minimized 标记。缩略图需窗口 DOM 截取/transform 快照，依赖 P3 窗口层结构，Phase 2 打磨项。
3. **最小化动画 transform-origin 注入**：P4 的 `wb-anim-minimize` 支持 CSS 变量注入 Dock 方位；Dock 侧未导出 item 位置查询 API。若 P4/P11 需要，可用 `[data-testid="wb-dock-item-{typeId}"]` 或 `button[data-type-id]` 查 DOM 位置。
4. **hover 放大的材质档降级**用了 Tailwind 任意变体 `[[data-wb-material="minimal"]_&]`，依赖 P4 在 `<html data-wb-material>` 上落属性（契约一致）；P4 若在 `wb-dock-item` 里实现了官方 hover 动效，可把 DockItem 里这段工具类删掉（集中到 CSS）。
5. Dock 层叠用了 `z-[1000]`（windowStore 的窗口 zIndex 从 10 递增且无上限归一时可能超过它）；P11 总装时应把窗口层与 Dock 层放在**不同 stacking context**（窗口层容器自成 isolation），或依赖 P1 的 zIndex 紧凑归一。

## 需要接线代理（P11）处理的事项

1. **导入路径**：`Dock` 组件与固定区 API 从 `src/features/workbench/components/Dock.tsx` 相对导入（`import { Dock, useDockPinned, setDockPinned, getDockPinned, subscribeDockPinned } from './Dock'`）。**刻意未追加到 `workbench/index.ts`**——避免业务模块 import workbenchBus 时把 Dock/AppMenu 组件链拉进 legacy bundle（违反“开关关闭不加载 workbench chunk”）。P11 若需要可自行追加导出。
2. **快照接线**：恢复时 `setDockPinned(snapshot.dockPinned)`；保存时 `getDockPinned()`（引用稳定，可配 `subscribeDockPinned` 触发防抖保存）。Dock pinned 默认值（chat/files/settings/todo）由 P11 在装配时 set。
3. **autohide 设置接线**：`<Dock autohide={settings.dockAutohide} />`。
4. **定位假设**：Dock 根节点为 `absolute inset-x-0 bottom-0`，要求挂在 `position: relative` 的桌面容器内（WorkbenchDesktop 根）。
5. **launch 依赖 bus enabled**：Dock 点击走 `workbenchBus.launch`，P11 需保证 workbench 模式下 `workbenchBus.setEnabled(true)` 已调用。
