## 二、视觉与交互决策（供人工复核）

- 骨架：快速加载（&lt;120ms）靠画布层 120ms 延迟淡入等效「不闪」；就绪后根层 260ms opacity 淡出再卸载。
- files 视图切换：grid↔list 用 `scale(0.985)+opacity`（`--wb-motion-standard`），非 FLIP 逐项（legacy 虚拟列表不可侵入）。
- hover 预览：420ms 延迟、`wb-glass` 玻璃卡、跟随指针并钳位；文件夹不预览。
- 拖出：越过 files 窗边界才出徽标；松手窗外走 bridge（O13 handler 优先，否则兜底 launch）；窗内松手不干预 legacy dnd-kit。
- `LaunchReason` 未扩 `desktop-drop`，bridge 兜底 launch 使用既有 `reason: 'files'`（见第三节）。
