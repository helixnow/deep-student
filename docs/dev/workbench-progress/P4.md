## 遗留问题

1. **无运行时视觉核验**：按规则未启动 dev server，玻璃质感/阴影/动效只做了静态推敲，P11 总装后需在明暗两主题 × full/reduced/minimal 三档下人工过一遍（尤其 Windows WebView2 上 `color-mix` + `backdrop-filter` 叠加的实际观感）。
2. `wb-dock` 自带定位（bottom 10px 水平居中，用 `translateX(-50%)`）；P5 做 autohide 滑入滑出时请用 `translate(-50%, y)` 复合形式覆盖，避免丢失水平居中。
3. `wb-anim-minimize` 的收敛点默认向正下方（50%/130%）；要精确飞向 Dock 图标，P3/P5 需在窗口元素上注入 `--wb-minimize-origin-x/y`（桌面坐标系百分比或 px 均可）。
4. 自定义图片壁纸的 value 需是 CSS 可直接消费的 URL（asset protocol / http / data:）；本地文件路径→URL 的转换（如 `convertFileSrc`）归 P10 设置页。
5. `setMaterialTier` 接受扩展入参 `'auto'`（恢复跟随平台），是对编排文档签名的向上兼容扩展，P10 分段控件「跟随平台」直接传 `'auto'` 即可。
