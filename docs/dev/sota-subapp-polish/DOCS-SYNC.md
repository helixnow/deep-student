## 三、i18n 结论

本轮 UI 改动（Dock tooltip 钉住、窗口列表应用名头部、Exposé 焦点环、focus trap）均复用既有文案：

- Dock tooltip 与窗口列表头部显示的应用名来自应用注册表的 `nameKey`（已有中英翻译）；
- 焦点环 / focus trap 为纯行为与样式变更，无新增用户可见字符串。

**无新增 i18n key 需求。**（番茄休息复习入口的 `pomodoro.breakReview`、`menubar.pomodoroBreakRemaining` 已随 `f8e1b47a` 在 zh-CN / en-US 同步补齐，非本次改动。）
