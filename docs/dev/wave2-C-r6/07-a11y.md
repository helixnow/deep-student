## 5. 非阻塞观察（不改码，留给后续轮次裁量）

1. **水位环触发器 aria-label 是静态文案**（`chatV2:tokenUsage.contextWindow`
   「上下文窗口」），读屏用户不点开弹层无法得知当前百分比。建议后续在
   ContextUsagePopover（非本轮可改文件）把 aria-label 拼上
   `tokenUsage.contextUsedPercent`，或在 button 上补 `aria-description`。
2. `focusOrder.source.test.ts` 的 `collectInertContexts` 只跳过以 `//`、`*`、`/*`
   开头的注释行，ComposerInlinePanel :91 JSX 注释块的续行（「收起态…同时 inert…」）
   会被当作实现收进 contexts——因同行含 `closing/closed` 恰好通过 gating 过滤,
   当前无害，但该启发式偏脆，改注释措辞时须留意。
3. inert 经 `useEffect`（paint 后）同步:opening 首帧存在极短的 inert 残留窗口,
   实测感知可忽略;若追求严格可换 `useLayoutEffect`,非必要。
4. 关闭面板瞬间若焦点在面板内，inert 会把焦点掉到 body;焦点归还触发器属
   InputBarUI / 面板协调器职责（非本轮范围），建议 coord 侧确认是否已有归还逻辑。
