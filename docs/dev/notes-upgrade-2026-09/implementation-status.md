## 整合中发现并修复的问题

1. 历史预览自动永久 pin 会让查看历史成为无法永久删除笔记的单向操作。现改为只读预览，用户可明确长期保留或解除；恢复仍事务性保护源版本与恢复前版本。
2. Crepe 对合法 Markdown 的规范化被逐字比对当作写入失败，真实内置模板无法应用。新增使用当前 schema/remark 的纯预检，允许已知排版规范化并验证语法树和 PM 往返；丢失未知节点、代码 metadata 或图片语义仍拒绝。全文 API 返回实际应用快照，AI 成功、重试及撤销使用该快照。
3. 保存回流与加载更多期间的输入可能被旧窗口覆盖。改为读取操作前 live 完整草稿、校验笔记身份与 revision，失败恢复 live 窗口而非磁盘旧窗口。
