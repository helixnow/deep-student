# 宣传页场景复现

网页使用 `demo.html` 中的生产 App、消息 store、事件适配器和产物组件；IPC 返回预设数据。演示中逐字出现的回答并非实时模型推理。自由输入使用明确的预设回复，页面提供的继续提问按完整输入匹配剧本。

入口下方的「获取学习材料与完整提问」将 `fixtures.ts` 与 `attachmentAssets.ts` 中的材料打包下载。包括三张 PNG、60 页教学样本 PDF、英文原文、六份首问/追问/来源摘录和桌面操作说明。PDF 是项目编写的教学样本，不是同名出版物的扫描件。

## 六条操作路径

| 场景 | 桌面准备 | 用户可操作的结果 | 后续探索 |
| --- | --- | --- | --- |
| PDF 精读 | 导入样本 PDF 并引用到对话；启用文件阅读、导图和制卡能力 | 引用页码、完整导图与大纲编辑、挖空卡、自测文本 | 比较参数服务器和 AllReduce |
| 错题制卡 | 加入三张图片；视觉模型；将包内摘录保存为学习笔记；问答卡模板 | 照片预览、卡片翻面、编辑、保存 | 展开积分换元 |
| 研究综述 | 记忆中保存复习时间与偏好；配置网络和学术检索 | 论文来源、比较表、阅读顺序 | 逐篇记录建模假设与目标 |
| 周度学习看板 | 在提问中提供材料记录；启用交互界面能力 | 材料清单和复习安排 | 展开下一次复习步骤 |
| 知识点出题 | 新建题目集并引用；启用题库技能；配置可用出题模型 | 草稿勾选、加入所选、右侧题目集作答与解析 | 查询实际收录内容与作答记录 |
| 双语阅读 | 粘贴包内英文原文与术语要求；启用交互界面能力 | 原文/译文对照表、术语表、复制 Markdown | 理解吞吐量与收敛 |

桌面模型产出的措辞和布局可以变化；复现标准是输入可提供、工具存在、产物可通过对应入口使用。研究场景的网络返回取决于服务配置。网页题目存储保留在当前访问的内存中，刷新会重新开始；桌面使用真实题库数据库。双语场景展示对话内表格，不承诺调用独立翻译保存工具。网页 APKG 导出与 Anki 同步会提示在桌面完成。

## 2026-09-11 本地验证记录

- 环境：`npm run tauri dev` 的真实桌面进程；没有打开 hero/demo 做视觉验证。
- 实际模型请求：题库 `qbank_ai_generate_questions`，数据并行/梯度压缩材料，指定两道 single_choice。配置中的 deepseek-flash 模型成功生成两道完整草稿。
- 入库路径：将上述真实任务返回的草稿挂到生产 `QbankQuestionsBlock` 验证容器，取消第二题，点击「加入所选 1 题」。UI 显示「已入库 1 题」，`qbank_list_questions` 返回一题，题干、答案 B、解析完整。专用题目集名为「数据并行训练 · 宣传复现」。验证容器随后移除。
- 另一次经对话工具调用使用默认供应商时返回 503 / bot_unavailable。完整聊天自动调用生成链尚未通过，成功证据是上面的真实生成命令与生产选择入库组件，不能混同。
- 在真实桌面挂载生产 `AgentTaskPanel`，使用双语 fixture 展开产物，观察到三行原文译文、术语表和导出操作。这是生产渲染验证，不是模型翻译质量验证。
- 在真实桌面调用 `buildDemoMaterials` 生成 288857 字节 ZIP，MIME 为 application/zip，文件头为 PK。浏览器下载接收与 ZIP 内每项内容的最终检查尚未完成。
- 桌面连接随后断开，真实剪贴板写入尚未验证；产物按钮到 Markdown 导出函数的回归测试另行覆盖。六个场景的全部在线模型流程仍需逐项验收。

- `npm run tauri dev` 重新启动真实桌面，自动化桥连接地址为 `http://127.0.0.1:1422/`。以专用题目集 `exam__P8TJZRwRj` 为输入，经聊天附件预览事件打开右侧题库，点击「开始做题」，选择 B 并提交。界面显示「回答正确」，展开「查看解析」后显示完整解析；真实 `qbank_get_question` 返回 `user_answer=B`、`is_correct=true`、`attempt_count=1`、`correct_count=1`。

## 回归重点

同一 iframe 切换场景，完成的历史保留；追问通过真实输入框发送。检查切换时旧打字任务只清理原会话草稿。题库 `tool_call` 的 preparing 和直接 start 都应映射为 `qbank_questions`，失败显示错误。产物展开后应注入实际 actionHandlers。下载模块保持动态加载，避免破坏 mock IPC 先于 App 求值的顺序。
