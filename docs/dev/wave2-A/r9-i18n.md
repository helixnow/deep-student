# Wave2-A 第 9 轮：新增日志与用户文案一致性复核

> 范围：本枝相对 `cursor/0824-cde6` 新增、且属于 A 所有权的运行时日志与
> 用户可见文案。仅静态检查；未运行 npm/cargo/安装/测试，未改产品代码或
> i18n JSON。

## 结论

- 15 个检查项中，12 个保持；其中 11 个是内部日志，Anthropic 四槽预算没有
  新增运行时文案。
- 第 10 轮建议改 3 处：两处 persistence 日志把 `save_results will backfill`
  说成必然，但 wake/retry 新 message id 无对应 CONTENT 行时并不能兜底；
  TauriAdapter 的失败原文会被 `formatUserFacingError` 拼进通知，英文
  `fail-closed`、内部键名与底层错误对用户过于技术化。
- issue #122 三条探针只记录长度/计数，不记录 chunk 原文、字节或用户文本；
  “已替换/补 U+FFFD”描述的是该次 lossy 分支的实际动作，不等于声称乱码已修。
  文件头也明确“不声称修复 #122”。
- 同子系统口径总体一致：ChatV2 pipeline 新日志继续使用英文内部运维文案；
  UTF-8/SSE 探针统一使用中文说明加英文技术字段；PromptCache 使用英文
  debug 字段。唯一越过用户边界的中英混用是 TauriAdapter 失败通知。

  tool anchor 未匹配 warn，是基座已有文案，本轮仅改写控制流/移动行号，未列为

  已关闭；本轮新增探针仍只能定位 decoder/SSE buffer 两层。
