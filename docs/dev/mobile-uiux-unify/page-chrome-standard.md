# 移动页面标题、动作与内容布局标准

2026-09-23。延续 [五条统一规范](./README.md#统一规范验收口径)，补充标题归属和动作层级，用于闪卡移动端改造。

## 研究依据

本轮在 `npm run tauri dev` 的真实应用（390px 宽独立开发窗口）查看技能浏览/新建、学习资源、待办收件箱、Anki 制卡；同时对照模板管理、设置和聊天的源码。桌面窄窗证据不等同于 Android/iOS 真机证据。

| 页面/机制 | 已观察的行为 | 采用的规则或现有差异 |
| --- | --- | --- |
| `SkillsManagementPage.tsx` | 浏览页标题「技能管理」，顶栏右侧新建；新建时标题变化、左侧返回 | 当前状态决定标题与导航；新建是页面级动作。编辑器底部保存是现有差异，不作为新增页面的范例 |
| `TodoContentView.tsx` | 收件箱显示「收件箱」，不重复显示「待办」；自动化配置刷新/新建动作 | 顶栏标识当前页面，不只显示所属模块名；搜索/排序是内容控件 |
| `LearningHubPage.tsx` | 全局标题和刷新；子屏接管标题/返回/动作 | 复用统一顶栏。Finder 页内仍有新建入口，是现有差异 |
| `AnkiTasksApp.tsx` | 移动端隐藏桌面页标题，抽屉提供统一导航；图表有自身分组名 | 内容分组标题可保留。刷新仍在列表工具栏，是现有差异 |
| `TemplateManagementApp.tsx` | 浏览态菜单/面包屑；编辑态返回/编辑工具 | 页面状态与返回目标一致，不在内容区另放返回栏 |
| `Settings.tsx` | MCP 新建和编辑保存进入顶栏右侧 | 新建/编辑的主要提交动作进入全局顶栏 |
| `MobileHeaderContext.tsx` / `MobileSlidingLayout.tsx` | 一个 viewId 一个配置写者，顶栏跟随主屏移动，抽屉共享全局入口 | 不额外造页内壳，不让多个子组件争写同一 viewId |

## 页面标准

1. **唯一页面标题。** 当前页面名称放全局顶栏；内容区不重复页面标题、模块名或一套页面工具栏。真正的内容分组名（如「复习活动」「评分分布」）可以保留。计数/进度可放简短顶栏副标题；说明放对应内容附近。
2. **主入口菜单，子页返回。** 今日、卡片库、统计等同级页面在统一抽屉切换。新建、全屏编辑、复习是子状态，顶栏返回回到实际来源。系统返回与顶栏返回调用同一处理；浮层先关闭。保活隐藏页不得消费返回。
3. **页面级热点动作上顶栏。** 新建、开始复习、刷新、保存等放右侧，最多两个入口；溢出动作收进「更多」。图标要有可访问名称，每个目标至少 44×44px。忙碌/禁用状态同步，不保留一套重复页内按钮。
4. **内容操作随内容。** 搜索、筛选、排序、多选批处理、单行操作和评分属于内容交互。它们不占用全局顶栏动作名额；避免为了折叠而让重要操作不可发现。内联行编辑仍属于该行，保存和取消随行；全屏编辑则接管顶栏。
5. **有效空间优先。** 复用 56px 顶栏和安全区 token；手机内容左右通常 16px。用文字层级、间距和细分隔组织内容，不增加装饰性彩色侧条、厚阴影和多层圆角卡片。颜色用于状态/图表含义。节省空间不能缩小触控目标或把正文变成小字。
6. **滚动归属清楚。** 页面列表/表单用共享滚动组件；手机新建表单及短高视口必须可滚动。评分可保持底部操作区，长卡面独立滚动。横向图表只用一个共享横向滚动容器。抽屉 track 带 transform，菜单浮层须使用现有 Portal。
7. **适配按行为验收。** 在 390px 和 320px/短高窗口检查页面切换、标题、动作、返回、表单、长内容及滚动；桌面保留自身布局。自动化测试验证动作绑定和状态还原；实际界面用于验证占用空间和可达性。软键盘、安全区与系统返回的设备验证单独记录，未验证不写通过。

## 闪卡状态映射

| 状态 | 顶栏标题 | 左侧 | 右侧 | 内容区调整 |
| --- | --- | --- | --- | --- |
| 今日 | 今日复习 | 菜单 | 开始复习、刷新 | 移除页面标题/刷新/重复开始按钮，保留紧凑进度、到期预览、空态引导 |
| 卡片库 | 卡片库；副标题显示数量 | 菜单 | 新建、更多（导入/刷新） | 直接开始搜索/筛选和列表，无重复标题/创建工具栏 |
| 新建卡片 | 新建卡片 | 返回库（保存中等待） | 保存并加入复习 | 手机显示独立滚动表单，隐藏列表和搜索；桌面仍内联 |
| 学习统计 | 学习统计 | 菜单 | 刷新 | 从数据概览开始；保留图表分组标题和来源说明 |
| 复习 | 复习；副标题进度 | 返回来源页 | 撤销、更多（编辑/跳过/暂停/恢复） | 删除页内返回/操作工具栏；保留卡面、评分和必要状态提示 |
| 复习中编辑 | 编辑卡片 | 返回当前卡片（保存中等待） | 保存 | 隐藏重复取消/保存工具栏，内容为可滚动字段 |
| 复习结束/失败 | 复习 | 返回来源页 | 可用的撤销/更多 | 保留结果/重试/继续复习；移除重复返回按钮 |

当前差距是全局固定「闪卡」，各屏另有标题和热点动作。落地时由 `FlashcardsApp` 唯一注册全局顶栏，当前屏只向宿主提供标题、动作及子状态返回回调；桌面及独立屏测试保持原有承载。
