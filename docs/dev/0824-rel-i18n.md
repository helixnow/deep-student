# 0824 release i18n / persisted-storage recovery

## Scope

- Base: `origin/cursor/0824-cde6` at `427c775f`
- Comparison release: `v0.9.44`
- Work branch: `cursor/0824-rel-i18n-cde6`
- The base branch was not modified or pushed.

## Bugs found

### Missing i18n paths and ineffective fallbacks

An AST audit of TypeScript changed since `v0.9.44` found 31 calls whose requested
leaf path was absent from at least one locale. Eighteen calls had a fallback, but
that still bypassed an existing translation. Thirteen calls had no fallback:

- document search used nonexistent `chatV2:documentViewer.{noMatches,prevMatch,nextMatch}`;
- both RAG panels used nonexistent multimodal-rerank label/helper paths;
- the vendor API-key reveal status used a nonexistent status path;
- two mind-map calls used correct locale-specific plural shapes, but had no
  fallback while the deferred namespace was unavailable.

Several fallback-backed paths had the same issue: sidebar workbench actions,
Crepe block types, DSTU resource loading, the mobile attachment menu, notes
replace/stats/tag feedback, MCP expansion, and wallpaper-library capacity.
Some fallbacks were Chinese literals, so an English session could display
Chinese while a deferred namespace loaded.

### Auto-sync persisted state could not recover

`useAutoSyncStore` was introduced after `v0.9.44` with Zustand's default JSON
storage. A malformed `localStorage["dstu-auto-sync"]` value made
`createJSONStorage` throw from `JSON.parse`. Zustand caught the hydration error,
but hydration remained incomplete and the same value failed again at every
launch.

The store's `migrate` callback only ran when the persisted version differed.
Valid JSON carrying a current `version: 2` but invalid field types therefore
bypassed migration and was shallow-merged into typed runtime state.

## Fixes

- Reused existing bilingual keys instead of adding duplicate locale entries:
  - chat document search → `chatV2:messageList.search.*`;
  - reranking → `enhanced_rag:enable_reranking` and
    `chat_host:rag.panel.rerank_helper`;
  - sidebar → `sidebar:navigation.*`;
  - block menu → existing `notes:slashMenu.*` / `notes:toggle.slashLabel`;
  - resource operation → `dstu:resource.getResource`;
  - notes, MCP, vendor-key, attachment, and wallpaper feedback → their existing
    namespace keys.
- Bound newly referenced namespaces to the affected React components.
- Kept explicit `defaultValue` only where no equivalent leaf exists or locale
  plural storage intentionally differs. The final audit has four
  fallback-backed calls and zero missing calls without a fallback.
- Added a `dstu-auto-sync` persistence adapter that discards malformed JSON and
  completes hydration with defaults.
- Added a sanitizing merge for every persisted snapshot, including current
  version payloads. Outcomes, interval presets, timestamps, and booleans are
  validated before entering runtime state.
