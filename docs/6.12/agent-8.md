# 代理 8 —— 移动端 UI/UX 体验(全局横切)

> 先读 [README.md](./README.md) 总览,遵守全局规则;状态文档:`docs/6.12/status/agent-8-status.md`。
> 本组横切所有特性界面,以**体验审阅**为主、以**适配层修改**为辅,改动权限见第 5 节分级。

## 1. 负责域

Android(及未来 iOS)上 DeepStudent 的整体用户体验:响应式布局、触控交互、
软键盘协调、手势、安全区域、移动端性能与离线弱网表现。逐特性(对话、资源中心、
阅读器、练习、制卡、笔记、导图、翻译、设置……)过一遍移动端可用性。

## 2. 移动端基础设施清单(本组核心阵地)

| 模块 | 路径 | 要点 |
|------|------|------|
| 移动布局框架 | `components/layout/MobileSlidingLayout.tsx`、`MobileLayoutContext.tsx`、`components/layout/` 其余 | 滑动布局、移动上下文 |
| 响应式 hooks | `hooks/useBreakpoint.ts`、`useMediaQuery.ts`、`usePreventScroll.ts`、`useTouchFriendlyDndSensors.ts` | 断点、触控拖拽 |
| 平台检测 | `src/utils/platform.ts` | isMobile/平台分支 |
| Android 壳 | `src-tauri/mobile/android/`、`tauri.android.conf.json`、`src-tauri/gen/` | 原生层配置 |
| 全局样式 | `src/styles/`、`tailwind.config.js`(断点定义) | 视口、safe-area |
| 各特性内 isMobile 分支 | 全代码库 `isMobile|useBreakpoint|MOBILE` 引用点(启动后先 grep 建立清单) | 散落的适配代码 |

已知重点适配场景(来自 README/CHANGELOG):移动端阅读模式(滚动收起键盘防误触)、
会话侧栏滑动、输入栏(InputBarUI)移动布局、设置页移动排版。

## 3. 审阅重点清单(按用户旅程)

### 全局
- [ ] 断点体系一致性:各特性用的是统一 useBreakpoint 还是各自 hardcode 宽度。
- [ ] 触控目标尺寸(≥44px)、误触防护、长按/滑动手势冲突(系统返回手势 vs 应用内滑动)。
- [ ] 软键盘:弹出时输入框遮挡、收起时布局回弹、阅读模式自动收起键盘的可靠性。
- [ ] 安全区域(刘海/导航条 inset)、横竖屏切换、字体缩放(系统大字体)下的布局健壮性。
- [ ] Android 返回键语义:各页面/弹层的返回栈行为。
- [ ] 移动端性能:首屏启动、长列表虚拟化、大组件懒加载、动画掉帧(framer-motion 在低端机)。
- [ ] 弱网/离线:加载骨架、错误重试入口、流式输出中断表现。

### 逐特性走查(每项在状态文档记录截图/问题/建议)
- [ ] 对话:多 Tab 在小屏的导航、消息长内容(代码块/表格/公式)横向溢出、输入栏附件操作。
- [ ] 资源中心:文件列表触控操作、向量化状态在小屏的可读性。
- [ ] PDF/DOCX 阅读:分屏在手机上的降级策略(切换式?)、缩放手势、选区注入聊天的触控流。
- [ ] 练习做题:作答控件触控友好度、计时显示、提交确认。
- [ ] 制卡:模板编辑器在移动端的可用性定位(只读预览?)、任务看板。
- [ ] 笔记/导图:Milkdown 移动端工具栏、导图触控拖拽与缩放。
- [ ] 翻译/作文:双栏在窄屏的降级、标注触控选择。
- [ ] 设置/命令面板/待办番茄钟:小屏排版、开关触控。

## 4. 不归属本组(别改)
- 业务逻辑与数据层(任何 `src-tauri/` 业务代码)→ 各业务组。
- 桌面端专属布局问题 → 代理 7。

## 5. 修改权限分级(横切组特别约定)

| 级别 | 范围 | 动作 |
|------|------|------|
| 直接改 | 第 2 节"移动端基础设施清单"内的文件;纯样式/类名级的响应式修补(不改组件逻辑) | 改后跑验证,登记状态文档 |
| 协商改 | 各特性组件内的结构性适配(改 JSX 结构、拆移动分支组件) | 先在状态文档「跨组问题」登记方案 → 标注目标代理编号 → 用户裁决后实施 |
| 只报告 | 业务逻辑、后端、基础 UI 组件(`components/ui`) | 记录问题与建议,归属代理 1–7 |

## 6. 验证
按 README 3.4 执行;另:
- 浏览器移动视口冒烟:`npm run dev` 后用 DevTools 设备模拟(360×800、390×844 等)走查;
- 有条件时 Android 真机/模拟器:`npm run tauri android dev`(构建配置见 `docs/BUILD-CONFIG.md`);
- 改样式后跑 `npm run lint:css`。
