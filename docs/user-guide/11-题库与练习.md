# 题库与练习

> 把教材、试卷、错题变成属于你自己的可练习题库：AI 识别录题、九种练习模式、自动判分、AI 解析与知识点掌握度追踪。

## 功能概览

在 Deep Student 中，一份可练习的题库叫做「题目集」。每个题目集都是学习资源中的一个文件，里面可以装入成百上千道题目，并围绕它完成完整的刷题闭环：

- **多种录题方式**：手动新建（支持九种题型）、拍照 / 截图 / 文档识别导入、CSV 批量导入，也可以在 AI 对话中直接让 AI 出题。
- **九种练习模式**：顺序练习、随机练习、错题优先、仅练错题、按标签、限时练习、模拟考试、每日一练、组卷练习。
- **自动判分**：客观题即时判分；主观题可由 AI 评判打分，也可以对照参考答案自评。
- **AI 解析**：答完题后一键让 AI 流式生成解题分析。
- **错题与复习**：错题自动进入「错题」视图，还可为题目创建间隔重复的「复习计划」。
- **知识点掌握度**：按标签统计每个知识点的掌握率，做题成绩会回流到你的薄弱点画像，并影响闪卡复习的排期（见 [13-闪卡复习](13-闪卡复习.md)）。
- **学习统计与做题历史**：正确率、学习进度、打卡日历、每道题的答题记录与修改历史。

适合场景：期末刷题、考证备考、错题订正、把一本教材"吃透"后自测。

## 入口与界面布局

**怎么打开：**

1. 打开侧边栏的「学习资源」，点击新建按钮，选择「题目集」，即可创建一个空题目集并直接打开。
2. 已有的题目集文件在学习资源里双击打开即可。
3. 如果你使用「学习桌面」模式（桌面端默认），也可以从底部 Dock 打开「题目集」应用，在里面「新建题目集」或打开最近的题目集。

**界面分区（题目集打开后）：**

- **顶部 Tab 栏**：
  - 「题库」— 题目列表，浏览、搜索、编辑题目；空题目集时这里就是「新建 / 导入」启动台。
  - 「做题」— 进入练习模式选择页和答题界面。
  - 「更多」菜单 — 收纳六个二级视图：错题、复习计划、收藏、知识点、统计、管理。
  - 右侧「导出」按钮和「添加题目」菜单（新建题目 / 识别导入 / 导入 CSV）。
- **内容区**：随所选 Tab 切换，做题时显示题目卡片、作答区和答题卡。

## 核心操作

### 一、向题目集里添加题目

**方式 1：手动新建**

1. 点击右上角「添加题目」→「新建题目」。
2. 填写题目内容，选择题型（单选题、多选题、不定项选择题、填空题、简答题、论述题、计算题、证明题、其他）。
3. 选择题点击选项字母即可设为答案；可补充解析、难度、标签、笔记和题目图片。
4. 点击「创建题目」完成。

**方式 2：识别导入（拍照 / 截图 / 文档）**

1. 点击「添加题目」→「识别导入」。
2. 选择文件：支持图片（PNG / JPG / WebP / HEIC）或文档（DOCX / XLSX / XLS / PDF / TXT / MD），移动端还支持「拍照导入」。也可以把文件直接拖进来。
3. 点击「开始识别」（文档则是「解析文档」）：图片会先 OCR 识别，再由 AI 结构化题目；界面会实时显示「已解析题目」。
4. 进入「确认录入」步骤：查看题目总数和题型分布，展开「筛选题目」可取消勾选不需要录入的题目（比如已掌握的），最后点「确认导入」。
5. 如果导入中途中断，题库列表上方会出现「继续导入」按钮，可从断点恢复，已保存的题目不会丢失。

> 提示：PDF 文本层质量较低时，系统会询问你「仅使用解析文本」还是「启用 OCR」。

**方式 3：CSV 批量导入**

1. 点击「添加题目」→「导入 CSV」。
2. 按向导四步走：选择文件 → 字段映射（至少要映射「题干内容」字段，系统会给出推荐映射）→ 去重策略（跳过重复 / 覆盖已有 / 合并补充）→ 查看导入结果。
3. 支持 UTF-8 和 GBK 编码。

**方式 4：让 AI 出题（对话出题）**

1. 打开 AI 对话，上传教材、讲义或直接描述需求，例如："根据这份 PDF 帮我出 20 道单选题，建一个题目集"。
2. AI 会自动创建题目集并批量写入题目，回复中会给出可点击的题目集引用，点击即可直接打开开始练习。
3. 也可以让 AI 往已有题目集里补题、生成某道题的变式题。详见 [02-AI对话与会话管理](02-AI对话与会话管理.md) 与 [15-技能与MCP扩展](15-技能与MCP扩展.md)。

### 二、开始做题

1. 切到「做题」Tab，首次会进入「选择练习模式」页面。
2. 从九种模式中选一种：
   - **顺序练习** — 按题号顺序依次练习
   - **随机练习** — 随机打乱题目顺序
   - **错题优先** — 优先练习答错的题目
   - **仅练错题** — 只练习已经答错的题目
   - **按标签** — 按知识点标签分类练习
   - **限时练习** — 设置倒计时挑战自己
   - **模拟考试** — 模拟真实考试环境
   - **每日一练** — 智能推荐今日练习
   - **组卷练习** — 自定义生成练习试卷
3. 答题界面中：作答后点「提交答案」，用「上一题 / 下一题」切换，答错可点「重做」；还可以收藏题目、写「我的笔记」、搜索题目内容快速跳转。
4. 界面右上角的「设置」里有两个实用开关：
   - **专注模式** — 隐藏统计卡片和标签，专注刷题。
   - **暗记模式** — 遮挡选项、点击显示（或按 H 键），适合记忆类题目。
5. 常用快捷键可在设置面板的「快捷键」区查看（选择选项、提交答案、上 / 下一题、重做 R、暂停计时、暗记模式 H）。

### 三、限时练习

1. 在练习模式中选「限时练习」，设置时长（分钟）和题目数量，系统会显示预计每题用时。
2. 点击「开始练习」，顶部显示剩余时间，可随时「暂停 / 继续」。
3. 时间不足 1 分钟会有提醒；做完或时间到后点「交卷」查看正确率。
4. 交卷后回到配置页会显示**上一轮总结**：已答题数、答对数、正确率（超时结束会带「超时」徽标）；点「再来一轮」直接沿用上轮的时长与题量再战一场。

### 四、模拟考试

1. 选择「模拟考试」，配置考试时长、题目数量，可选设置「题型配比」「难度配比」，并勾选是否「打乱题目顺序」「包含错题」。
2. 点击「开始考试」，进入考试状态，顶部倒计时显示剩余时间。
3. 点「交卷」时如有未作答题目会二次确认。
4. 交卷后查看「成绩单」：总题数、正确、错误、未答、用时和题型统计，可「再考一次」。

### 五、每日一练

1. 选择「每日一练」，设置「今日目标（题数）」。目标数按题目集记住，下次打开自动恢复。
2. 系统按智能推荐策略选题：优先选择错题巩固薄弱知识点，其次选择新题拓展范围，最后补充复习题防止遗忘；今天已答过的题不会重复推荐，题量不足时可「再练一组」回补。
3. 面板上的「今日进度」随做题实时更新，完成今日目标会出现庆祝动画。
4. 完成后累计「连续打卡天数」，「打卡日历」可查看本月打卡、做题总数和连续打卡记录；「达标」按你当天设置的目标题数判定。

### 六、自动判分与 AI 解析

1. **客观题**（选择、填空）：提交后立即判分，显示「回答正确 / 回答错误」，并给出正确答案与解析。
2. **主观题**（简答、论述、计算、证明）：提交后系统会自动进行「AI 评判」，给出 AI 评分（0–100）和「正确 / 部分正确 / 错误」的判定；如果 AI 评判失败，也可以对照「参考答案」点「我答对了 / 我答错了」自评。
3. 任何题目判分后，都可以点击「AI 解析」按钮，AI 会流式生成这道题的深度解析（考点分析与解题思路），生成结果会缓存，下次查看无需重新生成。

> 提示：AI 评判和 AI 解析需要先配置好模型，见 [14-模型与供应商配置](14-模型与供应商配置.md)。

### 七、错题与复习计划

1. **错题视图**：「更多」→「错题」，集中查看待复习的错题，可勾选后「开始复习」。累计答对 2 次的题目会自动标记为「已掌握」。
2. **复习计划**（间隔重复）：「更多」→「复习计划」：
   - 首页显示「今日待复习」「全部待复习」「已掌握」「平均正确率」，以及按到期时间排序的「复习队列」。
   - 可为选中题目或全部题目「创建复习计划」，也可以「暂停复习 / 恢复复习 / 删除计划」。
   - 点「开始复习」进入复习会话：查看题目 → 显示答案 → 按掌握程度评分（重来 / 困难 / 良好 / 简单，可按 1–4 快速评分），系统会根据你的表现自动安排下次复习时间。
   - 「复习日历」以热力图追踪你的复习记录、当前连续天数和最长连续天数。

> 题目集的复习计划与闪卡复习是两套独立的间隔重复系统：前者针对题目，后者针对 Anki 卡片，详见 [13-闪卡复习](13-闪卡复习.md)。

### 八、知识点掌握度追踪

1. 给题目打上知识点标签（编辑题目时添加，AI 出题通常会自动带标签）。
2. 「更多」→「知识点」：查看总题数、掌握率、每个知识点的题量与待掌握数量，可搜索知识点，点某个知识点旁的「练习」直接按标签刷题。
3. 「更多」→「统计」：查看学习进度、正确率等整体数据。
4. 做题成绩会自动回流到你的薄弱点画像，并对闪卡复习的排期做有界调整——薄弱知识点的卡片会更早出现（见 [13-闪卡复习](13-闪卡复习.md)）。

### 九、组卷练习与导出

1. 选择「组卷练习」，打开「组卷生成器」：填写试卷标题，配置各题型数量，可按难度、标签筛选，勾选是否打乱顺序、包含答案 / 解析。
2. 点「生成试卷」预览，再点「导出」。当前支持 Markdown 导出与预览；PDF / DOCX 选项在格式选择器中置灰并标注「即将推出」，暂不可用。
3. 题目集本身也可以通过顶部「导出」按钮导出为 JSON / TXT / CSV 文件，可自选包含答案、解析、学习状态、答题统计等字段，并选择文件编码（UTF-8 / 带 BOM / GBK）。

### 十、管理题目与做题历史

1. 「更多」→「管理」：表格视图批量管理题目，支持搜索、筛选、全选、批量删除、批量「重置进度」（清除答题记录并恢复为"新题"，但保留笔记和标签）。
2. 在管理视图中打开某道题的「历史记录」，可查看这道题的修改历史和每次答题记录（创建、修改、答题、状态变更）。

## 进阶用法

- **让 AI 帮你复盘**：在对话中让 AI 分析某个题目集的学习趋势、活跃度热力图和薄弱知识点，或让它生成某道错题的变式题再练一遍。
- **对话内发起限时练习 / 模拟考**：可以直接对 AI 说"给我来一场 30 分钟的模拟考"，AI 会准备好考试并在题目集界面中打开，作答和交卷仍由你在界面里完成。
- **收藏夹**：做题时点星标收藏难题，「更多」→「收藏」集中回顾。
- **计时器**：普通练习也有计时器，可随时暂停 / 继续。

## 📱 移动端说明

- **入口**：移动端打开「学习资源」后是三屏结构——左侧抽屉选分类、中间文件列表、右屏打开题目集。左抽屉和文件列表工具栏的「+」菜单都可以「新建题目集」。
- **拍照录题**：识别导入中的「拍照导入」按钮在移动端可直接调用相机拍摄试卷。
- **Tab 栏**：题目集顶部 Tab 在小屏幕上可横向滑动，右缘渐隐表示还有更多入口。
- **确认提示**：退出复习、丢弃草稿等确认在移动端以页面内横幅形式出现，而不是弹窗。
- **形态差异**：移动端不提供「学习桌面」模式，题目集始终以全屏页面打开；导出文件类操作在移动端可能受系统限制。更多移动端通用差异见 [17-移动端指南](17-移动端指南.md)。

## 常见问题

**Q1：识别导入的题目有错漏怎么办？**
A：识别结果不会直接定稿。在「确认录入」步骤可以先排除有问题的题目；导入后在「题库」列表点开任意题目进入编辑，修改题干、选项、答案和解析即可。

**Q2：题目做错了想重新来一遍，怎么清空记录？**
A：「更多」→「管理」，勾选题目后点「重置进度」。这会清除答题记录和正确率统计，题目恢复为"新题"，但你写的笔记和标签会保留。

**Q3：主观题为什么显示「AI 评判中...」很久或失败？**
A：AI 评判需要调用你配置的模型。请在设置中确认模型可用（见 [14-模型与供应商配置](14-模型与供应商配置.md)）；失败时可以点「我答对了 / 我答错了」手动自评，不影响统计。

**Q4：「错题优先」和「复习计划」有什么区别？**
A：「错题优先 / 仅练错题」是练习模式，立刻把错题拿出来刷；「复习计划」是间隔重复系统，按遗忘曲线安排每道题在未来某天到期复习，适合长期记忆。

**Q5：知识点视图是空的？**
A：说明题目还没有知识点标签。编辑题目时添加标签，或让 AI 出题时自动打标，之后就能按知识点分类练习和查看掌握率。

**Q6：组卷能导出 PDF 吗？**
A：暂时不能。组卷当前支持预览和 Markdown 导出，PDF / DOCX 导出即将推出；如需打印，可先导出 Markdown 再用其他工具转换。

## 已知差异（2026-08-24 走查）

以下为当前版本已确认、尚未修复的行为差异，供对照参考（不影响答题记录本身的保存）：

- **限时练习 / 模拟考试不支持断点续考**：进行中的会话只保存在内存里，中途关闭或重启应用后无法恢复，需要重新开始一场。
- **多窗口同时只支持一场进行中的练习会话**：学习桌面下打开两个题目集窗口时，后发起的限时练习 / 模拟考会顶掉先前进行中的那场。

> 走查中发现的另外三项（每日一练进度恒 0、打卡达标按固定 10 题判定、主观题自评重复计数）已在本轮修复，正文描述即当前行为。
