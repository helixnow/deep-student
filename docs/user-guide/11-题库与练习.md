# 题目集与练习

> 把教材、试卷、错题变成属于你自己的可练习题库：AI 识别录题、九种练习模式、自动判分、AI 解析与知识点掌握度追踪。

## 功能概览

在 Deep Student 中，一份可练习的题库叫做「题目集」。每个题目集都是资源库里的一个文件，里面可以装入成百上千道题目，并围绕它完成完整的刷题闭环：

- **多种录题方式**：手动新建（支持九种题型）、拍照 / 截图 / 文档识别导入、CSV 批量导入、「AI 出题」面板按资料和知识点出题，也可以在 AI 对话中直接让 AI 出题。
- **九种练习模式**：顺序练习、随机练习、错题优先、仅练错题、按标签、限时练习、模拟考试、每日一练、组卷练习。
- **自动判分**：普通练习交卷后统一判分；「刷题」保留逐题判分。填空题和主观题由 AI 评判，也可以对照参考答案自评。
- **AI 解析**：在题目浏览或刷题界面直接查看、生成解析，无需先作答；首次完整返回即持久化保存。
- **错题与复习**：错题自动进入「错题」视图，所有题目集的错题还汇总在资源库的「错题本」里，可以一批挑出来重做；还可为题目创建间隔重复的「复习计划」，到期的错题能跨题目集一次复习完。
- **知识点掌握度**：按标签统计每个知识点的掌握率，做题成绩会回流到你的薄弱点画像，并影响闪卡复习的排期（见 [闪卡复习](./13-闪卡复习.md)）。
- **学习统计与做题历史**：正确率、学习进度、打卡日历、每道题的答题记录与修改历史。

适合场景：期末刷题、考证备考、错题订正、把一本教材"吃透"后自测。

## 入口与界面布局

**怎么打开：**

1. 在资源库点「新建」→「新建题目集」，即可创建一个空题目集并直接打开。
2. 已有的题目集在资源库里双击打开即可（学习桌面里会开成独立窗口）。
3. 学习桌面里也可以在「全部应用」打开「题目集」，在里面新建或打开最近的题目集。

**界面分区（题目集打开后）：**

- **顶部 Tab 栏**：
  - 「题库」— 题目列表，浏览、搜索、编辑题目；空题目集时这里就是「新建 / 导入」启动台。
  - 「做题」— 进入练习模式选择页和答题界面。
  - 「试卷」— 管理已保存的组卷试卷、继续作答、查看结果和导出。
  - 「更多」菜单 — 收纳六个二级视图：错题、复习计划、收藏、知识点、统计、管理。
  - 右侧「导出」按钮和「添加题目」菜单（新建题目 / 识别导入 / 导入 CSV / AI 出题）。
- **内容区**：随所选 Tab 切换，做题时显示题目卡片、作答区和答题卡。

## 核心操作

### 一、向题目集里添加题目

**方式 1：手动新建**

1. 点击右上角「添加题目」→「新建题目」。
2. 填写题目内容，选择题型（单选题、多选题、不定项选择题、填空题、简答题、论述题、计算题、证明题、其他）。
3. 选择题点击选项字母即可设为答案；可补充解析、难度、标签、笔记和题目图片。
4. 点击「创建题目」完成。

**方式 2：识别导入（拍照 / 截图 / 文档）**

1. 点击「添加题目」→「识别导入」。
2. 选择图片（PNG / JPG / WebP / HEIC）或文档（DOCX / XLSX / XLS / PDF / TXT / MD）。试题和单独答案文件可一起添加；JSON / ZIP 用于恢复导出的 v2 题库。移动端还支持拍照。
3. 选择解析模型。多模态主模型直接理解完整原始图文；只有主模型不能读图而材料包含视觉内容时，才使用配置的视觉模型提供证据，再交给主模型处理。界面会显示实际模型路线。
4. 1–20 页的完整材料在一次主解析请求中提供，不逐页调用模型。超过 20 页也不会静默只读前 20 页；遇到模型窗口、图片数或输出限制会明确报错，请调整模型配置或自行分段。
5. 解析结束后是待确认草稿，尚未进入正式题库。核对共享材料、题目、答案及待复核事项，取消勾选不需要的题目，再点「确认录入」。只有提交成功才显示正式题目。
6. 中断后可通过继续导入恢复已保存来源或草稿。若模型配置已变化，应创建新解析任务。同源重解析遇到映射歧义会要求复核，不覆盖人工编辑和作答历史。

原文没有答案时会保留为空，不让下游模型自动解题填充。缺页、截断和不确定内容不会被当作完整导入。

**方式 3：CSV 批量导入**

1. 点击「添加题目」→「导入 CSV」。
2. 按向导四步走：选择文件 → 字段映射（至少要映射「题干内容」字段，系统会给出推荐映射）→ 去重策略（跳过重复 / 覆盖已有 / 合并补充）→ 查看导入结果。
3. 支持 UTF-8 和 GBK 编码。

**方式 4：AI 出题面板**

1. 点「添加题目」→「AI 出题」（空题目集的启动台上也有这个入口）。
2. 设置「题型与数量」（可以添加多种题型，总题量不超过 100）、「难度偏好」（默认自动分布），可选填「知识点范围」或从「知识点」里挑选。
3. 「参考资料」可以「从资源库选择」或「上传本地文件」，最多 3 份、每份不超过 20MB；扫描件需要出题模型支持读图。勾选「参考题目集现有题目出变式题」，会照着已有题目出变式。
4. 点「开始生成」。出题在后台进行，可以「关闭并后台运行」，完成后会通知你「AI 出题完成：N 道题待确认」。
5. 在结果里勾选要的题，点「加入所选 N 题」；不满意就「调整要求重新生成」。没通过校验的题会自动剔除并说明原因。

出题用的模型可以在面板里单独选，留空使用默认主模型。输出与导入使用相同的材料、题组和子题契约，确认后才入库。

**方式 5：在对话里让 AI 出题**

1. 打开 AI 对话，上传教材、讲义或直接描述需求，例如：「根据这份 PDF 帮我出 20 道单选题，建一个题目集」。
2. AI 会自动创建题目集并批量写入题目，回复中会给出可点击的题目集引用，点击即可打开开始练习。
3. 也可以让 AI 往已有题目集里补题、生成某道题的变式题。详见 [AI 对话与会话管理](./02-AI对话与会话管理.md) 与 [技能与 MCP 扩展](./15-技能与MCP扩展.md)。

对话中命题直接使用当前对话模型，不额外切到出题/批改模型槽。仅解析预览不会自动写入正式题；AI 应以工具返回的正式提交回执报告创建数量。

### 共享材料与题组

阅读文章、共用条件和共用图片只保存一份材料，多个小问各自是一道可作答题。即使随机抽中某一道子题，也会显示完整必要材料；各子题独立判分、收藏、复习和统计。材料编辑使用独立版本校验，冲突时不会覆盖其他修改。仍被题组引用的材料不能直接删除。

### 二、开始做题

1. 切到「做题」Tab，首次会进入「选择练习模式」页面。
2. 从九种模式中选一种：
   - **顺序练习** — 按题号顺序依次练习
   - **随机练习** — 随机打乱题目顺序
   - **错题优先** — 优先练习答错的题目
   - **仅练错题** — 只练习已经答错的题目
   - **按标签** — 按知识点标签分类练习
   - **限时练习** — 设置倒计时挑战自己
   - **模拟考试** — 模拟真实考试环境
   - **每日一练** — 智能推荐今日练习
   - **组卷练习** — 自定义生成练习试卷
3. 普通练习期间自动保存作答，使用「上一题 / 下一题」或答题卡自由切换、返回修改和清空答案，最后点「交卷」统一判分。交卷前不显示正误、答案或解析。关闭页面或重启后，可从「继续练习」恢复；未交卷草稿只保存在本机。
4. 「刷题」入口保留逐题提交、立即判分与重做，支持顺序、随机、错题优先、仅错题和按标签选题。
5. 界面右上角的「设置」里有两个实用开关：
   - **专注模式** — 隐藏统计卡片和标签，专注刷题。
   - **暗记模式** — 遮挡选项、点击显示（或按 H 键），适合记忆类题目。
6. 桌面端普通练习和刷题均支持快捷键；普通练习顶部的键盘图标、刷题设置面板可查看当前可用按键。

| 按键 | 普通练习（统一交卷） | 刷题（逐题判分） |
| --- | --- | --- |
| `1–9` / 当前选项字母 | 选择或切换选项，仅保存作答 | 选择或切换选项 |
| 判断题 `1` / `2` | 选择正确 / 错误，仅保存作答 | 选择正确 / 错误 |
| `Enter` | 保存并下一题；最后一题停留，不会交卷 | 提交当前题，提交后下一题 |
| `←` / `→` | 保存后切题；保存失败留在当前题 | 切换题目，有未提交内容时先确认 |
| `F` | 收藏 / 取消收藏 | 收藏 / 取消收藏 |
| `R` / `H` / `Space` | 不启用，不重置本轮、显示答案或暂停考试 | 答错后重做 / 暗记模式 / 暂停可控计时器 |

选项字母优先于同名功能键（例如存在 F 选项时按 F 选择该选项）。填空题按 Enter 逐空前进，末空执行当前模式的主动作；单行数值或简答输入同理，多行输入的 Enter 仍为换行。输入法确认、长按重复按键、搜索框和其他控件不触发做题快捷键。弹窗或其他练习窗口激活时，背景练习让出快捷键；结果页按当前筛选范围切题，不修改已交卷答案。小屏幕仍以触控操作为主，不启用这些单键快捷键。

### 三、限时练习

1. 在练习模式中选「限时练习」，设置时长（分钟）和题目数量，系统会显示预计每题用时。
2. 点击「开始练习」，顶部显示剩余时间。退出后倒计时仍继续，重启后从「继续练习」恢复。
3. 做完点「交卷」确认已答、未答题数；到时会自动交卷，重开已到期练习也会处理交卷。
4. 交卷后在结果页查看正确、错误、未答和待批改题；「重新练习」沿用本轮题目并创建新记录。

### 四、模拟考试

1. 选择「模拟考试」，配置考试时长、题目数量，可选设置「题型配比」「难度配比」，并勾选是否「打乱题目顺序」「包含错题」。
2. 点击「开始考试」，进入考试状态，顶部倒计时显示剩余时间。
3. 点「交卷」时如有未作答题目会二次确认。
4. 交卷后查看「成绩单」：总题数、正确、错误、未答、用时和题型统计，可「再考一次」。

### 五、每日一练

1. 选择「每日一练」，设置「今日目标（题数）」。目标数按题目集记住，下次打开自动恢复。
2. 系统按智能推荐策略选题：优先选择错题巩固薄弱知识点，其次选择新题拓展范围，最后补充复习题防止遗忘；今天已答过的题不会重复推荐，题量不足时可「再练一组」回补。
3. 面板上的「今日进度」随做题实时更新，完成今日目标会出现庆祝动画。
4. 完成后累计「连续打卡天数」，「打卡日历」可查看本月打卡、做题总数和连续打卡记录；「达标」按你当天设置的目标题数判定。

### 六、自动判分与 AI 解析

1. **客观题**：普通练习在整轮交卷后判分；刷题模式在每题提交后立即判分。
2. **填空题和主观题**（简答、论述、计算、证明）：交卷后自动排队进行「AI 评判」，给出 AI 评分（0–100）和「正确 / 部分正确 / 错误」的判定；离开题目页面不影响后台批改。失败题保留待批改，可重试或对照参考答案自评，不会误计为答错。每轮结果独立保存，可在「练习记录」查看并重新练习。
3. 在题目浏览或「刷题」中，无需作答便可点「查看解析」。没有解析时可点「AI 解析」生成，首次完整返回会自动写入题目并提示保存完成，切题、重启和重置学习进度后仍可查看。已有解析不会被自动覆盖；替换须确认。
4. 普通练习、限时和模拟考试交卷前隐藏解析，交卷后按本轮快照查看。中断的 AI 文本会保留并提示重试，不作为完整解析保存。

> 提示：AI 评判和 AI 解析需要先配置好模型，见 [模型与供应商配置](./14-模型与供应商配置.md)。

### 七、错题与复习计划

1. **错题视图**：「更多」→「错题」，集中查看待复习的错题（题干、答案和解析里的公式按 LaTeX 渲染），可勾选后「开始复习」。累计答对 2 次的题目会自动标记为「已掌握」。
2. **复习计划**（间隔重复）：「更多」→「复习计划」：
   - 首页显示「今日待复习」「全部待复习」「已掌握」「平均正确率」，以及按到期时间排序的「复习队列」。
   - 可为选中题目或全部题目「创建复习计划」，也可以「暂停复习 / 恢复复习 / 删除计划」。
   - 点「开始复习」进入复习会话，先答再看：
     - 选择题会列出选项，翻面前直接点选作答（也可以按选项字母键，多选题可选多个）；其他题型可以先在「你的答案」框里写下答案（可选）。
     - 点「核对答案」（没作答时是「显示答案」）翻面，正确选项会标出来。选择题会提示「答对了，建议『良好』」或「你选了 A，正确是 B，建议『重来』」，建议的评分按钮带描边，按空格 / 回车就是选它。
     - 按掌握程度评分（重来 / 困难 / 良好 / 简单，可按 1–4 快速评分），你的作答会一起记进复习记录，系统会根据表现自动安排下次复习时间。
   - 「复习日历」以热力图追踪你的复习记录、当前连续天数和最长连续天数。

3. **跨题目集复习到期错题**：不用逐个打开题目集。点对话首页「今日待复习」里的「错题复习 N」，或错题本上方的「复习到期错题」，会弹出「错题复习」，把所有题目集里今天到期的错题排成一轮，复习方式同上。今天没有到期的错题时，可以点「查看全部错题」去错题本。

> 题目集的复习计划与闪卡复习是两套独立的间隔重复系统：前者针对题目，后者针对 Anki 卡片，详见 [闪卡复习](./13-闪卡复习.md)。

### 八、错题本：所有题目集的错题

拍照录的错题、作文错误点等往往各自落在不同的题目集里，「错题本」把它们放到一起看：

1. 在资源库打开「全部题目集」视图（在「桌面」添加对应快捷方式即可，见 [资源库](./04-学习资源中心.md)），顶部切到「错题本」；在某个题目集的「更多」→「错题」里点「所有题目集的错题」也能直达。
2. 顶部显示「N 道错题 · 来自 M 个题目集」。可以按题目集筛选，按「最近做错 / 错得最多」排序；资源库的搜索框在这里搜错题的题干、答案和知识点。答错后还没掌握的题都在这里，重做答对掌握了就会移出。
3. 点一行展开：题干、选项、「我的答案」对「正确答案」和解析，公式按 LaTeX 渲染。下面有这些操作：
   - 「去题目集重做」：打开所在的题目集并定位到这道题；
   - 「问 AI 讲解」：新开一个对话，把题目和你的答案填进输入框，请 AI 指出错误思路、讲清考点；
   - 「生成同类题」：新开对话请 AI 出 2 道同知识点的题并加进原题目集；
   - 「出处」：题目记着来源资料时，回到那份资料。
   「问 AI 讲解」「生成同类题」只填好输入框、不自动发送，你可以先补充再发。
4. **一批错题当一套题重做**：勾选几道错题点「重做所选 N 题」；不勾选时重做当前列出的错题（一次最多 100 道）。作答自动保存，统一交卷后更新原题成绩；可从错题本继续未完成的练习。
5. 「复习到期错题」：打开跨题目集的到期错题复习（见上一节）。

### 九、知识点掌握度追踪

1. 给题目打上知识点标签（编辑题目时添加，AI 出题通常会自动带标签）。
2. 「更多」→「知识点」：查看总题数、掌握率、每个知识点的题量与待掌握数量，可搜索知识点，点某个知识点旁的「练习」直接按标签刷题。
3. 「更多」→「统计」：查看学习进度、正确率等整体数据。
4. 做题成绩会自动回流到你的薄弱点画像，并对闪卡复习的排期做有界调整——薄弱知识点的卡片会更早出现（见 [闪卡复习](./13-闪卡复习.md)）。

### 十、组卷练习与导出

题目集顶部的「试卷」页保存已生成试卷，退出或重启后仍可打开。支持重命名、继续作答、重新练习、查看历史结果和导出。题目和共享材料使用生成时的快照；答案与解析开关仅控制导出内容，不删除判分所需参考信息。试卷及已交卷记录参与云同步，未交卷答案仅本机保存。

导出支持 Markdown、PDF 和 Word（DOCX），桌面与安卓共用保存流程。PDF/DOCX 使用 A4 纵向排版，保留作答空间，勾选的答案与解析附在卷末。Word 正文和表格可编辑，公式使用高清图片；共享材料、题目图片和结构化题型随试卷导出。

1. 选择「组卷练习」，打开「组卷生成器」：填写试卷标题，配置各题型数量，可按难度、标签筛选，勾选是否打乱顺序、包含答案 / 解析。
2. 点「生成试卷」后立即保存，可在「试卷」页打开并独立选择 Markdown、PDF 或 Word 导出。导出完成、失败会通知；取消保存不会报告导出成功。
3. 题目集本身可导出 v2 JSON 或包含资产的 ZIP 便携包，保留共享材料、题组、结构化题型和来源。跨设备搬运图片请使用便携包；仅 JSON 不携带本机图片字节。TXT/Markdown 是展示格式，CSV 面向独立题，不能作为共享关系的无损备份。

### 十一、管理题目与做题历史

1. 「更多」→「管理」：表格视图批量管理题目，支持搜索、筛选、全选、批量删除、批量「重置进度」（清除答题记录并恢复为"新题"，但保留笔记和标签）。
2. 在管理视图中打开某道题的「历史记录」，可查看这道题的修改历史和每次答题记录（创建、修改、答题、状态变更）。

## 进阶用法

- **让 AI 帮你复盘**：在对话中让 AI 分析某个题目集的学习趋势、活跃度热力图和薄弱知识点，或让它生成某道错题的变式题再练一遍。
- **对话内发起限时练习 / 模拟考**：可以直接对 AI 说"给我来一场 30 分钟的模拟考"，AI 会准备好考试并在题目集界面中打开，作答和交卷仍由你在界面里完成。
- **收藏夹**：做题时点星标收藏难题，「更多」→「收藏」集中回顾。
- **计时器**：普通练习也有计时器，可随时暂停 / 继续。

## 📱 移动端说明

- **入口**：移动端打开资源库后是三屏结构——左侧抽屉选分类、中间文件列表、右屏打开题目集。左抽屉和文件列表工具栏的「+」菜单都可以「新建题目集」。在左抽屉选题目集类型后，列表顶部同样有「全部题目集 / 错题本」切换；「错题重做」和「错题复习」在手机上全屏打开，系统返回键关闭。
- **拍照录题**：识别导入中的「拍照导入」按钮在移动端可直接调用相机拍摄试卷。
- **Tab 栏**：题目集顶部 Tab 在小屏幕上可横向滑动，右缘渐隐表示还有更多入口。
- **确认提示**：退出复习、丢弃草稿等确认在移动端以页面内横幅形式出现，而不是弹窗。
- **形态差异**：移动端不提供「学习桌面」模式，题目集始终以全屏页面打开；导出文件类操作在移动端可能受系统限制。更多移动端通用差异见 [移动端指南](./17-移动端指南.md)。

## 常见问题

**Q1：识别导入的题目有错漏怎么办？**
A：识别结果不会直接定稿。在「确认录入」步骤可以先排除有问题的题目；导入后在「题库」列表点开任意题目进入编辑，修改题干、选项、答案和解析即可。

**Q2：题目做错了想重新来一遍，怎么清空记录？**
A：「更多」→「管理」，勾选题目后点「重置进度」。这会清除答题记录和正确率统计，题目恢复为"新题"，但你写的笔记和标签会保留。

**Q3：主观题为什么显示「AI 评判中...」很久或失败？**
A：AI 评判需要调用你配置的模型。请在设置中确认模型可用（见 [模型与供应商配置](./14-模型与供应商配置.md)）；失败时可以点「我答对了 / 我答错了」手动自评，不影响统计。

**Q4：「错题优先」和「复习计划」有什么区别？**
A：「错题优先 / 仅练错题」是练习模式，立刻把错题拿出来刷；「复习计划」是间隔重复系统，按遗忘曲线安排每道题在未来某天到期复习，适合长期记忆。想跨题目集刷错题，用资源库的「错题本」重做一批；想按计划复习，用「复习到期错题」。

**Q5：知识点视图是空的？**
A：说明题目还没有知识点标签。编辑题目时添加标签，或让 AI 出题时自动打标，之后就能按知识点分类练习和查看掌握率。

**Q6：组卷能导出 PDF 吗？**
A：可以。在「试卷」页打开已保存试卷后，选择 PDF、Word 或 Markdown 并导出，支持桌面和安卓。

## 已知差异（2026-08-24 走查）

### 题目导入与共享材料更新（2026-10-23）

- 对话或手动解析后产生的内容先保存为草稿。题目集内的「待确认草稿」入口可以继续复核和录入，无需重新解析；只有正式提交成功才计入题数。
- 「题组与材料」支持调整子题顺序、加入或移出成员、编辑题组名称和材料关联。解散题组时保留每题必要的材料；删除题组及子题需要明确确认。被引用的材料不能直接删除。
- 「导入记录与重解析复核」审计旧预览卡片，展示草稿与正式题的来源映射和字段差异。保留原题、导入为新题或替换均需明确选择；不会按相似题干猜测覆盖，也不会自动恢复已删除题目。
- 题目编辑中的「原题来源」打开真实原页并显示已有坐标框；旧数据没有可靠页号、页图或坐标时会明确提示，不编造定位。
- 完整请求遇到供应商上下文、图片数或请求体限制时，可明确选择原始页范围，并把所需材料和答案范围一起选入。未处理范围仍保留在覆盖记录中，部分导入不代表整份文档完成。

以下为当前版本已确认、尚未修复的行为差异，供对照参考（不影响答题记录本身的保存）：

- **限时练习 / 模拟考试续答**：草稿保存在本机，倒计时跨退出和重启继续；已到期练习自动交卷。
- **多窗口练习**：每轮练习使用独立会话保存进度；同一份草稿在两个窗口同时修改时会提示版本冲突，避免静默覆盖答案。
