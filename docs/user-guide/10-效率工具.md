# 效率工具

> 待办清单、番茄钟、学习统计中心、命令面板和语音听写——帮你管好任务、管好时间、掌握学习节奏，并用一个快捷键直达任意笔记、闪卡和对话。

## 三步上手

**想把今天的学习安排得明明白白：**

1. **看一眼今日汇总**：打开「待办」，先看顶部「今日学习汇总」卡片里的到期闪卡、错题与待办，点「开始今日冲刺」或按 `N` 连续录入今天的新任务。
2. **开一个番茄专注**：点击任务行旁的「开始专注」（或直接按 `Space`），配合环境音与置顶小窗进入心流；休息时顺手点「去复习 N 张」清几张到期闪卡。
3. **随时 `Ctrl / ⌘ + K` 直达**：想找某张闪卡、某篇笔记或某段历史对话，按下 `Ctrl / ⌘ + K` 输入关键词，选中结果即可一步直达内容本身，不用层层翻菜单。

## 功能概览

本章介绍五个日常效率与学习总览工具：

- **待办**：顶部汇总今日学习概览并可一键发起「今日冲刺」，支持自然语言快速添加（"明天交作业 !高"）、四象限视图、子任务与 AI 拆解、重复任务与提醒，还能创建定时运行的自动化任务。
- **番茄钟**：内嵌在待办页面，支持严格模式、环境音、沉浸专注、置顶小窗和专注趋势统计，可与具体待办绑定。
- **学习统计中心与周报**：将今日指挥中心、学习热力图、模型与模块用量分布和学习周报收口在一处，一站式查看学了多少、该复习什么。
- **命令面板（全局直达）**：按 `Ctrl / ⌘ + K` 唤起，除了执行应用内几乎所有命令，还支持**跨内容直达搜索**——带上下文摘要直接跳进指定**闪卡**、**笔记 / 文件**和**历史会话**，无结果时可一键「前往 AI 对话提问」；快捷键可自定义。
- **语音输入（听写）**：对着麦克风说话，自动转成文字插入输入框。

## 待办

### 入口与界面布局

学习桌面里点程序坞（Dock）的「待办」打开；经典布局点左侧导航的「待办」。界面分两栏：

- **左侧「待办导航」**：上方是「智能视图」——收件箱、今日、即将到期、四象限、已过期、已完成；中间是你的自定义「列表」和「收藏」；底部有「定时任务」和「回收站」入口。
- **右侧主区**：顶部展示**「今日学习汇总」**卡片（汇总今日到期的闪卡、错题 FSRS、待复习笔记与今日待办，并提供一键**「开始今日冲刺」**入口），下方是快速添加框、搜索与任务列表；右侧区域驻留番茄钟面板。

### 快速添加一条待办

1. 点击顶部输入框（占位提示「添加待办，试试「明天交作业 !高」...」），或在列表区按 **`N`** 直接聚焦输入框。
2. 直接用自然语言输入，应用会自动识别并以小标签预览：
   - **日期**：今天 / 明天 / 后天 / 3天后 / 周五 / 下周一 / 6月1日……
   - **时间**：19:00 / 晚上8点 / 3pm……
   - **优先级**：`!紧急`、`!高`、`!中`、`!低`（或 p1～p4）
   - **重复**：每天 / 每周三 / 每月 / 每个工作日……
   - **提醒**：加上「提醒我」即可按识别出的时间设置提醒
   - **标签**：`#英语` 这样的井号标签
3. 按 **`Enter`** 或点「添加」创建，输入框保持聚焦，方便 **`N` 聚焦 + `Enter` 连续快速添加**多条待办；识别结果不对时，可在创建后进详情修改。

### 待办键盘快捷键

- 列表内（非输入状态）：`j / k` 或 `↑ / ↓` 移动焦点行，`Space / x` 完成，`Enter` 打开详情，`Delete` 删除，`Esc` 依次退出多选 → 详情 → 焦点行；`/` 聚焦搜索，`n` 聚焦快速添加。
- 视图跳转：`Ctrl / ⌘ + 1..6` 依次切换 收件箱 / 今日 / 即将到期 / 四象限 / 已过期 / 已完成，`Ctrl / ⌘ + 7` 定时任务，`Ctrl / ⌘ + 8` 回收站。
- 在「学习桌面」里，以上快捷键都只在**待办窗口处于聚焦状态**时生效——桌面上仅仅开着一扇待办窗不会截走按键。待办上下文之外，`Ctrl / ⌘ + 1` 仍是命令面板的全局导航快捷键（跳转到智能对话）；两者按「当前窗口优先」自然共存。

### 管理任务

1. 点击任务圆圈标记完成；点击任务行打开「详情」面板。在「今日」视图中把当天任务全部勾完后，页面会展示**今日待办全清零反馈**。
2. 详情中可编辑：状态、优先级、截止日期与时间、描述、预估「番茄」数、重复规则、提醒（准点 / 提前 15 分钟 / 提前 1 小时）、标签。
3. **子任务**：在「子任务」区逐条添加；勾选完成的子任务会**保留在列表中可见**（带完成态标记），方便回溯推进脉络，不会勾选后立刻消失；点「AI 拆解」可让 AI 自动把任务拆成可执行的子任务。
4. **改期**：任务行的「改期」菜单提供今天 / 明天 / 周末 / 下周一 / 两周后 / 选择日期；「已过期」视图中还有「全部改到今天」一键顺延。
5. **整理**：新建列表给任务分类，支持列表收藏、改色、拖拽排序；任务可按截止日期 / 优先级 / 标题排序，或手动拖拽。
6. 删除的列表和任务进入「回收站」，可恢复或彻底删除。

### 给待办关联资料

像「复习第三章」这样的待办，可以把要用的资料直接挂上去，开始做时一键打开：

1. 在任务详情的「关联资料」区点「添加」，从「最近打开」里挑，或输入关键词搜索笔记、教材、题目集等资料。
2. 已关联的资料列在这一区，点名称直接打开（学习桌面里会开到对应的应用窗口）；点旁边的 × 取消关联。资料被删除后会显示为划掉的灰色，打不开，但仍可以取消关联。
3. 任务列表里，带关联资料的任务会显示回形针和数量；点行尾的回形针按钮：只关联了一份就直接打开，有多份就打开详情让你挑。

### 提醒与通知

- **点到点提醒直达那条待办**：点系统弹出的待办提醒，会打开待办并选中那一条（它不在当前视图时，会自动切到它所在的清单）；错过的提醒汇总里只有一条时同样如此。
- **早间学习提醒**：每天 7 点后，如果有到期的闪卡、错题或待复习笔记，应用会发一条「今日有 N 项待复习」通知（默认在应用处于后台时才发）。点它直接进入复习：有到期卡片时打开闪卡，否则打开到期错题复习，再否则打开笔记的「近期复习」。
- 电脑上的系统通知没有点击回调，所以按「通知发出后 3 分钟内第一次回到应用」视为点了通知；之后再切回来不会跳转。手机上点通知即直达。

### 四象限视图

1. 点击智能视图中的「四象限」。
2. 任务按优先级与紧急程度分入四格：重要且紧急、重要不紧急、紧急不重要、不紧急不重要，帮你决定先做什么。

### 定时任务（自动化）

1. 点击左侧的「定时任务」，再点「新建任务」。
2. 最快的方式是「用一句话快速创建」：输入「每天早上8点提醒我背单词」，应用解析出排期后点「填充表单」。
3. 任务动作有两类：「通知 + 待办」（到点弹通知并生成待办），或填写「Agent 指令」让 AI 在后台自动执行（如「汇总我今天新增的错题」）。
4. 周期支持每天 / 工作日 / 每周 / 每月 / 固定间隔 / 仅一次；可设置错过执行时的补偿策略（补跑一次 / 逐次补跑 / 跳过）。高级排期项均使用直观的日常表述（如「重试等待秒数」「时区名称」），无需记忆技术参数名。
5. 内置模板可一键起步：每日错题汇总、每周学习报告、晨间复习提醒、考前冲刺计划、每月知识盘点、久坐休息提醒、周中弱项加练。
6. 「运行历史」记录每次执行的状态与摘要，Agent 任务可「查看会话」回看完整过程；「关闭窗口后继续运行」开关决定任务是否在后台执行。

## 番茄钟

### 开始一个番茄

1. 进入「待办」页面，右侧就是番茄钟面板；也可以在任务行点「开始专注」，把这个番茄和具体任务绑定（任务详情会累计「已完成 x/y 个番茄」）。
2. 点「开始专注」进入倒计时，也可直接按 **`Space`** 快捷启停；期间可「暂停 / 继续 / 停止」，休息阶段可随时用「+1 / +5 分钟」延长，专注阶段的延长按钮会在倒计时最后 2 分钟内出现。
3. 专注结束自动进入「短休息」，每完成若干个番茄进入「长休息」；休息时可「跳过休息」。面板上方实时展示**今日目标徽章**，直观呈现当天番茄目标完成进度与达标状态。
4. 完成时会弹出系统通知（「番茄完成」「休息结束」等）。

### 番茄钟设置

点击面板上的「番茄钟设置」，可调整：

- **时长**：专注时长、短休息、长休息、长休息间隔（默认 25/5/15 分钟节奏）
- **自动化**：自动开始休息、休息后自动开始专注
- **专注**：严格模式（专注期间不可暂停）、正计时（秒表向上计时）、结束前提醒
- **目标**：每日目标个数，达成时弹出「今日目标达成！」
- **声音**：环境音（海浪 / 细雨 / 白噪 / 雨声）、音量、专注时自动播放环境音

### 沉浸模式与置顶小窗

1. 点「进入沉浸式专注模式」全屏显示倒计时和当前任务，按 `Space` 暂停 / 恢复，按 `Esc` 退出。
2. 桌面端点「弹出置顶小窗」，番茄钟会变成一个始终置顶的迷你窗口，方便边学边看；点小窗上的按钮可「收回到主窗口」。
3. 番茄计时期间离开待办页面，应用角落会出现全局悬浮计时器（药丸），随时可回到番茄钟。为避免重复投影，「学习桌面」激活期间或置顶小窗打开时，药丸会自动让位（关闭小窗后自动恢复）。

### 学习桌面中的番茄钟

开启「学习桌面」后，番茄钟以独立窗口形态工作：

- **自动投射**：开始专注时番茄窗口自动出现（在后台开窗，不会打断你正在操作的窗口）；点「停止」后窗口不会立刻消失，而是以空闲态保留约 2–3 秒——想续上就直接再点「开始专注」，不操作则自动关闭。
- **菜单栏状态**：桌面顶部菜单栏右侧实时显示番茄状态——倒计时专注显示「专注剩余」、正计时显示「已专注」、休息阶段显示「休息剩余」、暂停时显示「已暂停」；点击可回到番茄窗口。
- **休息期复习**：番茄完成进入休息后，如果有到期的闪卡，窗口内会出现「去复习 N 张」入口，点击直达到期卡复习，把休息碎片用在记忆巩固上。

### 专注统计

点击面板上的「统计」打开「专注趋势」：热力图展示每天的番茄专注分布，并附带 **`15 / 30 / 60+ 分钟` 分档图例**；可切换 7 / 30 天等区间，显示番茄总数、日均、本周与上周对比，以及「连续 x 天达标」记录。

## 学习统计中心与学习周报

想看今天该做什么、这一周学得怎么样、以及全局的学习与用量统计，主要有两个入口：

**对话首页**：新会话的输入框下方会显示「今日待复习」（「到期卡片」「错题复习」「待复习笔记」及数量，点一下直接开始复习）；有作答记录后，下面一行还有最多 3 个「薄弱知识点」（带掌握度百分比）和「本周周报」入口，当天没有到期内容时也会显示。

- 点某个薄弱知识点，会新开一个对话、在输入框里填好请求：先讲清核心概念，再出 3 道练习题写进「薄弱点练习」题目集（知识点标签就是这个薄弱点），最后提示易错点。去题目集里作答，掌握度才会更新。
- 点「本周周报」先预览周报，可以「与 AI 复盘」或「存为笔记…」。
- 还没有任何卡片和错题的新用户，这里显示「第一次用？三步走通」：导入资料 → 在资料菜单里选「用这份资料制卡」→ 每天回这里复习，附「打开资源库」按钮；点 × 「不再显示」即可关掉。

**学习数据与统计总览（学习统计中心）**：

1. 按 `Ctrl / ⌘ + K` 打开命令面板，搜「今日」「统计」或「周报」，或在应用入口打开「学习数据与统计总览」。
2. **今日指挥中心**：汇总到期闪卡、错题复习、待复习笔记、今日待办和运行中的任务，每项都可以点「前往」；「薄弱知识点」可以一键到对话里讲解并练习。
3. **统一统计图表**：
   - **学习热力图**：支持切换**「活动 / 时长」双口径**，不仅统计前台操作、做题与复习，**音视频播放也会计入学习时长**；
   - **模型与模块用量分布**：直观查看不同 AI 模型与各学习模块的使用占比。
4. **本周周报**：查看本周的学习天数、做题数量与正确率、卡片复习次数、番茄专注时长、学习时长（都和上周对比），以及薄弱知识点和下一步建议；有学习时长的日子也算作学习天数。底部可以「与 AI 复盘」（新开对话，带着周报内容和 AI 一起回顾），或「存为笔记…」保存下来。
5. **数据治理直达入口**：需要做数据备份、空间清理或云同步维护时，页面底部保留了直达**「设置 → 数据与系统 → 数据治理」**的快捷入口（详见 [数据管理与云同步](./16-数据管理与云同步.md)）。

## 命令面板与内容直达搜索

### 三步直达任意命令、闪卡、笔记或历史对话

1. **唤起面板**：随时按 `Ctrl / ⌘ + K`（或点击窗口顶部标题区的「命令面板」按钮），空输入时自动展示「最近使用」，点命令旁的星标可「收藏」置顶。
2. **输入关键词搜索**：支持中文与拼音搜索；输入 `>` 可按分类（导航 / 对话 / 笔记 / 制卡 / 学习 / 设置 / 全局等）筛选命令。同时系统会在后台并行检索你的学习内容，结果按分组附上摘要清晰呈现：
   - **文件**：搜索全部笔记、教材、题目集、翻译、思维导图等资料，显示类型与路径摘要；选中后**直接打开那份笔记或文档**。
   - **闪卡**：直接按卡片正面、背面或标签检索卡片库，结果附带所属牌组与内容摘要；选中后**直接跳到闪卡「库」标签，自动筛选对应牌组与关键词并展开定位到那张卡片**（不再只停在空白今日页，详见 [闪卡复习](./13-闪卡复习.md)）。
   - **会话**：全文搜索历史 AI 对话的标题与消息内容，显示命中片段摘要；选中后**直接切进那场历史对话**。
3. **一键执行或转问 AI**：用 `↑ / ↓` 选择、`Enter` 直达、`Esc` 关闭。如果输入的问题**没有匹配到任何命令或学习内容**，面板会直接提供「**前往 AI 对话提问**」快捷入口，把你的输入送到新对话里问 AI。

### 常用全局快捷键速查

以下常用快捷键均可在「快捷键设置」中自定义：

| 快捷键 | 作用 |
|---|---|
| `Ctrl / ⌘ + K` | 打开命令面板（命令 + 文件 / 闪卡 / 会话直达） |
| `Ctrl / ⌘ + P` | 全局搜索 / 笔记快速打开 |
| `Ctrl / ⌘ + N` | 新建对话 / 新建笔记（随当前窗口上下文） |
| `Ctrl / ⌘ + 1` | 跳转到智能对话 |
| `Ctrl / ⌘ + E` | 跳转到资源库 |
| `Ctrl / ⌘ + ,` | 打开设置 |
| `Ctrl / ⌘ + S` | 保存当前内容 |
| `Ctrl / ⌘ + \` | 切换侧边栏显示 / 隐藏 |
| `Ctrl / ⌘ + Alt + ← / → / ↑ / ↓ / E / D` | 学习桌面窗口左右/上下分屏、窗口总览与显示桌面 |
| `Ctrl / ⌘ + Shift + Space` | 全局语音听写（默认按住说话） |

### 自定义快捷键

1. 按 `Ctrl / ⌘ + K` 打开命令面板，搜索并执行「快捷键设置」。
2. 找到目标命令，点「编辑」后按下你想要的组合键（冲突时会提示「与以下命令冲突：」）。
3. 可对单个命令「重置」「禁用」，或「全部重置」；配置支持导出 / 导入，方便在多台设备间迁移。

## 语音输入（听写）

### 在对话中语音输入

1. 在 AI 对话输入栏点击「语音输入」（麦克风）按钮，首次使用需允许麦克风权限。
2. 说话，完毕后点「停止录音」，应用会显示「转写中...」，随后把文字插入输入框——只插入文本，不会自动发送，你可以检查修改后再发。

### 全局听写快捷键

1. 在应用内任意支持的输入框（笔记、待办、搜索框等）聚焦后，按住 `Ctrl / ⌘ + Shift + Space`（默认快捷键）开始听写，松开即停止转写并插入文字。
2. 在「设置 → 语音听写」中可以：更换快捷键；把触发方式从「按住」改为「按一次开始，再按一次停止」；维护「自定义词典」（每行一个想优先识别的专业词）；查看「最近听写」历史找回文本；用「诊断」排查麦克风问题。
3. 语音识别需要先在「设置 → 模型分配」中选择「语音识别（ASR）模型」，并在「模型服务」中给它所属的提供方配好 API 密钥（支持 **DeepSeek 官方 ASR**、硅基流动、阿里云百炼、OpenAI 及 OpenAI 兼容中转站），详见 [模型与供应商配置](./14-模型与供应商配置.md)。

## 📱 移动端说明

- **待办**：抽屉 →「待办」，为两屏布局（左抽屉视图导航 + 主列表）。任务详情以全屏面板打开，X 或系统返回键关闭；快速添加框只在清单视图显示，智能视图（今日 / 四象限等）下暂不能快速添加；长按拖拽可手动排序。部分列表管理操作（新建清单、重命名、收藏）在触屏上入口较隐蔽，如遇不便可在桌面端操作。
- **番茄钟**：移动端完整可用，包括开始 / 暂停 / 严格模式、环境音、设置、统计和沉浸模式；「弹出置顶小窗」仅桌面端提供。
- **命令面板**：通过抽屉中的「搜索与命令」打开，同样支持搜索命令、文件、闪卡和会话直达；执行、关闭均可用系统返回键。移动端暂无待办页的导航命令。
- **语音输入**：对话输入栏的「语音输入」按钮在移动端可用；基于键盘快捷键的全局听写主要面向桌面端。

## 常见问题

**Q1：快速添加把「明天」识别错了怎么办？**
识别结果会先以小标签预览，创建后也可以进详情手动改日期；你手动设置的字段始终优先于自动解析。

**Q2：番茄钟开始后能改时长吗？**
可以。休息阶段可随时「+1 / +5 分钟」，专注阶段在最后 2 分钟内可延长；在「番茄钟设置」中修改专注 / 休息时长会**立即对当前阶段生效**——已消耗的时间保持不变，按新时长重算剩余（新时长不长于已消耗时间时，本阶段随即完成）。正计时会话没有目标时长，不受影响。

**Q3：严格模式下想暂停怎么办？**
严格模式的设计就是不可暂停（提示「严格模式下专注不可暂停」），只能「停止」结束本番茄。不确定时建议先不开严格模式。

**Q4：定时任务在电脑关机时会执行吗？**
不会。显式退出应用或关机会停止任务；重新打开应用后，会按你设置的「错过执行」策略补跑或跳过。「关闭窗口后继续运行」只保证窗口关闭（应用仍驻留）时继续执行。

**Q5：待办提醒没有弹出来？**
请确认系统允许 Deep Student 发送通知，且任务设置了截止时间和提醒选项；错过的提醒会在下次打开应用时汇总提示「你错过了 N 条提醒」。早间学习提醒「今日有 N 项待复习」默认只在应用处于后台时发送，应用在前台时请看对话首页的「今日待复习」。

**Q6：语音输入提示鉴权失败 / 请先配置？**
说明语音识别模型或密钥未配置好。按提示进入设置，先在「模型服务」中添加提供方 API 密钥，再到「模型分配」中完成「语音识别（ASR）模型」分配。
