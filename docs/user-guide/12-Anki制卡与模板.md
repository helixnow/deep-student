# Anki 制卡与模板

> 在对话里用一句话把 PDF、图片、笔记、音视频变成高质量记忆卡片，配合可视化模板编辑器与任务看板，直接在内置闪卡中复习，或一键导出 APKG / 通过 AnkiConnect 同步到本机 Anki。

## 三步上手

**想把一份课件或章节变成可复习的闪卡：**

1. **发起制卡**：打开 AI 对话上传资料（PDF / 图片 / 笔记），说一句「把第 3 章的核心概念和公式做成问答卡片」；或者在资源库右键资料选「用这份资料制卡」。
2. **边看边微调**：卡片流式生成在对话的「Anki 卡片」块中，点击即可翻面检查，随时编辑文字、删除多余卡，或留意顶部质检汇总修正疑点。
3. **保存或同步**：点「加入卡片库」直接进入应用内置复习（见 [闪卡复习](./13-闪卡复习.md)）；需要配合桌面 Anki 或 AnkiDroid 时，点「导出 APKG」或「同步到 Anki」一键带走（图片与音频一并保留）。

## 功能概览

Deep Student 的制卡体系由三部分组成：

- **对话制卡**：在 AI 对话中用自然语言发起制卡（如「把这份文档做成卡片」），支持纯文本、PDF、图片、截图、手写照片、Markdown 等素材，AI 自动拆解内容、批量生成卡片，并在对话中生成可人工微调的卡片预览块。
- **模板管理**：内置多种卡片模板（问答、填空等），并提供可视化模板编辑器——支持自定义版式与字段占位符、实时预览、字段管理、AI 提取规则，让卡片长成你想要的样子。
- **制卡任务看板**（「Anki制卡」应用）：所有制卡任务集中管理，进度追踪、暂停 / 恢复、失败分段重试、断点续传、批量导出。

除了在对话里说，还可以从资料、阅读器、音视频和笔记里直接发起制卡（见「其他制卡入口」）。

生成的卡片可以：**加入卡片库**（进入应用内置的闪卡复习，见 [闪卡复习](./13-闪卡复习.md)）、**导出 APKG 文件**（导入 Anki / AnkiDroid），或通过 **AnkiConnect 同步到本机 Anki**。你还可以把已有的 `.apkg` 牌组反向导入进来，桌面端与浏览器 WebUI 均完整还原内嵌图片与音频。

## 入口与界面布局

- **对话制卡**：任意 AI 对话中直接下达制卡指令即可，无需切换页面。卡片会以「Anki 卡片」块的形式出现在对话里。
- **制卡任务**：学习桌面里在「全部应用」打开「Anki制卡」（可以固定到程序坞）；经典布局点左侧导航的「闪卡」，切到顶部的「制卡」分区（「闪卡」页面把复习、制卡、模板三个分区合在一起）。有任务进行中时，顶部状态栏会显示「N 个制卡任务进行中」，程序坞图标也有数量角标，扫一眼就知道后台还有几个任务在跑。界面从上到下依次是：统计概览（卡片总数、制卡文档、任务状态、模板库）、搜索与筛选栏、任务列表（按「进行中 / 需要注意 / 已完成」分组）。任务数据长期保留，不需要时可手动删除。
- **模板管理**：经典布局左侧导航的「闪卡」→ 顶部「模板」分区（制卡任务页的「打开模板库」也会直达），或学习桌面「全部应用」里的「模板管理」。顶部标签为导航，主区是模板库：网格 / 列表双视图（切换后会记住你的选择，下次打开保持不变）、搜索框、按类型（问答 / 填空 / 其他）和来源（内置 / 自定义）筛选、排序。

## 核心操作

### 一、在对话中生成卡片

1. 打开一个 AI 对话，上传素材（PDF / 图片 / 截图，也可以直接粘贴文本），然后说明需求，例如：「把第 3 章的概念做成问答卡片，重点是定义和公式」。可以顺带附上额外要求（如「答案用中文」「每段最多 5 张卡」「不要翻译专业术语」），这些要求会直接影响生成。
2. AI 会自动启用制卡流程。对话中出现进度面板，显示当前阶段（路由 → 导入 → 生成 → 完成）与所选处理路线（纯文本 / 图文轻量 / 图文增强），以及卡片数、分段数。处理路线由 AI 结合素材类型、文本质量与制卡目标智能规划：例如扫描质量差的 PDF 会自动走图文增强路线；规划置信度不足时回退到稳妥的规则判断，制卡不会因此中断。
3. 卡片逐张流式出现在「Anki 卡片」块中，可以边生成边浏览：
   - 「列表视图 / 网格视图」切换布局；
   - 点击卡片「翻到背面 / 翻回正面」，或「展开详情」查看全部字段；
   - 每张卡可「编辑」（Enter 保存、Shift+Enter 换行、Esc 取消）或「删除卡片」（删除后可短暂「撤销」）；
   - 也可以批量选择多张卡片，一次性执行删除等操作。
4. 生成过程中可「暂停 / 继续 / 取消」；个别分段失败时点「重试失败分段」。
5. 生成完成后，卡片块底部会显示「已生成 N 张卡片」与用时，并提供后续操作按钮（见下一节）。制卡完成时还会收到系统通知。

> 提示：可以在对话里指定模板：「用填空模板」或「先列出可用模板给我看」；生成后也可以让 AI 把这批卡片换一个模板重新排版。

### 二、处理生成好的卡片（保存 / 导出 / AnkiConnect 同步）

在对话的卡片块上：

1. **加入卡片库**：点「加入卡片库」，卡片保存到应用内的卡片库，之后可在闪卡应用中入队复习（见 [闪卡复习](./13-闪卡复习.md)）。保存时会自动跳过错误卡，并提示重复卡片数量。
2. **复习这批**：卡片保存进卡片库后点「复习这批」，直接对这批卡片发起一轮闪卡复习（还没保存时按钮不可用）。
3. **导出 APKG**：点「导出 APKG」，选择保存位置生成 `.apkg` 文件，然后在 Anki（或手机上的 AnkiDroid）中打开导入。
4. **同步到 Anki**：点「同步到 Anki」，通过 **AnkiConnect**（v6 协议）把卡片连同图片、音频与图像遮挡卡直接写入本机正在运行的 Anki。进度面板中有 AnkiConnect 状态徽章（已连接 / 未连接），可点击刷新。

**AnkiConnect 准备工作（仅「同步到 Anki」需要）：**

1. 在电脑上安装并启动 Anki，为其安装 AnkiConnect 插件（Anki → 工具 → 插件 → 获取插件，代码 `2055492159`）。
2. 在 Deep Student 的「设置 → 常规 → AnkiConnect」里打开「启用 AnkiConnect」，点「测试连接」确认能连上并读取到你的牌组与笔记类型。
3. 同一处还可以设置「导出后自动导入」（导出 APKG 后自动送进 Anki）、「导入后删除 APKG」、「失败时打开目录」和默认的「导出牌组名称」。
4. 保持 Anki 处于运行状态即可同步；未连接时依然可以导出 APKG 文件手动导入。

**AnkiConnect 同步时的图片与音频处理**：

- 默认情况下，同步到 Anki 时会自动把卡片里的图片与音频上传到 Anki 媒体目录，并**按文件名自动去重**（多张卡片共用同一张图或同一段音频时只会上传一次），单个媒体文件上限 **32 MiB**。
- 如果个别媒体文件读取或上传失败，系统会给出清晰警告并跳过该文件，**不会中断整批卡片的同步**。

<details>
<summary>技术说明：AnkiConnect v6 媒体同步模式配置（可选阅读）</summary>

底层同步支持三种媒体处理策略（通过设置键 `anki_connect_media_mode` 控制，默认 `upload_media`）：

- **`upload_media`（默认）**：通过 AnkiConnect v6 的 `storeMediaFile` 将本地图片与音频上传至 Anki 媒体目录，按文件名幂等去重，单文件上限 **32 MiB**。
- **`inline_base64`**：将图片转为内联图片直接写入卡片字段（不额外向 Anki 媒体目录写文件）；注意该模式不支持内联音频，遇到音频会自动跳过并记录警告。
- **`skip`**：跳过所有媒体附件，仅同步卡片文字字段，适合纯文本快传。

</details>

### 三、导入已有的 `.apkg` 牌组（含 WebUI 媒体完整还原）

最简单的方式是在「闪卡」的卡片库点「导入 .apkg」，卡片直接进入复习，在 Anki 里复习过的卡会沿用原来的进度（见 [闪卡复习](./13-闪卡复习.md)）。想先在对话里检查、编辑再入库，可以走对话导入：

1. 在对话中上传 `.apkg` 文件，并告诉 AI「把这个牌组导入进来」。
2. 系统会解析牌组中的卡片和媒体文件（图片、音频引用），导入到当前会话的卡片文档中，并返回导入统计。若牌组此前由 Deep Student 导出，本地缺失的模板会自动补建；外部 Anki 牌组的模板不会重建，卡片以字段内容导入。
3. **桌面端与 WebUI 媒体一致渲染**：
   - 导入的 `.apkg` 牌组里带有的**内嵌图片与音频**，无论在桌面应用还是浏览器 WebUI 中打开都能正常显示与播放（即使数据目录迁移过，系统也会自动按文件名兜底找回媒体）。
   - 在卡片库列表浏览时，不会把丑陋的原始文件名或 `[sound:...]` 标签直接暴露出来，而是展示简洁的媒体徽标；展开详情或进入复习翻面时，图片清晰呈现、音频可直接播放（支持自动播放与按 `R` 重播）。
4. 若牌组带媒体包，卡片块上会显示**媒体导入报告**：成功导入多少个文件、跳过多少个及原因（如文件名不安全、单文件过大、清单无法解析等），跳过条目附样例文件名，方便你判断是否需要在 Anki 侧手动补媒体。
5. 导入后可以像普通生成结果一样编辑、保存入库、入队复习。

### 其他制卡入口

不想打字描述需求时，可以从这些地方一步发起：

| 从哪里 | 怎么做 | 结果 |
|---|---|---|
| 资源库里的资料 | 右键 →「用这份资料制卡」 | 新开一个对话，引用这份资料并预填制卡指令，按资料类型取材（概念与易错点、公式、单词与例句等） |
| PDF / Word / EPUB 里选中的文字 | 划词工具条 →「制卡」 | 后台直接生成，卡片放进「划词制卡::资料名」牌组 |
| 音视频字幕 / 讲义 | 在音视频页内点「制作闪卡」，或选中指定字幕行点「制卡」 | 按整段讲义或所选字幕生成卡片，保留时间戳出处，复习翻面可回看原时刻 |
| 翻译工作台 | 译文区右上角点「存为生词闪卡」 | 直接把原文与译文存入「翻译生词本」并加入每日复习队列 |
| 一篇笔记 | 「更多笔记操作」→「生成卡片」 | 按整篇笔记生成一组卡片 |
| 词表（Excel） | 把词表引用进对话，说「按词表每个词做一张卡」 | 逐词生成单词卡 |

AI 制卡时会按「学科::主题」给卡片分牌组（例如「考研英语::Unit10」），任务名也用牌组名，不同科目的卡不会都堆进 Default。

### 四、管理制卡任务（任务看板）

1. 打开「制卡任务」页面，顶部可看到卡片总数、制卡文档数、任务状态与模板库入口，还有「今日制卡 / 本周制卡」等近期活动统计。
2. 用搜索框按文档名称查找，用筛选（全部 / 进行中 / 需要注意 / 已完成）和排序（按时间 / 按卡片数 / 按名称）定位任务。
3. 展开任务行可以：
   - 查看进度、分段数、卡片预览（正面 / 背面、所用模板）；
   - 「暂停 / 恢复」任务——大文档制卡支持断点续传，中断后随时恢复，已生成的卡片不会丢失；
   - 「重试失败段」重新处理失败的分段，展开可查看每个失败分段的错误原因。只要任务存在失败分段，任务行右侧就会常显重试按钮（即使任务同时处于暂停状态），无需展开也能一键重试；
   - 「导出 APKG」把该任务的卡片直接导出；
   - 「跳转到聊天」回到发起制卡的对话继续微调；
   - 「删除」任务（两次点击确认）。
4. 顶部工具还有：
   - 「防休眠」开关——开启后制卡期间系统不会进入睡眠，任务结束自动解除；
   - 「恢复卡住任务」——把中断超过 10 分钟的「处理中」任务标记为已暂停，之后点「恢复」继续；
   - 「刷新」重新拉取任务状态。
5. 还没有任何任务时，空态会给出两条路：「去聊天发起制卡」直接开始第一个任务，或「管理模板」先到模板库把卡片样式准备好再制卡。任务数据长期保留，不需要的任务可手动删除。

### 五、浏览与管理模板

1. 打开「模板管理」，在模板库中浏览：每张模板卡片展示正 / 背面预览，可切换预览面；「内置 / 自定义」「默认」徽章标明来源与状态。
2. 常用操作：
   - **设为默认**：之后制卡默认使用该模板；
   - **编辑 / 复制 / 删除**：删除为卡片内二次确认；删除的内置模板不会随版本升级自动恢复，改动过的内置模板升级时也会保留你的版本；
   - **导入**：页内「导入外部模板」面板选择 JSON 文件导入（支持批量、可选覆盖同名模板）；也可以一键「导入内置模板」补齐官方设计模板（学术选择题、学术填空题、手稿风格等 **16 套**）。导入失败时会给出明确原因——文件无法读取、不是有效 JSON、不符合模板导出格式、或没有文件权限——按提示处理后重试即可；
   - **导出**：勾选模板后批量导出为 JSON 文件，分享给其他用户导入。
3. 键盘操作（学习桌面窗口内）：按 `Ctrl / ⌘ + F` 直接聚焦模板搜索框；在搜索框中按 `↓` 或 `Enter` 跳入结果列表，之后用方向键在网格 / 列表间移动（网格视图支持上下左右按行列走位），`Enter` 打开选中模板编辑，`Delete` 删除自定义模板（卡片内二次确认），`Home` / `End` 跳到首尾。

### 六、创建与编辑模板（可视化模板编辑器）

1. 在模板管理中点「新建模板」（或对现有模板点「编辑」）。
2. 编辑器按标签页组织：
   - **基本信息**：模板名称、描述、作者、版本号、笔记类型、激活状态；页内还有「字段管理」分区——添加 / 删除 / 排序字段，设置必填 / 选填，重命名字段会自动同步模板中的引用；
   - **模板代码**：分别编写「正面模板」「背面模板」（用 `{{字段名}}` 占位符插入对应字段内容）和「CSS样式」，桌面端为代码分栏 + 实时预览布局。编辑器提供：
     - 「插入字段」按钮把字段占位符插到光标处；
     - 「快捷插入」：挖空（Anki 填空语法）、条件段、反向条件、纯文本过滤器、正面内容占位符；
     - 语法检查：未定义字段、未配对花括号、未闭合条件段等会实时提示；
   - **预览数据**：编辑示例数据，实时驱动预览效果；
   - **提取规则**：定义 AI 生成卡片时每个字段的内容要求（字段类型、是否必填、给 AI 的提示），并可查看自动拼装的「完整提示词预览」；
   - **高级设置**：填写「核心要求与说明」——你只需描述卡片的核心要求，系统会自动生成字段约束与示例等完整提示词。
3. 右侧「实时预览」随编辑即时渲染正面 / 背面，可切换深色 / 浅色预览；校验不通过（如引用了未定义字段）时无法保存，会列出需要修正的错误。
4. 点「保存模板」完成。之后在对话制卡时告诉 AI 使用这个模板即可。

<details>
<summary>技术说明：模板代码语法兼容范围（可选阅读）</summary>

模板代码兼容标准 HTML / CSS 与 Anki 双花括号占位语法（Mustache 风格，包括 `{{字段}}`、`{{#字段}}...{{/字段}}` 条件段、`{{^字段}}...{{/字段}}` 反向条件、`{{cloze:字段}}` 挖空与 `{{FrontSide}}`）。模板内嵌的 JavaScript 出于安全沙箱策略不会在内置预览中执行，含脚本的高级模板以导入桌面 Anki 后的实际渲染为准。

</details>

### 七、3D 翻转预览

1. 在对话卡片块或制卡结果中打开单卡预览，可以像真实卡片一样翻面查看正 / 背面渲染效果，并用「上一张 / 下一张」逐张检查。
2. 预览与闪卡复习均使用模板的真实版式渲染，样式基本等同导出后在 Anki 中的效果。卡面内置高质量数学与化学公式排版——兼容 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 及化学方程式，手机端无需依赖系统预装数学字体也能清晰显示，长卡片滚动流畅。卡面或预览中的插图、图表与截图支持点击打开 **200-DPI 高清图片灯箱**（可放大、缩小与 1:1 还原），便于细看复杂公式与图表细节。

## 进阶用法

- **统一公式排版、错误卡修复与智能质检**：AI 制卡会统一把数学公式整理为 `$...$`（行内）与 `$$...$$`（块级），减少格式杂乱。批量制卡偶尔会产生「错误卡片」（生成失败或被截断），系统会标记并从导出中自动排除，你可以在任务看板重试对应分段，或在对话中让 AI 修复这几张卡。此外，每张卡生成时都会经过一轮**内置质检**（检查正反面雷同、挖空语法错误、答案泄漏、占位符残留、批内重复、字段越界以及**漏写公式定界符检查**——若发现公式忘记加 `$` 符号，会标记为警告提示而**不会丢弃卡片**）：有疑点的卡片会显示「质检」徽标（按提示 / 警告 / 错误分级），卡片块顶部还有汇总条提示共有几张卡需要复查；点击徽标可展开逐条原因，人工确认或修改后再导出。
- **让 AI 管理卡片库**：对话中的 AI 覆盖生成、编辑、批量变换、换模板、复习管理、导入导出全流程。你可以让它检索卡片库、修改某张卡、暂停某张卡的复习、把某批卡换模板重排、查询近期复习统计等。
- **批量整理与安全审批**：需要对多张卡做统一修改（替换某个术语、清理格式、批量加 / 删标签）时，直接告诉 AI（如「把所有卡里的 mitochondria 统一改成『线粒体（mitochondria）』，并加上 biology 标签」）。常规改动由内置安全工具完成；更复杂的条件批量改写会先在本机隔离环境准备处理方案，执行前弹窗**完整展示内容**征求你确认，并先做「试运行」给出逐卡前后对比，经你同意后再实际写入，不会盲写。手机端同样支持常用的安全批量操作。
- **换模板与自动补字段**：让 AI 把一批卡换成新模板时，若新模板有旧卡没有的字段，可以要求 AI「顺便把缺的字段补上」——换模板完成后 AI 会按卡片原文批量生成缺失字段的内容并写回；个别卡补齐失败不影响已完成的模板更换，可再手动编辑补齐。
- **从错题制卡**：结合题库（见 [题目集与练习](./11-题库与练习.md)），把错题内容发给 AI 让它做成卡片，实现「做错 → 制卡 → 复习」的闭环。
- **复习数据反哺制卡**：如果你已经在用内置闪卡复习（见 [闪卡复习](./13-闪卡复习.md)），制卡时系统会默认参考你的**复习画像**——哪些卡片你反复遗忘、哪些主题容易混淆——避免生成与「老大难」卡片重复的新卡，并倾向把复杂知识点拆成多张小卡。希望某次不受历史记录影响时，在对话里说「这次忽略我的复习记录」即可。
- **精细控制生成过程**：绝大多数情况下交给 AI 自动决策即可，需要时可以在对话里精细指定：处理路线（「强制走图文增强」）、看图重点（「重点提取第 3 页流程图的节点和箭头」）、材料形态（「这是术语表，逐条做卡」）或限制分析图片数量。
- **命令面板**：按 `Ctrl / ⌘ + K`，可执行「导入 Anki 牌组（.apkg）」直接选择本地牌组导入卡片库，或用「跳转到制卡任务」「跳转到卡片模板」快速直达。

## 移动端说明

- **对话制卡完全可用**：移动端聊天中发起制卡流程相同；「Anki 卡片」块同样内嵌在消息流中，可编辑、导出卡片。
- **制卡任务入口**：在移动端抽屉的 4×2 应用启动器里点「闪卡」，再切到顶部的「制卡」标签即可查看制卡任务与模板管理。
- **模板编辑器形态**：移动端模板编辑器为单屏上下滚动布局；「模板代码」会切到独立屏幕编辑正面 / 背面 / CSS，编辑后返回。
- **同步到 Anki 的限制**：AnkiConnect 需要连接本机运行的 Anki 桌面程序，移动端通常无法直接同步；建议在手机上「导出 APKG」，再用 AnkiDroid 等应用打开导入。
- **学习桌面不可用**：移动端没有学习桌面模式，程序坞入口不存在，请使用抽屉导航。

## 常见问题

**Q1：「同步到 Anki」一直显示未连接？**
A：依次检查：电脑上的 Anki 是否正在运行；AnkiConnect 插件是否已安装（代码 `2055492159`）并重启过 Anki；「设置 → 常规 → AnkiConnect」里是否打开了「启用 AnkiConnect」，可以点「测试连接」确认。点进度面板中的 AnkiConnect 徽章可重新检测。即使无法连接，也可以导出 APKG 手动导入。

**Q2：制卡到一半退出应用，进度会丢吗？**
A：不会。制卡任务在后台按分段持久化，支持断点续传。重新打开应用后，到「Anki制卡」找到该任务点「恢复」即可继续；已生成的卡片都在。如果任务显示「处理中」但长时间不动，点「恢复卡住任务」。

**Q3：生成的卡片里有几张标着「错误卡片」，会影响导出吗？**
A：不会混进你的牌组。错误卡（生成失败或被截断）会被自动排除在导出和保存之外。你可以在任务看板「重试失败段」，或删除这几张卡后再导出。

**Q4：卡片样式不好看，怎么换个模板？**
A：两种方式：制卡前在对话里指定模板（「用学术填空题模板」）；或到「模板管理」编辑 / 新建模板后设为默认。对已生成的一批卡片，也可以在对话里让 AI 换模板重新排版；新模板多出来的字段可以让 AI 自动补齐（见「进阶用法 · 换模板与自动补字段」）。

**Q5：可以把我在 Anki 里的旧牌组搬进来复习吗？图片和音频还在吗？**
A：可以，且图片和音频会一并保留。在「闪卡」卡片库点「导入 .apkg」，卡片直接进入复习，在 Anki 里复习过的卡沿用原进度，桌面端与浏览器 WebUI 均完整渲染内嵌图片与音频；也可以把 `.apkg` 发到对话里让 AI 导入（外部牌组的模板不会重建为本地模板）。见 [闪卡复习](./13-闪卡复习.md)。

**Q6：加入卡片库和导出 APKG 有什么区别？**
A：「加入卡片库」是把卡片留在 Deep Student 内部，用内置闪卡系统复习，不需要安装 Anki；「导出 APKG / 同步到 Anki」是把卡片交给外部的 Anki 生态使用。两者不冲突，可以同时进行。
