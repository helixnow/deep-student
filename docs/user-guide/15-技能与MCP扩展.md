# 技能与 MCP 扩展

> 技能（Skills）让 AI 按需加载专门能力，MCP 让 AI 连上外部工具——两者都可以自己装、自己写，把 Deep Student 扩展成你想要的样子。

## 功能概览

- **技能**：一个技能就是一份"AI 工作说明书"（SKILL.md 文件），激活后 AI 才加载对应的指令和工具，不用时不占上下文。应用内置了 40 多个技能/工具组（知识检索、ChatAnki 制卡、调研模式、导师模式、文献综述助手、智能题库、思维导图、记忆管理、DOCX/PPT/Excel 工具、会话管理等），也支持安装社区技能和自己编写。
- **技能来源分三级**：内置 → 全局（你自己安装的，对所有会话可用）→ 项目（跟随特定项目目录）。外部安装的技能默认"未信任"，信任后才对 AI 生效。
- **社区技能市场与 GitHub 技能源**：可以直接浏览、校验并安装社区技能，安装前会自动做风险扫描和分级提示。
- **MCP（Model Context Protocol）**：开放的工具协议。添加 MCP 服务器后，AI 就能调用它提供的外部工具（如 Arxiv 搜索、Context7 文档查询、网页抓取等）。支持预置服务一键添加和 OAuth 授权。

## 入口与界面布局

- **技能管理**：点击侧边栏的「技能管理」；在「学习桌面」模式下也可从 Dock 打开「技能管理」应用窗口，功能一致。页面主体是技能列表，顶部有筛选标签（按来源：全部 / 内置 / 全局 / 项目；按类型：整合型 / 独立型）、搜索框，以及「新建技能」「导入」「导入包」「技能源」「检查更新」等按钮。点击某个技能可查看详情或进入编辑器。技能卡片支持纯键盘操作：`Tab` 聚焦卡片后，`Enter` / 空格打开该技能，`E` 快速启用 / 停用，`Delete` 删除非内置技能（列表顶部会出现确认横幅，确认后才真正删除）。
- **对话中的技能面板**：在聊天输入栏点击技能按钮，弹出「技能」面板，可搜索、激活/取消激活技能，底部「获取更多技能」可跳转技能管理。
- **MCP 管理**：打开「设置 → MCP工具」，可看到连接概况、服务器列表、工具缓存等区块。
- **对话中的 MCP 面板**：在聊天输入栏点击 MCP 按钮，打开「MCP工具」面板，选择本会话要启用的 MCP 服务器。

## 核心操作

### 在对话中激活技能

1. 在聊天输入栏点击技能按钮，打开「技能」面板。
2. 搜索或浏览技能，点击「激活」。已激活的技能会显示"已激活"，对话时自动应用。
3. 不需要时点击「取消激活」。有些技能会被 AI 的工具调用临时加载（显示"工具已加载"），点击"钉住到会话"可让它整段会话持续生效。

小技巧：常用的技能可以在技能管理里点「设为默认」，默认技能会在新建会话时自动激活。

### 从社区技能市场安装技能

1. 打开「技能管理」，点击「技能源」，切换到「社区技能市场」标签。
2. 在搜索框输入关键词（留空显示热门技能），默认开启「仅显示非可疑技能」过滤。
3. 每个技能会显示市场校验状态（已通过 / 未通过 / 审核中）与安全状态（干净 / 可疑 / 恶意）。注意：市场审核通过不代表本地已信任。
4. 点击「安装」。应用会先校验并下载扫描，然后弹出确认框，展示**风险分级**（低风险 / 中风险 / 高风险）和具体风险信号（是否包含脚本、网络访问、外部链接、凭据关键字、二进制文件等）。
5. 确认安装后，技能默认处于**未信任**状态，需要在技能管理中信任后才生效。

### 从 GitHub 仓库安装技能

1. 「技能源」对话框切换到「GitHub」标签。
2. 粘贴仓库链接（如 `https://github.com/owner/repo`），点击「浏览」。
3. 应用会列出仓库中找到的 SKILL.md 技能（采用常见桌面代理技能格式），点击「安装」，流程与社区技能市场相同（装前扫描 + 风险确认）。

也可以直接「导入」单个 .md 文件，或「导入包」安装 .zip 技能包。

### 信任与停用技能

1. 外部技能安装后显示「未信任」：此时技能包的文件完全不会展示给 AI。
2. 在技能详情中点击「信任此技能」：信任后 AI 可以只读查看技能包文件，其中的脚本可在本地命令中使用（敏感操作仍需运行时审批）。
3. 随时可「撤销信任」；不想用但不想删的技能可以「停用」，停用后不参与对话，可随时重新「启用」。

### 编写自己的技能

1. 在「技能管理」点击「新建技能」。
2. 在「基本信息」标签填写：技能 ID（小写字母、数字、连字符）、名称、描述（建议 50 字以上，帮助 AI 判断何时使用）、版本、优先级、技能类型（独立 = 自带完整工具集合；组合 = 会建议加载其他相关技能）。
3. 在「技能内容」标签用 Markdown 编写指令——这就是 SKILL.md 的正文，告诉 AI 这个技能做什么、怎么做。
4. 需要时在「绑定工具」标签添加内嵌工具定义（技能激活时注入给 AI）。
5. 保存后即可在对话中激活。你也可以把自己的技能「导出」为 .md/.zip，或用「导出源」打包成技能源仓库分享给他人。

内置技能不可删除，但可以修改（会标记"已修改"），随时「恢复默认」。点「恢复默认」会先弹出确认提示——确认后该技能的全部自定义修改（内容、工具、优先级等）都会被丢弃并恢复为内置版本，此操作不可撤销，请确认后再执行。

### 更新已安装的技能

1. 在「技能管理」点击「检查更新」。仅通过链接、zip 或 社区技能市场安装的技能支持更新检查。
2. 发现更新时会提示"N 个技能有上游更新"，点击「全部更新」按安装来源重新下载并覆盖安装。
3. 注意：更新后技能内容已变化，会**回到未信任状态**，需重新信任后才生效。

### 添加 MCP 服务器

1. 打开「设置 → MCP工具」，点击「新增服务器」。
2. 选择传输类型：
   - **Stdio（本地进程）**：本机启动一个命令（如 `npx @modelcontextprotocol/server-filesystem`）。⚠️ 仅桌面版（Windows/macOS/Linux）可用，移动端无法启动本地进程。
   - **SSE / Streamable HTTP / WebSocket**：连接远程 MCP 服务，填写对应端点 URL，可选填 API Key。
3. 可用「图形表单」逐项填写，也可切到「JSON 模式」直接粘贴标准 MCP 配置。
4. 保存前建议点「测试连接」；保存后点「重新连接」让工具列表生效。
5. 在聊天输入栏的「MCP工具」面板中勾选该服务器，AI 即可在本会话调用它的工具。

### 一键添加预置 MCP 服务

「设置 → MCP工具」的「预置 MCP 服务器」区域收录了常用远程服务，一键添加、跨平台可用：

- **Context7**（文档，免费无需 Key）、**Exa Search**（神经搜索）、**Wikipedia**（维基百科）、**Firecrawl**（网页抓取）、**Cloudflare Docs**、**Tavily**（实时搜索）、**Hugging Face**、**GitHub**。
- 点击「添加预置」前会弹出权限说明，标注**风险等级**、**数据范围**和**是否出网**；需要密钥的服务会提示「获取 API Key / Token」，部分服务可勾选「以 OAuth 方式安装」。

### MCP 的 OAuth 授权

1. 对支持 OAuth 的远程 MCP 服务器，在编辑页的「OAuth 授权」区域点「使用 OAuth 登录」，浏览器中完成授权。
2. 授权成功显示"已授权（令牌已安全存储）"，可随时「重新授权」或「注销」。
3. 注意：若同时填写了 API Key，**API Key 优先于 OAuth** 生效；OAuth 浏览器登录仅在桌面端可用。

### 通过对话让 AI 管理技能与 MCP

除了在界面里手动操作，你也可以直接在聊天里让 AI 代劳——所有敏感操作都会先弹出审批卡，由你确认后才执行：

- **技能**：可以让 AI「停用/启用某个技能」（需确认）、「删除某个技能包」（每次都必须审批，不可恢复）、「申请信任某个技能」——AI 会先做一次只读安全扫描，把技能包指纹和风险信号讲给你听，你审批后信任才生效，且信任绑定当时的包内容，包一变信任自动失效。
- **MCP 服务器**：可以让 AI「修改某个 MCP 服务器的配置」「启用/停用」「删除」。修改和删除每次都必须审批且不可"记住"；AI 永远拿不到你的 API Key——它只能声明需要哪些环境变量名，值仍由你在「设置 → MCP工具」里填写。修改后会自动连测，失败自动回滚旧配置。
- **子代理角色（persona）**：可以让 AI 起草可复用的子代理角色（例如"论文摘要员"），AI 先给出提案和变更摘要，你审批后才写入 `workspaces/agents/` 目录，写入后 `subagent_call` 立即可用；删除同样需要审批。
- 这些对话式管理和界面操作写的是同一份数据：例如 AI 停用某个 MCP 服务器后，「设置 → MCP工具」里的开关也会同步变化。

**Linux 桌面用户注意**：本地 shell 工具（终端命令）现已支持 Linux，使用 bubblewrap 沙箱隔离运行。需要先用发行版包管理器安装 `bubblewrap` 包（如 `sudo apt install bubblewrap` / `sudo dnf install bubblewrap`）；未安装时 AI 的命令预检会明确报告沙箱不可用并给出安装指引，不会在无沙箱状态下执行命令。

## 进阶用法

- **技能组合**：在技能面板把当前激活的一组技能「存为组合」，之后一键激活整套组合。
- **MCP 运维**：服务器多了以后，可用「刷新清单」重新拉取工具列表、「体检」批量检测连通性、「清空缓存」重置前端缓存。
- **安全策略**：「设置 → MCP工具」的「安全策略」可配置工具白名单/黑名单、请求超时和速率限制，建议禁用文件删除、命令执行等危险工具。
- **工具权限**：「设置」中的「工具权限管理」可为每个工具设置敏感等级、管理本地目录授权与终端命令规则；技能和 MCP 带来的敏感操作都会走这套审批。

## 📱 移动端说明

- 「技能管理」在移动端通过抽屉菜单进入，功能与桌面端一致；点「编辑」会从右侧滑入全屏编辑器，可用顶栏返回或手势滑回。
- **Stdio 类型的 MCP 服务器在移动端不可用**（无法启动本地进程），请改用 SSE / Streamable HTTP / WebSocket 远程服务；预置 MCP 服务器均为网络类型，移动端可正常使用。
- **MCP 的 OAuth 浏览器登录仅在桌面端可用**。
- 对话中的技能面板、MCP 面板在移动端均可正常使用（从输入栏工具按钮打开）。

## 常见问题

**Q：技能和 MCP 有什么区别？**
A：技能是"给 AI 的指令与内置工具包"，主要改变 AI 的工作方式；MCP 是"外部工具服务器"，给 AI 增加新的可调用工具。两者可以配合：技能里可以指导 AI 怎么用某些 MCP 工具。

**Q：安装的技能为什么不生效？**
A：外部技能默认未信任。到「技能管理」找到该技能，点「信任此技能」；同时确认它没有被「停用」，并在对话中激活（或设为默认）。

**Q：装前风险扫描提示"高风险"还能装吗？**
A：可以，但请确认来源可信。高风险通常意味着技能包含可执行脚本、命令执行或网络访问声明。即使安装并信任，敏感操作在运行时仍需你逐次审批。

**Q：MCP 服务器显示"未连接"怎么办？**
A：在服务器行的菜单里点「重新连接」；仍失败时用「测试连接」查看具体错误——远程服务多为地址/密钥问题，Stdio 服务需确认本机已安装对应命令（如 Node.js 的 npx）。

**Q：为什么聊天里看不到 MCP 工具？**
A：MCP 服务器是会话级启用的：在聊天输入栏打开「MCP工具」面板勾选服务器后，该会话的 AI 才能使用它的工具。另外确认所用聊天模型已标记"支持工具调用"能力。

**Q：技能会消耗很多 Token 吗？**
A：技能按需加载：只有激活的技能才把指令注入对话。建议只激活当前任务需要的技能，用完取消激活，或用"默认技能"精简常驻集合。
