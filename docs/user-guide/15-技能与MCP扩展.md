# 技能与 MCP 扩展

> 技能（Skills）让学习 Agent 按需加载工作流与工具组，MCP 让它连接外部工具服务器；若需要新增界面应用或专属功能，还可前往插件工坊用自然语言直接构建插件。

## 功能概览

Deep Student 提供三种面向不同场景的扩展机制，按需选择即可：

| 扩展方式 | 解决什么问题 | 典型形态 | 适用平台 |
|---|---|---|---|
| **技能（Skills）** | 改变学习 Agent 的工作方式、沉淀方法论与按需披露内置工具 | 一份 Markdown 工作说明书（`SKILL.md`）与工具声明，不激活时不占上下文 | 桌面端 / WebUI / 移动端（`browser-tools` 仅 Windows / macOS） |
| **MCP 服务器** | 给学习 Agent 接入外部系统或第三方工具 | 标准 Model Context Protocol 服务（本地进程或远程接口） | 远程类型全平台可用；Stdio 本地进程与 OAuth 登录仅桌面端 |
| **插件（插件工坊 / `.dstuplugin`）** | 给应用新增学习桌面窗口、选区按钮、交互卡片、渠道连接或 Agent 新工具 | 通过自然语言在插件工坊生成或导入 `.dstuplugin` 包 | 仅桌面端与自托管 WebUI（详见 [AI 插件工坊与插件管理](./20-AI插件工坊与插件管理.md)） |

关于技能与 MCP 的核心要点：

- **内置技能（58 个）**：应用静态内置 **58 个**技能，包含 **8 个工作流技能**（如深度调研、导师模式、ChatAnki 制卡、文献综述等）与 **50 个渐进披露工具组**（按需展开知识检索、思维导图、题目集、音视频、闪卡、记忆、DOCX/PPT/Excel、会话管理等工具）。Linux、移动端与自托管 WebUI 为 **57 个**（49 个工具组，不含依赖 Windows/macOS 原生窗口的 `browser-tools`）；桌面端加载插件工坊后还会动态追加随包技能 `dstu-plugin-development`，用于指导学习 Agent 按规范构建插件。
- **技能来源分三级**：**内置** → **全局**（你自己安装，对所有会话可用）→ **项目**（跟随工作区项目目录）。项目级技能兼容 `.skills`、`.agents/skills`、`.claude/skills`、`.github/skills` 四个标准目录，**仅在你显式配置了工作区根目录后才会扫描**。
- **强信任边界与准入校验**：外部安装的技能默认「未信任」，后端会持久化记录技能包的目录身份与完整包 SHA-256 哈希，并在每次加载时重新校验（不再仅依赖前端缓存）；包内容只要发生任何改动，信任即自动失效。
- **社区技能市场与 GitHub 技能源**：可直接浏览、校验并安装社区技能，安装前会自动执行风险扫描与分级提示。
- **MCP（Model Context Protocol）**：开放的工具协议。添加 MCP 服务器后，学习 Agent 即可调用外部工具（如 Arxiv 搜索、Context7 文档查询、网页抓取等）。内置 **8 个预置远程服务**，支持一键添加与 OAuth 授权。

## 入口与界面布局

- **技能管理**：学习桌面里在「全部应用」打开「技能管理」（可固定到 Dock）；经典布局点击左侧导航的「技能管理」。页面顶部提供三段式场景分类——**「学习精选」（默认） / 「全部技能」 / 「系统与扩展」**，同时支持按来源（全部 / 内置 / 全局 / 项目）与类型筛选、关键词搜索，以及「新建技能」「导入」「导入包」「技能源」「检查更新」等操作。
  - **跨分类搜索提示**：在当前分类（例如默认的「学习精选」）中搜索无结果、但其他分类存在匹配技能时，列表顶部会出现一键切换提示，点击即可跳转查看命中结果。
  - **纯键盘操作**：`Tab` 聚焦技能卡片后，`Enter` / 空格打开详情，`E` 快速启用或停用，`Delete` 删除非内置技能（列表顶部会出现确认横幅，确认后才真正删除）。
- **对话中的技能面板**：在聊天输入栏点击技能按钮，弹出「技能」面板，可搜索、激活或取消激活技能，底部「获取更多技能」可直达技能管理。
- **MCP 管理**：打开「设置 → MCP工具」，可查看连接概况、服务器列表、预置服务与工具缓存。
- **对话中的 MCP 面板**：在聊天输入栏点击 MCP 按钮，打开「MCP工具」面板，勾选本会话要启用的 MCP 服务器。

## 核心操作

### 在对话中激活技能

1. 在聊天输入栏点击技能按钮，打开「技能」面板。
2. 搜索或浏览技能，点击「激活」。已激活的技能会显示「已激活」，对话时自动应用。
3. 不需要时点击「取消激活」。有些工具组会被学习 Agent 临时按需加载（显示「工具已加载」），点击「钉住到会话」可让它整段会话持续生效。

小技巧：常用技能可以在技能管理里点「设为默认」，默认技能会在新建会话时自动激活。

### 从社区技能市场安装技能

1. 打开「技能管理」，点击「技能源」，切换到「社区技能市场」标签。
2. 在搜索框输入关键词（留空显示热门技能），默认开启「仅显示非可疑技能」过滤。
3. 每个技能都会展示市场校验状态（已通过 / 未通过 / 审核中）与安全状态（干净 / 可疑 / 恶意）。注意：市场审核通过不代表本机已信任。
4. 点击「安装」。应用会先校验并下载扫描，再弹出确认框展示**风险分级**（低风险 / 中风险 / 高风险）与具体风险信号（是否含脚本、网络访问、外部链接、凭据关键字、二进制文件等）。
5. 确认安装后，技能默认处于**未信任**状态，需要在技能管理中信任后才生效。

### 从 GitHub 仓库或本地包安装技能

1. 「技能源」对话框切换到「GitHub」标签，粘贴仓库链接（如 `https://github.com/owner/repo`），点击「浏览」。
2. 应用会列出仓库中符合标准的 `SKILL.md` 技能，点击「安装」，流程与社区技能市场相同（装前扫描 + 风险确认）。
3. 也可以直接点击「导入」导入单个 `.md` 文件，或点击「导入包」安装 `.zip` 技能包。

### 信任边界、停用与 4 类准入拦截

外部技能在加载给学习 Agent 前会经过严格的后端准入校验：

1. **后端哈希持久化校验**：安装外部技能后默认为「未信任」，技能包内的文件完全不会暴露给学习 Agent。在技能详情中点击「信任此技能」后，后端会持久化记录该技能的**目录身份与完整包 SHA-256 哈希**；之后每次加载技能时后端都会重新计算并比对，确保包内文件未被外部篡改。
2. **随时撤销与停用**：信任后学习 Agent 可只读查看技能包文件，其中脚本的敏感执行仍受运行时审批约束。你可随时「撤销信任」或「停用」技能。
3. **4 类准入拦截提示**：如果某个技能暂时无法生效，技能卡片与详情会明确提示具体原因：
   - **未信任**：外部安装、刚完成更新或本地文件被改动，需重新核对并信任；
   - **已停用**：该技能已被手动停用，重新启用即可恢复；
   - **缺少 `bins` 或 `env` 依赖**：技能声明了运行所需的本机命令（`bins`）或环境变量（`env`），当前环境尚未配置；
   - **依赖技能不可用**：组合型技能所依赖的前置技能缺失、未信任或已停用。

### 编写自己的技能

1. 在「技能管理」点击「新建技能」。
2. 在「基本信息」标签填写：技能 ID（小写字母、数字、连字符）、名称、描述（建议 50 字以上，帮助学习 Agent 判断何时调用）、版本、优先级与技能类型（独立 = 自带完整工具集合；组合 = 会建议加载其他相关技能）。
3. 在「技能内容」标签用 Markdown 编写指令——即 `SKILL.md` 正文。
4. 需要时在「绑定工具」标签添加内嵌工具定义（技能激活时注入给学习 Agent）。
5. 保存后即可在对话中激活。你也可以把自己的技能「导出」为 `.md` / `.zip`，或用「导出源」打包成技能源仓库分享给他人。

内置技能不可删除，但可以编辑（会标记「已修改」），随时可点击「恢复默认」。点击「恢复默认」后会弹出二次确认——确认后该技能的全部自定义修改都会被丢弃并恢复为内置版本，此操作不可撤销。

### 更新已安装的技能

1. 在「技能管理」点击「检查更新」。仅通过链接、`.zip` 或社区技能市场安装的技能支持更新检查。
2. 发现更新时会提示「N 个技能有上游更新」，点击「全部更新」按原来源重新下载并覆盖安装。
3. 注意：更新后包哈希已变化，后端校验会自动将其**重置为未信任状态**，需重新信任后才会生效。

### 添加 MCP 服务器

1. 打开「设置 → MCP工具」，点击「新增服务器」。
2. 选择传输类型：
   - **Stdio（本地进程）**：本机启动一个命令（如 `npx @modelcontextprotocol/server-filesystem`）。⚠️ 仅桌面端（Windows / macOS / Linux）可用，移动端与浏览器无法启动本地进程。
   - **SSE / Streamable HTTP / WebSocket**：连接远程 MCP 服务，填写对应端点 URL，可选填 API Key。
3. 可用「图形表单」逐项填写，也可切到「JSON 模式」直接粘贴标准 MCP 配置。
4. 保存前建议点击「测试连接」；保存后点击「重新连接」让工具列表生效。
5. 在聊天输入栏的「MCP工具」面板中勾选该服务器，学习 Agent 即可在本会话调用它的工具。

### 一键添加预置 MCP 服务

「设置 → MCP工具」的「预置 MCP 服务器」区域内置 **8 个常用远程服务**，一键添加、跨平台可用：

- **Context7**（文档检索，免费无需 Key）、**Exa Search**（神经搜索）、**Wikipedia**（维基百科）、**Firecrawl**（网页抓取）、**Cloudflare Docs**、**Tavily**（实时搜索）、**Hugging Face**、**GitHub**。
- 点击「添加预置」前会弹出权限说明，标注**风险等级**、**数据范围**与**是否出网**；需要密钥的服务会提供「获取 API Key / Token」引导，部分服务可勾选「以 OAuth 方式安装」。

### MCP 的 OAuth 授权

1. 对支持 OAuth 的远程 MCP 服务器，在编辑页的「OAuth 授权」区域点击「使用 OAuth 登录」，在浏览器中完成授权。
2. 授权成功后显示「已授权（令牌已安全存储）」，可随时「重新授权」或「注销」。
3. 注意：若同时填写了 API Key，**API Key 优先于 OAuth** 生效；OAuth 浏览器登录仅在桌面端可用。

### 通过对话让学习 Agent 管理技能与 MCP

除了在界面里手动操作，你也可以直接在聊天里让学习 Agent 代劳——所有敏感操作都会先弹出审批卡，经你确认后才执行：

- **技能**：可让学习 Agent「停用/启用某个技能」（需确认）、「删除某个技能包」（每次必须审批，不可恢复）、「申请信任某个技能」——它会先做只读安全扫描，向你汇报包指纹和风险信号，审批通过后信任才生效。
- **MCP 服务器**：可让学习 Agent「修改配置」「启用/停用」「删除」。修改和删除每次都必须审批且不可「记住」；学习 Agent 拿不到你的 API Key，它只能声明所需的环境变量名，实际密钥仍由你在「设置 → MCP工具」填写。修改后会自动测试连通性，失败则自动回滚旧配置。
- **子代理角色（persona）**：可让学习 Agent 起草可复用的子代理角色（如「论文摘要员」），给出变更摘要并经你审批后写入 `workspaces/agents/`，随后即可被子代理调用；删除同样需要审批。
- 对话式管理与设置界面读写的是同一份数据，状态实时同步。

**Linux 桌面用户注意**：本地 shell 工具在 Linux 上使用 `bubblewrap` 沙箱隔离运行。请先通过发行版包管理器安装 `bubblewrap`（如 `sudo apt install bubblewrap` / `sudo dnf install bubblewrap`）；未安装时命令预检会直接报告沙箱不可用并给出指引，绝不会在无沙箱状态下执行本地命令。

## 进阶用法

- **技能组合**：在技能面板把当前激活的一组技能「存为组合」，之后一键激活整套组合。
- **MCP 运维**：服务器较多时，可用「刷新清单」重新拉取工具列表、「体检」批量检测连通性、「清空缓存」重置缓存。
- **安全策略**：「设置 → MCP工具」的「安全策略」支持配置工具白名单/黑名单、请求超时与速率限制，建议禁用文件删除、命令执行等高危外部工具。
- **MCP 配置门与危险模式**：默认启用配置门机制——本地 MCP Stdio 进程只能严格按你在「设置 → MCP工具」中已保存的服务器配置原样启动。「危险区」底部的「允许未批准的 MCP stdio 启动」开关默认关闭；一旦打开，任意脚本都可能触发未预先登记的本地进程启动，风险极高，仅建议排障时短暂开启并在用完后立即关闭（切换后需重启应用生效）。
- **工具权限**：「设置」中的「工具权限管理」可按工具配置敏感等级、本地目录授权与终端命令规则，技能与 MCP 引入的敏感操作都会走这套审批。

## 📱 移动端说明

- 「技能管理」在移动端通过抽屉 8 格应用启动器中的「技能」进入，功能与桌面端基本一致（内置 57 个技能，不含桌面专属 `browser-tools`）；点「编辑」会从右侧滑入全屏编辑器，可用顶栏返回或手势滑回。
- **Stdio 类型的 MCP 服务器在移动端不可用**，请改用 SSE / Streamable HTTP / WebSocket 远程服务；8 个预置 MCP 服务器均为远程类型，移动端可正常使用。
- **MCP 的 OAuth 浏览器登录仅在桌面端可用**。
- 对话中的技能面板与 MCP 面板在移动端均可从输入栏工具按钮正常打开。

## 常见问题

**Q：技能、MCP 和插件工坊有什么区别？**
A：技能是「给学习 Agent 的工作说明书与内置工具包」，改变它怎么干活；MCP 是「外部工具服务器」，让它能调用外部系统；插件则能直接给 Deep Student 扩展新窗口、选区按钮或渠道连接（详见 [AI 插件工坊与插件管理](./20-AI插件工坊与插件管理.md)）。

**Q：安装的技能为什么不生效？**
A：先在「技能管理」查看卡片上的准入提示：常见原因包括「未信任」（外部技能安装或更新后需手动信任）、「已停用」、缺少声明的 `bins` / `env` 依赖，或所依赖的前置技能不可用。排查通过后再在对话中激活（或设为默认）。

**Q：项目目录里放了 `.claude/skills` 或 `.skills`，为什么列表里没出现？**
A：项目级技能仅在你**显式配置了工作区根目录**后才会扫描 `.skills`、`.agents/skills`、`.claude/skills`、`.github/skills` 四个标准目录，避免应用擅自读取未授权目录。

**Q：装前风险扫描提示「高风险」还能装吗？**
A：可以，但请务必确认来源可信。高风险通常表示技能包包含可执行脚本、命令执行或网络访问声明。即使安装并信任，敏感操作在运行时仍需你逐次审批。

**Q：MCP 服务器显示「未连接」或聊天里看不到 MCP 工具怎么办？**
A：先在服务器行菜单点「重新连接」或「测试连接」排查地址、密钥或本机命令（如 `npx`）是否可用；连接正常后，记得在聊天输入栏打开「MCP工具」面板为**当前会话**勾选该服务器，并确认当前聊天模型支持工具调用。

**Q：技能会消耗很多 Token 吗？**
A：不会无节制消耗。内置工具组采用渐进披露机制，只有激活的技能才会把指令注入对话。建议只激活当前任务需要的技能，或用「学习精选」搭配「默认技能」保持轻量常驻。
