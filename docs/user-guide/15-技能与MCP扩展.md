# 技能与 MCP 扩展

> 技能（Skills）教 AI 按你想要的方法干活，MCP 让 AI 连接外部工具服务器；如果想打包整套学科规则/模板，或者给应用加新窗口与按钮，还可进一步使用插件与 `.dspack` 学习包。

## 快速上手：你想做什么？

| 你想做什么 | 3 步操作 | 你会看到 |
|---|---|---|
| **让 AI 按特定学习法辅导（如导师模式/调研模式）** | 1. 对话输入框打 `/` 或点「＋」→「技能」→ 2. 点选技能「激活」→ 3. 开始提问 | 输入栏上方出现**已绑定技能标签**，随时点 `×` 取消激活 |
| **安全查看一个技能的完整内容而不误改** | 1. 打开「技能管理」→ 2. 点任意技能卡片 → 3. 阅览简介、触发词、权限与正文 | 先打开**只读详情预览**，只有明确点「编辑」才会进入可写编辑模式 |
| **一键接入外部免费工具（如维基百科/文档库）** | 1. 打开「设置 → MCP工具」→ 2. 在「预置 MCP 服务器」选一个并「添加预置」→ 3. 对话输入栏点「＋」→「连接器」→「管理连接器」勾选它 | 无需手写配置，AI 本会话即可调用该外部工具 |
| **把自己写的学习法打包分享给同学** | 1. 编写纯 Markdown 学习技能（如 `study-*` / `learned-*`）→ 2. 无脚本低风险即兼容零代码学习包 → 3. 搭配模板打包为 `.dspack` 分享 | 同学导入即用，无需写任何代码 |

## 功能概览：技能、MCP 与插件怎么选？

Deep Student 提供三类互补扩展，按需求对号入座即可：

| 扩展方式 | 解决什么问题 | 常见形态 | 适用平台 |
|---|---|---|---|
| **技能（Skills）** | 教 AI 怎么干活（学习方法论、固定步骤、按需调用内置工具） | Markdown 工作说明书（`SKILL.md`），不激活不占上下文 | 全平台（`browser-tools` 仅 Windows / macOS） |
| **MCP 服务器** | 给 AI 接上外部工具或第三方数据源 | 标准 MCP 服务（本机进程或远程接口） | 远程类型全平台可用；本机进程（Stdio）与 OAuth 仅桌面端 |
| **学习包（`.dspack`）与插件（`.dstuplugin`）** | 打包分享批改规则/提示词/闪卡模板，或给应用加新窗口、选区按钮与渠道连接 | 零代码 `.dspack` 学习包、AI 插件工坊作品或完整 `.dstuplugin` 插件 | 桌面端与自托管 WebUI（详见 [AI 插件工坊与插件管理](./20-AI插件工坊与插件管理.md)） |

关于技能与 MCP 的核心特点：

- **58 个内置技能开箱即用**：含 **8 个学习工作流**（如深度调研、导师模式、ChatAnki 制卡、文献综述等）与 **50 个按需加载工具组**（知识检索、导图、题库、音视频、闪卡、记忆、Word/PPT/Excel 等）。Linux、移动端与自托管 WebUI 为 **57 个**（不含依赖 Windows/macOS 原生窗口的 `browser-tools`）；桌面端启用插件工坊后还会附带 `dstu-plugin-development` 技能。
- **技能分三级来源**：**内置** → **全局**（你自己安装，全部会话可用）→ **项目**（仅在你显式绑定了工作区根目录后，才扫描目录内的 `.skills`、`.agents/skills`、`.claude/skills`、`.github/skills`）。
- **默认不自动信任外部技能**：从社区技能市场、GitHub 或 `.zip` 导入的技能安装前都会执行风险扫描；安装后默认「未信任」，需你核对后手动点击「信任此技能」才生效，且文件内容一旦被篡改会自动撤销信任。
- **8 个预置远程 MCP 服务**：免写 JSON 一键添加，跨平台可用；支持 OAuth 浏览器授权与细粒度安全策略。

## 入口与界面布局

- **技能管理**：学习桌面点「全部应用 → 技能管理」（可固定到 Dock）；经典布局点左侧导航「技能管理」。顶部按三段场景分组——**「学习精选」（默认） / 「全部技能」 / 「系统与扩展」**；在当前分类搜不到但其他分类有命中时，顶部会弹出「查看全部匹配技能」一键切换。支持纯键盘浏览：`Tab` 选卡片、`Enter` / 空格打开只读预览、`E` 启用/停用、`Delete` 删除非内置技能。
- **对话中的技能面板与已绑定技能标签条**：在聊天输入栏点 **「＋」→「技能」** 可搜索激活；**已绑定的技能会以标签胶囊常驻显示在输入栏上方**，一眼看清哪些技能正在生效，点标签可回开技能面板，点 `×` 立即取消激活；同时绑定 2 个及以上技能时还提供 **「清空全部」**。本轮生效的技能还会记录在每条 AI 回复下方的「技能」归因胶囊中。
- **MCP 管理**：在 **「设置 → MCP工具」** 管理服务器、预置服务、安全策略、工具权限管理与工具缓存；在对话输入栏点 **「＋」→「连接器」→「管理连接器」** 勾选本会话要启用的外部服务器。

## 核心操作：技能（Skills）

### 1. 在对话中激活、查看与解绑技能

1. 在输入栏开头输入 `/` 挑选技能，或点 **「＋」→「技能」** 打开「技能」面板点 **「激活」**。
2. 激活后，输入栏上方会出现**已绑定技能标签条**，标明当前会话已绑定的技能。
3. 不再需要时，直接点标签右侧的 `×` 取消激活（绑定多个时可点 **「清空全部」**）。若某个工具组是 AI 临时按需加载的（标为「工具已加载」），点「钉住到会话」可让它整段会话持续生效。
4. 常用技能可在技能管理里点 **「设为默认」**，以后每次新建对话自动激活。

### 2. 安全查看详情（只读预览）与按需编辑

1. 在「技能管理」点击任意技能卡片，会先打开**只读详情预览**（展示技能名称、说明、`/` 触发命令、依赖与工具权限以及完整指令正文），不会一不小心误改文字。
2. 看完按 `Esc` 或关闭按钮即可退出；确认要修改时，再点显式的 **「编辑」** 按钮进入编辑器。
3. 内置技能不可删除，编辑后会标为「已修改」，随时可点 **「恢复默认」**（带二次确认，确认后丢弃自定义并还原内置版本）。

### 3. 从社区技能市场、GitHub 或本地文件安装

1. 打开「技能管理」→ 点 **「技能源」**：
   - **社区技能市场**：关键词搜索（留空看热门），默认勾选「仅显示非可疑技能」，清楚标出市场审核状态与安全状态（注意：市场通过不等于本机已信任）。
   - **GitHub**：粘贴仓库链接（如 `https://github.com/owner/repo`）点「浏览」，列出其中的 `SKILL.md` 技能。
2. 点 **「安装」**，应用会先扫描并展示**风险分级（低 / 中 / 高风险）**与具体风险信号（是否含脚本、联网、外部链接、凭据关键字或二进制文件）。
3. 也可以在技能管理页直接点 **「导入」**（单个 `.md`）或 **「导入包」**（`.zip` 技能包）。
4. 安装后默认为 **「未信任」**，在详情里确认内容无误并点 **「信任此技能」** 后才会生效；点 **「检查更新」** 升级外部技能后，因内容变化会自动重置为未信任，需重新核对信任。

### 4. 技能不能生效？对照 4 类准入提示排查

如果技能卡片提示暂时无法激活，直接看卡片上的原因即可对症解决：

- **未信任**：外部安装、刚更新或本地文件被改动过，核对后点「信任此技能」；
- **已停用**：该技能被手动停用，重新点「启用」即可；
- **缺少运行依赖**：技能声明了需要的本机命令（`bins`）或环境变量（`env`），补齐环境后生效；
- **依赖技能不可用**：组合型技能依赖的前置技能缺失、未信任或已停用。

### 5. 编写自定义学习技能 & 衔接 `.dspack` 零代码学习包

1. 在「技能管理」点 **「新建技能」**，依次填好基本信息（ID、名称、50 字以上清晰描述、优先级与独立/组合类型）、Markdown 指令正文和可选的绑定工具。
2. 保存后即可激活，也可「导出」为 `.md` / `.zip` 或「导出源」打包分享。
3. **纯 Markdown 学习技能直通 Plugin v2 零代码学习包（`.dspack`）**：
   - 如果你（或学习 Agent 在技能工坊中）编写的是纯 Markdown 学习方法技能——技能 ID 以 `study-` 或 `learned-` 开头、只包含 Markdown 文档、不含任何可执行脚本且零风险信号——它不仅能通过低风险快速通道校验，还与 **Plugin v2 第一层零代码学习包（`.dspack`）** 的声明式技能格式无缝衔接。
   - 你可以把这类纯 Markdown 学习技能与作文/解题批改规则、闪卡模板、学习工作流一起打进一个 `.dspack` 文件，分享给同学一键导入使用，全程无需一行代码（详见 [AI 插件工坊与插件管理](./20-AI插件工坊与插件管理.md#三层扩展体系从零代码学习包到完整插件)）。

## 核心操作：MCP 外部工具服务器

### 1. 一键添加 8 个预置远程 MCP 服务

打开 **「设置 → MCP工具」**，在「预置 MCP 服务器」区直接挑常用服务，全平台可用：

- **Context7**（技术文档检索，免费免 Key）、**Exa Search**、**Wikipedia**（维基百科）、**Firecrawl**（网页抓取）、**Cloudflare Docs**、**Tavily**、**Hugging Face**、**GitHub**。
- 点 **「添加预置」** 前会清楚列出风险等级、数据范围和是否出网；需要密钥的附带获取指引，部分支持「以 OAuth 方式安装」。

### 2. 手动添加自定义 MCP 服务器

1. 打开「设置 → MCP工具」→ 点 **「新增服务器」**。
2. 选择连接方式：
   - **远程服务（SSE / Streamable HTTP / WebSocket）**：填端点 URL 与可选 API Key，桌面端、WebUI 与移动端均可用；支持 OAuth 的服务器可在桌面端点「使用 OAuth 登录」（若同时填了 API Key，API Key 优先）。
   - **本机进程（Stdio）**：在本机启动命令（如 `npx ...`），**仅桌面端可用**。
3. 支持图形表单或直接粘贴标准 JSON 配置；先点 **「测试连接」**，保存后点 **「重新连接」**，再在聊天输入栏点 **「＋」→「连接器」→「管理连接器」** 为当前会话勾选即可。

### 3. 安全模式下的自动暂停保护（防卡死 / 排障）

当应用处于**安全模式**（例如你点击了「安全模式排查」，或启动连续崩溃触发安全模式恢复）时：

- **外部自定义 MCP 服务器的自动连接会自动暂停**，顶部安全模式横幅也会明确提示：**「外部自定义 MCP 自动连接也已暂停（你仍可在设置中手动查看和测试）」**。
- 这样可以防止卡死的本机进程、失效的外部接口或异常工具拖慢排查；你已保存的 MCP 配置和密钥丝毫不会丢失，依然可以在「设置 → MCP工具」中手动检查或点「测试连接」。
- 排查完成并点击 **「退出安全模式并恢复正常启动」** 后，MCP 自动连接会自动恢复（完整救援步骤见 [AI 插件工坊与插件管理](./20-AI插件工坊与插件管理.md#安全模式-1-分钟自救指南)）。

### 4. 在对话里让 AI 代管技能与 MCP

你也可以直接对 AI 说「帮我停用某个技能」「帮我修改/停用某个 MCP 服务器」或「起草一个论文摘要子代理角色」——所有敏感变更都会先弹出审批卡片，经你确认才执行；AI 接触不到你的 API Key，MCP 配置改动后会自动测试连通性，失败则自动回滚旧配置。

## 进阶用法

- **技能组合**：在对话的 **「＋」→「技能」** 面板把当前激活的一组技能「存为组合」，以后一键批量激活。
- **MCP 批量运维与安全策略**：服务器多时可用「刷新清单」「体检」「清空缓存」；在「设置 → MCP工具 → 安全策略」中可设工具黑白名单、超时与限频，建议禁用高危删除或命令工具。
- **工具权限管理**：在 **「设置 → MCP工具 → 工具权限管理」**（默认折叠，展开后统一配置）设置敏感操作审批级别与本地目录授权。
- **本地编程 CLI 与本地 MCP 桥（桌面端）**：在 **「设置 → 工具与扩展 → 编程 CLI」** 可接入本机 Claude Code、Codex CLI、OpenCode、Pi Agent、Antigravity CLI（`agy`）、DeepSeek Harness（`dsh`）及自定义命令行工具；开启「共享当前学习上下文」后，本地编程 CLI 通过内置本地 MCP 桥与当前会话互通学习笔记与资料片段，与外部 MCP 服务器形成互补（详见 [AI 对话与会话管理](./02-AI对话与会话管理.md#本地编程-cli-与多工具协同桌面端)）。

- **技能信任防篡改**：点击「信任此技能」后，后端会持久化记录技能包的目录身份与完整包 SHA-256 哈希，每次加载都会重新比对；包内任何文件被修改都会使信任立即失效。
- **Linux 本地命令沙箱**：Linux 桌面端运行本地 shell 工具依赖 `bubblewrap`（如 `sudo apt install bubblewrap` / `sudo dnf install bubblewrap`）；未安装时命令预检会直接报错并指引安装，绝不会在无沙箱状态下执行。
- **MCP 配置门**：默认只允许启动你在「设置 → MCP工具」中预先保存好的本地 Stdio 配置。「危险区」底部的「允许未批准的 MCP stdio 启动」默认关闭，非排障场景请勿打开（切换后需重启生效）。

## 移动端说明

- 通过抽屉应用启动器进入「技能」，支持只读详情预览、场景分类、搜索、社区技能市场安装与信任管理（内置 57 个技能，不含桌面专属 `browser-tools`）；对话内同样显示已绑定技能标签条。
- 移动端不支持本机进程（Stdio）MCP 与 OAuth 浏览器登录；8 个预置远程 MCP 及自定义远程 MCP（SSE / Streamable HTTP / WebSocket）均可正常使用。

## 常见问题

**Q1：为什么进入安全模式后，之前配好的 MCP 工具连不上了？**
A：这是安全模式的保护机制——应用会自动暂停外部自定义 MCP 自动连接，避免异常外部服务干扰排查。你仍可在「设置 → MCP工具」查看或手动测试，点击「退出安全模式并恢复正常启动」后即自动恢复连接。

**Q2：安装的技能为什么不生效？**
A：在「技能管理」查看该技能卡片提示：常见原因是「未信任」（装完或更新后需手动信任）、「已停用」、缺少声明的本机命令/环境变量，或前置依赖技能不可用。排查通过后再在对话中激活或设为默认。

**Q3：为什么项目目录里放了 `.skills` 或 `.claude/skills`，列表里却没显示？**
A：为了保护隐私，应用只会在你**显式绑定了工作区根目录**后，才扫描该目录下的 `.skills`、`.agents/skills`、`.claude/skills`、`.github/skills`。

**Q4：技能会白白消耗很多 Token 吗？**
A：不会。内置工具组按需加载，未激活的技能不会塞进上下文。建议用「学习精选」搭配少量「默认技能」，不用时直接点输入栏上方技能标签的 `×` 取消即可。

**Q5：技能、`.dspack` 学习包和 `.dstuplugin` 插件怎么选？**
A：只想改 AI 的提问/讲题步骤用**技能**；想把纯 Markdown 学习法连同批改标准、闪卡模板一起无代码分享给同学用 **`.dspack` 学习包**；想给应用加独立小窗口、选区按钮或接入外部软件用 **插件工坊 / `.dstuplugin`**（见 [AI 插件工坊与插件管理](./20-AI插件工坊与插件管理.md)）。
