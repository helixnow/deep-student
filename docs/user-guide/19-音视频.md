# 音视频

> 「音视频」把网课、讲座与 B 站课程变成可检索、可伴读、可测验的学习材料：转写带时间戳字幕，围绕当前播放时刻与章节实时「伴读即时问答」并一键回跳 `▶ mm:ss`，一键生成章节化讲义、后台制卡与课中检查点。

## 三步上手

**想把一节网课变成可搜索、可追问、可复习的学习资料：**

1. **导入课程**：打开「音视频」，点「导入音视频」选择本地视频 / 录音（电脑端直接拖入即可），或点「B 站链接」粘贴 B 站课程链接免下载导入。
2. **准备字幕**：在「字幕」标签点「转写」生成带时间戳字幕；已有字幕文件就点「导入字幕」零费用载入（B 站课程自带字幕，无需转写）。
3. **边看边问并巩固**：切到「问答」标签，在「伴读即时问答」里直接提问或点快捷预设，点击回答里的 `▶ mm:ss` 立刻跳回原片段；看完后在「讲义」生成章节讲义，在「练习」一键生成课中检查点或后台制卡。

## 功能概览

- **转写与字幕交互**：把音轨转成带时间戳的字幕，支持搜索、点句跳转、播放跟随高亮、字幕字号调节（小 / 中 / 大）；支持勾选字幕段（含 `Shift` 连选）一键引用或制卡、划选即入图、拖入思维导图 / 笔记与字幕反链胶囊；已有字幕文件可直接导入，不花转写费用。
- **B 站链接与出口管理**：贴 B 站链接拉取 UP 主字幕或 AI 字幕并在应用内播放，支持扫码登录、多 P 批量导入、悬浮条「清晰度」切换与桌面端「B 站出口」（含浏览器桥用户脚本配对与请求诊断）。
- **锚定播放时刻的「伴读即时问答」与「问刚才这段」**：在「问答」标签中，伴读问答实时锚定当前播放位置与所处章节（`mm:ss · 课名 · 章节`），结合课程字幕给出有依据的讲解与可点击跳转的 `▶ mm:ss` 时间戳，支持一键「迁入主会话」展开深度讨论；「截取当前帧」自动附带前后各 30 秒字幕。
- **章节化讲义与内联讲义阅读器**：一键生成图文讲义，`##` 小节自动变为播放器课程章节与目录跳转；内置「内联讲义阅读器」支持分节精读、按难度筛选、随堂概念自测与打印 / 导出。
- **课中检查点、页内制卡与单课台账**：按课程节奏生成课中检查点（答错一键回看前 15 秒）；页内点「制作闪卡」直接后台启动制卡；列表与「练习」标签实时统计本课闪卡与题目集台账，且与闪卡、题目集、学习总览全链路联动回跳。

「音视频」不是另一个文件仓库，而是**资源库的专用视角**：音视频文件仍然存放在资源库里，备份、同步、搜索都和其他资料一样；这里只是把「看一门课」需要的步骤串在一起。产出的内容分别落在 对话、笔记、思维导图、闪卡、题目集 里。

## 入口

| 位置 | 怎么进 |
|---|---|
| 学习桌面 | 程序坞（Dock）或「全部应用」里的「音视频」 |
| 经典布局 | 左侧导航的「音视频」（在「资源库」下面） |
| 命令面板 | 按 `Ctrl / ⌘ + K` 搜索「跳转到音视频」 |
| 资源库 / 对话右侧面板 | 打开一个音视频文件后，工具栏上的「在音视频中学习」 |
| Android | 抽屉应用启动器里的「音视频」 |

## 媒体库（首页）

首页列出资源库里所有的音频和视频，按最近活动排序，最近看过、刚导入或刚转写的排在前面。

- **导入音视频**：点「导入音视频」（电脑在顶栏右侧，手机在页面底部），用系统文件选择框选择文件，可多选；电脑上也可直接拖到页面上。只导入一个文件时，完成后直接进入它的学习页。导入的文件存放在资源库根目录。
- **B 站链接**：点「B 站链接」（在「导入音视频」旁边），粘贴视频页地址、`b23.tv` 分享短链或 BV 号解析，支持选分 P 与字幕批量导入。详见下文「[B 站链接与出口管理](#b-站链接与出口管理)」。
- **搜索与筛选**：按名称搜索；用「全部 / 在看 / 未转写 / 已转写」筛选。
- **按分组看**：搜索框右侧在「列表」和「按分组」之间切换。分组即这些音视频在资源库里所在的文件夹，支持折叠，未归类项位于「未分组」。
- **多选与全选**：点顶部「选择」进入多选（长按一行也可进入），底部操作条提供「全选」「移动到分组…」（支持「新建分组…」并自动提取共同标题作默认名）「删除」。按 `Esc` 或点「完成」退出。
- **每一行显示**：缩略图（B 站条目是视频封面，底边带观看进度条）、名称、时长、转写状态、**学习台账摘要（「卡 N · 题 M」）**、观看进度条和上次观看时间。转写状态包括：「未转写」「排队中」「转写中 n/m」「已转写」「已导入字幕」「部分完成」「转写失败」。看完的课名称旁有对勾；B 站链接条目带「B 站」标记。
- **行菜单「⋯」**：
  - 「导入字幕文件…」：导入 `.srt`、`.vtt` 或 B 站字幕 JSON；
  - 「从 B 站链接获取字幕…」（本地音视频）或「重新获取 B 站字幕…」（B 站链接条目）；
  - 「导出为 SRT」「导出为 WebVTT」「导出为纯文本」（有字幕后可用）；
  - 「重命名」「在资源库中显示」「删除」（移入资源库回收站，可恢复）。

支持 MP4、MOV、MKV、M4A、MP3、WAV、FLAC 等常见格式，单个文件最大 **4 GB**。

## 学习页与播放器体验

在首页点一节课进入学习页：左边是播放器，右边是四个标签——「字幕」「讲义」「问答」「练习」（窗口较窄时标签面板移到播放器下方），顶栏左侧返回箭头回到首页。

### 播放器工具栏与微交互

播放器上方工具栏提供：

- **当前章节提示（「本章：xxx」）**：生成讲义后，工具栏会实时显示当前所处讲义章节，点击可快速切换章节；
- 「转写」：开始转写；转写中显示进度并可「取消」；
- 「截取当前帧」（视频）：把当前画面截帧引用到对话，并**自动附带前后各 30 秒字幕**，让学习 Agent 既看到板书 / PPT 又明白老师当时在讲什么；
- 「在 B 站打开」（B 站链接条目）：在浏览器里从当前位置打开原视频；
- 「⋯」：导入字幕、获取 / 重拉 B 站字幕与三种格式字幕导出。

播放器内置的流畅微交互与播放保护：

- **9 档倍速与临时加速**：支持 `0.5×` 至 `3×` 共 **9 档倍速**；观看时**长按画面**或**按住右方向键（`→`）**可临时以 `3.0×` 倍速快进，松手即恢复原速。
- **触屏双击快进 / 快退**：双击画面左侧 35% 区域快退 10 秒、右侧 35% 区域快进 10 秒，连续点击支持**连续累加**（如连点三次快进 30 秒）。
- **进度条悬停缩略图预览**：鼠标悬停在进度条上时预览对应时刻的画面缩略图，拖动定位更直观；若已生成讲义或课中检查点，进度条上还会标出章节分割线、检查点作答状态与答错回看高亮区。
- **清晰度切换（B 站应用内播放器）**：悬浮控制条提供「清晰度」菜单，详见下文 B 站一节。
- **播放期屏幕常亮与断点续播**：播放视频时自动保持屏幕常亮，避免长时间听课息屏；下次打开自动从上次看到的位置继续播放。
- **画面字幕与字号调节**：画面叠加字幕可随时开关，并支持调节字幕字号（**小 / 中 / 大**）。
- **播放异常与浏览器限制保护**：在浏览器 WebUI 或手机端播放时，系统会自动将媒体流转为浏览器可流畅拖动的分段播放地址；若遇到浏览器限制非静音自动播放，会自动切为静音播放并弹出「**取消静音**」按钮；遇到编码不兼容、地址失效或播放被拦截等情况时，会直接给出可读的中文提示与排查建议，绝不卡死在无响应的播放按钮上。

### 字幕

- 显示带时间戳的字幕，支持**搜索**、**点任意一句跳播**与**播放自动跟随高亮**（手动滚动时暂停跟随，方便回看）。
- **选择字幕段（含 `Shift` 连选）**：点击字幕区「选择字幕段」即可逐行勾选，按住 `Shift` 点击可连续选中一段字幕，底部操作栏支持直接「**引用到对话**」或「**制卡**」。
- **划选即入图、拖入导图 / 笔记与字幕反链胶囊**：划选字幕文本可直接「划选即入图」送入思维导图，或直接将字幕段落拖进思维导图 / 笔记窗口；已被笔记、闪卡或思维导图引用的字幕行会显示**字幕反链胶囊**，点击即可回跳对应产物。
- 还没有字幕时，显示「转写」和「导入字幕」两个按钮。

### 讲义：章节化与内联讲义阅读器

- **一键生成章节化讲义**：有字幕后点「生成讲义」，AI 会结合字幕与关键画面（本地视频）整理图文讲义并保存为笔记。讲义中的 `##` 二级小节会**自动转化为课程章节**：
  - 播放器进度条自动显示章节分割线；
  - 顶部工具栏显示「本章：xxx」；
  - 「讲义」标签页展示章节目录，点击即可跳播对应时间段，已播章节自动打上已播标记；
  - 笔记与讲义里的时间锚点统一渲染为可点击的 `▶ 00:05` 徽章。
- **内联讲义阅读器**：无需跳出音视频页面，点击讲义即可在内置的「内联讲义阅读器」中精读，支持：
  - **分节精读**与**按难度筛选**（快速聚焦核心或难点小节）；
  - **随堂概念自测**（读完即检验理解）；
  - **导出 / 转存笔记 / 打印视图**（讲义本身也是笔记，也可在笔记导出菜单中导出 Word「讲义 / 公文版式」，见 [笔记](./07-笔记.md)）。

### 问答：锚定播放时刻的「伴读即时问答」与「问刚才这段」

听课卡壳时，切到「问答」标签即可用两种方式随时追问，不用离开播放器：

**一、伴读即时问答（页内随看随问）**

1. **自动锚定当前时刻与章节**：问答面板内置「**伴读即时问答**」卡片，底部胶囊会随播放进度实时显示当前上下文锚点——**`mm:ss · 课名 · 章节`**（未分章节时显示 `mm:ss · 课名`；如需脱离当前时刻自由提问，可点胶囊右侧 `×` 移除锚点）。
2. **基于字幕的有依据解答**：输入问题，或直接点击预设快捷按钮（**「解释当前段落」「推导此步公式」「出一道变式题」**）。系统会自动收集当前播放位置附近（回看 60 秒 + 前瞻 45 秒）的字幕、当前章节目录以及全课与你问题最相关的字幕片段（短课直接带上完整字幕），调用你配置的 AI 模型给出条理清晰的讲解，而不是机械复读字幕。
3. **点击 `▶ mm:ss` 一键回跳，或「迁入主会话」深聊**：
   - AI 回答中引用的课程原话、定义与公式都会渲染成可点击的 **`▶ mm:ss`** 时间戳按钮（如回答未含行内时间戳，气泡下方也会附上「相关片段：」按钮），点一下播放器立刻跳回那一刻重听。
   - 想围绕这个话题继续做多轮深度推导或结合其他资料讨论时，点右上角「**迁入主会话**」，即可把这段伴读记录和当前时间锚点完整带入主 AI 对话；暂时不用时按 `Esc` 或点最小化，可收起为轻巧的「**伴读小窗**」胶囊。
   - **未配置 AI 模型时的贴心降级**：如果你还没填好模型 API 密钥，伴读问答不会编造假回答，而是直接提示「未配置 AI 模型，已为您定位相关字幕片段」，列出最相关的可点击 `▶ mm:ss` 原话片段，并附一键「**前往设置配置 AI 模型**」按钮。

**二、「问刚才这段」与整课提问**

- **「问刚才这段」**：专为「刚才老师那句话没听懂」设计，点一下会自动截取当前播放时刻**前 1 分钟的字幕**并在主对话中预填提问，附带可跳转时间引用。
- **「就这门课提问」与常用问题**：新开主对话自动附上这节课并启用「课程学习」技能；另提供「总结这节课」「列出重点和难点」等常用问题入口。

### 练习：课中检查点、页内直接制卡与本课台账

1. **本课台账**：顶部实时汇总本节课的学习产出与掌握度：
   - **闪卡台账**：显示本课闪卡总数、到期数与新卡数，附一键「**复习本课卡片**」按钮；
   - **题目台账**：显示本课题目数、正确率与错题数，附一键「**去做题**」按钮。
2. **课中检查点与答错回跳重看**：
   - 点「**生成课中检查点**」，AI 会按课程节奏（约**每 5 分钟一题**）自动出题，存入名为「`课名 · 检查点`」的题目集；
   - 播放器进度条会标出每个检查点的作答状态（未答 / 答对 / 答错）与答错回看高亮区；
   - 播放到检查点时刻自动弹出测验卡片（可勾选「**到点暂停**」避免错过后续讲解）；
   - 如果答错，点击卡片上的「**回看这一段**」，播放器会自动回跳到该检查点锚点**前 15 秒**重新播放对应讲解。
3. **页内直接制卡与对话定制**：
   - 点击「**制作闪卡**」会**直接在后台启动制卡任务**（约每 10 分钟生成 6 张，总量控制在 **6–40 张**，每张卡片背面自动附带时间锚点），完成后进入「闪卡」并更新本课台账，无需手动切去对话；
   - 若想自定义题型、难度或覆盖范围，点击次要按钮「**在对话中制卡（可补充要求）**」，会打开预填指令的对话供补充说明后再生成。
4. **生成练习题**：打开对话预填出题指令，生成的题目存入「题目集」并附出处时间点（参见 [Anki 制卡与模板](./12-Anki制卡与模板.md)、[题目集与练习](./11-题库与练习.md)）。
5. **本课统计**：下方展示观看时长、是否看完、字幕段数等进度信息。

## 转写与字幕

### 转写

1. 在「字幕」标签或工具栏点「转写」。
2. 弹窗显示时长、预计段数和所用模型，确认后开始。转写按语音识别的调用量计费，因此每次都会先让你确认。
3. 应用在本机解码音轨、按停顿切分语音段，再逐段识别；进度显示在工具栏和首页的状态里。

- **在后台进行**：转写开始后可以切到别的页面或看别的课，转写会继续；应用从后台切回前台时也会刷新状态。
- **可以取消、可以续做**：取消或中断后已完成的段会保留，下次点「转写」从断点继续；部分段失败显示「部分完成」，再转写一次只补失败段。
- **短音频自动转写**：10 分钟以内的短音频，导入后会自动开始转写。
- **语音识别模型配置**：转写和对话里的「语音输入」共用「设置 → 模型分配 → 语音识别（ASR）模型」，支持硅基流动、DeepSeek 官方 ASR、阿里云百炼（`qwen3-asr-flash`）、OpenAI 及兼容中转站；硅基流动一键分配会自动配好 Qwen3-ASR（未分配时若已配硅基流动密钥默认使用 `Qwen/Qwen3-ASR-1.7B`）。详见 [模型与供应商配置](./14-模型与供应商配置.md)。

### 导入与导出字幕

- **导入**：首页行菜单或学习页「⋯」→「导入字幕」，支持 `.srt`、`.vtt` 和 B 站字幕 JSON（Android 支持通过系统文件选择器导入 ≤ 20 MB 的字幕文件）。不调用模型、不产生费用，导入后即可用全部学习功能。
- **导出**：「导出字幕」→ SRT / VTT / 纯文本，方便在其他播放器里使用或分享。

### B 站链接与出口管理

不用下载视频，贴链接就能把 B 站上的课变成可检索、可伴读的学习材料：

- **字幕来源与扫码登录（可选）**：支持拉取 UP 主上传字幕或 B 站自动生成的 AI 字幕，不登录也能用。在「B 站链接」弹窗顶部点「扫码登录」用 B 站 App 扫码确认后，请求字幕和视频流会带上你的登录态，AI 字幕更全、可选更高清晰度且更不易触发风控。登录凭证仅加密保存在本机（不进设置与备份），同一行可随时「退出」。
- **新建与多 P 批量导入**：贴视频地址、`b23.tv` 短链或 BV 号 → 解析 → 选择字幕与分 P（合集支持「全选」或勾选多 P 一次导入，带「正在导入 3/16」进度与随时「停止」）。重复导入同一视频的同一 P 会更新原条目字幕，不会重复新建。无字幕的分 P 自动跳过；为避免限流，每 P 间会稍作间隔。
- **应用内播放与清晰度切换**：
  - 学习页默认使用**应用内播放器**转发播放（不保存视频文件），完整支持拖动、倍速、截帧附字幕、检查点、字幕高亮与进度记录。
  - 应用内播放器悬浮控制条提供「**清晰度**」菜单：根据当前登录态动态拉取可用清晰度档位，切换后自动记住你的偏好；若某个视频没有所选最高档位，会自动降档并给出降档提示。
  - 少数受限视频无法在应用内直接播放时，会自动切换为 **B 站网页内嵌播放器**并提示（工具栏可在「改用 B 站播放器」与「重试应用内播放」间切换）；使用网页内嵌播放器时不支持应用内清晰度切换、截帧与进度记录。也可点「在 B 站打开」去浏览器或 App 观看。
- **B 站出口与浏览器桥配对（桌面端）**：
  - 桌面端「B 站链接」弹窗提供「**B 站出口**」面板，支持四种请求策略切换：**自动 / 浏览器桥 / 应用原生 / 可信代理**，并内置**请求诊断**工具，方便在遇到 B 站风控或地区 / 网络受限时快速排查链路状态。
  - **浏览器桥用户脚本配对**：在「B 站出口」面板中按引导安装配套的浏览器用户脚本，在浏览器打开 B 站并输入弹窗中的配对码完成配对后，即可复用你常用浏览器的真实会话与网络出口稳定拉取字幕与视频流。
- **给本地视频挂字幕 / 重新拉取**：本地已下载的 B 站视频可通过「从 B 站链接获取字幕…」省去转写费用；链接条目无本地文件不支持语音转写，但可随时「重新获取 B 站字幕…」或导入外部字幕。暂不支持番剧 / 影视、课堂（付费课程）、音频和直播链接。

## 跨应用回跳与学习总览联动

音视频与全应用的学习闭环深度打通：

- **时间戳引用跳转**：对话中回答带的 `▶ 01:23 · 文件名` 点一下在对话右侧面板打开并定位到那一刻；笔记 / 讲义中的 `▶ 00:05` 徽章点一下直接打开「音视频」学习页并跳播。
- **闪卡回跳**：由音视频生成的闪卡在翻面后会显示「`▶ 回看 mm:ss`」按钮（评「重来」后底部的撤销提示条同样提供「回看」入口），记不清时一键重看老师原话。
- **题目集回跳**：在题目集刷课中检查点或课程练习题时，题目追问栏点击「出处」或「回看 mm:ss」直接跳回原视频对应时刻。
- **学习总览联动**：学习总览会自动向学习 Agent 同步你**最近 5 门课的观看进度与答错的检查点时刻**，让你在首页问「我最近哪些网课有薄弱点」时，AI 能精准定位到具体课程与时间段给出复习建议。

## 和资源库的关系

- **是同一份文件**：在「音视频」导入的文件就在资源库里，在资源库导入的音视频也会出现在「音视频」首页。移到课程文件夹后，「音视频」里照样能看到并可按分组浏览。
- **资源库照样能看**：在资源库打开音视频仍展示播放器、字幕与转写；需要完整伴读、讲义、检查点与台账流程，点工具栏的「在音视频中学习」。
- **删除即删除资源**：在「音视频」删除会移入资源库回收站，随时可恢复。引用、知识库检索、跨学习空间挂载与同步均与其他资源一致，详见 [资源库](./04-学习资源中心.md)。

## 📱 移动端说明

- **入口与抽屉**：抽屉应用启动器进入「音视频」；左侧抽屉上半部分提供「最近在看」，一键续播。
- **导入与 B 站能力**：点页面底部「导入音视频」通过系统文件选择器多选导入；Android 支持 **B 站扫码登录、多 P 批量导入、字幕获取**以及通过系统文件选择器导入字幕文件（≤ 20 MB），但**暂不支持桌面端的浏览器桥出口与应用内清晰度切换**。
- **学习页布局、伴读与触控**：播放器固定在顶部（16:9），下方为「字幕 / 讲义 / 问答 / 练习」四标签，在移动端同样完整支持「伴读即时问答」与点击 `▶ mm:ss` 跳转；支持触屏双击左右 35% 连续快退 / 快进（每次 10 秒可累加）、长按画面临时 `3.0×` 倍速、播放期屏幕常亮与字幕字号调节。
- **移动端播放保护**：在手机浏览器（WebUI / PWA）播放时，如果浏览器策略禁止自动带声播放，会自动切换为静音播放并弹出「取消静音」按钮；遇到视频格式不受浏览器支持或网络中断时，会立即展示清晰的中文原因提示，不会点不动或黑屏无反应。
- **行菜单与返回键**：长按一行或点行尾「⋯」打开操作菜单；返回键按「先关菜单 / 弹层 → 返回首页」顺序响应。
- **转写**：在前台进行；切到后台被系统暂停后，回到应用会继续转写，已完成段不丢失。

## 常见问题

**Q1：导入或播放时提示格式不支持或无法播放？**
Opus 编码的 WebM / OGG、AC-3 音轨等格式在部分浏览器或系统里暂不支持，播放器会直接提示具体原因（如编码不兼容或媒体源不可用）。建议先用格式转换工具转成 MP4（视频）或 M4A（音频）再导入；若在手机浏览器看到静音提示，点横幅上的「取消静音」即可恢复声音。

**Q2：点「转写」提示未配置？**
转写需要语音识别模型。到「设置 → 模型服务」配好提供方的 API 密钥，再到「设置 → 模型分配」选择「语音识别（ASR）模型」（与语音输入共用）。不想付费转写的话，可以直接导入现成的字幕文件或从 B 站链接拉取字幕。

**Q3：B 站拉取字幕或播放频繁被拦截怎么办？**
优先在「B 站链接」弹窗顶部完成「扫码登录」；桌面端还可以在「B 站出口」面板切换为「浏览器桥」并完成用户脚本配对，或运行「请求诊断」排查网络出口。如果视频缺少目标清晰度，播放器会自动降档并提示；无法直连播放时可切换 B 站网页内嵌播放器。

**Q4：文件很大，导入很慢，或转写到一半关了应用怎么办？**
单个文件最大 4 GB，导入与播放均采用分段读写不占满内存；转写中断后已完成的段会保留，再次点「转写」从断点续做，不会重复计费已完成部分。

**Q5：点「制作闪卡」为什么没有跳转对话？如果想自定义出卡要求怎么办？**
点击「制作闪卡」直接在后台按课程节奏生成（约每 10 分钟 6 张、上限 6–40 张），省去来回切换；如需补充额外要求（如指定侧重点或题型），点击旁边的「在对话中制卡（可补充要求）」即可。

**Q6：讲义能导出成 Word 吗？**
能。讲义会保存为笔记，也可在内联讲义阅读器中导出、转存笔记或使用打印视图；在笔记导出菜单里可导出 Word，可选「讲义 / 公文版式」。
