# 闪卡复习

> 应用内置的间隔重复复习系统：卡片库统一管理你的所有记忆卡片，FSRS 算法安排每张卡的最佳复习时机，不装 Anki 也能坚持每天复习。

## 功能概览

「闪卡」应用是 Deep Student 内置的复习中心，与制卡功能（见 [12-Anki制卡与模板](12-Anki制卡与模板.md)）无缝衔接：

- **今日复习**：每天打开就能看到到期卡片数、今日进度环和连续学习天数，一键开始复习。
- **卡片库**：集中管理所有卡片——搜索、筛选、编辑、入队、暂停、批量操作。
- **FSRS 智能调度**：根据你每次的评分（重来 / 困难 / 良好 / 简单）自动计算下次复习时间，评分按钮上直接显示预测间隔。
- **与知识点掌握度联动**：做题产生的薄弱点画像会小幅影响卡片排期——薄弱知识点的卡片更早到期、优先出现，掌握牢固的适当延后（调整幅度有上限，不会破坏整体节奏）。
- **学习统计**：复习热力图、每日复习量、评分分布、卡片状态构成、连续学习记录。

卡片来源主要有三个：在对话中生成卡片后「加入卡片库」、导入 .apkg 牌组、以及让 AI 直接把内容（如作文错误点、错题）整理成卡片入队。

## 入口与界面布局

**怎么打开：**

1. 闪卡应用位于「学习桌面」模式中（桌面端默认开启）：点击底部 Dock 的「闪卡」图标即可打开，图标角标会显示当前到期卡片数。
2. 也可以打开 Dock 上的「全部应用」面板，搜索"闪卡"。
3. 有到期卡时，学习桌面顶部菜单栏也会出现闪卡到期数入口，点击直接发起一轮到期复习。

**界面分区：**

- 顶部三个标签页：
  - **今日** — 今日复习概览与入口（有到期卡时标签上会显示数量角标）；
  - **库** — 卡片库管理；
  - **统计** — 学习统计报表。
- 开始复习后进入全屏的复习会话界面：中间是卡面，底部是评分栏，顶部显示进度与用时。

## 核心操作

### 一、每天的复习流程

1. 打开「闪卡」→「今日」标签，查看：待复习、新卡、学习中的数量，今日进度环（已复习 / 剩余），以及「连续学习 N 天」。
2. 点「开始复习」进入复习会话。到期卡较多时系统会分批进行，提示"本轮先练前 N 张"。
3. 对每张卡：
   - 先回忆答案，然后**翻面**——点击卡片，或按空格 / Enter；
   - 对照背面内容，按掌握程度评分：**重来**（完全忘记）、**困难**（勉强想起）、**良好**（稍加思考想起）、**简单**（立刻想起）。每个评分按钮上会显示这样评分后的下次复习间隔；
   - 必须先翻面才能评分。
4. 一批复习完出现小结：本轮已评张数、用时、最长连击和评分分布；如果还有到期卡会提示"仍有 N 张到期"，可继续下一批或「返回今日」。
5. 当天全部完成后，「今日」页会显示"今日复习全部完成"。

**复习会话中的更多操作：**

- **撤销评分**：手滑评错了点「撤销评分」（或按 Z / Ctrl+Z），回到上一张重新评；本轮会话内可**逐级连续撤销**最近的多次评分（不再只有最近一步）。若某张卡在此期间被其他入口（如 AI 代评）改动过，对应步骤会自动跳过以免回退到过期状态。
- **编辑卡片**：点「编辑卡片」（或按 E）直接修改正面 / 背面和标签；填空卡的正面必须保留有效的挖空标记。
- **暂停卡片**：暂时不想复习这张卡，点「暂停卡片」把它移出调度，之后可在卡片库恢复。
- **跳过**：按 S 跳过当前卡。
- **键盘评分**：翻面后按 1–4 分别对应重来 / 困难 / 良好 / 简单；已翻面时再按空格 / Enter 相当于评"良好"。

### 二、管理卡片库

1. 切到「库」标签，查看全部卡片（分页显示，底部「上一页 / 下一页」）。
2. **搜索与筛选**：顶部搜索框按正面 / 背面 / 标签搜索；筛选器可按状态过滤——全部、已到期、新卡、学习中、复习中、已暂停、未入队；排序支持按到期时间、创建时间、字母顺序升 / 降序。
3. **单卡操作**：展开卡片详情可查看状态、到期时间、创建时间、标签和最近评分；可对单卡执行：
   - 「复习」— 立即单独复习这张卡；
   - 「入队」— 把尚未参与调度的卡加入 FSRS 复习队列（新保存的卡默认"未入队"，入队后才会被安排复习）；
   - 「暂停 / 恢复」— 移出或移回调度；
   - 「编辑」— 修改正面、背面和标签（逗号分隔）；
   - 「撤销最近评分」、「删除」（删除不可撤销，会二次确认）。
4. **批量操作**：勾选多张卡（「全选本页」可整页选中）后，底部批量栏提供：复习所选、入队、暂停、恢复、删除（再次点击确认）。
5. 键盘党提示：列表内支持 ↑↓ 移动、回车展开、空格勾选。

### 三、把新卡片放进复习循环

1. 在对话中生成卡片后点「加入卡片库」（见 [12-Anki制卡与模板](12-Anki制卡与模板.md)）。
2. 到「库」标签，筛选「未入队」，勾选后批量「入队」；或在对话里直接点「复习这批」立刻开始。
3. 也可以直接让 AI 帮你入队："把刚才这批卡片加入复习队列"。
4. 入队后卡片从「新卡」状态开始，随着复习逐步进入「学习中 → 复习中」；答错会进入「重新学习」。

### 四、查看学习统计

1. 切到「统计」标签，顶部是调度概览：今日已复习、当前到期、新卡、学习中、复习中、重新学习、已暂停、已入队总数。
2. 下方图表包括：
   - **复习热力图** — 近一年每天的复习活跃度；
   - **每日复习** — 最近若干天的复习量柱状图；
   - **评分分布** — 重来 / 困难 / 良好 / 简单的构成；
   - **卡片状态构成** — 各状态卡片占比；
   - **连续学习** — 当前连续天数、历史最长、活跃日数。
3. 注意：部分活动图表基于每张卡最近一次复习在前端估算，仅供参考趋势。
4. 统计页底部还有「调度设置」区：可调整**每日新卡上限**、**每日复习上限**（0–9999）与**目标保持率**（0.50–0.99）。保存后「今日」页的到期数会随之刷新。想控制每天复习量的用户请到这里设置。

### 五、与知识点掌握度的联动（自动进行，无需配置）

1. 你在题库中的做题成绩（见 [11-题库与练习](11-题库与练习.md)）和闪卡评分会共同回流到"薄弱点画像"。
2. 系统据此对 FSRS 的排期做**有界微调**：
   - 薄弱知识点的卡片会适当**提前**到期，且在到期队列中**优先**出现；
   - 掌握牢固的卡片会**轻微延后**；
   - 调整幅度有严格上限（提前最多约 40% 且不超过 3 天，延后最多约 15% 且不超过 1 天），刚学的短间隔卡不受影响。
3. 你不需要做任何设置——保持正常做题和复习，系统会自动把复习火力集中到薄弱环节。

## 进阶用法

- **触屏 / 触控板滑动评分**：复习时可直接滑动卡片评分——左滑 = 重来，下滑 = 困难，右滑 = 良好，上滑 = 简单，与主流记忆软件手势一致。
- **番茄钟休息时顺手清卡**：学习桌面的番茄钟窗口在短 / 长休息期间，如果有到期卡会显示「去复习 N 张」按钮，点击直接跳到闪卡应用开始到期复习——用休息碎片完成每日复习。
- **让 AI 驱动复习**：在学习桌面模式下，可以让聊天助手"打开闪卡开始今天的复习"——AI 能打开应用、发起到期复习、翻面，但**不会代替你评分**。
- **对话内查询复习状态**：直接问 AI"我现在有多少张卡到期？最近一周复习情况如何？"。
- **模板渲染卡面**：卡片按其 Anki 模板真实渲染（含样式与挖空），填空卡在正面遮住挖空处、背面揭示。

## 📱 移动端说明

- **移动端暂无闪卡应用入口**：闪卡应用依托「学习桌面」模式，而移动端不提供学习桌面。目前手机上无法打开卡片库和今日复习界面。
- **移动端的替代方案**：
  1. 在手机上正常用对话制卡，然后「导出 APKG」，用 AnkiDroid（Android）等应用复习；
  2. 卡片数据在桌面端与移动端之间同步后，回到电脑上完成每日复习（同步配置见 [16-数据管理与云同步](16-数据管理与云同步.md)）。
- 题库的「复习计划」（针对题目的间隔重复）在移动端可正常使用，见 [11-题库与练习](11-题库与练习.md)。

## 常见问题

**Q1：卡片保存进卡片库了，为什么「今日」一直显示没有到期卡？**
A：新保存的卡片默认是「未入队」状态，不会被安排复习。到「库」标签筛选「未入队」，勾选后点「入队」，它们就会作为新卡进入今日队列。

**Q2：四个评分按钮到底怎么选？**
A：凭回忆答案的难易程度：完全忘记选「重来」；勉强想起选「困难」；稍加思考想起选「良好」；立刻想起选「简单」。按钮上会显示对应的下次复习间隔，日常大多数卡评「良好」即可，不必纠结。

**Q3：这套复习和 Anki 是什么关系？必须装 Anki 吗？**
A：不必须。闪卡复习是应用内置的完整复习系统（FSRS 调度，与新版 Anki 同源的算法思路），卡片、进度都存在本地。只有当你想在 Anki 生态里复习时，才需要导出 APKG 或用 AnkiConnect 同步。

**Q4：有些卡片最近老是提前出现，是 bug 吗？**
A：多半不是。如果这些卡对应你最近做题错得多的知识点，系统会把它们适当提前、优先安排（有界偏置）。多复习几轮、掌握度回升后，间隔会恢复正常。

**Q5：误删了一张卡 / 评错了分怎么办？**
A：评分可以撤销——会话中点「撤销评分」或按 Z；卡片库中也有「撤销最近评分」。但**删除卡片不可撤销**，删除前请留意确认提示。

**Q6：可以调整每天的新卡上限、学习步长这些参数吗？**
A：新卡上限可以调。到「统计」标签底部的「调度设置」区，可设置每日新卡上限、每日复习上限和目标保持率（提高保持率会缩短复习间隔、增加复习量），保存即生效。学习步长等更细的参数暂不开放，由调度器自动管理。
