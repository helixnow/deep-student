# 闪卡复习

> 应用内置的间隔重复复习系统：卡片库统一管理数千张记忆卡片，FSRS-6 算法按你的本地时区准确排期，并配合考前今日冲刺统筹每日复习节奏，不装 Anki 也能高效巩固记忆。

## 三步上手

**想每天 10 分钟高效巩固已学知识：**

1. **看今日队列**：打开「闪卡 → 今日」，查看待复习、新卡数量和连续学习天数，点「开始复习」（或按牌组单独复习）。
2. **先想再翻面评分**：看到正面先在脑海回忆答案，按空格 / `Enter` 翻面，对照背面按掌握程度选「重来 / 困难 / 良好 / 简单」（快捷键 `1`–`4`），按钮上直接提示下次复习间隔。
3. **随时找卡与冲刺**：卡片库哪怕存了 5,000 张卡，也支持按 `Ctrl / ⌘ + K` 搜词直达定位到具体那张卡；临近考试时在「今日」页设好考试日期，一键开启「今日冲刺」统筹复习。

## 功能概览

「闪卡」应用是 Deep Student 内置的复习中心，与制卡功能（见 [Anki 制卡与模板](./12-Anki制卡与模板.md)）无缝衔接：

- **今日复习与考前冲刺**：每天打开就能看到到期卡片数、今日进度环和连续学习天数，一键开始复习或按牌组复习；还提供**「今日冲刺 / 考前准备度（Exam Sprint）」**，设置考试日期与每日时间预算后，将到期闪卡、错题 FSRS 与思维导图薄弱节点合并编排。
- **面向大卡库的「库」视图**：集中管理数千张卡片——防抖搜索、按牌组和状态筛选、每页 `20 / 50 / 100 张` 切换、编辑、入队、暂停、批量操作、导入 / 导出 `.apkg` 与 `.csv`，且**自动记住你当前的筛选条件、每页条数、展开行与滚动位置**，编辑或复习返回不丢进度。
- **FSRS-6 本地智能调度**：采用与新版 Anki 同源的 **FSRS-6** 算法，按**本地日历日**计算每日限额、到期日与连续天数（不受夏令时切换影响）；根据每次评分自动计算下次复习时间，复习够多后可在本机一键「用我的复习记录优化」专属节奏，不上传任何学习数据。
- **与知识点掌握度联动**：做题产生的薄弱点画像会小幅影响卡片排期——薄弱知识点的卡片更早到期、优先出现，掌握牢固的适当延后（调整幅度有上限，不会破坏整体节奏）。
- **学习统计**：默认优先读取真实复习日志，提供复习热力图、每日复习量、评分分布、卡片状态构成、**未来 7 天已排定**预测、**记忆曲线**（当前预计回忆率、近 30 天复习答对率、单卡遗忘曲线对比）与**记忆稳固度与难度分布**面板。

卡片来源有好几种：对话里生成后「加入卡片库」、资料右键「用这份资料制卡」、阅读时划词「制卡」、翻译工作台「存为生词闪卡」、音视频字幕 / 讲义制卡、笔记「生成卡片」、思维导图背诵时「背不出的做成卡片」、在卡片库手动新建或制作图片遮挡卡、导入 `.apkg` / `.csv` 牌组，以及让 AI 直接把作文错误点、错题等整理成卡片入队。每张卡都记着来源（来自对话 / 笔记 / 资料 / 音视频 / 制卡任务 / APKG 导入），可以「查看出处」。

## 入口与界面布局

**怎么打开：**

1. 学习桌面：在「全部应用」里打开「闪卡」（右键程序坞图标可「固定到程序坞」，之后角标会显示到期卡片数）。有到期卡时，顶部状态栏也会显示到期数，点击直接开始一轮复习。
2. 经典布局：点左侧导航的「闪卡」，默认进入「复习」分区（同一页面顶部还有「制卡」「模板」分区）。
3. 对话首页：有到期卡时，新会话输入框下方会显示「今日待复习」，点一下直接开始复习。
4. 全局搜索直达：在应用任意位置按 `Ctrl / ⌘ + K` 输入卡片关键词，点击命中的闪卡会直接打开「库」标签并展开聚焦到那张卡。

**界面分区：**

- 顶部三个标签页：
  - **今日** — 今日复习概览与入口（有到期卡时标签上会显示数量角标）；
  - **库** — 卡片库管理；
  - **统计** — 学习统计报表与调度设置。
- 开始复习后进入全屏的复习会话界面：中间是卡面，底部是评分栏，顶部显示进度与用时。

## 核心操作

### 一、每天的复习流程

1. 打开「闪卡」→「今日」标签，查看：待复习、新卡、学习中的数量，今日进度环（今日已复习 / 剩余），以及「连续学习 N 天」。
2. 点「开始复习」进入复习会话。到期卡较多时系统会分批进行，提示「本轮先练前 N 张」。
3. 对每张卡：
   - 先回忆答案，然后**翻面**——点击卡片，或按空格 / `Enter`；
   - 对照背面内容，按掌握程度评分：**重来**（没回忆出正确答案）、**困难**（回忆正确，但很费力）、**良好**（正常回忆正确）、**简单**（迅速、轻松地想起）。每个评分按钮上会显示这样评分后的下次复习间隔；
   - 必须先翻面才能评分。
4. **想多学几张新卡**：新卡超过了每日上限、还有卡在排队时，「今日」页会出现「今天多学 N 张」（一次最多 10 张，取最早的待学新卡），评分照常记进复习记录，每日上限不变；旁边的「调整每日新卡上限」直接跳到调度设置。
5. 一批复习完出现小结：本轮已评张数、回忆率、用时、最长连击和评分分布；如果还有到期卡会提示「本批结束，仍有 N 张到期」，可继续下一批或「返回今日」。
6. 当天全部完成后，「今日」页会显示「今日复习全部完成」。

**按牌组复习**：卡片属于多个牌组时（如 AI 按「学科::主题」分的牌组），「今日」页下方有「按牌组复习」，以牌组树列出每个牌组的「到期 N」「新卡 N」，有子牌组的可以展开。

- 点「复习 N」只复习这个牌组（含子牌组）的到期卡；没有到期卡时按钮是「学 N 张新卡」（一次最多 10 张）。
- 评分照常记录，不影响全局的到期队列和每日上限。
- 行尾的书本图标「在卡片库查看」会打开卡片库并筛到这个牌组。没有分牌组的卡归在「未分组」。

**复习会话中的更多操作：**

- **撤销评分**：手滑评错了点「撤销评分」（或按 `Z` / `Ctrl+Z`），回到上一张重新评；本轮会话内可**逐级连续撤销**最近的多次评分（不再只有最近一步）。若某张卡在此期间被其他入口改动过，对应步骤会自动跳过以免回退到过期状态。
- **编辑卡片**：点「编辑卡片」（或按 `E`）直接修改正面 / 背面和标签；填空卡的正面必须保留有效的挖空标记。
- **暂停卡片**：暂时不想复习这张卡，点「暂停卡片」把它移出调度，之后可在卡片库恢复。
- **查看出处**：忘了一张卡时，点工具栏或菜单里的「查看出处」，支持**语义锚点**与 **PDF 页码精确回跳**，直接回到它来自的笔记段落、PDF 对应页、思维导图或生成它的对话；来自**音视频**的卡片在翻面后会显示**「`▶ 回看 mm:ss`」**按钮，点击直接跳回原视频该时刻，如果评了「重来」，底部的 **8 秒撤销条**中也会同步提供回看入口，方便立刻回去重听片段。导入或手动新建的卡没有出处，会提示一声。
- **问 AI 这张卡**：新开一个对话，把卡片正反面填进输入框，请 AI 讲清考点、给个好记的办法并出 1 道小题检验你（不自动发送，可以先补充自己卡在哪）。
- **埋藏到明天**：今天不想再看到这张卡，按 `-` 或点「埋藏到明天」，明天它会自动回来；刚埋藏的卡可以立刻「取消埋藏」。同一笔记的兄弟卡（如正反卡、同一篇填空的其他空）在评分后会自动埋藏到明天，避免背靠背出现（可在调度设置里关闭）。
- **跳过**：按 `S` 跳过当前卡。
- **音频**：卡面里的音频会自动播放，按 `R` 重播；带提示折叠、链接的卡面可以直接点开，点卡面空白处照常翻面。
- **键盘评分**：翻面后按 `1`–`4` 分别对应重来 / 困难 / 良好 / 简单；已翻面时再按空格 / `Enter` 相当于评「良好」。

### 二、管理卡片库（支持数千张大卡库记忆与直达定位）

1. **分页与大卡库顺畅浏览**：切到「库」标签查看全部卡片。针对 **5,000+ 张卡片**的大卡库，底部分页导航支持切换「每页」显示数量（**`20 张` / `50 张` / `100 张`**），并提供「首页」「上一页」「下一页」与页码直达。
2. **会话状态记忆（切页/复习回来不迷路）**：你在卡片库里设好的**搜索词、牌组筛选、状态筛选、排序方式、页码、每页条数、当前展开的卡片行以及滚动位置**，都会在本次会话中自动记住。无论你是行内编辑保存了一张卡、点进去单卡复习再返回、在「今日 / 库 / 统计」标签间切换，还是关闭重开闪卡窗口，回到「库」时依然稳稳停在你刚才查看的那一页与那一行。
3. **`Ctrl / ⌘ + K` 直达单张卡片**：在应用任何地方按 `Ctrl / ⌘ + K` 打开命令面板，输入卡片正/背面或标签关键词，在「闪卡」分组中点击目标卡片，系统会**直接切到「库」标签，自动带上对应牌组与搜索词，并展开滚动聚焦到那张卡片**，省去手动翻页找卡。
4. **搜索与筛选**：顶部搜索框按正面 / 背面 / 标签搜索；只要卡片库中存在**任意 1 个具名牌组**，筛选器就会显示「牌组」下拉（「全部牌组」或某个牌组，含子牌组），各状态计数随之按这个牌组统计；筛选器可按状态过滤——全部、已到期、新卡、学习中、复习中、已暂停、未入队，筛选和计数针对整个卡片库，不只是当前页。「已到期」指到期的学习卡和复习卡，没学过的新卡不算。排序支持按到期时间、创建时间、字母顺序升 / 降序。
5. **单卡操作**：展开卡片详情可查看状态、到期时间、创建时间、标签和最近评分；可对单卡执行：
   - 「复习」— 立即单独复习这张卡；
   - 「入队」— 把尚未参与调度的卡加入 FSRS 复习队列（新保存的卡默认「未入队」，入队后才会被安排复习）；
   - 「暂停 / 恢复」— 移出或移回调度；
   - 「编辑」— 修改正面、背面和标签（逗号分隔）；
   - 「查看来源」——回到生成这张卡的对话、笔记或资料（音视频卡支持「跳到课程 mm:ss 处播放」）；
   - 「重置进度」（清除这张卡的全部复习记录，需再次点击确认）、「撤销最近评分」、「删除」（删除不可撤销，会二次确认）。
6. **批量操作**：勾选多张卡（「全选本页」可整页选中，支持 `Shift` 连选）后，底部批量栏提供：复习所选、入队、暂停、恢复、删除（再次点击确认）。列表内支持 `↑ / ↓` 移动、回车展开、空格勾选。
7. **手动新建与图片遮挡卡**：点「新建卡片」，填写「卡片正面」「卡片背面」，并可选择或输入**「所属牌组（可选）」**（若当前卡片库正在按某个牌组筛选，会自动沿用该牌组），点「保存并入队」后直接进入复习队列；也可以点「新建图片遮挡卡」上传或粘贴图片、框选遮挡区域批量制作遮挡卡。
8. **导入 / 导出牌组**：
   - **「导入 .apkg」 / 「导入 .csv」**：导入本地 Anki 牌组或 CSV / TSV 表格。在 Anki 里复习过的卡会沿用原来的复习进度（开过 FSRS 直接沿用，旧 SM-2 自动换算）；卡片里的图片和音频一并导入并在桌面端与浏览器 WebUI 完整渲染。
   - **「导出 .apkg」 / 「导出 .csv」**：勾选卡片时仅导出选中项，未勾选时导出整个卡片库。导出的 `.apkg` 保留模板、样式、排期、FSRS 记忆状态与复习记录，导入 Anki / AnkiDroid 后可接着复习。

### 三、把新卡片放进复习循环

1. 在对话中生成卡片后点「加入卡片库」（见 [Anki 制卡与模板](./12-Anki制卡与模板.md)）。
2. 到「库」标签，筛选「未入队」，勾选后批量「入队」；或在对话里直接点「复习这批」立刻开始。
3. 也可以直接让 AI 帮你入队：「把刚才这批卡片加入复习队列」。
4. 入队后卡片从「新卡」状态开始，随着复习逐步进入「学习中 → 复习中」；答错会进入「重新学习」。

### 四、查看学习统计与本地日历日调度设置

1. 切到「统计」标签，顶部是「调度概览」：今日已复习、当前到期、新卡库存、学习中、复习中、重新学习、已暂停、已入队总数。
2. 统计报表**默认优先读取真实复习日志**计算（仅在缺少完整日志的早期记录中回退估算），涵盖以下图表与面板：
   - **复习热力图** — 近一年每天的复习活跃度；
   - **每日复习** — 最近若干天的复习量柱状图；
   - **未来 7 天已排定** — 柱状图展示未来 7 天每天预计到期的已学卡片数量，方便提前安排节奏；
   - **记忆曲线** — 展示整体**当前预计回忆率**、**近 30 天复习答对率**，并支持查看**单卡遗忘曲线对比**与单卡完整复习历史，直观感受记忆衰减与每次复习后的巩固；
   - **记忆稳固度与难度分布** — 展示到期卡片的记忆稳固度（预计能记多久）与题目难度分布，需要时可点「展开 21 项参数明细」查看当前 FSRS-6 参数；
   - **评分分布** — 重来 / 困难 / 良好 / 简单的构成；
   - **卡片状态构成** — 各状态卡片占比；
   - **连续学习** — 当前连续天数、历史最长、活跃日数。
3. 统计页底部是「调度设置」区：
   - **每日新卡上限**、**每日复习上限**（0–9999）与**目标记忆保持率**（0.50–0.99，推荐 0.90）；
   - **学习步 / 重学步**：用空格分隔，单位 `s / m / h / d`，默认「1m 10m」与「10m」，与 Anki 相同；FSRS 建议都在当天完成；
   - **提前复习分钟数（0 关闭）**：允许将即将到期的学习中卡片提前若干分钟拉入本轮队列，减少零散等待；
   - **下一天开始于（点）与本地零点保护**：默认凌晨 4 点（4 点前复习仍算前一天，适合晚睡作息）。所有每日限额、到期日翻天与连续学习天数均严格按**你的本地日历日**计算，采用纯日历日算法——即使你身处实行**夏令时（DST）**的地区，一年两次 23 小时 / 25 小时的时间跳变也绝不会错算到期日或意外断掉连续学习记录；
   - **最大间隔（天）**、**间隔微调打散**（默认开启，微调并打散同一天学的卡，避免将来同一天扎堆到期）；
   - **复习卡顺序**（按到期先后 / 最可能忘的先 / 随机）、**新卡位置**（复习之后 / 复习之前 / 穿插在复习中）、**埋藏同笔记的新卡 / 复习卡到明天**、**作答计时上限（秒）**（默认 60 秒）；
   - **个性化记忆节奏**：点「用我的复习记录优化」，全部在**本机直接完成计算**（不上传任何数据、也无需安装额外插件），基于你的真实复习日志调校专属参数；只有新参数预测更准才会采用，并重新估算每张卡的记忆状态（不改变已经排好的到期日）。每月优化一次即可，随时可点「恢复默认参数」。
   保存后「今日」页的到期数会随之刷新。

### 五、今日冲刺与考前准备度（Exam Sprint）

备考阶段往往同时背负闪卡、错题和导图知识点，「今日冲刺 / 考前准备度」把它们合成一条清晰的每日冲刺队列：

1. 在闪卡「今日」页设置你的**考试日期**与**每日时间预算**，系统会计算并展示当前的**考前准备度**，按剩余天数与时间预算动态编排每天的冲刺任务。
2. **统一编排三类复习来源**：将**到期闪卡**、**错题 FSRS 复习队列**（见 [题目集与练习](./11-题库与练习.md)）和**思维导图背诵薄弱节点**（见 [思维导图](./08-思维导图.md)）合并到同一轮冲刺中，也可以从待办顶部的「今日学习汇总」卡片一键点「开始今日冲刺」进入。
3. **考前 3 天缓冲期**：临近考试的最后 3 天会自动进入缓冲期，**暂停投放新卡**，把有限时间集中用于巩固已学内容和消灭薄弱点。

### 六、与知识点掌握度的联动（自动进行，无需配置）

1. 你在题库中的做题成绩（见 [题目集与练习](./11-题库与练习.md)）和闪卡评分会共同回流到「薄弱点画像」。
2. 系统据此对 FSRS 的排期做**有界微调**：
   - 薄弱知识点的卡片会适当**提前**到期，且在到期队列中**优先**出现；
   - 掌握牢固的卡片会**轻微延后**；
   - 调整幅度有严格上限（提前最多约 40% 且不超过 3 天，延后最多约 15% 且不超过 1 天），刚学的短间隔卡不受影响。
3. 你不需要做任何设置——保持正常做题和复习，系统会自动把复习火力集中到薄弱环节。

## 进阶用法

- **触屏 / 触控板滑动评分**：复习时可直接滑动卡片评分——左滑 = 重来，下滑 = 困难，右滑 = 良好，上滑 = 简单，与主流记忆软件手势一致。
- **番茄钟休息时顺手清卡**：学习桌面的番茄钟窗口在短 / 长休息期间，如果有到期卡会显示「去复习 N 张」按钮，点击直接跳到闪卡应用开始到期复习——用休息碎片完成每日复习。
- **让 AI 驱动复习**：在学习桌面模式下，可以让聊天助手「打开闪卡开始今天的复习」——AI 能打开应用、发起到期复习、翻面，但**不会代替你评分**。
- **对话内查询复习状态**：直接问 AI「我现在有多少张卡到期？最近一周复习情况如何？」。
- **模板渲染卡面**：卡片按其 Anki 模板真实渲染（含样式、挖空、音视频媒体与公式排版），填空卡在正面遮住挖空处、背面揭示。

## 常见问题

**Q1：卡片保存进卡片库了，为什么「今日」一直显示没有到期卡？**
A：新保存的卡片默认是「未入队」状态，不会被安排复习。到「库」标签筛选「未入队」，勾选后点「入队」，它们就会作为新卡进入今日队列。

**Q2：四个评分按钮到底怎么选？**
A：凭回忆答案的难易程度：没回忆出选「重来」；回忆正确但很费力选「困难」；正常想起选「良好」；迅速轻松想起选「简单」。按钮上会显示对应的下次复习间隔，日常大多数卡评「良好」即可，不必纠结。

**Q3：这套复习和 Anki 是什么关系？必须装 Anki 吗？**
A：不必须。闪卡复习是应用内置的完整复习系统（FSRS-6 调度，与新版 Anki 同源），卡片、进度都存在本地。只有当你想在 Anki 生态里复习时，才需要导出 APKG 或用 AnkiConnect 同步。

**Q4：有些卡片最近老是提前出现，是 bug 吗？**
A：多半不是。如果这些卡对应你最近做题错得多的知识点，系统会把它们适当提前、优先安排（有界偏置）。多复习几轮、掌握度回升后，间隔会恢复正常。

**Q5：在几千张卡片的卡库里编辑或复习完一张卡，会跳回第 1 页吗？**
A：不会。卡片库会自动记住你的页码、每页显示条数（`20 / 50 / 100 张`）、搜索词、牌组 / 状态筛选、展开行和滚动位置，编辑或单卡复习返回后仍留在原位。想快速找到某张特定卡片，也可以直接按 `Ctrl / ⌘ + K` 搜索卡片内容一键直达并展开。

**Q6：误删了一张卡 / 评错了分怎么办？**
A：评分可以撤销——会话中点「撤销评分」或按 `Z`；卡片库中也有「撤销最近评分」。但**删除卡片不可撤销**，删除前请留意确认提示。

**Q7：可以调整每天的新卡上限、学习步长或熬夜跨天时间吗？**
A：可以。到「统计」标签底部的「调度设置」区，可设置每日新卡 / 复习上限、目标记忆保持率、学习步与重学步、提前复习分钟数（`0` 关闭）、「下一天开始于（点）」（按本地日历日且不受夏令时影响）、最大间隔、间隔微调打散、复习顺序等，保存即生效。也可以在对话里直接让 AI 帮你改每日上限、保持率等常用项，例如「把每日新卡上限调到 50」。
