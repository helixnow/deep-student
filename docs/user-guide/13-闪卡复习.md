# 闪卡复习

> 应用内置的间隔重复复习系统：卡片库统一管理你的所有记忆卡片，FSRS 算法安排每张卡的最佳复习时机，不装 Anki 也能坚持每天复习。

## 功能概览

「闪卡」应用是 Deep Student 内置的复习中心，与制卡功能（见 [Anki 制卡与模板](./12-Anki制卡与模板.md)）无缝衔接：

- **今日复习**：每天打开就能看到到期卡片数、今日进度环和连续学习天数，一键开始复习。
- **卡片库**：集中管理所有卡片——搜索、筛选、编辑、入队、暂停、批量操作，也能手动新建卡片、导入 / 导出 Anki 牌组（.apkg）。
- **FSRS 智能调度**：与新版 Anki 同一套 FSRS-6 算法（fsrs-rs），根据你每次的评分（重来 / 困难 / 良好 / 简单）自动计算下次复习时间，评分按钮上直接显示预测间隔；复习够多后可以「用我的复习记录优化」参数，让排期贴合你自己的记忆规律。
- **与知识点掌握度联动**：做题产生的薄弱点画像会小幅影响卡片排期——薄弱知识点的卡片更早到期、优先出现，掌握牢固的适当延后（调整幅度有上限，不会破坏整体节奏）。
- **学习统计**：复习热力图、每日复习量、评分分布、卡片状态构成、连续学习记录，以及分时段的真实保留率、难度 / 稳定度 / 可提取率分布和每日作答时长。

卡片来源有好几种：对话里生成后「加入卡片库」、资料右键「用这份资料制卡」、阅读时划词「制卡」、笔记「生成卡片」、在卡片库手动新建、导入 .apkg 牌组，以及让 AI 直接把作文错误点、错题等整理成卡片入队。每张卡都记着来源（来自对话 / 笔记 / 资料 / 制卡任务 / APKG 导入），可以「查看来源」。

## 入口与界面布局

**怎么打开：**

1. 学习桌面：在「全部应用」里打开「闪卡」（右键 Dock 上的图标可「固定到 Dock」，之后角标会显示到期卡片数）。有到期卡时，顶部状态栏也会显示到期数，点击直接开始一轮复习。
2. 经典布局：点左侧导航的「闪卡」，默认进入「复习」分区（同一页面顶部还有「制卡」「模板」分区）。
3. 对话首页：有到期卡时，新会话输入框下方会显示「今日待复习」，点一下直接开始复习。

**界面分区：**

- 顶部三个标签页：
  - **今日** — 今日复习概览与入口（有到期卡时标签上会显示数量角标）；
  - **库** — 卡片库管理；
  - **统计** — 学习统计报表。
- 开始复习后进入全屏的复习会话界面：中间是卡面，底部是评分栏，顶部显示进度与用时。

## 核心操作

### 一、每天的复习流程

1. 打开「闪卡」→「今日」标签，查看：待复习、新卡、学习中的数量，今日进度环（已复习 / 剩余），以及「连续学习 N 天」。
2. 点「开始复习」进入复习会话。到期卡较多时系统会分批进行，提示"本轮先练前 N 张"。
3. 对每张卡：
   - 先回忆答案，然后**翻面**——点击卡片，或按空格 / Enter；
   - 对照背面内容，按掌握程度评分：**重来**（完全忘记）、**困难**（勉强想起）、**良好**（稍加思考想起）、**简单**（立刻想起）。每个评分按钮上会显示这样评分后的下次复习间隔；
   - 必须先翻面才能评分。
4. 一批复习完出现小结：本轮已评张数、用时、最长连击和评分分布；如果还有到期卡会提示"仍有 N 张到期"，可继续下一批或「返回今日」。
5. 当天全部完成后，「今日」页会显示"今日复习全部完成"。

**复习会话中的更多操作：**

- **撤销评分**：手滑评错了点「撤销评分」（或按 Z / Ctrl+Z），回到上一张重新评；本轮会话内可**逐级连续撤销**最近的多次评分（不再只有最近一步）。若某张卡在此期间被其他入口（如 AI 代评）改动过，对应步骤会自动跳过以免回退到过期状态。
- **编辑卡片**：点「编辑卡片」（或按 E）直接修改正面 / 背面和标签；填空卡的正面必须保留有效的挖空标记。
- **暂停卡片**：暂时不想复习这张卡，点「暂停卡片」把它移出调度，之后可在卡片库恢复。
- **埋藏到明天**：今天不想再看到这张卡，按 - 或点「埋藏到明天」，明天它会自动回来；刚埋藏的卡可以立刻「取消埋藏」。同一笔记的兄弟卡（如正反卡、同一篇填空的其他空）在评分后会自动埋藏到明天，避免背靠背出现（可在调度设置里关闭）。
- **跳过**：按 S 跳过当前卡。
- **音频**：卡面里的音频会自动播放，按 R 重播；带提示折叠、链接的卡面可以直接点开，点卡面空白处照常翻面。
- **键盘评分**：翻面后按 1–4 分别对应重来 / 困难 / 良好 / 简单；已翻面时再按空格 / Enter 相当于评"良好"。

### 二、管理卡片库

1. 切到「库」标签，查看全部卡片（分页显示，底部「上一页 / 下一页」）。
2. **搜索与筛选**：顶部搜索框按正面 / 背面 / 标签搜索；筛选器可按状态过滤——全部、已到期、新卡、学习中、复习中、已暂停、未入队，筛选和计数针对整个卡片库，不只是当前页。「已到期」指到期的学习卡和复习卡，没学过的新卡不算。排序支持按到期时间、创建时间、字母顺序升 / 降序。
3. **单卡操作**：展开卡片详情可查看状态、到期时间、创建时间、标签和最近评分；可对单卡执行：
   - 「复习」— 立即单独复习这张卡；
   - 「入队」— 把尚未参与调度的卡加入 FSRS 复习队列（新保存的卡默认"未入队"，入队后才会被安排复习）；
   - 「暂停 / 恢复」— 移出或移回调度；
   - 「编辑」— 修改正面、背面和标签（逗号分隔）；
   - 「查看来源」——回到生成这张卡的对话、笔记或资料；
   - 「重置进度」（清除这张卡的全部复习记录，需再次点击确认）、「撤销最近评分」、「删除」（删除不可撤销，会二次确认）。
4. **批量操作**：勾选多张卡（「全选本页」可整页选中）后，底部批量栏提供：复习所选、入队、暂停、恢复、删除（再次点击确认）。
5. 键盘党提示：列表内支持 ↑↓ 移动、回车展开、空格勾选。
6. **手动新建**：点「新建卡片」，填写「卡片正面」「卡片背面」，「保存并入队」后直接进入复习队列。
7. **导入 Anki 牌组**：点「导入 .apkg」选择本地牌组。导入的卡片会加入复习；在 Anki 里复习过的卡会沿用原来的复习进度——在 Anki 里开过 FSRS 的卡直接沿用其记忆状态，否则按 Anki 官方公式从 SM-2 排期换算。卡片里的图片和音频会一并导入，字段里的格式按原样显示。
8. **导出 Anki 牌组**：点「导出 .apkg」，导出为保留模板和样式的 Anki 牌组；勾选了卡片时「导出选中」，没勾选就导出整个卡片库（导出后都在同一个牌组里，原来的牌组层级保留在标签中）。在本应用里复习过的卡会连同排期、FSRS 记忆状态和复习记录一起导出，导入 Anki / AnkiDroid 后可以接着复习。

### 三、把新卡片放进复习循环

1. 在对话中生成卡片后点「加入卡片库」（见 [Anki 制卡与模板](./12-Anki制卡与模板.md)）。
2. 到「库」标签，筛选「未入队」，勾选后批量「入队」；或在对话里直接点「复习这批」立刻开始。
3. 也可以直接让 AI 帮你入队："把刚才这批卡片加入复习队列"。
4. 入队后卡片从「新卡」状态开始，随着复习逐步进入「学习中 → 复习中」；答错会进入「重新学习」。

### 四、查看学习统计

1. 切到「统计」标签，顶部是调度概览：今日已复习、当前到期、新卡、学习中、复习中、重新学习、已暂停、已入队总数。
2. 下方图表包括：
   - **复习热力图** — 近一年每天的复习活跃度；
   - **每日复习** — 最近若干天的复习量柱状图；
   - **评分分布** — 重来 / 困难 / 良好 / 简单的构成；
   - **卡片状态构成** — 各状态卡片占比；
   - **连续学习** — 当前连续天数、历史最长、活跃日数。
3. 注意：部分活动图表基于每张卡最近一次复习在前端估算，仅供参考趋势。
4. 统计页底部还有「调度设置」区：
   - **每日新卡上限**、**每日复习上限**（0–9999）与**目标保持率**（0.50–0.99）；
   - **学习步 / 重学步**：用空格分隔，单位 s / m / h / d，默认「1m 10m」与「10m」，与 Anki 相同；FSRS 建议都在当天完成；
   - **下一天开始于**：默认凌晨 4 点，4 点前复习仍算前一天，适合晚睡的作息；
   - **最大间隔**、**间隔随机抖动**（默认开启，打散同一天学的卡，避免将来同一天扎堆到期）；
   - **复习卡顺序**（按到期 / 最可能忘的先 / 随机）、**新卡位置**（复习后 / 复习前 / 穿插）、**兄弟卡埋藏**、**作答计时上限**（默认 60 秒）；
   - **参数个性化**：点「用我的复习记录优化」，用与 Anki 相同的优化器训练参数；新参数预测更准才会采用，并按新参数重新估算每张卡的记忆状态（不改变已经排好的到期日）。每月优化一次就够。
   保存后「今日」页的到期数会随之刷新。

### 五、与知识点掌握度的联动（自动进行，无需配置）

1. 你在题库中的做题成绩（见 [题目集与练习](./11-题库与练习.md)）和闪卡评分会共同回流到「薄弱点画像」。
2. 系统据此对 FSRS 的排期做**有界微调**：
   - 薄弱知识点的卡片会适当**提前**到期，且在到期队列中**优先**出现；
   - 掌握牢固的卡片会**轻微延后**；
   - 调整幅度有严格上限（提前最多约 40% 且不超过 3 天，延后最多约 15% 且不超过 1 天），刚学的短间隔卡不受影响。
3. 你不需要做任何设置——保持正常做题和复习，系统会自动把复习火力集中到薄弱环节。

## 进阶用法

- **触屏 / 触控板滑动评分**：复习时可直接滑动卡片评分——左滑 = 重来，下滑 = 困难，右滑 = 良好，上滑 = 简单，与主流记忆软件手势一致。
- **番茄钟休息时顺手清卡**：学习桌面的番茄钟窗口在短 / 长休息期间，如果有到期卡会显示「去复习 N 张」按钮，点击直接跳到闪卡应用开始到期复习——用休息碎片完成每日复习。
- **让 AI 驱动复习**：在学习桌面模式下，可以让聊天助手"打开闪卡开始今天的复习"——AI 能打开应用、发起到期复习、翻面，但**不会代替你评分**。
- **对话内查询复习状态**：直接问 AI"我现在有多少张卡到期？最近一周复习情况如何？"。
- **模板渲染卡面**：卡片按其 Anki 模板真实渲染（含样式与挖空），填空卡在正面遮住挖空处、背面揭示。

## 📱 移动端说明

- **入口**：在抽屉的应用启动器里点「闪卡」，功能与桌面端一致（今日复习、卡片库、统计与调度设置）。
- **复习手势**：滑动卡片评分的手势在手机上同样可用。
- **用 AnkiDroid 复习**：也可以在卡片库「导出 .apkg」，导入 AnkiDroid 等应用复习（同步配置见 [数据管理与云同步](./16-数据管理与云同步.md)）。
- 题库的「复习计划」（针对题目的间隔重复）在移动端可正常使用，见 [题目集与练习](./11-题库与练习.md)。

## 常见问题

**Q1：卡片保存进卡片库了，为什么「今日」一直显示没有到期卡？**
A：新保存的卡片默认是「未入队」状态，不会被安排复习。到「库」标签筛选「未入队」，勾选后点「入队」，它们就会作为新卡进入今日队列。

**Q2：四个评分按钮到底怎么选？**
A：凭回忆答案的难易程度：完全忘记选「重来」；勉强想起选「困难」；稍加思考想起选「良好」；立刻想起选「简单」。按钮上会显示对应的下次复习间隔，日常大多数卡评「良好」即可，不必纠结。

**Q3：这套复习和 Anki 是什么关系？必须装 Anki 吗？**
A：不必须。闪卡复习是应用内置的完整复习系统（FSRS 调度，与新版 Anki 同源的算法思路），卡片、进度都存在本地。只有当你想在 Anki 生态里复习时，才需要导出 APKG 或用 AnkiConnect 同步。

**Q4：有些卡片最近老是提前出现，是 bug 吗？**
A：多半不是。如果这些卡对应你最近做题错得多的知识点，系统会把它们适当提前、优先安排（有界偏置）。多复习几轮、掌握度回升后，间隔会恢复正常。

**Q5：误删了一张卡 / 评错了分怎么办？**
A：评分可以撤销——会话中点「撤销评分」或按 Z；卡片库中也有「撤销最近评分」。但**删除卡片不可撤销**，删除前请留意确认提示。

**Q6：可以调整每天的新卡上限、学习步长这些参数吗？**
A：可以。到「统计」标签底部的「调度设置」区，可设置每日新卡 / 复习上限、目标保持率（提高保持率会缩短复习间隔、增加复习量）、学习步与重学步、下一天开始的时间、最大间隔、复习顺序等，保存即生效。也可以在对话里直接让 AI 帮你改每日上限、保持率等常用项，例如"把每日新卡上限调到 50"（AI 通过闪卡调度设置工具读写同一份配置）。
