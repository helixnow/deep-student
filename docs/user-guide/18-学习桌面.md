# 学习桌面

> 桌面端（Windows / macOS / Linux）默认窗口化工作台：用学习流阶段预设一键排布多窗，状态栏集中掌控今日节律、AI 桌面操控与紧急断电，支持 UI 插件扩展。

## 功能概览

- **桌面端专属默认界面**：学习桌面**仅适用于 Windows、macOS、Linux 桌面端**，安装后默认直接进入。Android 移动端（使用抽屉导航，见 [移动端指南](./17-移动端指南.md)）与 WebUI 均不使用窗口化学习桌面。
- **一切皆窗口**：对话、资源库、笔记、题目集、闪卡、AI 仪表盘、插件工坊、设置等都是独立窗口；每份教材、笔记、题目集也可各自开窗，同一个应用还能同时开多个窗口并排对照。
- **学习流阶段预设与空间联动**：顶部状态栏提供一键切换的认知阶段分屏预设，并可与学习空间联动自动保存和恢复窗口布局快照。
- **随时可退回经典布局**：如果不习惯窗口化，随时可切回「左侧导航 + 单页」的经典布局；桌面上的窗口布局会被保留，下次切回来仍在。

## 界面组成

| 区域 | 位置 | 作用 |
|---|---|---|
| 状态栏 | 屏幕顶部 | 品牌菜单、当前应用与窗口菜单、学习流阶段预设切换器、搜索/设置、今日节律、AI 桌面操控与紧急断电、时钟与今日日程 |
| 桌面 | 中间 | 窗口摆放区；右侧可显示「日程」与「AI 学习简报」双组件，双击空白处可显示桌面 |
| Dock | 屏幕底部 | 打开常用应用、查看运行标记，以及右侧的「全部应用」与「AI 桌面操控」入口 |

### 顶部状态栏

从左到右，状态栏集中了桌面端的核心控制能力：

1. **品牌菜单（DeepStudent 图标）**：打开学习桌面菜单，支持「重命名桌面…」「全部应用」「键盘快捷键」「系统设置…」「退出学习桌面」。
2. **当前聚焦应用菜单与「窗口」菜单**：随当前焦点窗口自动切换专属应用菜单；旁边的**「窗口」菜单**集中提供窗口平铺、最小化、恢复和打开窗口列表切换。
3. **中央「学习流阶段预设切换器」**：一键把桌面窗口编排为确定性的学习布局（切入预设时无关窗口会被最小化而非关闭，绝不丢失未保存草稿）：
   - **精读导图**：左栏阅读讲义、文档或音视频，右栏同步构建思维导图与笔记；
   - **笔记共创**：左栏沉浸写作笔记与导图，右栏 AI 对话实时共创；
   - **刷题订正**：左栏闪卡复习或题目集作答，右栏错题笔记与 AI 诊断；
   - **自由桌面**：将平铺窗口恢复为自由浮动排布；
   - 切换器旁还支持一键开关**伴读侧栏**（如 AI 伴读侧栏）与**双读对照**（双源阅读 + 导图汇聚）。
4. **搜索与设置**：放大镜图标打开「全部应用」（`⌘K` / `Ctrl+K`），齿轮图标打开系统设置。
5. **今日节律**：汇总今日到期闪卡、**今日到期错题**、**待复习笔记**、进行中的制卡任务、番茄钟专注状态与定时自动化健康状态。点开可查看明细并直接跳转到对应应用开始复习或处理。
6. **AI 桌面操控控制中心与「紧急断电」开关**：
   - 点开可实时切换 AI 操控方式（跟随 / 后台 / 关闭），查看支持语义操控的 8 个学习应用能力清单；
   - 内置**「紧急断电」**红色开关：二次确认后**一键立即停止全部正在运行的 Agent 并暂停所有定时自动化**。
   - **分步安全恢复**：断电后状态栏会显示「Agent 已断电」横幅。恢复时分两步进行——先点击「恢复 Agent」，确认环境无误后再单独点击「恢复自动化」（并再次确认），避免定时任务在未就绪时立即触发。
7. **时钟与今日日程**：最右侧显示实时时钟，点击展开「今日日程」浮层，快速查看或勾选今天的待办事项。

### 桌面区域、双组件与右键菜单

- **右侧双桌面组件**：桌面右侧默认展示 **`日程`** 与 **`AI 学习简报`** 两个桌面组件。两张卡片既可以在设置中分别开关，也可以在组件标题栏点击折叠，方便在窄屏时腾出工作区宽度。
- **双击空白处显示桌面**：在桌面空白区域双击，可以快速触发「显示桌面」（最小化全部窗口 / 再操作恢复）。
- **桌面右键菜单**：在桌面空白处右键，可直接执行「新建对话」「打开资源库」「全部应用…」「整理窗口（平铺全部窗口 / 窗口俯瞰）」「桌面壁纸（含管理壁纸…与自定义图片）」「视觉材质」切换、「显示桌面组件」开关、「显示桌面 / 恢复窗口」「键盘快捷键」以及「桌面设置…」。

### Dock

默认固定四个应用：「对话」「资源库」「设置」「待办」；最右边是「全部应用」和「AI 桌面操控」快捷入口。正在运行的应用图标下方会有圆点标记。

在 Dock 图标上右键，可以「新建窗口」「显示全部窗口」「关闭全部窗口」，或「固定到 Dock」「从 Dock 移除」。常用的应用（比如「闪卡」「AI 仪表盘」「插件工坊」）都可以固定上去。

### 全部应用

点 Dock 右侧的「全部应用」或按 `⌘K` / `Ctrl+K` 打开。支持搜索**应用、命令、资源和聊天记录**，`↑` / `↓` 选择、`Enter` 打开、`Esc` 关闭，可在网格与列表视图间切换。

当前共内置 **16 个官方应用**（在「设置 → 学习桌面」开启「内置浏览器」后为 **17 个**）：

- **对话**、**资源库**、**笔记**、**题目集**、**翻译**、**作文批改**、**音视频**
- **待办**、**闪卡**、**Anki制卡**、**模板管理**、**技能管理**、**番茄钟**
- **AI 仪表盘**、**[插件工坊](./20-AI插件工坊与插件管理.md)**、**设置**
- **浏览器**（可选，在「设置 → 学习桌面」开启「内置浏览器」后出现）

此外，通过插件工坊安装的**第三方 UI 插件页面会自动镜像进入「全部应用」**，你可以像内置应用一样搜索、打开独立窗口或将其固定到 Dock。

## 核心操作

### 第一次打开与布局快照恢复

- 桌面上没有打开窗口时保持清爽壁纸，可通过底部 Dock、桌面快捷方式或右键菜单快速打开任意应用；存在可恢复的上次桌面快照时，顶部居中会显示轻量的「恢复上次桌面」胶囊。
- **退出保存与启动恢复**：关闭应用时当前窗口状态会自动保存，下次启动时可在空桌面点击「恢复上次桌面（N 个窗口）」一键还原；若想每次启动自动恢复，到「设置 → 学习桌面」开启「启动时自动恢复上次桌面」（默认关闭以加快启动）。
- **与学习空间联动的布局快照恢复**：在学习空间设置里绑定「学习桌面布局预设」后，切换学习空间时系统会自动保存前一个空间的窗口布局，并恢复目标空间的窗口布局快照（同时提示「已恢复空间桌面布局」），不同科目各有一套整洁的工作台。

### 打开应用和资料

- **应用**：点 Dock 图标，或在「全部应用」里搜索启动。
- **资料**：在「资源库」里双击，教材、题目集、翻译、作文批改、图片、文件会各自开成窗口；笔记与思维导图在对应工作区窗口打开。
- **会话**：在「对话」窗口的会话列表里，点会话右侧的「…」→「在新窗口打开」，即可把多个会话并排对比。

### 摆放窗口

- **移动和缩放**：拖动标题栏移动窗口，拖动窗口边缘调整大小。
- **拖到边缘平铺**：把窗口拖到屏幕左 / 右边松手占半屏；拖到四个角占四分之一屏；拖到顶部填满桌面；拖到底边中间占下半屏。拖动时按住 `⌥`（Windows / Linux 为 `Alt`），吸附热区会变大，按住 `⌥` / `Alt` 拖到顶边则平铺为上半屏。
- **标题栏三个圆点**：红色关闭，黄色最小化，绿色在「填满桌面」和「原尺寸」之间切换。悬停绿点可展开平铺选项（左右半屏、上下半屏、四个角、填满、居中、进入沉浸模式）。按住 `⌥` / `Alt` 再点红点或黄点，会关闭或最小化该应用的全部窗口。
- **双击标题栏**：默认是缩放，可在「设置 → 学习桌面」改为最小化或无操作。
- **沉浸模式**：窗口填满桌面，状态栏和 Dock 自动收起（鼠标移至屏幕边缘滑出），适合专心精读；按 `Esc` 或再点绿点退出。
- **一键整理**：在桌面右键菜单或状态栏「窗口」菜单中，可使用「平铺全部窗口」「窗口俯瞰」「显示桌面」「恢复窗口」。

### 切换窗口

- **全局窗口切换器**：按住 `Ctrl` 再按 `Tab`（或 `Shift+Tab`）循环切换全部窗口，松开即聚焦。
- **同应用窗口切换**：按 ``Ctrl+` ``（macOS ``⌘` ``）在当前应用的多个窗口之间快速循环。
- **窗口俯瞰与 App Exposé**：按 `Ctrl+Alt+E`（macOS `⌘⌥E`）进入全局窗口俯瞰；按 `Ctrl+Alt+Shift+E`（macOS `⌘⌥⇧E`）进入**应用窗口俯瞰（App Exposé）**，仅俯瞰当前焦点应用的所有窗口。
- **显示桌面**：按 `Ctrl+Alt+D`（macOS `⌘⌥D`）或双击桌面空白处最小化全部窗口，再操作一次恢复。

### 退出学习桌面

点状态栏最左边的 DeepStudent 图标 →「退出学习桌面」，或在「设置 → 学习桌面」关掉「学习桌面（默认）」开关，即可切回经典布局。若有窗口存在未保存内容，会先取消退出并提醒你保存或关闭这些窗口，避免丢数据。想回来时再打开开关即可。

## 进阶用法

### 让 AI 帮你操作桌面

在对话里让学习 Agent 整理资料或推进学习时，它可以通过已注册的语义动作操作笔记、思维导图、待办、资源库、题目集、闪卡、番茄钟和浏览器（共 8 个应用），不使用坐标盲点，也不会替你答题、交卷或给闪卡评分。你可以在状态栏「AI 桌面操控」控制中心或「设置 → 学习桌面 → AI 助手操控」中切换模式：

- **跟随**（默认）：AI 操作时自动打开目标窗口并带到前台，便于实时监督；操作中随时可暂停、停止或撤销。
- **后台**：AI 在后台直接执行，不抢当前焦点，完成后在 Dock 上提示。
- **关闭**：AI 仅查看当前窗口状态，不打开、关闭或操作窗口；需要改数据时在后台数据面完成。

「操控演出节奏」可选快速、正常或演示（放慢步骤便于观看）。破坏性操作在任何模式下都会先请你确认；紧急情况下随时点击状态栏控制中心的**「紧急断电」**即可刹停全部 Agent 与自动化任务。

### UI 插件扩展槽位与降级保护

学习桌面通过统一的 UI 插件内核向官方与第三方插件开放四类标准扩展槽位（管理方式见 [AI 插件工坊与插件管理](./20-AI插件工坊与插件管理.md)）：

- **`views`**：注册独立页面视图，自动镜像进入「全部应用」并可像原生应用一样开窗使用；
- **`statusbar.items`**：在顶部状态栏添加状态指示器或快捷操作按钮；
- **`desktop.widgets`**：向桌面右侧组件区扩展新的信息卡片；
- **`app.menu`**：向顶部应用菜单或上下文菜单贡献扩展动作。

**降级保护机制**：当某个桌面窗口或插件页面所依赖的 Host 插件被禁用、加载失败或暂时不可用时，学习桌面会自动隔离故障，在窗口内展示友好的降级提示（不会影响其他窗口和桌面运行），并引导你前往[插件工坊](./20-AI插件工坊与插件管理.md)查看原因、恢复进度或重新启用插件。

### 外观与性能

在「设置 → 学习桌面」里还可以按需调整：

- **性能档位**：画质 / 均衡 / 性能，一键平衡视觉效果与流畅度；较旧电脑建议选「性能」。
- **视觉材质**：控制玻璃与透明层次（跟随平台 / 全效果 / 降透明 / 极简），也可在桌面右键菜单快捷切换。
- **Dock 与状态栏**：调整 Dock 大小、自动隐藏 Dock、自动隐藏菜单栏、平铺间距。
- **桌面壁纸**：使用内置风景与渐变，或通过壁纸管理器上传自定义图片。
- **显示桌面组件**：分别开关右侧的「日程」与「AI 学习简报」。

为节省内存，长时间不用的后台窗口可能会自动休眠（对话后台窗口会挂起流式渲染并在切回时补渲），点一下即可瞬间唤醒；有未保存内容的窗口不会被休眠。

## 📱 移动端与 WebUI 说明

学习桌面**仅适用于 Windows、macOS、Linux 桌面端**。Android 移动端（见 [移动端指南](./17-移动端指南.md)）与 WebUI 均不使用窗口化学习桌面，设置中也不会显示学习桌面相关选项。

## 常见问题

**Q1：打开应用后只看到一张空桌面，左边的导航栏去哪了？**
这是学习桌面模式，所有应用都在底部 Dock 和「全部应用」（`Ctrl+K` / `⌘K`）里。如果偏好左侧固定导航栏，点状态栏最左边的 DeepStudent 图标 →「退出学习桌面」即可切回经典布局。

**Q2：窗口太多找不到了怎么办？**
按 `Ctrl+Alt+E`（macOS `⌘⌥E`）进入全局窗口俯瞰，按 `Ctrl+Alt+Shift+E`（macOS `⌘⌥⇧E`）只看当前应用的窗口；也可以在顶部「窗口」菜单切换，或直接点中央「学习流阶段预设」一键重排。

**Q3：误触了「紧急断电」怎么恢复？**
打开顶部状态栏的「AI 桌面操控」控制中心（或断电横幅）：先点「恢复 Agent」恢复正常对话与代理能力；如果你还启用了定时学习任务，再单独点「恢复自动化」并确认，定时调度才会重新启动。

**Q4：窗口里显示「窗口已休眠」或「插件暂时不可用」？**
「窗口已休眠」是为省内存暂停了闲置后台窗口，数据未丢，点一下立即唤醒；「插件暂时不可用」则是该窗口依赖的 Host 插件处于禁用或异常状态触发了降级保护，前往[插件工坊](./20-AI插件工坊与插件管理.md)重新启用或查看恢复进度即可。

**Q5：电脑风扇响、拖窗口有点卡？**
到「设置 → 学习桌面」把「性能档位」切到「性能」，或把「视觉材质」改成「极简」，同时可在桌面右键关闭暂时不需要的桌面组件。
