# 知识导图

> 一句话让 AI 生成完整的知识体系导图，再用大纲和画布双视图精细整理，还能开启背诵模式自测记忆。

## 功能概览

知识导图（思维导图）帮你把零散的知识整理成结构：

- **AI 生成**：在对话中说一句"帮我生成高中生物思维导图"，AI 就会创建一张完整导图，并支持多轮对话继续修改
- **双视图编辑**：「大纲」视图像列表一样快速录入，「导图」视图在画布上自由布局，两者随时切换、内容同步
- **多种结构与主题**：思维导图 / 逻辑图 / 组织结构图 / 时间轴等布局，多套配色主题
- **背诵模式**：把节点文字"挖空"遮盖起来，逐个揭示自测，适合背诵知识点；还能按历史错误率「难点优先」复习
- **版本历史**：每次保存和 AI 修改都有版本记录，可预览、可恢复
- **导入导出**：支持导入 .xmind / .mmap（MindManager）/ OPML / Markdown / .mm 等格式，导出 PNG / SVG / PDF / Markdown / OPML / JSON / .xmind；.xmind 中的小图会直接内嵌显示，多画布文件可用「画布切换器」分别查看

## 入口与界面布局

导图和笔记一样存放在「学习资源」中：

- **手动创建**：进入「学习资源」，点击工具栏「+」→「新建知识导图」。
- **对话生成**：在 AI 对话中直接提出需求（如"帮我做一张牛顿三定律的知识导图"），AI 创建后回复中会出现可点击的导图链接，点击即可查看；导图同时也会出现在学习资源里。

打开导图后：

- **顶部工具栏**：左侧是「大纲 / 导图」视图切换；中间是撤销 / 重做（`Ctrl / ⌘ + Z`、`Ctrl / ⌘ + Shift + Z`）、「结构」「样式」按钮；右侧是「搜索」（`Ctrl / ⌘ + F`）、「学习」（背诵模式）、「演示模式」、「展开 / 折叠到层级」、「版本历史」、「导入」「导出」和「快捷键列表」等入口，以及保存状态（「已保存 / 未保存 / 保存中...」，`Ctrl / ⌘ + S` 手动保存）。
- **大纲视图**：以缩进列表呈现所有节点，适合快速录入和调整层级。
- **导图视图**：画布上呈现节点连线图，可缩放、拖动画布、框选多个节点。

## 核心操作

### 用 AI 生成一张导图

1. 打开 AI 对话，输入需求，例如："生成一张《细胞结构》知识导图，覆盖细胞膜、细胞质、细胞核三大部分。"
2. AI 会调用导图工具创建导图，回复中出现导图卡片 / 链接，点击「在新窗口打开」或直接点开即可查看。
3. 继续对话就能多轮修改，例如："在细胞核下面补充染色质和核仁的要点"——AI 会直接编辑对应节点。
4. 打开「版本历史」可以看到每一轮的改动来源（「手动保存」「自动保存」「AI 更新」「AI 编辑节点」），不满意可恢复到任意版本。

### 在大纲视图中编辑

1. 点击工具栏的「大纲」切换到大纲视图。空导图会提示「按 Enter 开始输入第一个节点」。
2. 常用键位：`Enter` 新建同级节点，`Tab` 缩进（变为子节点），`Shift + Tab` 反缩进，拖拽小圆点可移动节点。
3. 双击节点圆点或按 `Ctrl / ⌘ + 单击`可「进入专注模式」，只看这个分支；面包屑可退出。
4. 节点支持「添加备注」（支持 Markdown）、标记完成、加粗、标蓝、高亮。
5. 多选节点：`Shift + 单击`范围选、`Ctrl / ⌘ + 单击`散选，底部会出现批量操作条：完成、转为任务、复制、缩进、反缩进、折叠等（画布视图中则可按住空白处拖动框选）。

### 在导图视图中编辑

1. 点击工具栏的「导图」切换到画布。选中节点后按 `Tab` 添加子节点，`Enter` 添加同级节点，`Delete` 删除；**方向键**按空间位置在相邻节点间移动选择（`Alt + 方向键`则是移动节点本身）。分屏或多窗口同时打开多张导图时，键盘导航只作用于当前聚焦的那张画布，`Esc` 也会正常交还给背诵 / 演示模式等上层退出逻辑。
2. 右键节点打开菜单：编辑、添加同级节点、编辑备注、标记完成、加粗 / 斜体 / 下划线 / 删除线、标题级别、文字颜色、高亮、添加图标、复制 / 剪切 / 粘贴为子节点、「关联资源」（把笔记、文件等挂到节点上）、「添加关联线」（在两个节点间画一条带标签的连线）等。关联线也可以用键盘操作：选中起点节点按 `Ctrl / ⌘ + L` 进入连线模式，点击目标节点完成（`Esc` 取消）；选中已有关联线后按 `Enter` 或 `F2` 直接编辑标签，右键关联线可编辑标签或删除。
3. 右键空白处可「新建主题」「粘贴」「适应视图」；画布支持两种拖拽模式——「框选」和「拖动画布」，可在画布角落切换。
4. 点击「结构」可切换布局：思维导图（向左 / 向右 / 平衡）、逻辑图、组织结构图（上下左右）、时间轴。
5. 点击「样式」可切换全局主题（默认、极简、彩色、深色、卡片风、纸墨等），也可以单独设置选中节点的文本颜色、背景颜色、加粗。

### 搜索与聚焦

1. 按 `Ctrl / ⌘ + F` 打开搜索框，输入关键词。
2. 搜索有两种模式：「过滤」（大纲只显示匹配节点及其祖先路径）和「定位」（保留全树，跳转到匹配节点），可选「区分大小写」「全词匹配」。
3. 用「上一个 / 下一个搜索结果」在匹配之间跳转。

### 背诵模式（节点遮挡自测）

1. 先做"挖空"：选中节点里要背的文字，点击浮出的「挖空」按钮，可以在多个节点上标记多处挖空。
2. **按分支批量挖空**：右键任意节点选「挖空整个分支」，该分支下所有节点会整行挖空，适合快速把一整章内容变成填空题；「清除分支挖空」可一键还原。
3. 点击工具栏的「学习」→「进入背诵模式」，所有挖空文字会被遮盖。
4. 逐个点击遮盖块（或用快捷键「揭示下一个挖空」）检验自己是否记得；顶部状态条显示进度条、已揭示数 / 总数、完成百分比和剩余数量。
5. **难点优先复习**：应用会记住你每次背诵的表现——被翻开的挖空视为"没背出来"，保持遮盖的视为"背出来了"。点击背诵状态条上的「难点优先」，会按历史错误率从高到低排出复习队列（常错 > 没背过 > 稳定记住），用「上一个 / 下一个」在队列中跳转，视图会自动聚焦到对应节点。学习记录按导图保存在本机，多背几轮排序会越来越准。
6. 可随时「全部揭示」或「重新遮盖」，按 `Esc` 或点「退出」结束背诵（退出时才记入本轮学习记录；一次都没翻开的轮次不计入）。
7. 不再需要时可「取消挖空」或「清除所有挖空」。

### 导入与导出

1. **导入**：点击「导入」，支持 .xmind、.mmap（MindManager）、OPML、Markdown、.mm、JSON 等常见格式。大文件导入期间工具栏下方会显示进度提示。注意：导入会覆盖当前未保存的修改，应用会先弹出确认，可选「保存并导入」。
   - **多画布 .xmind**：会自动合并为一张导图并注明来源；工具栏会出现「画布切换器」下拉，可在「全部」和各个原画布之间切换视角（本质是聚焦到对应一级分支，随时可回到全图）。
   - **图片节点**：.xmind 中体积较小的图片（约 256KB 以内）会直接内嵌保留，在画布节点和大纲里显示缩略图；过大或缺失的图片仍在备注中留下占位说明，导入完成的提示里会汇报内嵌 / 丢弃数量。
2. **导出**：点击「导出」，可选 PNG 图片、SVG 矢量图、Markdown、OPML、JSON、.xmind；「导出 PDF」会打开系统打印对话框，选「另存为 PDF」即可。导出图片需要在导图视图下进行。

### 版本历史

1. 点击工具栏的「版本历史」。
2. 每条记录标明来源（手动保存 / 自动保存 / AI 更新 / AI 编辑节点），点击「预览」可查看该版本标题结构。
3. 点击「恢复」并确认，即可回到该版本；恢复前当前未保存的修改会先自动保存。

## 进阶用法

- **演示模式**：点击「演示模式」进入全屏展示，按 `Esc` 退出，适合讲解和汇报。
- **经典大纲键位**：可在偏好中打开「经典大纲键位」：`⌘ + Enter` 标记完成、`Shift + Enter` 编辑描述，并可用 `⌘ + [` / `⌘ + ]` 聚焦层级。
- **快捷键列表**：工具栏的「快捷键列表」面板汇总了通用、导图视图、大纲视图、背诵模式四组全部键位（复制 / 剪切 / 粘贴、上移下移、折叠展开、聚焦进入 / 返回上级、行中拆分 / 行首合并、范围多选等）。
- **关联资源**：右键节点选「关联资源」，把笔记、教材、文件挂到节点上，点击即可打开，把导图变成资料索引。
- **隐藏已完成**：把节点标记完成后，可用工具栏的「隐藏已完成」过滤，只看剩余内容。
- **超大导图**：大纲视图对上千节点的导图启用窗口化渲染，只挂载视口附近的行，滚动依然流畅；搜索定位、背诵聚焦会自动把目标行滚入视野。
- **草稿保护**：意外关闭后重新打开导图，若有未保存内容会提示「已恢复未保存的本地草稿」；多设备同时编辑发生冲突时，应用会切换到最新版本并暂存你的修改，可点「恢复我的修改」。

## 📱 移动端说明

- **入口**：抽屉 →「学习资源」→ 左抽屉「+」→「新建知识导图」，或在对话中让 AI 生成后点击链接打开。
- **手势**：画布支持双指缩放和单指拖动；导图区域的滑动不会触发应用的左右切屏手势，可放心操作。
- **编辑**：移动端选中节点后会出现专用的节点工具条，提供添加子节点 / 同级节点、删除等常用操作，代替桌面端的键盘快捷键。
- **形态差异**：依赖键盘快捷键的高级操作（如批量多选、经典大纲键位）主要面向桌面端；移动端以点按和工具条为主。

## 常见问题

**Q1：AI 生成的导图保存在哪里？**
保存在「学习资源」中，和手动创建的导图一样，可以随时打开继续编辑。

**Q2：让 AI 改导图会不会弄丢我手动编辑的内容？**
每次修改都会记录版本。打开「版本历史」可以查看「AI 更新 / AI 编辑节点」前后的版本并一键恢复。

**Q3：为什么导出 PNG / SVG 时提示要切换视图？**
图片导出基于画布渲染，请先切换到「导图」视图再导出（提示文案为「请切换到思维导图视图后导出图片」）。

**Q4：背诵模式下不能编辑？**
是的，背诵模式是只读的自测状态。如需修改挖空或内容，先点「退出」（或按 Esc）再编辑；选中文字挖空时若还在背诵模式，会提示「退出背诵并创建挖空」。

**Q5：导图太大保存失败？**
节点数量或层级超过上限时会提示「导图节点过多 / 层级过深，无法保存」，请拆分为多张导图。

**Q6：能导入哪些文件？**
支持导入 .xmind、.mmap（MindManager）、OPML、Markdown、.mm、JSON 等格式。纯文本大纲可保存为 Markdown 或 OPML 后导入。
