# AI 对话与会话管理

> 与学习 Agent 围绕你的资料展开多轮对话，支持边读边问、生成式交互界面、任务计划与变更审阅，并用学习空间、标签和搜索把每次对话管理得井井有条。

## 功能概览

AI 对话是 Deep Student 的核心入口。它不只是一个聊天窗口，你可以在这里：

- 与 AI（学习 Agent）多轮对话，随时附上图片、PDF、Word 等资料一起提问
- 引用资源库里的笔记、教材、题目集，回答带出处，点引用直接跳回原文；桌面端还可切到「边读边问」文档优先布局
- 开启推理模式（思维链）并滑块调节推理强度，也可在紧凑模型菜单里多选模型并排对比回答
- 用四档执行档位（`谨慎` / `宽松` / `完全访问` / `危险完全访问`）管理 AI 调用工具与命令行的权限，并逐文件审阅或回滚本轮修改
- 在消息流中直接交互——支持 `openui-lang` 流式交互卡片、结构化学习块、HTML 交互沙箱与多种学科专用渲染格式
- 从任意回答「从此处分支」，对旧历史重试自动分叉保护原记录
- 用**学习空间（Study Space）**组织会话，配置空间根文件夹、考试倒计时、长期记忆范围、桌面布局预设，并可跨空间直接挂载资料（不复制文件）
- 按需开启实验性 **Super 会话**，作为多任务总控助手并行推进后台只读任务

适合的场景：解题答疑、围绕教材精读提问、整理资料、让 AI 生成思维导图 / 题目集 / 闪卡（详见对应章节），以及一切「想问点什么」的时刻。

## 入口与界面布局

学习桌面里点 Dock 的「对话」打开对话窗口；经典布局下，打开应用默认就是对话页（左侧导航的「新会话」）。界面分为四个区域：

- **左侧会话栏**：顶部是「新对话」和「所有对话」（开启 Super-agent 后还会置顶 `Super` 会话）；下面依次是「学习空间」（可设图标、主题色，并展示考试倒计时与每日预算角标）、「置顶会话」、最近会话（按今天 / 昨天 / 最近 7 天等分组）、「收件箱」（未归属学习空间的临时会话，支持拖拽分组）和「已归档会话」入口。右上角「筛选会话」可以选择是否「显示子代理会话」（默认隐藏）。
- **中间消息区**：显示对话内容。新会话为空状态页，标题「开始对话」，下方提供示例任务；有到期的闪卡、错题或笔记时，输入框下方会显示「今日待复习」，有作答记录后还会列出「薄弱知识点」和「本周周报」入口；首次使用的新用户会看到「第一次用？三步走通」引导（详见 [效率工具 · 今日与学习周报](./10-效率工具.md)）。桌面端打开右侧文档预览后，还可以一键切到左文档 + 右对话的「边读边问」布局。
- **输入栏上方任务面板**：附着在输入栏正上方（不占用右侧边栏），统一收拢本轮任务计划（含 DAG 拓扑视图）、来源、本地运行时、工作区文件、浏览器下载、产物、变更（含 Diff 审阅面板）与完成总结。附件缩略图和引用卡片也展示在这里。
- **底部输入栏**：左侧是「＋」菜单（激活「插件工坊」「完全访问」或「危险访问」时，旁边会出现可点击退出的状态角标）；中间是输入框（支持多会话草稿箱与长粘贴自动折叠）；右侧依次是紧凑的「推理/模型」组合菜单、**上下文水位环**、语音输入和发送 / 停止按钮。

小提示：随时按 `Ctrl / ⌘ + N` 新建对话。

## 核心操作

### 发送消息、排队与插话

1. 点击底部输入框，输入问题；未发出的内容会自动存入当前会话的**多会话草稿箱**，切去别的会话再回来依然保留。
2. 按 `Enter` 发送，`Shift + Enter` 换行；中文输入法选字时按 Enter 不会误发送。
3. AI 回复过程中，发送按钮会变成「停止」，点击可中断生成；键盘上采用**双击 `Esc` 防误触停止**，避免单手误按一次 Esc 打断长回复。
4. **消息排队与插话增强**：AI 回复时继续输入并发送，新消息会自动排队，等当前回复结束后依次发送。切换为「引导」模式后，排队气泡上会出现「引导」按钮，点击即可打断当前步骤优先处理。若某条排队消息发送失败，支持对其单独「重试」「跳过」，或点击「全部清空」。
5. **长粘贴自动折叠**：粘贴超长文本时，会自动折叠为输入栏胶囊或转为虚拟 `.txt` 附件，既不撑爆输入框，也方便随时展开检查或移除。

### 「＋」菜单里有什么

点输入框左侧的「＋」（「添加与会话选项」），常用选项一览：

| 菜单项 | 作用 |
|---|---|
| 添加文件 | 「添加附件」从本地选文件；「资源库」引用已导入的资料；移动端还有「拍照」 |
| 模式 | 直接选择四档执行档位（`谨慎` / `宽松` / `完全访问` / `危险完全访问`），并在底部分隔线下提供「插件工坊」开关 |
| 知识库 | 包含「知识库检索（RAG 总开关）」「主动检索」以及检索范围限定（在已绑定根文件夹的学习空间中会自动限定本空间知识库） |
| 联网搜索 | 顶层总开关，控制当前会话能否调用外部搜索引擎联网检索（关闭后深度调研也无法联网） |
| 插件工坊 | 顶层开关，打开后进入插件工坊模式，输入栏左侧出现可点击退出的「插件工坊」角标（详见 [AI 插件工坊与插件管理](./20-AI插件工坊与插件管理.md)） |
| 连接器 | 选择本次对话可用的 MCP 服务器等外部工具（见 [技能与 MCP 扩展](./15-技能与MCP扩展.md)） |
| 技能 | 查看和激活内置或自定义技能 |
| 对话控制 | 调整温度、Top-P、上下文长度等生成与检索参数（见「进阶用法」） |

> 提示：「压缩上下文」不再放在「＋」菜单中，已移至输入栏右侧的**上下文水位环**点击弹层内。

### 上传附件（图片 / PDF / Word 等）

1. 「＋」→「添加文件」→「添加附件」选择文件；也可以直接把文件拖进窗口，或粘贴剪贴板里的图片。
2. 大小与数量限制：单个附件最大 200MB，图片最大 50MB；一条消息最多 20 个附件。超限的附件会被拒绝并给出提示。
3. 附件以缩略图形式出现在输入栏上方，处理过程中显示进度（提取文本、渲染、OCR、索引等阶段）。
4. 点附件旁的「注入」标签可以切换注入方式：
   - 图片：「图片」（把原图交给模型，需要多模态模型）或「OCR」（只给识别出的文字）
   - PDF：「文本」（提取的文字）、「OCR」或「图片」（整页截图，需要多模态模型）
5. 当前模型不支持图片输入时，应用会自动把图片附件降级为文字 / OCR 方式并提示你。

### 引用资源库中的资料与多模态页图

1. 「＋」→「添加文件」→「资源库」，挑选笔记、教材、题目集或整个文件夹（资料要先导入，见 [资源库](./04-学习资源中心.md)）。
2. 选中的资料以「引用内容」小卡片显示在输入栏上方，点击可预览，也可以逐个移除或「清空所有引用」。标记为「持久引用」的资料会在之后每一轮对话里持续生效。
3. 也可以从资料那边发起：在 PDF、Word、EPUB 或翻译工作台里选中一段文字，点划词工具条的「添加到聊天」；在 PDF 页面角落勾选几页，页码会以标签形式出现在输入框上方；或者用 PDF 阅读器的「框选提问」框出公式、图表，截图会作为图片附件加进输入框（详见 [文档阅读与翻译](./05-文档阅读与翻译.md)）。
4. **多模态知识库自动传页图**：使用多模态模型并开启知识库检索时，如果检索命中了已索引的 PDF 页面，系统会自动把最相关的 PDF 页图一并送给模型（单次最多 4 张），让 AI 直接「看到」原书中的公式推导、电路图或统计图表。

### 查看出处与文档优先阅读（「边读边问」）

AI 引用了你的资料时，回答里会出现引用徽章（如 `[1]`、「第 4 页」）：

- 点徽章或引用的页面缩略图，会直接打开原文并跳到对应页，被引用的那句话会在页面上高亮。
- 引用的是思维导图时，会打开思维导图并定位到对应节点。
- 知识库引用（`[知识库-N]`）指向笔记时，笔记会在对话右侧预览面板打开，并滚到被引用段落闪烁标出；对不上原文时停在笔记开头，无需离开对话页。
- **「边读边问」文档优先布局**：在桌面端（视口宽度 ≥800px），打开右侧文档预览后，面板顶部会出现**「边读边问 / 恢复对话布局」**切换按钮。进入「边读边问」后，系统自动折叠左侧会话导航，界面变为**左文档 + 右对话**双栏，支持鼠标拖拽分栏条或键盘微调宽度比例。
- **PDF 内置「AI 论文导读」**：在预览或精读 PDF 时，可打开内置的「AI 论文导读」大纲，快速把握章节脉络与核心贡献，并沿着导读大纲逐段追问。

### 选择模型、推理强度与多模型对比

1. 点输入栏右侧的紧凑**「推理/模型」组合菜单**即可切模型与调推理（不再弹出占屏大面板）。
2. 菜单内置搜索、**星标收藏**（悬停或选中模型按快捷键 `F` 可快速收藏/取消收藏）与**「最近选择」**，模型按「收藏 → 最近 → 按供应商」顺序排列，也可以把常用模型「设为系统默认」。
3. **推理强度滑块**：在组合菜单内直接开启推理模式并用滑块调节思考强度（**低 / 中 / 高 / 极高 / 最高**五档，后端按模型能力自动映射；不支持推理的模型会明确标注）。开启后，回答上方会出现可折叠的「思维链」区块。
4. **多模型并行对比**：打开菜单内的**「多选模式」**开关，勾选多个模型后发送（或在输入框里用 `@模型名` 指定多个模型），多个回答会并排生成对比。并行期间支持「全部停止」，完成后用「上一个变体 / 下一个变体」切换查看，单个变体可单独「重试」或「删除」。
5. 对已有回答不满意时，点消息下方的「重试」，可以在「选择模型重试」里换模型或选多个模型「并行重试」。

模型需先在设置里配置，见 [模型与供应商配置](./14-模型与供应商配置.md)。

### 执行档位与安全保护

学习 Agent 在对话中可以调用工具（写笔记、操作文件、执行本地命令等）。在「＋」→「模式」中直接选择四档执行档位（原「问一问 / 想一想」独立开关已取消）：

- **谨慎**：中高风险操作逐项弹出「工具执行确认」卡片，不提供「本会话允许」。
- **宽松**（默认）：低风险和中风险操作直接执行，高风险或无法判断风险的操作逐项确认。确认卡片支持「本次允许」「拒绝」（可填写修改原因）；策略允许时还提供「本会话允许」（仅当前会话有效，重启后失效）。
- **完全访问**：工具和命令行不再逐步确认，本地命令行解除工作目录、文件和网络沙箱限制；安装技能 / MCP 等特权操作仍会单次确认，可识别的灾难性命令始终拒绝。开启后输入栏左侧出现「完全访问」角标，点击立即降回宽松。
- **危险完全访问**：本地命令行完全不设限，命令规则、灾难命令防护、环境变量过滤、超时和输出上限全部关闭，仅保留取消和进程回收；特权操作仍单次确认。开启前会弹出强警告，输入栏左侧显示红色「危险访问」角标，点击立即降回宽松。除非你清楚后果，否则请勿开启。

新会话会继承你上次选择的「谨慎」或「宽松」；「完全访问」与「危险完全访问」仅对当前会话生效，不会成为新会话默认档。

安全与命令执行增强：

- **疑似密钥自动打码**：你发送的消息若包含疑似 API Key、访问令牌或密钥片段，消息气泡会自动将其打码显示，点击可临时查看原文，防止截屏或录屏泄露。
- **安全密钥请求卡**：当工具或脚本运行需要临时凭据时，消息流会弹出「安全密钥请求卡」。你在卡片中输入的密钥**不会进入会话历史，也不会进入模型上下文**，并可选择仅在内存中记住 10 分钟（到期或退出应用即销毁）。
- **回复内 Shell 代码块一键运行**：AI 回复中的 shell 命令行代码块右上角提供一键「运行命令 / 停止运行」按钮，方便直接验证命令（执行仍受当前执行档位与安全边界约束）。

### 上下文水位环与压缩上下文

输入栏右侧的**上下文水位环**实时反映当前对话占用的上下文比例：

- 占用超过 **70%** 时水位环变为警告色，超过 **90%** 时变为危险色，提醒你及时压缩或新开会话。
- 点击水位环打开弹层，可查看本会话 Token 用量、**Prompt 缓存命中**情况、费用估算以及压缩前后对比，并点击「压缩上下文」手动压缩早期对话。
- 对话过长时也会自动触发压缩，在消息流中生成「上下文已压缩 · 学习状态摘要」卡片。原始消息完整保存，摘要卡片支持**「撤销压缩」**、**「定位原文」**和**「复制摘要」**。

### 7 行活动窗口、任务面板、DAG 拓扑与回合 Diff 审阅

当学习 Agent 执行多步骤任务时，界面通过三层结构保持清晰可控：

1. **7 行活动窗口与终态一行摘要**：执行过程中，消息气泡内的工具调用过程区最多滚动展示最近 **7 行**活动，避免刷屏。凡是需要你介入的交互块（工具审批、提问卡片、安全密钥请求卡、交互卡片）都会被强制提升到可见区，**永不折叠**。整轮执行结束后，过程区自动收束为**一行多维摘要**（包含耗时、调用次数、检索来源或变更统计等），点击即可展开回看。
2. **输入栏上方任务面板**：附着在输入栏上方，按标签整合八类运行态信息：
   - **计划**：查看任务分解进度；点击**「DAG 拓扑视图」**打开**「学习计划与任务拓扑」**抽屉——以三态进度（待办 / 进行中 / 已完成）和前置解锁依赖呈现复杂学习或项目任务，支持一键**「派发」**就绪任务给 AI 执行，也能直接编辑关联笔记（若别处同时修改过，会提示刷新最新内容以避免互相覆盖）；
   - **来源**：本轮命中的搜索结果与资料引用；
   - **本地运行时**：正在运行或已结束的本地命令进程；
   - **工作区文件**：本轮读写或提及的文件清单；
   - **浏览器下载**：内置浏览器或工具触发的下载文件；
   - **产物**：AI 生成的看板、卡片组、笔记与文件（支持预览、保存到笔记库或撤销写入）；
   - **变更**：本轮对笔记或工作区文件的所有修改；点击**「Diff 审阅面板」**展开**「本轮修改审阅」**，逐文件审阅增删 Diff，支持**单文件回滚**、**一键回滚本轮修改**，以及部分场景下的**恢复（Redo）**；
   - **完成总结**：本轮最终结论与交付物清单。

### 会话挂起 / 恢复、分叉保护与睡眠块

- **后台窗口挂起与切回补渲**：在学习桌面同时打开多个窗口时，切到后台的对话窗口会自动挂起流式渲染以降低 CPU / 内存占用；切回该窗口后立即补渲最新内容，不会丢字也不会卡顿。
- **异常中断续写与旧历史分叉保护**：遇到网络抖动或服务端异常中断时，支持在原气泡上直接续写且不产生重复片段；若你对较早的历史消息点击「重试」，系统会自动创建分叉会话继续探索，保护原会话的后续记录不被抹掉。
- **子代理睡眠块与唤醒**：复杂任务中主代理派出子代理并在后台等待其完成时，消息流会显示**睡眠块**，标明正在等待哪些子任务；需要提前介入时，可直接点击「唤醒」让主代理立即恢复响应。

### 消息的常用操作

鼠标悬停在任意消息上（移动端点消息旁的菜单按钮），可以：

1. 「复制」消息文本。
2. **朗读（TTS）**：点击朗读按钮直接语音播报这条回答（详见模型分配中的语音合成配置）。
3. 「编辑」你发过的消息并「重发」，对话从这条消息重新继续。
4. 「重试」让 AI 重新回答（对旧历史重试会自动分叉保护后续内容）。
5. 「删除」这条消息：采用**内联两步确认**——第一次点击变为确认状态，再次点击才执行删除；3.5 秒内未确认会自动复位，避免弹窗打断。
6. 「保存为笔记」：把回答存进笔记库，笔记里会保留来源回链，之后可一键回到这条消息（见 [笔记](./07-笔记.md)）。
7. 「导出为 Markdown」：把这条回答导出为 `.md` 文件。
8. 「从此处分支」：以当前位置为起点复制出新会话，原消息上会出现「已从此处分支」角标，点击可跳转到分支会话。

选中消息里的一段文字，会浮出快捷工具条：「复制」「解释」「翻译」「添加到聊天」。

### 用学习空间（Study Space）组织会话

左侧原来的课题分组已升级为**学习空间**，把会话、资料库目录、复习节奏与桌面布局串成一体：

1. 在左侧「学习空间」区域点「新建学习空间」（或编辑已有空间），配置页分为三个标签：
   - **基础与提示词**：填写空间名称、描述、图标、14 种预设主题色、空间 System Prompt、默认技能、关联来源，以及可选的默认项目目录。
   - **目标与记忆调度**：
     - **空间根文件夹**：绑定资源库里的某个文件夹（支持一键「在资料库中打开」），该空间内的对话会自动限定在对应知识库范围内检索；
     - **目标考试日期**：设定后侧栏会展示 `D-N` / `D-Day` 倒计时角标；
     - **每日学习预算（分钟）**与**目标记忆留存率**：用于校准复习与专注节奏；
     - **默认闪卡牌组**：指定本空间优先复习的牌组（也可保持全局到期队列）；
     - **长期记忆范围**：选择 `本空间优先 + 全局画像`、`仅限本空间隔离` 或 `仅使用全局记忆`（详见 [深度调研与智能记忆](./03-深度调研与智能记忆.md)）。
   - **挂载与工作台**：
     - **学习桌面布局预设**：为该空间指定切入时联动的桌面布局（专注对话 / 双栏阅读与对话 / 双栏笔记与对话 / 刷题与闪卡复习 / 保持当前自由布局）；
     - **跨空间挂载资料**：通过「添加挂载资料」或在资源库中右键任意文件选择「挂载到学习空间…」，把其他目录的资料直接引用进本空间，不复制文件也不重复建索引，随时可解除挂载。
2. 未归属任何学习空间的临时会话会自动落在**「收件箱」**，支持直接把会话**拖拽**到任意学习空间中归类。
3. 在空间条目上可快速新建会话、置顶、重命名或归档。

### 管理单个会话

在会话条目上右键（或点条目上的「…」）：

- 「重命名线程」：修改标题（`Enter` 保存，`Esc` 取消）
- 「置顶线程」/「取消置顶」
- 「移动到分组」：把会话归入某个学习空间或退回收件箱
- 「归档线程」：从列表隐藏，可在设置里的「已归档会话」中查看和恢复
- 「删除会话」：永久删除，不可恢复
- 「导出会话」：把整个会话导出成文件
- 「在新窗口打开」（仅学习桌面）：给这个会话单独开一个窗口，与其他会话并排对照

### 搜索与浏览所有会话

1. 点会话栏顶部的「所有对话」，进入会话浏览视图。
2. 顶部可切换「按时间分组 / 按分组浏览 / 按工作区浏览」。
3. 搜索框支持两种模式：「标题」（匹配标题、简介、标签）和「内容」（全文搜索对话内容并展示命中片段）。
4. 「按标签筛选」按标签过滤；在会话卡片上可直接「添加标签」或移除标签。
5. 卡片上显示 AI 任务状态（进行中 / 已阻塞 / 已完成）和产物数量，悬停卡片可直接「导出会话」。
6. 外部导出的会话快照可通过「导入会话快照」恢复。

## 交互式可视化与生成式界面

除了纯文本和 Markdown，Deep Student 在对话中内置了三套互补的交互式可视化与生成式界面机制，按需为你呈现表单、图表、图解与动态演示：

### 1. 流式交互卡片（`openui-lang`）

当回答适合做成交互界面时，AI 会按行流式输出交互卡片——不用等整条回复写完，表单、统计图表、步骤条、数学公式与交互控件就会边生成边成型。生成后你可以直接在卡片里筛选或填写，也可以点操作栏上的**「固定到画布」**或**「存入空间」**，把它留成当前学习空间的长期可视化资料。

### 2. 结构化学习卡片（18 种内置块）

针对高频学习场景，系统内置了 **18 种结构化学习与数据块**（涵盖统计指标、对比表、步骤条、闪卡预览、复习日历、错题分析、导图嵌入、论文速览、研究计划与报告等）。它们全部按声明式数据渲染，**不执行任意脚本**；凡是涉及修改笔记、入库或执行动作的按钮，都必须由你亲自点击确认后才会触发。

### 3. 可视化讲解与隔离交互沙箱

- **Diagram / SVG 局部修改与撤销**：当 AI 绘制流程图、结构图或 SVG 教学图解时，如果只对某一处标注、配色或分支不满意，可以直接要求局部修改而无需整张重画；改坏了可一键撤销回上一版本。
- **高保真 HTML 交互沙箱**：遇到物理仿真、函数动态滑块、算法单步演示等富交互讲解时，应用会在**无同源权限的隔离沙箱**中运行——既保持流畅交互，又与主应用界面、本地文件和账号凭据彻底隔开，且不向外联网。
- **普通 HTML 代码块一键预览**：即便 AI 输出的是普通 `html` 代码块，也可以点击代码块上的**「内联运行交互」**直接在消息里体验，或点**「在沙箱中打开」**以独立沙箱视图查看。

## Super 会话（多任务总控助手，实验性）

如果你经常需要同时推进多件耗时事项（例如一边查文献综述、一边整理本周错题、一边比对两份讲义），可以启用实验性的 **Super 会话**，把它当作常驻的总控助理。

### 开启与配置

1. 前往**「设置 → 自动化 → Super-agent（多任务总控助手）」**（默认关闭）。
2. 打开「启用 Super-agent」开关；关闭后该会话会从侧栏隐藏，但历史记录完整保留，重新打开即可恢复。
3. 可在下方填写自然语言的**「额外指令」**（例如「只处理和学习相关的请求；遇到需要修改数据的事先问我」），这些规则会自动加入总控助手的系统提示词。

### 使用方式与安全边界

- **置顶常驻入口**：开启后，左侧会话列表顶部（桌面端与移动端一致）会固定出现带有 `Super` 标记的常驻会话。
- **Router 并行派发只读 Worker**：你随时可以在 `Super` 会话里交代多项需求。内置的 **Router** 会快速响应并拆解耗时任务，并行派发给多个后台 **Worker** 分头处理。出于安全考虑，后台 Worker 默认**仅使用只读工具**，不会擅自修改你的笔记、文件或执行命令。
- **「后台事件」卡片与状态控制**：Worker 的阶段性成果和最终结论会以**「后台事件」**卡片汇总到 `Super` 会话中；点击卡片可展开查看单个 Worker 的详细执行过程，也可以随时**暂停 / 继续处理**后台任务。
- **托盘常驻推进**：在桌面端把应用窗口关闭到系统托盘后，已经派发的后台任务仍会继续推进，完成后会在会话里同步最新进展。

## 进阶用法

- **对话控制**：「＋」→「对话控制」可以调整「温度」「Top-P」「上下文长度」「最大输出」「频率惩罚」「存在惩罚」，以及知识库检索参数（Top-K、重排、多模态检索）。这些参数只影响之后新建的对话。
- **学科专用渲染能力开关**：前往**「设置 → 常规 → 聊天渲染能力」**，按你的专业方向按需开关 8 项专用格式渲染：
  - 有机化学结构（SMILES）
  - 数据图表（Vega-Lite）
  - 关系图（Graphviz DOT）
  - 乐谱（ABC 记谱法五线谱）
  - 数字时序图（WaveDrom）
  - 化学结构文件（Molfile / SDF）
  - 三维分子（可旋转 3D 分子模型）
  - 地理数据（GeoJSON 本地矢量地图，不请求在线底图）
  关闭不需要的格式后，聊天不再渲染该格式，也不会向模型注入对应的语法提示，既保持界面干净又节省上下文 Token。
- **技能斜杠命令**：在输入框开头输入 `/` 会弹出「技能命令」列表，回车即可为这条消息激活某个技能（如 `/research-mode`），已激活的会标注「已激活」。详见 [技能与 MCP 扩展](./15-技能与MCP扩展.md)。
- **语音输入**：点麦克风按钮录音，松开后自动转写进输入框。在「模型分配」里选择「语音识别（ASR）模型」即可，硅基流动、阿里云百炼、DeepSeek、OpenAI 及兼容中转站都能用。
- **生成图片**：直接描述需求（如「帮我画一张细胞结构示意图」），AI 会调用生图工具产出示意图或插图（需先在「模型分配」配置生图模型）。
- **子代理（实验性）**：复杂任务里 AI 可能派出子代理在后台分头工作，消息流里会出现子代理卡片与睡眠块，点「查看完整会话」可回看完整过程。
- **Token、缓存与费用统计**：每条回答下方以及上下文水位环弹层里，均可查看本条与本会话累计的 Token 用量、**Prompt 缓存命中**情况和费用估算。

## 在学习桌面中使用对话

- 「对话」是一个窗口：点 Dock 图标打开或切到它，窗口左侧是会话列表与学习空间。
- 想同时看两个会话，在会话的「…」菜单里选「在新窗口打开」，同一个会话不会重复开窗；后台窗口会自动挂起流式渲染，切回即补渲。
- 从子代理卡片、通知、全部应用（`⌘K` / `Ctrl+K`）跳转到某个会话时，会自动切到对话窗口并定位该会话。
- 切换学习空间时，可联动恢复该空间绑定的学习桌面布局预设与窗口快照。
- `Ctrl / ⌘ + N` 和全部应用里的「新建对话」在任何时候都有效。

学习桌面的通用操作见 [学习桌面](./18-学习桌面.md)。

## 📱 移动端说明

- **布局**：移动端为三屏结构。中间是对话；点左上角 ☰ 或从屏幕左边缘右滑打开会话抽屉（新对话 / Super 会话 / 学习空间 / 最近 / 收件箱 / 已归档）；从右边缘左滑打开资源库面板。
- **返回键**：Android 返回键按「浮层 → 面板 → 抽屉 → 页面」的顺序逐层关闭，不会直接退出应用。
- **会话操作**：会话条目上点「…」可重命名、置顶、归档、删除，也支持滑动手势快速置顶或删除；「所有对话」在抽屉导航里有入口。
- **消息操作**：消息旁常显复制按钮，朗读（TTS）、重试、保存为笔记、从此处分支、删除等收在「…」菜单里。
- **输入栏**：「＋」→「添加文件」里多了「拍照」；模型选择、对话控制、技能与上下文水位弹层均贴合小屏优化。
- **多模型对比**：并行回答以横向卡片轮播呈现，左右滑动逐个查看。
- **键盘**：软键盘弹出时，抽屉手势会暂时屏蔽以防误触，收起键盘后恢复。

更多移动端操作见 [移动端指南](./17-移动端指南.md)。

## 常见问题

**Q1：发送按钮是灰的 / 提示「当前会话尚未就绪」？**
通常是还没有配置对话模型。到「设置 → 模型分配」选好对话模型即可，详见 [模型与供应商配置](./14-模型与供应商配置.md)。第一次配好供应商后，应用也会自动分配并提示「已自动将 ×× 设为默认对话模型」。

**Q2：上传了图片，AI 却说看不到图？**
当前模型可能不支持图片输入，应用会把图片自动降级为 OCR 文字。想让模型直接「看图」，在输入栏右侧的「推理/模型」菜单里换一个多模态模型，并把附件注入方式切回「图片」。

**Q3：AI 回答到一半卡住或网络断了怎么办？**
如果因网络异常中断，可以直接在原回复气泡上触发续写，不会产生重复文本；若需要主动中断，点「停止」或双击 `Esc`，再点「重试」。对旧历史重试时会自动分叉保护后续对话。

**Q4：删除的会话能找回吗？归档和删除有什么区别？**
「删除会话」是永久删除、不可恢复；「归档线程」只是从列表隐藏，随时可以在设置里的「已归档会话」中恢复。不确定时建议用归档。

**Q5：怎么把一次有价值的对话保存下来？**
单条回答用「保存为笔记」或「导出为 Markdown」；整个会话在会话菜单或「所有对话」的卡片上用「导出会话」；`openui-lang` 交互卡片还可以直接「固定到画布」或「存入空间」。

**Q6：AI 修改了我的笔记或文件，怎么审阅或撤销？**
打开输入栏上方的任务面板，切到「变更」区域点击「Diff 审阅面板」，即可在「本轮修改审阅」里逐文件对比改动，支持单文件回滚、一键回滚本轮修改，以及部分场景的恢复（Redo）。如果希望每次高风险写入都先经过你确认，可在「＋」→「模式」中保持「宽松」或切到「谨慎」档位。

**Q7：AI 回答没有引用我导入的资料？**
确认三件事：① 资料已在资源库的「知识库索引」里显示「已索引」且配好了嵌入模型（见 [模型与供应商配置](./14-模型与供应商配置.md)）；② 「＋」→「知识库」里的「知识库检索」总开关已打开（想每轮先查资料可同时开「主动检索」）；③ 若在某个学习空间内，目标资料需位于该空间根文件夹或已挂载进当前空间，或直接从「资源库」手动引用进对话。
