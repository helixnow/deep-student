# AI 对话与会话管理

> 与 AI 围绕你的学习资料展开多轮对话，并用课题分组、标签、搜索和导出把每一次对话都管理好。

## 功能概览

AI 对话是 Deep Student 的核心入口。它不只是一个聊天窗口，你可以在这里：

- 与 AI 进行多轮对话，随时上传图片、PDF、DOCX 等资料一起提问
- 从资源库中引用笔记、教材、题目集作为对话上下文，AI 的回答可附带来源
- 开启推理模式（思维链），查看 AI 的完整思考过程
- 让多个模型同时回答同一个问题并排对比（实验性）
- 从任意一条回答「从此处分支」，探索不同的解题路径
- 用「问一问 / 想一想 / 做一做」三档权限控制 AI 能做多少事
- 把会话整理进课题（分组），配置分组专属的系统提示词和默认技能
- 搜索、置顶、归档、导出任意会话

适合的场景：解题答疑、围绕教材提问、整理资料、让 AI 帮你生成导图 / 题目 / 闪卡（详见对应章节），以及一切"想问点什么"的时刻。

## 入口与界面布局

打开应用后默认进入对话页面，界面分为三个区域：

- **左侧会话侧栏**：顶部是「新对话」按钮和「所有对话」入口；下方依次是「课题」（会话分组）、「置顶会话」、最近会话列表（按今天 / 昨天 / 最近7天等时间分组）、「未分组」以及「已归档会话」入口。侧栏可通过「收起侧边栏」按钮折叠。
- **中间消息区**：显示对话内容。新会话是一个空状态页，标题为「开始对话」，并给出几条示例任务（如"请调研2026年大语言模型的最新发展趋势"）供一键填入。
- **底部输入栏**：输入框（占位提示「输入消息...」）加一排功能按钮，包括加号菜单、模型选择、推理模式、语音输入、发送按钮等。

小提示：随时按 `Ctrl / ⌘ + N` 可新建对话。

## 核心操作

### 发送一条消息

1. 点击底部输入框，输入你的问题。
2. 按 `Enter` 发送，`Shift + Enter` 换行；中文输入法选字时按 Enter 不会误发送。
3. AI 回复过程中，发送按钮会变成「停止」，点击可中断生成。
4. 如果在 AI 回复时继续输入并发送，新消息会自动排队，待当前回复结束后按序发送；在「排队模式」设置中切换为「引导」模式后，每条排队气泡上会出现「引导」按钮，点击可打断当前回复、优先处理这条消息。

### 上传附件（图片 / PDF / DOCX 等）

1. 点击输入栏左侧的加号按钮（「添加与会话选项」），选择「添加文件」；也可以直接把文件拖进窗口，或粘贴剪贴板中的图片。
2. 大小与数量限制：单个附件最大 200MB，图片附件最大 50MB；一条消息最多添加 20 个附件。超限的附件会被拒绝并给出明确提示。
3. 附件会以缩略图形式出现在输入栏上方，处理过程中显示进度（提取文本、渲染、OCR、索引等阶段）。
4. 点击附件旁的「注入」标签可以切换注入模式：
   - 图片：「图片」（把原图交给模型，需多模态模型）或「OCR」（只注入识别出的文字）
   - PDF：「文本」（解析提取的文字）、「OCR」或「图片」（整页截图，需多模态模型）
5. 如果当前模型不支持图片输入，应用会自动把图片附件切换为文本 / OCR 模式并提示你。
6. 粘贴超长文本时会提示「已粘贴长文本」，可选择「转为附件」或「保留文本」。

输入栏角落会实时显示本次消息的 Token 估算（如「约 1200 tokens / 上下文」），帮助你判断内容是否过长。

### 引用资源库中的资料

1. 点击加号菜单 →「添加文件」→「资源库」，从学习资源中挑选笔记、教材、题目集、文件夹等（资源需要先导入，见 [学习资源中心](./04-学习资源中心.md)）；移动端加号菜单中「资源库」为直出项。
2. 选中的资源以「引用内容」小卡片显示在输入栏上方，点击可预览，也可以逐个移除或「清空所有引用」。
3. 标记为「持久引用」的资料会在后续每轮对话中持续生效。
4. AI 回答中带来源时，消息下方会出现来源面板，点击可跳回原文。

### 选择模型与多模型对比（实验性）

1. 点击输入栏上的模型名称，打开「选择模型」面板；支持按名称或模型 ID 搜索，可将某个模型「设为系统默认」。
2. 在面板中打开「对比模式」开关（提示「同时使用多个模型回答」），勾选多个模型后发送，多个回答会并排显示。
3. 也可以在输入框中直接输入 `@` 加模型名称来指定模型；选择多个则自动进入「多模型并行」。
4. 并行生成时可「全部停止」；生成结束后用「上一个变体 / 下一个变体」箭头切换查看，对不满意的变体可单独「重试」或「删除」。
5. 对已有回答不满意时，点击消息下方的「重试」，可在「选择模型重试」对话框中换一个模型重试，或选多个模型「并行重试」。

模型需要先在设置中配置，见 [模型与供应商配置](./14-模型与供应商配置.md)。

### 开启推理模式（思维链）

1. 点击输入栏上的「推理模式」按钮开启（不支持推理的模型会显示「不支持推理」）。
2. 长按或点击旁边的深度菜单可选择「推理强度」：低 / 中 / 高 / 超高（越高越慢）。
3. 开启后，AI 回答上方会出现「思维链」区块，显示"正在思考 N 秒…"，点击可展开完整推理详情。

### 权限模式：问一问 / 想一想 / 做一做

AI 在对话中可以调用工具（写笔记、执行命令、操作文件等）。权限档位在输入栏「＋」菜单（「添加与会话选项」）的「模式」子菜单中切换，共三档：

- **问一问**：打开「问一问」开关进入只读模式，所有写入类工具会被拒绝，适合纯提问。
- **想一想**：打开「想一想」开关后，AI 想执行写操作前会先弹出「确认执行计划」卡片，你点「确认执行」后才继续（超时自动拒绝）。
- **做一做**（默认）：两个开关都不开即此档，按下方「做一做执行档位」决定审批与沙箱边界；默认「宽松」只对高风险或无法判定风险的操作弹出「工具执行确认」卡片。

确认卡片上可选择「本次允许 / 拒绝」；策略允许记忆时还会提供「本会话允许」（shell / runtime 操作按卡片显示的精确作用域记忆，应用重启后失效）。当前版本不提供跨会话的「始终允许 / 始终拒绝」。拒绝时可以填写原因告诉 AI 该怎么改。「模式」子菜单中另有「做一做执行档位」，控制做一做模式下的审批策略与沙箱边界，共四档：

- **谨慎**：中高风险操作逐项确认，且不提供「本会话允许」记忆。
- **宽松**（默认）：低风险和中风险操作静默执行，高风险操作仍逐项审批；「本会话允许」记忆仅对本会话、已授权目录内的中风险审批生效。
- **完全访问**：工具与 shell 免逐步确认，并取消本地 shell 的 runtime root、宿主机文件与网络沙箱限制；技能信任 / MCP 安装 / runtime root 等特权操作仍单次确认，可识别的灾难命令始终拒绝。开启后输入栏会出现「完全访问」角标，点击可一键降回宽松。
- **危险完全访问**：兼容旧会话的高警告别名，当前执行权限边界与「完全访问」相同，并不会额外解锁外部 MCP；特权操作仍单次确认、灾难命令仍拒绝。开启前会弹出更强的确认警告，同样可通过输入栏红色角标一键降回宽松。

该档位只约束「做一做」；问一问 / 想一想模式本身的限制始终优先。

新会话的默认档位会记住你上次选择的安全档：切到「谨慎」后，之后的新会话默认就是谨慎；切回「宽松」则恢复宽松默认。「完全访问」和「危险完全访问」只对当前会话生效，绝不会成为新会话的默认档。

### 消息的常用操作

把鼠标悬停在任意消息上（移动端点击消息旁的菜单按钮），可以：

1. 「复制」——复制消息文本。
2. 「编辑」——修改你发过的消息并「重发」，对话将从这条消息重新继续。
3. 「重试」——让 AI 重新回答（会提示将删除后续消息）。
4. 「删除」——删除该条消息（有确认弹窗）。
5. 「保存为笔记」——把 AI 的回答一键存入笔记库（见 [笔记](./07-笔记.md)）。
6. 「导出为 Markdown」——把这条回答导出为 .md 文件。
7. 「从此处分支」——以当前位置为起点复制出一个新会话，原会话不受影响，适合探索不同解法。分支创建后，原会话中被分支的那条消息会出现「已从此处分支」角标（重启后仍可见），点击角标可直接跳到对应的分支会话。

选中消息中的一段文字，还会浮出快捷工具条：「复制」「解释」「翻译」「添加到聊天」。

### 用课题（分组）组织会话

1. 在左侧侧栏「课题」区域点击「新建分组」。
2. 在弹出的编辑窗口中填写「分组名称」，可选填「分组描述」「分组图标」。
3. 「分组 System Prompt」：进入该分组会话时默认注入的系统指令，例如"你是我的考研数学教练"。
4. 「默认技能」：为该课题下所有新会话预先激活的技能。
5. 「关联来源」：点击「浏览资源」挑选资料，这些资料会在该分组下所有会话中自动注入为上下文。
6. 「默认项目目录」（进阶）：为该课题绑定一个可读写的文件夹作为 AI 的工作区。
7. 保存后，在分组上点「在 ×× 中新建会话」即可创建带上述配置的会话；分组支持「置顶分组」「重命名分组」「归档分组」。

### 管理单个会话

在侧栏会话条目上右键（或点击条目上的菜单按钮）：

- 「重命名线程」：修改标题（`Enter` 保存，`Esc` 取消）
- 「置顶线程」/「取消置顶」
- 「移动到分组」：把会话归入某个课题
- 「归档线程」：归档后从列表隐藏，可在「已归档会话」（设置内）中查看和恢复
- 「删除会话」：永久删除，不可恢复
- 「导出会话」：把整个会话导出为 Markdown 或 JSON 文件

### 搜索与浏览所有会话

1. 点击侧栏顶部的「所有对话」，进入会话浏览视图。
2. 顶部可切换「按时间分组 / 按分组浏览 / 按工作区浏览」三种排列方式。
3. 搜索框支持两种模式：「标题」（匹配标题、简介、标签）和「内容」（全文搜索对话内容，显示命中片段）。
4. 点击「按标签筛选」可按标签过滤；在会话卡片上可直接「添加标签」或移除标签。
5. 会话卡片上还会显示 AI 任务状态（进行中 / 已阻塞 / 已完成）和产物数量，悬停卡片可直接「导出会话」。

## 进阶用法

- **对话参数**：打开对话控制面板可调整「温度」「Top-P」「上下文长度」「最大输出」「频率惩罚」「存在惩罚」，以及知识库检索配置（Top-K、重排、多模态检索）；这些参数仅影响下一次发起的新对话。
- **技能斜杠命令**：在输入框开头输入 `/` 会弹出「技能命令」补全列表，回车即可为本条消息激活某个技能（如 `/research-mode`）；已激活的技能会标注「已激活」。技能也可通过加号菜单 →「技能」面板管理，详见 [技能与MCP扩展](./15-技能与MCP扩展.md)。
- **语音输入**：点击麦克风按钮「语音输入」录音，松开后自动转写进输入框。需要先在设置中配置 SiliconFlow API Key 并分配语音输入模型。
- **生成图片**：图片生成是一项内置技能，直接在对话中描述需求（如"帮我画一张细胞结构示意图"），AI 会调用生图工具产出概念图、知识卡片插图等（需先在模型设置中配置生图模型）。
- **AI 任务面板**：当 AI 执行多步骤任务时，右侧会出现任务面板，展示「计划」步骤、「近期活动」、「产物」文件与「变更」记录；对 AI 写入的文件可以「预览」「保存到笔记库」，甚至「撤销写入」。
- **子代理执行（实验性）**：复杂任务中 AI 可能派出「子代理」在后台分头工作，消息流中会出现子代理卡片，显示执行中 / 已完成状态，点击「查看完整会话」可查看子代理的完整过程。
- **上下文压缩**：对话很长时，早期内容会被自动压缩为「上下文已压缩 · 学习状态摘要」卡片，点击可展开；原始消息仍完整保存，只是不再占用模型上下文。上下文接近上限时会提示"建议新开会话或精简引用内容"。
- **Token 统计**：每条回答下可查看本条与本会话累计的 Token 用量、缓存命中和费用估算。
- **引用预览失败提示**：点击消息里的资源引用或 PDF 引用时，若资源已被移除或引用信息不完整，会弹出「无法打开引用预览」/「无法打开 PDF 引用」提示，不再是点了没反应。

## 在学习桌面中使用对话

对话在学习桌面（Workbench）中以独立窗口打开（单实例应用，Dock 中点击对话图标即可启动或聚焦）。与桌面多窗环境相关的行为：

- **跨窗口跳转会话**：从子代理卡片「查看完整会话」、通知、命令面板等入口跳转某个会话时，应用会聚焦对话窗口并可靠地切到目标会话——即使对话窗口还在冷启动加载中，跳转意图也会挂起、待页面就绪后自动执行一次（不会被启动时的新草稿覆盖，也不会在你手动切换会话后再把你拽回去）。
- **新建会话**：`Ctrl / ⌘ + N` 或命令面板的「新建对话」在对话窗口尚未就绪时同样生效，窗口打开后自动进入新会话，不会重复创建。
- **命令面板**：在学习桌面聚焦主对话窗口时，`Ctrl / ⌘ + K` 打开的应用面板会提供已有真实功能入口的对话命令（如新建对话、停止生成、切换检索模式等）；焦点在其他应用窗口时不显示这些上下文命令。尚无消费者的占位命令不会出现在命令面板或快捷键设置中。
- **会话「在新窗口打开」**：在会话列表右键某个会话，可选择「在新窗口打开」——为这条会话单独开一个轻量会话窗口，与主对话窗口并排对照（例如一边翻旧会话一边继续新对话）。同一会话不会重复开窗，再次打开会聚焦已有窗口。

## 📱 移动端说明

- **布局**：移动端为三屏结构。中间是对话；点左上角 ☰ 或从屏幕左缘右滑打开会话抽屉（新对话 / 课题 / 最近 / 未分组 / 已归档）；从右缘左滑打开学习资源库面板。
- **返回键**：Android 返回键按"浮层 → 面板 → 抽屉 → 页面"的顺序逐层关闭，不会直接退出应用。
- **会话操作**：会话条目上点「…」菜单可重命名、置顶、归档、删除，与桌面端一致；会话条目还支持滑动手势快捷置顶或删除。「所有对话」会话浏览视图同样有移动端入口（抽屉导航中），会以主内容区形式打开。
- **消息操作**：消息旁常显复制按钮，其余操作（重试 / 保存为笔记 / 从此处分支 / 删除等）收在「…」菜单中；移动端用户消息菜单以「编辑」重发为主，形态与桌面端略有不同。
- **输入栏**：加号菜单在移动端额外提供「拍照」入口；技能、对话控制、推理深度等面板以贴近输入栏的面板形式弹出。
- **多模型对比**：移动端并行回答以横向卡片轮播呈现，左右滑动逐个查看（自动对齐到每张卡片）。
- **键盘**：软键盘弹出时抽屉导航会被暂时屏蔽以防误触，收起键盘后恢复。

更多移动端通用操作见 [移动端指南](./17-移动端指南.md)。

## 常见问题

**Q1：发送按钮是灰的 / 提示"当前会话尚未就绪"？**
通常是还没有配置对话模型。前往「设置 → 模型分配」配置默认对话模型后即可发送，详见 [模型与供应商配置](./14-模型与供应商配置.md)。首次配置好供应商后，应用也可能自动分配并提示「已自动将 ×× 设为默认对话模型」。

**Q2：上传了图片，AI 却说看不到图？**
检查当前模型是否支持多模态（图片输入）。不支持时应用会把图片自动降级为 OCR 文字；若想让模型直接"看图"，请在「选择模型」面板换用多模态模型，并把附件注入模式切回「图片」。

**Q3：AI 回答到一半卡住了怎么办？**
先点「停止」按钮中断，再点该条消息的「重试」。若提示「流式响应超时」，应用会自动重置状态，重新发送即可。

**Q4：删除的会话能找回吗？归档和删除有什么区别？**
「删除会话」是永久删除、不可恢复；「归档线程」只是从列表隐藏，随时可以在设置内的「已归档会话」中查看与恢复。不确定时建议用归档。

**Q5：怎么把一次有价值的对话保存下来？**
三种方式：对单条回答用「保存为笔记」或「导出为 Markdown」；对整个会话，在侧栏会话菜单或会话浏览卡片上用「导出会话」，可选 Markdown 或 JSON 格式。

**Q6：「问一问」模式下 AI 说操作被拒绝了？**
这是预期行为：问一问是只读档位，AI 的所有写入类操作都会被拦截，并提示「当前为问一问模式，写操作已被拒绝」。点击提示旁的「切换到想一想」即可让 AI 在确认计划后执行。
