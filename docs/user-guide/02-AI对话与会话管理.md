# AI 对话与会话管理

> 围绕你的学习资料和 AI 展开多轮对话，支持边读边问、互动学习卡片、透明查看 AI 记住了什么，并用学习空间把不同科目的对话与资料管理得井井有条。

## 快速上手：你想做什么？

| 你想做什么 | 3 步操作 | 你会看到 |
|---|---|---|
| **还没配 AI 就打开了对话** | 1. 看输入框上方的提示横幅 → 2. 点「配置 AI 模型」→ 3. 粘贴一把 API 密钥并保存 | 立刻自动配好常用模型，回到对话就能开始提问 |
| **边看教材/论文边向 AI 提问** | 1. 点输入栏左侧「＋」→「添加文件」→「资源库」选资料 → 2. 输入问题发送 → 3. 点回答里的页码引用，再点右侧预览顶部的「边读边问」 | 界面自动切为「左文档 + 右对话」，点引用直跳原文并高亮原句 |
| **检查并修正 AI 记住的偏好** | 1. 看 AI 回复下方的「记忆内核 · N 规则 / M 薄弱点」小胶囊 → 2. 点开查看本轮生效的规则与薄弱点 → 3. 不需要就点「忘掉这条规则」 | 规则从下一轮起不再注入，点错还能立即「撤销」 |
| **给考研/某门课建专属对话区** | 1. 左侧点「新建学习空间」→ 2. 绑定教材文件夹、考试日期与记忆范围 → 3. 在空间里新建对话 | 侧栏出现 `D-N` 倒计时，检索自动限定在本空间资料内 |

## 功能概览

AI 对话是 Deep Student 的核心入口。你可以在这里：

- **带着资料提问**：随时附上图片、PDF、Word 等文件，或引用资源库里的笔记、教材与题目集；回答附带出处，点一下就跳回原文。
- **T3 三栏统一选择器与多模型对比**：在一个面板内切换内置模型与桌面端「本地编程 CLI」、调节思考强度、开启联网、多选模型并排对比、微调参数与切换执行档位；回答截断或手动暂停后可直接原地「继续生成」。
- **桌面端本地编程 CLI 协同**：通过 T3 选择器或 `@claude`、`@codex`、`@opencode`、`@pi`、`@agy`、`@dsh`、`@all` 直接在对话内协同改代码，带原目录无侵入快照、内联审批、改动审阅回退与并发防冲突锁。
- **随时看清并管理 AI 的记忆与技能归因**：每条回答下方通过「记忆内核」胶囊展示本轮生效的互动规则和薄弱点（支持一键「忘掉」与「撤销」）；本轮使用了技能时并排展示「技能」归因胶囊，点开可查不可变快照。
- **自由掌控 AI 动手权限**：用四档执行档位（`谨慎` / `宽松` / `完全访问` / `危险完全访问`）控制 AI 修改笔记或运行命令的权限，改完后还能逐项对比并一键回滚。
- **直接在消息里互动**：支持边生成边交互的学习卡片、18 种结构化学习面板，以及安全隔离的动态演示沙箱。
- **按学习空间整理会话**：把同一门课的会话、资料文件夹、倒计时、复习牌组、记忆范围和桌面布局收拢在一起；还能从任意消息「从此处分支」，探索不同思路不丢原记录。
- **开启实验性 Super 会话**：把多项耗时任务交给常驻总控助手，后台只读分身并行推进。

## 入口与界面布局

学习桌面里点 Dock 的「对话」打开对话窗口；经典布局下，打开应用默认就是对话页。随时按 `Ctrl / ⌘ + N` 新建对话。界面分为四个区域：

- **左侧会话栏**：顶部是「新对话」和「所有对话」（开启 Super-agent 后还会置顶 `Super` 会话）；下面依次是「学习空间」（可设图标、主题色、考试倒计时与每日预算）、「置顶会话」、最近会话（按今天 / 昨天 / 最近 7 天等分组）、「收件箱」（未归属空间的临时会话，支持拖拽归类）和「已归档会话」。右上角「筛选会话」可选择是否「显示子代理会话」（默认隐藏）。
- **中间消息区**：显示对话内容。新会话为空状态页，有到期闪卡或错题时会显示「今日待复习」「薄弱知识点」和「本周周报」入口（详见 [效率工具](./10-效率工具.md)）。桌面端打开右侧文档预览后，可一键切到左文档 + 右对话的「边读边问」布局。
- **输入栏上方区域**：
  - **尚未配置 AI 模型提示横幅**：如果你刚装好应用、还没连接模型服务，输入框上方会出现清晰提示「尚未配置 AI 模型，连接一个模型服务后即可开始对话与学习」，右侧配有「配置 AI 模型」按钮，点一下直达「设置 → 模型服务」。
  - **已绑定技能标签条**：本会话手动激活的技能会以胶囊标签列在输入栏上方，点击标签可打开技能面板，点 `×` 一键取消激活（详见 [技能与 MCP 扩展](./15-技能与MCP扩展.md)）。
  - **任务与附件面板**：附着在输入栏正上方，统一收拢本轮任务计划、参考来源、本地运行进程、工作区文件、浏览器下载、生成产物、文件修改对比与完成总结，附件缩略图和资料引用也显示在这里。
- **底部输入栏**：左侧是「＋」菜单（开启「插件工坊」「完全访问」或「危险访问」时，旁边会出现可点击退出的状态角标）；中间是输入框（自动保存多会话草稿，长文本粘贴自动折叠，支持 `/` 斜杠指令与 `@` 提及模型或本地编程 CLI）；右侧依次是 **T3 统一模型选择器**（集模型、本地编程 CLI、思考强度、联网、多选对比、参数与执行档位于一体）、**上下文水位环**、语音输入和发送 / 停止按钮。

## 核心操作

### 还没配置 AI 模型？直接从对话页一键进入

如果你首次启动时点了「先随便看看」，之后打开对话页发送按钮会暂不可用，输入框上方会出现提示横幅：

1. 点击横幅右侧的 **「配置 AI 模型」** 按钮，直接跳转到「设置 → 模型服务」。
2. 在顶部的 **「连接 AI 模型服务」** 卡片粘贴任意支持服务商的 API 密钥并点 **「一键连接并配置」**，或切到 **「从工具导入」** 直接迁移本机 CC Switch / Magpie / OpenCode / Claude Code / Codex 配置（详见 [模型与供应商配置](./14-模型与供应商配置.md)）。
3. 回到对话窗口，横幅自动消失，即可直接开始提问。

### 发送消息、排队与插话

1. 在底部输入框输入问题；没发出的内容会自动保存在当前会话的草稿箱里，切换会话回来依然保留。
2. 按 `Enter` 发送，`Shift + Enter` 换行；中文输入法选字按 Enter 不会误发送。
3. AI 回复期间，点「停止」或**双击 `Esc`** 可中断生成（双击防误触，避免手滑打断长回复）；暂停后也可直接点消息底部的 **「继续生成」** 原地续写。
4. **排队与插话**：AI 还在回复时继续发送，新消息会自动排队依次发出。切到「引导」模式后，点排队气泡上的「引导」可优先处理；某条排队发送失败时可单独「重试」「跳过」或「全部清空」。
5. **长粘贴自动折叠**：粘贴大段文章时会自动收起为胶囊或虚拟 `.txt` 附件，既不撑爆输入框，也方便随时点开检查或删除。

### 「＋」菜单里有什么

点输入框左侧的「＋」（「添加与会话选项」），包含 **4 组**内容与能力入口：

| 菜单项 | 作用 |
|---|---|
| **添加文件** | 「添加附件」选本地文件；「资源库」引用已导入资料；移动端还有「拍照」 |
| **知识库** | 控制「知识库检索（RAG 总开关）」「主动检索」及检索范围（已绑定根文件夹的学习空间会自动限定本空间资料） |
| **技能** | 搜索并激活内置或自定义技能 |
| **连接器** | 点 **「管理连接器」**，勾选本次对话要用的外部 MCP 工具服务器（见 [技能与 MCP 扩展](./15-技能与MCP扩展.md)） |

> 提示：**「联网」**（联网搜索）、**「参数」**（对话控制：温度、上下文长度与检索参数等）与四档权限执行档位已迁至输入栏右侧的 **T3 统一模型选择器底栏**；**插件工坊**改由输入框输入 `/workshop` 斜杠命令或从「全部应用 → 插件工坊」进入（开启后输入栏旁仍显示可点击退出的「插件工坊」角标）；**「压缩上下文」**位于输入栏右侧的**上下文水位环**点击弹层内。

### 查看并修正「记忆内核」归因胶囊（每条回答透明可追溯）

当你开启了智能记忆（且未处于隐私模式），AI 每完成一条回复，消息下方会出现一枚低调的归因胶囊，显示本轮实际注入的记忆概要，例如 **`记忆内核 · 2 规则 / 3 薄弱点`**（没有规则或薄弱点时，会显示学习目标数量或「已注入」）。

- **技能归因胶囊并排可查**：如果本轮对话激活或按需加载了技能，消息下方还会与「记忆内核」胶囊并排显示一枚 **`技能 · 技能名`**（多技能显示 `+N`）归因胶囊；点击可展开 **「本轮已使用技能」** 不可变快照，查看各技能的触发来源（手动激活 / 工具已加载 / 本轮注入），后续解绑或切换不会改写历史记录。

**你想核对或改掉 AI 的某条习惯时，只需 3 步：**

1. 点击回答下方的 **`记忆内核 · N 规则 / M 薄弱点`** 胶囊，展开 **「当前轮生效记忆快照」** 弹窗。
2. 查看本条回答生成时实际生效的互动硬规则、活跃薄弱点或学习目标：
   - **每条消息独立留档**：每个回答（包括多模型对比或重试生成的不同变体）都会保留当时生效的记忆快照，之后改了规则也不会改写历史回答的归因记录。
   - **变更即时提示**：如果你在对话中途新增或删除了规则，弹窗顶部会出现提示，说明规则变更将从**下一轮**起生效。
3. 直接在弹窗内修正：
   - 点规则右侧的垃圾桶按钮（**「忘掉这条规则」**），该规则会立即从长期记忆内核移除（下一轮起不再生效）；弹窗内会弹出「已移除」提示条，点 **「撤销」** 可马上恢复。
   - 点薄弱点右侧的按钮（**「标记已掌握 / 忘掉」**），可将已经学会的知识点移出薄弱点清单。
   - 想进一步添加规则、看 10 个历史版本或整理建议，点弹窗底部的 **「管理记忆设置」** 即可直达记忆工作台（完整用法见 [深度调研与智能记忆](./03-深度调研与智能记忆.md)）。

### 上传附件与引用资源库资料

1. **上传本地文件**：点「＋」→「添加文件」→「添加附件」，或直接拖拽文件、粘贴截图进输入框。单个附件最大 200MB（图片最大 50MB），单条消息最多 20 个附件。
2. **切换注入方式**：点附件旁的「注入」标签，图片可在「图片」（交由多模态模型看图）与「OCR」（仅传文字）之间切换；PDF 可在「文本」「OCR」「图片」间切换。当前模型不支持看图时，系统会自动降级为文字 / OCR 并提示你。
3. **引用资源库资料**：点「＋」→「添加文件」→「资源库」挑选笔记、教材、题目集或文件夹；勾选「持久引用」可让资料在后续每一轮持续生效。也可以在 PDF、Word、EPUB 或翻译页划词后点「添加到聊天」，或在 PDF 中框选公式与图表直接截图提问（见 [文档阅读与翻译](./05-文档阅读与翻译.md)）。
4. **多模态知识库自动传页图**：使用多模态模型并开启知识库检索时，命中已索引的 PDF 页面会自动附带最相关的页面截图（单次最多 4 张），让 AI 直接「看到」公式推导与图表。

### 查看出处与「边读边问」

AI 引用了你的资料时，回答里会出现引用徽章（如 `[1]`、「第 4 页」）：

- 点徽章或页面缩略图，直接跳到原文对应页并高亮原句；引用导图会定位到对应节点；引用笔记会在右侧预览面板打开并闪烁标出段落，无需离开对话页。
- **「边读边问」双栏布局**：桌面端（宽度 ≥800px）打开右侧文档预览后，点顶部 **「边读边问 / 恢复对话布局」**，界面自动折叠左侧会话栏，变为**左文档 + 右对话**，可拖拽中线自由调节比例。
- **PDF 内置「AI 论文导读」**：在文档预览里可随时打开「AI 论文导读」，快速把握章节脉络并逐段追问。

### 选择模型、思考强度与多模型对比（T3 三栏统一选择器）

点击输入栏右侧的 **T3 统一模型选择器**，在一个面板内即可完成模型切换、本地编程 CLI 切换、思考深度调节与会话运行参数控制：

- **左栏（导航栏）**：依次列出 **收藏**、各已配置供应商图标，以及桌面端统一的 **「本地编程 CLI」** 终端图标。
- **中栏（搜索与列表）**：支持关键词搜索、悬停星标收藏以及 `⌘1`–`⌘9`（Windows / Linux 为 `Ctrl+1`–`Ctrl+9`）快速点选；切到「本地编程 CLI」并选中某个工具后，可在原地选择 **「跟随 CLI 默认配置」**、动态探测或精选模型，或直接输入自定义模型 ID。
- **右栏（思考强度）**：单选切换思考强度档位（自适应当前内置模型或所选本地编程 CLI 所支持的档位）；开启思考后回答上方会显示可折叠的「思维链」。
- **底栏（会话运行控制）**：左侧依次提供 **「联网」**（当前会话联网搜索总开关）、**「多选」**（同屏多模型对比：勾选多个模型并行对比回答；亦可在输入框 `@模型名` 指定多模型，生成期间可「全部停止」，完成后可切变体、单独「重试」或「删除」，已有回答也可点「重试」→「选择模型重试」或「并行重试」）与 **「参数」**（对话控制：温度、上下文长度、最大输出与检索参数）；右侧为四档权限执行档位选择。

### 执行档位与安全保护

AI 在对话中可以帮写笔记、整理文件或运行命令。在 **T3 统一模型选择器底栏右侧** 选择四档执行档位：

- **谨慎**：中高风险操作逐项弹出确认卡片，不提供「本会话允许」。
- **宽松（默认）**：低、中风险操作直接执行，高风险或无法判定风险的操作逐项确认；卡片支持「本次允许」「拒绝」（可填修改意见），策略允许时支持「本会话允许」。
- **完全访问**：工具和命令行不再逐步确认，并解除常规目录与网络限制；安装技能 / MCP 等特权操作仍会单次确认，灾难性命令始终拒绝。开启后输入栏左侧出现「完全访问」角标，点击立即降回宽松。
- **危险完全访问**：本地命令行完全不设限，开启前会弹出强警告，输入栏左侧显示红色「危险访问」角标，点击立即降回宽松。非必要请勿开启。

新会话会继承上次的「谨慎」或「宽松」；「完全访问」与「危险完全访问」仅对当前会话有效。

额外安全护栏：
- **疑似密钥自动打码**：你发送的消息若包含 API Key 或访问令牌，气泡会自动打码防截屏泄露，点击可临时查看原文。
- **安全密钥请求卡**：工具运行需要临时凭据时会弹出专用输入卡，内容**不会写入会话历史，也不会发给 AI 模型**，最多仅在内存中暂存 10 分钟。
- **命令行代码块一键运行**：AI 回复里的 shell 代码块右上角可直接点「运行命令 / 停止运行」（仍受当前执行档位保护）。

### 本地编程 CLI 与多工具协同（桌面端）

桌面端支持将本机已安装的命令行编程工具直接融入对话窗口，与内置学习助手同场协作：

- **两种呼出方式**：
  1. 在输入栏右侧的 **T3 统一模型选择器** 左侧切到 **「本地编程 CLI」**，选中本机工具（并可在原地切换模型与思考强度）；
  2. 在输入框直接输入 `@claude`、`@codex`、`@opencode`、`@pi`、`@agy`、`@dsh`、`@all`（全体协作代理）或自定义工具代号点名调用；也可使用 `/swarm` 发起多工具蜂群协作、`/handoff` 在工具间交接任务，或在任意消息菜单点 **「派发给外部编程 CLI」** 把讨论内容直接转交执行。
- **项目目录与无侵入快照**：在输入栏点击 **「选择项目目录」** 绑定本地代码目录——默认在原目录直接协作，每轮自动生成无侵入隐藏快照以便随时回退；如需隔离分支也可勾选 **「使用独立 Git 工作树」**。
- **内联审批与执行卡片**：
  - 外部工具需要执行敏感操作时，输入栏正上方会弹出内联审批条，支持 **「允许一次」** / **「本会话允许」** / **「拒绝」**；
  - 对话流内以**内联执行卡片**实时呈现运行进度、派生子代理追踪、工具调用计数与文件增删统计，完成后可直接点 **「查看改动」**、**「回退此轮」**、**「让主代理总结改动」**（把代码改动提炼为学习笔记或闪卡要点），协同期间也可随时点 **「接管」** / **「恢复自动协同」** 人工介入。
- **并发防冲突与学习上下文互通**：多个工具在同一目录并发修改时，内置**并发文件防冲突锁**自动按路径协调写入顺序防止覆盖；开启共享上下文后，外部编程工具可按需读取当前会话关联的学习笔记与资料片段。
- **配置入口**：前往 **「设置 → 工具与扩展 → 编程 CLI」** 查看自动探测状态、自定义各工具可执行路径与附加启动参数、添加自定义命令行工具模板，或调整协作安全选项（见 [模型与供应商配置](./14-模型与供应商配置.md#本地编程-cli-配置桌面端)）。

### 上下文水位环与压缩上下文

输入栏右侧的**上下文水位环**实时显示当前对话的上下文占用比例：

- 超过 **70%** 变提醒色，超过 **90%** 变警戒色。
- 点水位环可查看本会话 Token 用量、缓存命中与费用估算，并手动点「压缩上下文」把早期对话精简成摘要。
- 对话过长时也会自动压缩并生成「上下文已压缩 · 学习状态摘要」卡片；原消息完整保留，随时可「撤销压缩」「定位原文」或「复制摘要」。

### 透明进度、任务面板与本轮修改审阅

AI 执行多步骤任务时，你可以随时掌握进度与改动：

1. **精简过程区与永不折叠交互卡**：执行期间消息内最多滚动展示最近 7 行步骤，避免刷屏；凡是需要你点确认的卡片（审批、提问、密钥输入、互动卡片）始终置顶不折叠。完成后自动收成一行摘要，点击可展开回看。
2. **输入栏上方任务面板**：按标签集中展示八类信息：
   - **计划**：查看任务拆解与先后依赖关系（可打开任务依赖抽屉，一键「派发」就绪任务或直接编辑关联笔记）；
   - **来源**：本轮命中的搜索结果与资料引用；
   - **本地运行时**：运行中或已结束的本地命令进程；
   - **工作区文件 / 浏览器下载**：本轮读写或下载的文件清单；
   - **产物**：AI 生成的看板、卡片组、笔记与文件（可预览、保存或撤销）；
   - **变更**：点开修改审阅面板，逐文件对比 AI 增删了哪些内容，支持**单文件回滚**、**一键回滚本轮修改**，以及部分场景的恢复（Redo）；
   - **完成总结**：本轮结论与交付物清单。

### 原地「继续生成」、中断续写与常用消息操作

- **原地「继续生成」**：无论是因输出长度达到上限被截断，还是你手动点击「停止」/双击 `Esc` 暂停，消息底部都会显示提示条并提供 **「继续生成」** 按钮——点击后直接在原回复气泡内无缝续写，不会产生额外的用户消息轮次。
- **后台自动省电与切回补全**：学习桌面同时开多个对话窗时，切到后台的窗口会自动暂停流式渲染，切回时立刻补全，不丢字不卡顿。
- **断网续写与历史分叉保护**：遇到网络中断可在原气泡直接续写；对较早的历史消息点「重试」会自动创建新分支继续探索，原记录完好无损。
- **子代理睡眠块**：主代理在后台等待子任务完成时会显示睡眠块，想提前介入可直接点「唤醒」。
- **消息快捷操作**（悬停消息或移动端点击「…」）：支持「复制」、**「朗读（TTS）」**、「编辑并重发」、「重试」、**「删除」（行内二次点击确认，3.5 秒未确认自动取消）**、「保存为笔记」（保留来源回链）、「导出为 Markdown」、「从此处分支」，桌面端还支持 **「派发给外部编程 CLI」**。选中消息内任意文字会浮出「复制」「解释」「翻译」「添加到聊天」。

### 用学习空间（Study Space）组织会话

把同一门课的会话、资料库目录、复习节奏与桌面布局绑成一体：

1. 在左侧「学习空间」点「新建学习空间」（或编辑已有空间），按三个标签配置：
   - **基础与提示词**：设置名称、描述、图标、14 种主题色、空间专属系统提示词、默认技能、关联来源，以及可选的「默认项目目录」。
   - **目标与记忆调度**：
     - **空间根文件夹**：绑定资源库里的文件夹，该空间对话自动限定在这个目录下检索；
     - **目标考试日期**：侧栏展示 `D-N` / `D-Day` 倒计时；
     - **每日学习预算（分钟）** 与 **目标记忆留存率**：校准复习节奏；
     - **默认闪卡牌组**：指定本空间优先复习的牌组；
     - **长期记忆范围**：可选 `本空间优先 + 全局画像`、`仅限本空间隔离` 或 `仅使用全局记忆`（三层记忆范围的区别见 [深度调研与智能记忆](./03-深度调研与智能记忆.md#规则作用域学习空间隔离与项目目录的区别)）。
   - **挂载与工作台**：可指定切入空间时联动的桌面布局预设；通过「添加挂载资料」（或在资源库右键文件选「挂载到学习空间…」）直接跨空间引用其他目录资料，不复制文件、不重复建索引。
2. 未归属空间的临时会话自动进入 **「收件箱」**，直接拖拽到任意学习空间即可归类。

### 管理与搜索所有会话

- **单个会话菜单（右键或点「…」）**：「重命名线程」「置顶线程」「移动到分组」「归档线程」「删除会话」「导出会话」，学习桌面还支持「在新窗口打开」。
- **「所有对话」浏览页**：支持按时间 / 分组 / 工作区浏览，按「标题」或「内容」全文检索，按标签筛选、给卡片加标签、导出会话，以及通过「导入会话快照」恢复外部导出的会话。

## Super 会话（多任务总控助手，实验性）

需要同时推进多件耗时任务（如一边查文献、一边理错题、一边比对两份讲义）时，可启用常驻总控助手：

1. 前往 **「设置 → 自动化 → Super-agent（多任务总控助手）」**（默认关闭），打开「启用 Super-agent」，可按需填写自然语言的「额外指令」。
2. 开启后，左侧会话列表顶部会出现置顶的 `Super` 会话；你在里面交代多项需求，总控助手会自动拆解并交给后台多个**只读分身**并行处理——后台分身不会擅自改你的笔记、文件或执行写命令。
3. 阶段进展与最终结论会以 **「后台事件」** 卡片汇总进 `Super` 会话，随时可展开过程、暂停或继续；桌面端关到系统托盘后任务仍会继续推进。

## 进阶用法

- **对话控制（参数）**：点击输入栏右侧 T3 统一模型选择器底栏的 **「参数」**，调整温度、Top-P、上下文长度、最大输出、惩罚项与检索参数（只影响之后新建的对话；切换至本地编程 CLI 时参数沿用 CLI 自身采样策略）。
- **8 项学科专用渲染开关**：前往 **「设置 → 常规 → 聊天渲染能力」**，按专业按需开关有机化学结构（SMILES）、数据图表（Vega-Lite）、关系图（Graphviz DOT）、五线谱（ABC 记谱法）、数字时序图（WaveDrom）、化学结构文件（Molfile / SDF）、可旋转 3D 分子模型、本地矢量地理图（GeoJSON）。关掉不需要的格式更省上下文。
- **斜杠命令**：输入框开头输入 `/` 快速激活技能（如 `/research-mode`），或输入 `/workshop` 开启插件工坊、桌面端输入 `/swarm` / `/handoff` 进行多编程 CLI 协同，见 [技能与 MCP 扩展](./15-技能与MCP扩展.md)。
- **语音输入与生图**：点麦克风按钮语音转文字（需在「模型分配」配好语音识别模型）；直接描述即可调用生图模型画学习示意图。
- **Token 与费用统计**：每条回答下方与上下文水位环弹层均可查看 Token 用量、缓存命中与费用估算。

## 常见问题

**Q1：发送按钮是灰的，或者输入框上方提示「尚未配置 AI 模型」？**
A：点提示横幅上的 **「配置 AI 模型」**（或前往「设置 → 模型服务」），在顶部「连接 AI 模型服务」粘贴一把 API 密钥点 **「一键连接并配置」**，或切到 **「从工具导入」** 导入已有工具配置即可，详见 [模型与供应商配置](./14-模型与供应商配置.md)。

**Q2：AI 回答带了我以前定过的奇怪要求，怎么让它马上改掉？**
A：点该条回答下方的 **`记忆内核 · N 规则 / M 薄弱点`** 胶囊，找到那条规则点垃圾桶图标（**「忘掉这条规则」**），下一轮起立即不再生效；点错可立即点 **「撤销」**。

**Q3：上传了图片，AI 却说看不到图？**
A：当前模型不支持看图时，系统会自动降级为 OCR 文字。在输入栏右侧 T3 统一模型选择器换一个多模态模型，并把附件注入方式切回「图片」即可。

**Q4：AI 回答到一半卡住、被截断或手动暂停后怎么继续？**
A：无论是因输出长度被截断，还是你手动点击「停止」/双击 `Esc` 暂停，消息底部都会出现提示条与 **「继续生成」** 按钮，点一下即可在原回复气泡内无缝续写，不会新增一轮用户消息；网络中断同样支持原气泡续写。想推倒重来再点「重试」（对历史消息重试会自动分叉，不会抹掉后续记录）。

**Q5：归档和删除会话有什么区别？**
A：「删除会话」永久删除不可恢复；「归档线程」只是隐藏，随时可在「设置 → 数据治理与同步 → 归档」恢复。拿不准时建议用归档。

**Q6：AI 改了我的笔记或文件，怎么检查或撤销？**
A：打开输入栏上方任务面板的「变更」，逐文件对比改动，支持单文件回滚或一键回滚本轮修改。

**Q7：AI 回答没有引用我导入的资料？**
A：确认三件事：① 资料在资源库「知识库索引」显示「已索引」且配好了嵌入模型（见 [模型与供应商配置](./14-模型与供应商配置.md)）；② 「＋」→「知识库」里的「知识库检索」总开关已开启；③ 若在学习空间内，资料需位于该空间根文件夹或已挂载进当前空间。
