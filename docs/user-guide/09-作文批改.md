# 作文批改

> 覆盖高考、雅思、托福、四六级、考研等场景的 AI 作文批改：多维评分、原文高亮标注、逐句润色、参考范文，还支持多轮修改迭代。

## 功能概览

「作文批改」把一篇作文交给 AI 精读：

- **多场景批阅模式**：内置高考作文、高考英语小 / 大作文、中考作文、雅思大 / 小作文、托福写作、四六级作文、考研英语大作文、日常练习共 10 种模式，每种模式都按对应考试的评分标准打分（如高考 60 分、雅思 9 分制、四六级 15 分）
- **多维评分**：总分之外给出分项评分（如内容 / 表达 / 发展等级，或 Task Response / Lexical Resource 等），支持条形和雷达两种视图
- **原文标注**：建议删除（红色删除线）、建议增加（琥珀色下划线）、建议替换（琥珀色箭头）、批注（琥珀色虚线）、亮点（绿色高亮）、语法拼写等错误（红色波浪线），点击标注可看原文与建议对照，一键「应用修改」（支持撤销）
- **逐句详解与润色**：批改结果分「批注总览 / 逐句详解 / 润色提升 / 参考范文」四个标签页
- **多轮迭代**：改完再交，同一会话按轮次保存，随时回看每一轮；题目与作文原图随会话保存，重开可恢复
- **手写作文 OCR**：拖入或导入作文照片，自动识别文字；多张按上传顺序原位回填
- **存为笔记 / 导出**：批改结果可一键存入笔记库，或导出完整 Markdown 报告
- **自定义**：可自建批阅模式（自定义评分维度和总分）、自定义批改提示词、选择批改模型

## 入口与界面布局

作文以文件形式存放在「学习资源」中：

1. 点击左侧边栏的「学习资源」。
2. 点击工具栏「+」→「新建作文」，创建后自动打开批改工作台；已有作文双击打开即可。
3. 也可以按 `Ctrl / ⌘ + K` 打开命令面板，执行「打开作文批改」。

批改工作台分为左右两栏：

- **左侧「学生作文」**：作文输入区，支持直接输入、粘贴，或拖入图片做 OCR 识别；上方可展开「题目/参考材料」输入框；底部显示字符数、中文字、英文词、标点等统计。
- **右侧「批改结果」**：批改前显示「等待批改」；批改中实时流式显示批注；完成后展示评分卡和四个结果标签页。
- **顶部**：作文类型（记叙文 / 议论文 / 说明文 / 其他）、年级水平（初中 / 高中 / 大学 / 其他）、当前批阅模式、模型选择、「批改设置」入口，以及「作文批改 / 批改历史」两个页签。

## 核心操作

### 批改一篇作文

1. 新建或打开一篇作文，在左侧输入或粘贴作文正文。
2. （推荐）展开「题目/参考材料」，填入作文题目和要求——提供题目后才能生成「参考范文」。
3. 在顶部选择合适的「批阅模式」（如「雅思大作文」）、作文类型和年级水平；需要换模型时点击「选择模型」。
4. 点击「开始批改」。批改过程分阶段进行：准备中 → 批注中 → 评分中 → 润色中 → 生成范文中，期间输入区会锁定（提示「批改进行中，输入已暂时锁定」），可随时点「取消」。
5. 完成后右侧展示总分、分项评分和完整批注。

### 看懂批改结果

1. **评分卡**：显示总分和等级（优秀 / 良好 / 及格 / 不及格），分项评分可切换「条形视图 / 雷达视图」。
2. **批注总览**：原文带彩色标注。看不懂颜色时点「展开说明」查看图例：红色删除线 = 建议删除，琥珀色下划线 = 建议增加，琥珀色箭头 = 建议替换，琥珀色虚线 = 批注，绿色高亮 = 亮点，红色波浪线 = 语法 / 拼写等错误。可按「全部 / 错误 / 建议 / 亮点」过滤。
3. 点击任意标注弹出详情卡片，显示「原文」与「建议」对照，可「复制建议」，或点「应用修改」把建议直接写回左侧作文——同一片段在文中多次出现时会按前后文自动定位到正确位置；已采纳的建议会显示「已采纳」，可随时点「撤销」还原。
4. **逐句详解**：逐条列出所有修改点及原因（语法、时态、搭配、成语误用、逻辑等 18 类错误标签）。
5. **润色提升**：对可以写得更好的句子给出「原句 → 润色后」对照。
6. **参考范文**：根据题目生成的范文（未填题目时显示「暂无参考范文（请提供作文题目）」）。

### 多轮修改迭代

1. 根据批改意见直接在左侧修改作文正文（可配合「应用修改」逐条采纳建议），再点「开始批改」即产生新一轮（内容与批改配置和上一轮完全相同会提示「内容未修改」）。
2. 顶部轮次导航显示「第 x/y 轮」，可用「上一轮 / 下一轮」或轮次列表回看任何一轮的原文、批注和评分。
3. 正文有未保存修改时切换轮次会先弹出确认——切换会用所选轮次的正文覆盖输入区，确认前修改不会丢失。

### 手写 / 拍照作文识别（OCR）

1. 把作文照片直接拖进左侧输入区，或点击「导入图片」选择文件。
2. 支持 PNG / JPG / WEBP，最多 5 张；多张上传后正文中会按上传顺序插入「图片识别中 第 x/y 张」占位符，每张识别完成后在原位回填文字，即使后面的图片先识别完，最终文字顺序也与上传顺序一致（识别失败的占位符会自动移除，可点按失败缩略图重试）。
3. 识别完成后核对文字再开始批改；批改完成后作文原图与题目会随会话保存，重开会话可恢复查看。
4. 「题目/参考材料」区域同样支持「添加参考图片」。

### 批改设置与自定义模式

1. 点击「批改设置」打开设置面板，包含「批阅模式」「文体与年级」「模式管理」三部分。
2. **切换模式**：在模式列表中选择，每个模式显示总分和评分维度。
3. **自定义模式**：点「新建模式」，或选中内置模式后「复制当前模式 / 编辑当前模式」；可以增删评分维度、修改每个维度的名称和分值（总分需与维度之和一致，可点「同步为 ××」一键对齐），改过的内置模式可「重置」恢复默认。
4. **自定义提示词**：在「自定义批改提示词」中写下你的额外要求（如"重点检查论据是否充分"），保存后每次批改都会生效，可「恢复默认」。

### 批改历史

1. 切换到顶部的「批改历史」页签，浏览所有批改会话。
2. 支持搜索、收藏（星标）、「仅显示收藏」过滤、删除。
3. 点击任意记录可恢复整个会话，继续查看或追加新一轮批改。

### 复制、存为笔记与导出

1. 批改完成后点击「复制」把结果复制到剪贴板。
2. 点击「存为笔记」把题目、原文和整份批改结果整理成一条笔记直接写入笔记库，之后在「笔记」应用中可继续查看和编辑。
3. 点击「导出」可导出包含原文、评分表、批改详情、润色建议和参考范文的完整 Markdown 报告。

## 进阶用法

- **对话里聊作文**：在学习资源中右键作文可「将此作文添加到对话上下文」，让 AI 围绕这篇作文继续答疑。
- **中英文混合批改**：底部统计分别显示中文字数和英文词数；中文模式（高考 / 中考 / 日常练习）与英文模式（雅思 / 托福 / 四六级 / 考研 / 高考英语）按各自标准批阅。
- **清空重来**：点「清空」并确认，会同时清空输入与批改结果（批改进行中无法清空）。

## 📱 移动端说明

- **入口**：抽屉 →「学习资源」→ 左抽屉「+」→「新建作文」，批改界面在右屏打开。
- **布局**：移动端输入区与结果区改为上下 / 分屏浏览，通过页签切换查看批注、评分与润色。
- **图片 OCR**：可从相册选择作文照片导入识别，上限同样为 5 张。
- **注意**：长文批改建议在 Wi-Fi 环境进行；批改过程中请保持应用在前台，离线状态无法批改（会提示「离线状态下无法批改」）。

## 常见问题

**Q1：点「开始批改」没反应或报错？**
先检查是否已配置模型和 API 密钥（提示「未配置 API 密钥，请前往设置添加」时，去 [模型与供应商配置](./14-模型与供应商配置.md) 完成配置）；再确认网络连接正常。

**Q2：评分是官方分数吗？**
不是。评分由 AI 按对应考试的评分标准模拟给出，仅供学习参考，与真实考试成绩无必然关系。

**Q3：为什么没有「参考范文」？**
参考范文需要作文题目。请在「题目/参考材料」中填入题目后重新批改。

**Q4：点「应用修改」提示"未在正文中找到对应原文"？**
说明你在批改后又手动改过这句原文，标注失去了锚点（同一片段多次出现时会按前后文自动定位，但原句被改动后就无法定位）。请手动对照建议修改。已采纳的修改可以在详情卡片中点「撤销」还原。

**Q5：批改到一半中断了，内容还在吗？**
已生成的部分会以「部分结果」保留展示；点「重试」可重新批改。主动「取消」则不会保存本轮内容。

**Q6：字数有上限吗？**
有。输入达到上限时会提示「已达到字符上限」，粘贴超长内容会被自动截断；超长作文建议分段批改。
