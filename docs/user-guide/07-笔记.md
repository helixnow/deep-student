# 笔记

> 一个支持双链、标签、数学公式、PDF 溯源回跳和 AI 协作编辑的 Markdown 笔记系统，你的所有笔记都保存在本地。

## 三步上手

**想快速记一篇结构清晰、带知识关联的学习笔记：**

1. **新建笔记**：在资源库点「新建 → 新建笔记」（想一并填课程与复习日期就选「新建学习笔记…」），或在「更多笔记操作 → 笔记模板」挑一套现成起步框架。
2. **边写边连**：正文输入 `/` 插入公式、表格、高亮块和折叠块；输入 `[[` 连接其他笔记，输入 `@` 引用教材或错题；从 PDF 划词保存来的摘录会自动带上「来源 · 来自资料 · 第 N 页」，随时一键跳回原页。
3. **AI 润色与复习**：选中段落让 AI 帮你整理要点，逐组审阅接受改动；学完后点「生成卡片」或「生成思维导图」把笔记变成复习材料。

## 功能概览

笔记是 Deep Student 学习资源体系的一部分，你可以用它来：

- **富文本写 Markdown 笔记**：标题、列表、表格、代码块、图片、数学公式、高亮块、折叠块都能直接插入。
- **双链知识网络**：用「双链引用」把笔记互相链接起来，配合右侧「链接」和「图谱」面板梳理关联。
- **多标签与智能防混淆**：同时打开多篇笔记（即使标题前缀很长或相似），标签栏也会自动提炼区分片段，一眼认出目标笔记。
- **来源回跳与窄分栏对照**：从 PDF 划词、批注或对话存来的笔记自动带「来源 · 来自资料 · 第 N 页」入口与可点击反链，哪怕在 460px 窄分栏下与 PDF 并排阅读也能精准跳回原页并记住当前阅读位置；音视频讲义里的时间标记会自动显示为可点击的 `▶ mm:ss` 跳转徽章。
- **AI 协作修订与安全回滚**：支持按「选区 / 当前块 / 当前章节 / 整页」发起修订，逐块或逐组审阅确认，并支持多步检查点回滚。
- **一键转复习材料**：把整篇笔记变成闪卡或思维导图，还能打上课程、章节、掌握状态和复习日期，按「近期复习」安排回顾。
- **自由导入导出**：随时导入已有的 Markdown 文件，或导出为 Markdown / Word 文档带走。

适合的场景：课堂笔记、错题复盘、考前整理、边看论文边记文献摘录，以及配合 AI 对话做调研报告和知识总结。

## 入口与界面布局

笔记统一存放在「资源库」中（学习桌面与经典布局名称一致）：

1. 打开资源库，点工具栏的「新建」→「新建笔记」（也可以在文件夹上右键「在此新建笔记」）。想同时填好课程等学习属性，选「新建学习笔记…」。
2. 双击任意笔记即可打开编辑器。学习桌面里会打开笔记工作区窗口（见下文）。

打开笔记后，界面分为三部分：

- **正文编辑区**：顶部是笔记标题（若笔记来自 PDF 或对话，属性顶部还会显示「来源 · 来自资料 · 第 N 页」或「来源 · 来自对话」快捷回跳栏），下方是正文，占位提示为「输入 '/' 唤起命令菜单...」。
- **编辑器顶栏**：「阅读 / 编辑」切换按钮，以及「更多笔记操作」菜单。菜单里的「笔记工具」有「笔记模板」「生成卡片」「生成思维导图」「询问 Agent」「历史版本」；「查看」有「查找替换」「专注模式」「导出」。
- **右侧详情面板**：点击右上角「打开详情」展开，包含「属性」（来源、创建 / 更新时间、标签、学习属性、附件）、「大纲」（正文标题目录，点击可跳转）、「外链」（本笔记引用的其他笔记和外部链接）。

笔记会自动保存，顶部会显示「已保存」「保存中...」等状态；也可以随时按 `Ctrl / ⌘ + S` 手动保存。

## 笔记工作区（学习桌面）

在学习桌面里，从资源库打开笔记会进入一个独立的笔记工作区窗口，把文件管理、多标签编辑和链接网络集中在一处：

- **文件树侧栏**：左侧是知识库文件树，支持文件夹整理、拖拽移动、收藏区、标签筛选和文件名搜索；工具栏可直接新建笔记、文件夹和思维导图，回收站也在这里打开。窗口较窄时，工具栏尾部的低频按钮会自动折叠进「更多操作」菜单，不会被裁掉。按 `Ctrl / ⌘ + \` 可随时折叠 / 展开侧栏，把宽度留给正文。
- **多标签编辑与同名/同前缀标题消歧**：打开的笔记和思维导图以标签页并列，`Ctrl + PageUp / PageDown` 或 `Ctrl / ⌘ + Shift + ] / [` 循环切换；关闭前有未保存修改会先确认。当你同时打开多篇**前缀相同的长标题笔记**（例如《高等数学-第1章-极限》《高等数学-第2章-导数》《高等数学-第3章-积分》），标签栏会在自然词界或数字边界自动压缩重复前缀，只保留简短开头提示与各篇真正不同的后半段（如 `高等…第1章-极限` / `高等…第2章-导数`），鼠标悬停即可查看完整标题——即使窗口很窄也不会出现一排完全看不出区别的「高等数学…」。
- **460px 窄分栏自适应**：当你把笔记窗口和 PDF 阅读器左右分屏并排（窗口宽约 460px）时，编辑区留白、顶部工具栏和标签页会自动切换为紧凑排版，正文依然舒展清晰，不会互相挤占或裁切按钮。
- **快速打开与全文搜索**：按 `Ctrl / ⌘ + P` 弹出快速打开面板，空关键词时先列「最近打开」，输入即可按文件名模糊匹配（支持 `#标签` 过滤），也可切换到全文搜索模式在笔记内容中检索并高亮命中。搜索还支持操作符组合过滤：`tag:数学` 按标签、`path:课程` 按所在路径、`status:done` 按自定义属性（`key:value`），带空格的值用引号包裹（如 `tag:"线性代数"`）；已生效的操作符会以标签条展示，可一键移除。结果超过一屏时点底部「加载更多结果」继续翻页，不设硬性条数上限。
- **「属性」面板**：展示来源回跳、创建 / 更新时间、标签和正文大纲；纯正文保存（不改标题标签）后，更新时间与大纲也会实时刷新。此外可以给笔记添加**任意键值属性**（如 `status: 进行中`、`来源: 教材`）——点「添加属性」输入属性名和值即可，单篇最多 32 个；属性可直接在搜索中用 `key:value` 过滤。
- **「图谱」面板**：把当前笔记的链接网络画成一张局部关系图——中心是当前笔记，内环是与它直接相连的笔记（入链 + 出链），外环是再隔一跳的笔记。工具栏可切换「1 度 / 2 度」范围、手动刷新；尚未创建的 `[[未解析链接]]` 会以虚节点显示。**点击任意节点即可打开对应笔记**；连接特别多时会提示「仅显示部分节点」。
- **「链接」面板**：汇总当前笔记的**出链**、**反向链接**、**未链接提及**和**未解析链接**四类信息：
  - 点击任意条目会打开对应笔记，并**自动定位到引用出现的位置**（带 `#标题` 的链接直接滚动到该标题）；
  - **未链接提及**是正文里出现了某篇笔记标题、但还没写成 `[[双链]]` 的纯文本，点「转为链接」即可原地改写成双链——如果那篇笔记正在编辑且有未保存修改，会先提示保存；与其他窗口的并发修改冲突时也不会覆盖对方内容；
  - **未解析链接**（指向不存在笔记的 `[[链接]]`）可以直接点「创建笔记」补上目标。
- **重命名自动回写双链**：把一篇笔记改名后，其他笔记中按旧标题书写的 `[[双链]]` 会自动改写为新标题（保留 `#标题` 和 `|别名` 部分），完成后有通知汇总；正在编辑中的笔记会跳过并提示手动检查。
- **并排 / 覆盖自适应**：窗口足够宽时链接面板与正文并排显示，窗口较窄或开启分屏时自动改为覆盖层。
- **标签重命名全局传播**：在「属性」页重命名一个标签后，知识库里**所有**带这个标签的笔记都会同步改名，完成后有通知汇总数量。
- **大库分页加载**：文件很多时按分页加载完整列表；超过 20000 个文件才会截断，且会明确提示「文件树仅显示部分内容」，不会静默丢文件。

## 核心操作

### 新建并编辑一篇笔记

1. 在资源库点「新建」→「新建笔记」，输入笔记名称。
2. 打开笔记后先写标题，然后在正文输入 `/` 唤起命令菜单，可以插入：普通文本、一到六级标题、引用、分隔线、无序 / 有序 / 任务列表、图片、代码块、表格、数学公式、高亮块、折叠块。
3. 选中一段文字会浮出「格式化」工具条，可设置粗体、斜体、删除线、行内代码、标题级别、链接、双链引用、高亮块等。
4. 需要起步模板时，在「更多笔记操作」里点「笔记模板」，内置 8 种模板：「听课笔记」「错题复盘」「应试整理」「会议记录」「读书笔记」「周计划」「康奈尔笔记」「文献笔记」，也支持保存自己的「个人模板」。

### 插入图片与公式

1. **图片**：直接把图片拖进编辑器或粘贴剪贴板图片即可，也可以用 `/` 菜单选「图片」。单张图片上限 10MB，支持 PNG、JPG、GIF、WebP 等格式。点击图片可调整宽度、对齐方式和图片说明，再次点击可放大预览。
2. **数学公式**：用 `/` 菜单选「数学公式」，在弹出的编辑框中输入 LaTeX，右侧实时预览；「常用模板」里内置分数、积分、极限、矩阵等常见结构，按 `Ctrl / ⌘ + Enter` 快速插入。

### 用双链把笔记连起来

1. 在正文中输入 `[[`，会弹出笔记搜索列表，继续输入关键词筛选，回车即可插入一条指向其他笔记的「双链引用」。
2. 如果目标笔记还不存在，列表底部会出现「创建 "××"」，选择后会自动创建这篇新笔记并链接过去。
3. 把鼠标悬停在双链上可以预览目标笔记内容，点击即可跳转。
4. 在右侧详情面板的「外链」标签页可以查看当前笔记引用了哪些笔记和外部链接。

### 引用教材、错题等学习资源

1. 在正文中输入 `@`，弹出引用搜索框（提示「输入关键词以引用」）。
2. 搜索并选择要引用的对象（如教材、错题），笔记中会插入一张引用卡片。
3. 点击引用卡片可以预览内容；右键卡片可选择「打开原始资源」「发送到对话」「移除引用」等操作。

### 笔记来源回跳与 460px 分屏对照 PDF

从 PDF 划词、批注导出或对话回答保存而来的笔记，天然与原始资料保持精准回跳：

1. **顶部来源一键回跳**：在笔记属性顶部可以看到「**来源 · 来自资料 · 第 N 页**」（或「**来源 · 来自对话**」），点一下即可直接打开原 PDF 并跳到对应那一页（或回到原对话消息）。
2. **正文页码反链精准定位**：点击正文中的页码引用链接（`pdfref://`），即使处于 **460px 窄分栏并排布局**，或者原 PDF 窗口先前已关闭需要冷启动加载，系统都会自动定位到精确页码与对应的高亮原句，不会掉回第 1 页。
3. **返回笔记不丢阅读位置**：查完 PDF 切回笔记窗口时，系统会自动恢复你刚才在笔记里的滚动位置，长文献笔记不用反复上下翻找。

> 音视频讲义或课堂笔记正文里的时间标记，在非编辑态会自动显示为可点击的 `▶ mm:ss` 徽章，点击直接打开对应音视频并跳到该时刻播放；当光标移入徽章时，它会自动切回原始时间标记文本，方便直接修改。

### 给笔记打标签、加收藏

1. 在笔记页头或右侧详情面板的「属性」标签页中，点击「添加标签」，输入后回车即可；已有标签会作为建议出现。
2. 无论是在页头、属性面板手动增删标签，还是由 AI 代为修改笔记标签，左侧栏的标签筛选列表都会**实时同步刷新**，无需手动重载。
3. 在资源库的文件列表中右键笔记，可选择「收藏」；收藏的笔记可以在左侧「收藏」里找到。

### 查找与替换

1. 在「更多笔记操作」里点「查找替换」。
2. 在「查找…」框输入内容，用「上一个 / 下一个」在匹配之间跳转（`Enter` 下一个，`Shift + Enter` 上一个）。
3. 点击「展开替换」，输入替换内容后可「替换」单处或「全部」替换。

### 让 AI 帮你改笔记（AI 画布编辑）

1. **指定范围与落点**：打开一篇笔记，在对话或笔记内的 AI 编辑入口中让学习 Agent 协助修订（例如把笔记引用进对话后说「帮我把这一章整理成要点」）。发起修订时可以选定**范围**（选区 / 当前块 / 当前章节 / 整页）与**落点**（替换 / 插入下方 / 另存结果），既能局部润色，也能在保留原文的前提下另存新稿。
2. **双视图逐处审阅**：AI 给出修改方案后，编辑器进入审阅态，支持在两种清晰视图间切换：
   - **逐块差异微调**：按段落块逐处对照展示新增与删除，适合精准推敲措辞与结构；
   - **富文本逐组审阅**：以排版后的真实阅读效果按改动组逐一审阅，直观省眼。
   你可以逐处点「接受」或「拒绝」；审阅中途点「收起」会完整保留你已做出的决定，随时点「继续审阅」接着处理，不会从头再来。
3. **随时撤销与多步检查点回滚**：对于直接写回正文的修改，编辑器顶部会出现撤回提示条；连续经过多轮 AI 修改时，还提供**多步检查点回滚**（显示「可回滚 N 次」），可按步恢复到任意一轮修改前的状态，满意后点「全部保留」确认。若生成或写回中途意外中断，顶部会出现恢复条，方便一键找回候选继续审阅。

> 说明：这里介绍的是笔记编辑器内针对单篇笔记正文的精细修订与审阅；如果你是在对话中让学习 Agent 修改多个文件或执行整轮工作区改动，可在对话侧使用「回合改动审阅与回退」，详见 [AI 对话与会话管理](./02-AI对话与会话管理.md)。

### 阅读模式与专注模式

1. 点顶栏的「阅读」按钮进入只读浏览，再点「编辑」回到编辑。
2. 在「更多笔记操作」里点「专注模式」（快捷键 `Ctrl / ⌘ + Shift + U`）可隐藏周围界面、只留正文，适合长时间写作；再按一次或点击「退出专注模式」恢复。

### 从笔记生成卡片和思维导图

在「更多笔记操作」→「笔记工具」里：

- **生成卡片**：AI 读整篇笔记，生成一组复习卡片，和其他来源的卡片一样进入 Anki 制卡任务台，之后可以在「闪卡」里复习（见 [Anki 制卡与模板](./12-Anki制卡与模板.md)）。
- **生成思维导图**：按笔记的标题层级和列表结构直接生成导图，不调用 AI，几秒就出，建在笔记所在的文件夹并自动打开。节点很多（超过 40 个）时，第二层以下默认折叠，先看「根 → 章 → 核心概念」。公式会照常渲染，代码块里的 `#` 注释不会被当成标题。接着可以进背诵模式自测（见 [思维导图](./08-思维导图.md)）。

### 学习属性与学习视图

适合按课程系统整理笔记、安排回顾：

1. 新建时选「新建学习笔记…」，填写标题、「所属课程」，可以套用模板；已有的笔记在右侧「属性」里也能填。
2. 「学习属性」有四项：「课程」「章节」「掌握状态」（未开始 / 学习中 / 待巩固 / 已掌握）和「复习日期」。改完点「保存学习属性」。
3. 在资源库的「笔记」视图顶部可以切换「全部」「掌握状态」「近期复习」：「掌握状态」按四档分组；「近期复习」列出已逾期和未来 7 天内要复习的笔记，逾期的会标出来。
4. 复习完一篇，点那一行末尾的「复习完成」，选下次什么时候再看：「明天再看」「3 天后」「1 周后」「1 个月后」，或「已掌握，不再提醒」（清除复习日期并把掌握状态设为已掌握）。不用再打开属性面板手改日期，对话首页「今日待复习」里的「待复习笔记」数也会随之减少。

### 历史版本

在「更多笔记操作」→「历史版本」中，可以查看本机保存的完整版本时间线与差异对比：

1. 连续编辑自动按时间间隔合并版本，重要节点可点「长期保留此版本」防止被自动清理。
2. 点「恢复为新副本」默认把旧版另存为一份新笔记，不覆盖你正在写的内容。
3. 如需直接还原到当前笔记，可点「覆盖当前笔记…」（覆盖前会自动为你保留现有版本作安全保护），也可以选择「只恢复选定行」精确找回某几段。

### 导入与导出

1. **导入**：把 Markdown 文件拖进资源库，或用「导入资料…」「导入 Markdown」，都会直接导入为笔记；正文以一级标题开头时，它会成为笔记标题。之前作为资料导入的 Markdown，打开后点「转为笔记」即可编辑。PDF、Word 等文档作为资料导入（见 [资源库](./04-学习资源中心.md)）。
2. **导出单篇**：在「更多笔记操作」里点「导出」，支持普通 Markdown、保留布局的 Markdown，以及 **Word 文档（`.docx`）** 与 **Word（讲义/公文版式）**；也可以在文件列表中右键笔记选择「导出」。
3. **删除与恢复**：删除的笔记会进入「回收站」，可以在回收站中「恢复」或「永久删除」。

## 进阶用法

- **超长笔记分段加载**：行数很多的笔记会先加载开头部分，滚动到底部时自动「加载更多行」，避免卡顿。
- **内容冲突保护**：如果同一篇笔记在其他窗口或设备被修改过，保存时会提示「检测到内容冲突」，应用会自动刷新为最新版本，并把你未保存的内容备份，你可以点「对比」查看差异后选择「恢复我的版本」或「保留远端版本」。
- **AI 生成整篇笔记**：在对话中可以直接让学习 Agent 创建新笔记（例如调研报告会自动保存为笔记），详见 [深度调研与智能记忆](./03-深度调研与智能记忆.md)。
- **字体与排版**：在右侧详情面板的「属性」中可调整当前笔记的排版样式（字号、字体、全宽等）。

## 📱 移动端说明

- **入口**：移动端从抽屉进入资源库，采用三屏滑动布局——左侧抽屉（新建入口）、中间文件列表、右侧笔记编辑。点击左抽屉的「+」→「新建笔记」可直接创建并打开。
- **编辑**：移动端编辑同样自动保存；键盘上方会出现「移动端编辑工具条」，提供块菜单、增减缩进、粗体、斜体、标题、列表、任务列表、图片、撤销 / 重做等常用按钮。
- **大纲**：点击编辑器的侧栏按钮，大纲会以底部面板形式弹出。
- **形态差异**：
  - 右侧详情面板在移动端以全屏 / 面板形式打开；
  - 「导出」在移动端会提示不支持，请在桌面端导出；
  - 悬停类交互（如双链悬停预览）在触屏上以点击代替。

更多移动端通用操作见 [移动端指南](./17-移动端指南.md)。

## 常见问题

**Q1：笔记没保存上怎么办？**
应用默认自动保存，右上角会显示保存状态。若提示「笔记自动保存失败」，请先按 `Ctrl / ⌘ + S` 手动保存，或复制内容到安全位置。单篇笔记内容超过 1MB 会无法保存，请删减内容或拆分为多篇。

**Q2：图片插入失败或提示过大？**
单张图片上限 10MB。若提示「图片未能持久化保存」，说明图片只在本次会话可见，请检查后重新插入。

**Q3：提示「检测到内容冲突」是什么意思？**
说明这篇笔记已在其他窗口或设备被保存过。应用会显示最新版本，同时把你正在编辑的内容备份到本地，可通过通知里的「恢复我的版本」找回。

**Q4：误删了笔记还能找回吗？**
可以。删除的笔记会进入资源库的「回收站」，在那里点「恢复」即可；「永久删除」和「清空回收站」则不可撤销。

**Q5：AI 修改笔记后不满意怎么办？**
你可以在「逐块差异微调」或「富文本逐组审阅」中逐处拒绝不需要的改动；即使已经直接写回或应用了多轮改动，也可以通过顶部的撤销条或**多步检查点回滚**恢复到修改前的版本，或者在「历史版本」中找回旧稿。

**Q6：双链 `[[` 弹不出搜索列表？**
请确认 `[[` 是在正文段落中输入（代码块内不会触发），且当前是编辑模式而非阅读模式。
