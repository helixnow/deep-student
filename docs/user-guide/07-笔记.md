# 笔记

> 一个支持双链、标签、数学公式和 AI 协作编辑的 Markdown 笔记系统，你的所有笔记都保存在本地。

## 功能概览

笔记是 Deep Student 学习资源体系的一部分，你可以用它来：

- 用富文本方式写 Markdown 笔记：标题、列表、表格、代码块、图片、数学公式、高亮块、折叠块都能直接插入
- 用「双链引用」（Wikilink）把笔记互相链接起来，形成自己的知识网络
- 给笔记打标签、加收藏，配合文件夹整理
- 在笔记中引用教材、错题等学习资源
- 让 AI 直接帮你修改笔记：AI 的每一处改动都会先以「AI 编辑建议」的形式展示，由你决定接受还是拒绝
- 导入已有的 Markdown / PDF / DOCX 文件，或把笔记导出带走

适合的场景：课堂笔记、错题复盘、考前整理、读书摘录，以及配合 AI 对话做调研报告和知识总结。

## 入口与界面布局

笔记统一存放在「学习资源」中：

1. 点击左侧边栏的「学习资源」进入资源中心。
2. 在文件浏览区的工具栏点击「+」，选择「新建笔记」（也可以在文件夹上右键选择「在此新建笔记」）。
3. 双击任意笔记即可打开编辑器。

打开笔记后，界面分为三部分：

- **正文编辑区**：顶部是笔记标题，下方是正文。正文区域占位提示为「输入 '/' 唤起命令菜单...」。
- **编辑器顶栏**：从左到右依次是「笔记模板」「查找替换」「阅读模式 / 编辑模式」切换和「专注模式」按钮。
- **右侧详情面板**：点击右上角「打开详情」展开，包含三个标签页——「属性」（创建 / 更新时间、标签、附件）、「大纲」（正文标题目录，点击可跳转）、「外链」（本笔记引用的其他笔记和外部链接）。

笔记会自动保存，顶部会显示「已保存」「保存中...」等状态；也可以随时按 `Ctrl / ⌘ + S` 手动保存。

## 笔记工作区（学习桌面）

在「学习桌面」模式下，点击 Dock 上的「笔记」图标会打开一个独立的笔记工作区窗口，把文件管理、多标签编辑和链接网络集中在一处：

- **文件树侧栏**：左侧是知识库文件树，支持文件夹整理、拖拽移动、收藏区、标签筛选和文件名搜索；工具栏可直接新建笔记、文件夹和思维导图，回收站也在这里打开。窗口较窄时，工具栏尾部的低频按钮会自动折叠进「更多操作」菜单，不会被裁掉。按 `Ctrl / ⌘ + \` 可随时折叠 / 展开侧栏，把宽度留给正文。
- **多标签编辑**：打开的笔记和思维导图以标签页并列，`Ctrl + PageUp / PageDown` 或 `Ctrl / ⌘ + Shift + ] / [` 循环切换；关闭前有未保存修改会先确认。
- **快速打开与全文搜索**：按 `Ctrl / ⌘ + P` 弹出快速打开面板，空关键词时先列「最近打开」，输入即可按文件名模糊匹配（支持 `#标签` 过滤），也可切换到全文搜索模式在笔记内容中检索并高亮命中。搜索还支持操作符组合过滤：`tag:数学` 按标签、`path:课程` 按所在路径、`status:done` 按自定义属性（`key:value`），带空格的值用引号包裹（如 `tag:"线性代数"`）；已生效的操作符会以标签条展示，可一键移除。结果超过一屏时点底部「加载更多结果」继续翻页，不设硬性条数上限。
- **「属性」面板**：右侧面板的「属性」页展示创建 / 更新时间、标签和正文大纲；纯正文保存（不改标题标签）后，更新时间与大纲也会实时刷新。此外可以给笔记添加**任意键值属性**（如 `status: 进行中`、`来源: 教材`）——点「添加属性」输入属性名和值即可，单篇最多 32 个；属性可直接在搜索中用 `key:value` 过滤（见上）。
- **「图谱」面板**：右侧面板的「图谱」页把当前笔记的链接网络画成一张局部关系图——中心是当前笔记，内环是与它直接相连的笔记（入链 + 出链），外环是再隔一跳的笔记。工具栏可切换「1 度 / 2 度」范围、手动刷新；尚未创建的 `[[未解析链接]]` 会以虚节点显示。**点击任意节点即可打开对应笔记**；连接特别多时会提示「仅显示部分节点」。
- **「链接」面板**：右侧面板的「链接」页汇总当前笔记的**出链**、**反向链接**、**未链接提及**和**未解析链接**四类信息：
  - 点击任意条目会打开对应笔记，并**自动定位到引用出现的位置**（带 `#标题` 的链接直接滚动到该标题）；
  - **未链接提及**是正文里出现了某篇笔记标题、但还没写成 `[[双链]]` 的纯文本，点「转为链接」即可原地改写成双链——如果那篇笔记正在编辑且有未保存修改，会先提示保存；与其他窗口的并发修改冲突时也不会覆盖对方内容；
  - **未解析链接**（指向不存在笔记的 `[[链接]]`）可以直接点「创建笔记」补上目标。
- **重命名自动回写双链**：把一篇笔记改名后，其他笔记中按旧标题书写的 `[[双链]]` 会自动改写为新标题（保留 `#标题` 和 `|别名` 部分），完成后有通知汇总；正在编辑中的笔记会跳过并提示手动检查。
- **并排 / 覆盖自适应**：窗口足够宽时链接面板与正文并排显示，窗口较窄或开启分屏时自动改为覆盖层。
- **标签重命名全局传播**：在「属性」页重命名一个标签后，知识库里**所有**带这个标签的笔记都会同步改名，完成后有通知汇总数量。
- **大库分页加载**：文件很多时按分页加载完整列表；超过 20000 个文件才会截断，且会明确提示「文件树仅显示部分内容」，不会静默丢文件。

## 核心操作

### 新建并编辑一篇笔记

1. 在「学习资源」中点击「+」→「新建笔记」，输入笔记名称。
2. 打开笔记后先写标题，然后在正文输入 `/` 唤起命令菜单，可以插入：普通文本、一到六级标题、引用、分隔线、无序 / 有序 / 任务列表、图片、代码块、表格、数学公式、高亮块、折叠块。
3. 选中一段文字会浮出「格式化」工具条，可设置粗体、斜体、删除线、行内代码、标题级别、链接、双链引用、高亮块等。
4. 需要起步模板时，点击顶栏的「笔记模板」，内置 8 种模板：「听课笔记」「错题复盘」「应试整理」「会议记录」「读书笔记」「周计划」「康奈尔笔记」「文献笔记」。

### 插入图片与公式

1. **图片**：直接把图片拖进编辑器或粘贴剪贴板图片即可，也可以用 `/` 菜单选「图片」。单张图片上限 10MB，支持 PNG、JPG、GIF、WebP 等格式。点击图片可调整宽度、对齐方式和图片说明，再次点击可放大预览。
2. **数学公式**：用 `/` 菜单选「数学公式」，在弹出的编辑框中输入 LaTeX，右侧实时预览；「常用模板」里内置分数、积分、极限、矩阵等常见结构，按 `Ctrl / ⌘ + Enter` 快速插入。

### 用双链把笔记连起来

1. 在正文中输入 `[[`，会弹出笔记搜索列表，继续输入关键词筛选，回车即可插入一条指向其他笔记的「双链引用」。
2. 如果目标笔记还不存在，列表底部会出现「创建 "××"」，选择后会自动创建这篇新笔记并链接过去。
3. 把鼠标悬停在双链上可以预览目标笔记内容，点击即可跳转。
4. 在右侧详情面板的「外链」标签页可以查看当前笔记引用了哪些笔记和外部链接。

### 引用教材、错题等学习资源

1. 在正文中输入 `@`，弹出引用搜索框（提示「输入关键词以引用」）。
2. 搜索并选择要引用的对象（如教材、错题），笔记中会插入一张引用卡片。
3. 点击引用卡片可以预览内容；右键卡片可选择「打开原始资源」「发送到对话」「移除引用」等操作。

### 给笔记打标签、加收藏

1. 打开右侧详情面板的「属性」标签页，在「标签」区域点击「添加标签」，输入后回车即可；已有标签会作为建议出现。
2. 在「学习资源」的文件列表中右键笔记，可选择「收藏」；收藏的笔记可以在快速访问区找到。

### 查找与替换

1. 点击顶栏的「查找替换」按钮。
2. 在「查找…」框输入内容，用「上一个 / 下一个」在匹配之间跳转（`Enter` 下一个，`Shift + Enter` 上一个）。
3. 点击「展开替换」，输入替换内容后可「替换」单处或「全部」替换。

### 让 AI 帮你改笔记（AI 画布编辑）

1. 打开一篇笔记，同时在对话中让 AI 处理它（例如把笔记引用进对话后说"帮我把这篇笔记整理成大纲"，详见 [AI对话与会话管理](./02-AI对话与会话管理.md)）。
2. AI 提出修改时，编辑器里会出现「AI 编辑建议」面板，标明这次操作是「追加内容」「替换内容」还是「设置内容」，改动位置会在正文中高亮闪烁提示。
3. 点击「接受」应用改动，或点击「拒绝」放弃。
4. 接受后顶部会提示「AI 编辑已应用」，如果反悔可以点击「回滚整轮」恢复到 AI 修改前的完整内容，或点击「保留」确认结果。

### 阅读模式与专注模式

1. 点击顶栏的「阅读模式」按钮进入只读浏览，再次点击回到「编辑模式」。
2. 点击「专注模式」（快捷键 `Ctrl / ⌘ + Shift + U`）可隐藏周围界面、只留正文，适合长时间写作；再按一次或点击「退出专注模式」恢复。

### 导入与导出

1. **导入**：在「学习资源」的「+」菜单中选择「导入 Markdown」，选择本地 Markdown 文件即可导入为笔记；PDF、DOCX 文档也可以作为资料导入资源中心（见 [学习资源中心](./04-学习资源中心.md)）。
2. **导出单篇**：在文件列表中右键笔记选择「导出」，或通过命令面板执行「导出当前笔记」。
3. **删除与恢复**：删除的笔记会进入「回收站」，可以在回收站中「恢复」或「永久删除」。

## 进阶用法

- **超长笔记分段加载**：行数很多的笔记会先加载开头部分，滚动到底部时自动「加载更多行」，避免卡顿。
- **内容冲突保护**：如果同一篇笔记在其他窗口或设备被修改过，保存时会提示「检测到内容冲突」，应用会自动刷新为最新版本，并把你未保存的内容备份，你可以选择「恢复我的版本」或「保留远端版本」。
- **AI 生成整篇笔记**：AI 具备智能笔记能力（内置 `canvas-note` 技能组），在对话中可以让它直接创建新笔记（例如调研报告会自动保存为笔记），详见 [深度调研与智能记忆](./03-深度调研与智能记忆.md)。
- **字体与排版**：在右侧详情面板的「属性」中可调整当前笔记的排版样式（字号、行距、字体）。

## 📱 移动端说明

- **入口**：移动端从抽屉进入「学习资源」，采用三屏滑动布局——左侧抽屉（新建入口）、中间文件列表、右侧笔记编辑。点击左抽屉的「+」→「新建笔记」可直接创建并打开。
- **编辑**：移动端编辑同样自动保存；键盘上方会出现「移动端编辑工具条」，提供块菜单、增减缩进、粗体、斜体、标题、列表、任务列表、图片、撤销 / 重做等常用按钮。
- **大纲**：点击编辑器的侧栏按钮，大纲会以底部面板（Sheet）形式弹出。
- **形态差异**：
  - 右侧详情面板在移动端以全屏 / 面板形式打开；
  - 「导出」在移动端会提示不支持，请在桌面端导出；
  - 悬停类交互（如双链悬停预览）在触屏上以点击代替。

更多移动端通用操作见 [移动端指南](./17-移动端指南.md)。

## 常见问题

**Q1：笔记没保存上怎么办？**
应用默认自动保存，右上角会显示保存状态。若提示「笔记自动保存失败」，请先按 `Ctrl / ⌘ + S` 手动保存，或复制内容到安全位置。单篇笔记内容超过 1MB 会无法保存，请删减内容或拆分为多篇。

**Q2：图片插入失败或提示过大？**
单张图片上限 10MB。若提示「图片未能持久化保存」，说明图片只在本次会话可见，请检查后重新插入。

**Q3：提示「检测到内容冲突」是什么意思？**
说明这篇笔记已在其他窗口或设备被保存过。应用会显示最新版本，同时把你正在编辑的内容备份到本地，可通过通知里的「恢复我的版本」找回。

**Q4：误删了笔记还能找回吗？**
可以。删除的笔记会进入「学习资源」的「回收站」，在那里点「恢复」即可；「永久删除」和「清空回收站」则不可撤销。

**Q5：AI 修改笔记后不满意怎么办？**
每次 AI 编辑都要经过你「接受」才会生效；即使接受了，也可以在提示条上点「回滚整轮」恢复到修改前的内容。

**Q6：双链 `[[` 弹不出搜索列表？**
请确认 `[[` 是在正文段落中输入（代码块内不会触发），且当前是编辑模式而非阅读模式。
