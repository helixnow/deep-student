# 深度调研与智能记忆

> 让学习 Agent 像研究助理一样分阶段完成联网调研并写成报告，同时在长期使用与不同学习空间中自动记住你的偏好与学习状态。

## 功能概览

**深度调研（调研模式）**是一个内置的多步骤研究助手。给出一个调研主题后，AI 会先确认调研深度与输出格式偏好，随后拆解研究计划，通过联网搜索、多模态与文档知识库检索、灵感卡回溯进行交叉验证，在实时研究仪表盘中透明展示推进过程，并把结构化的调研报告直接写入你的笔记库。适合技术调研、课题综述前的资料收集、时事与趋势梳理等场景。

**智能记忆**让 AI 越用越懂你。开启后，AI 会在对话结束后自动提取关于你的信息（身份、偏好、学习目标、学科状态等），以普通笔记形式保存在本地；之后的对话会自动检索并注入相关记忆，并支持按学习空间隔离或共享长期记忆。你随时可以在记忆管理中内联展开预览、跳转原文笔记、编辑、删除、恢复或导出。

## 入口与界面布局

### 深度调研

调研模式是一项内置技能，在对话页面激活，有两种方式：

- **斜杠命令**：在输入框开头输入 `/`，从弹出的「技能命令」列表中选择「调研模式」（`/research-mode`）。
- **技能面板**：点击输入栏加号菜单（「＋」）→「技能」，在技能列表中搜索并「激活」调研模式；面板中会显示「已激活」标记。

> 提示：发起联网调研前，请确认对话输入栏「＋」菜单中的顶层**「联网搜索」**开关处于开启状态；若将其关闭，深度调研将无法访问外部搜索引擎。

调研进行时，消息区与输入栏上方会出现这些核心元素：

- **提问卡片**：AI 用来向你确认偏好，带选项按钮（含「推荐」标记）、「确认选择」和自定义回答输入框，可「忽略」（交互类卡片始终保持可见，不会被折叠）。
- **实时 5 阶段研究仪表盘**：动态呈现深度调研的 5 个推进阶段（制定检索计划 → 文献检索 → 引用筛选 → 子代理调研 → 综合报告）与实时状态，支持一键**「复制报告」**、**「导出计划」**和**「复制为 Markdown」**。
- **输入栏上方任务面板**：附着在输入栏正上方，同步展示「计划」（可点开**「DAG 拓扑视图」**查看任务依赖与派发进度）、「来源」、「产物」（报告笔记可直接预览）与「变更」（可进**「Diff 审阅面板」**审阅或回滚报告改动）。
- **搜索与知识库检索块**：显示每次检索的命中条数与来源类型，可展开核对出处。
- **笔记写入块**：报告写入笔记时显示「创建笔记」「追加内容」等操作，点「在学习资源中打开」可直接在资源库里查看报告。

### 智能记忆

记忆相关界面分布在四处：

- **设置 → 记忆**：桌面端与移动端统一在此配置总开关、存储位置、默认分类与自动提取频率。
- **资源库 → 左侧「AI 记忆」**：「记忆管理」页面，浏览、搜索、内联预览、跳转笔记、编辑、删除或恢复过期/归档记忆，并查看用户画像与记忆树。
- **学习空间设置 → 目标与记忆调度**：为单个学习空间配置专属的「长期记忆范围」隔离策略。
- **对话消息中**：当 AI 检索到相关记忆时，回答上方会出现「用户记忆」块，显示命中的记忆条数与类型。

## 核心操作

### 发起一次深度调研

1. 新建一个会话（建议每次调研单开会话，避免上下文过长），并确认「＋」菜单里的「联网搜索」开关已打开。
2. 输入 `/` 并选择「调研模式」，然后在同一条消息里写清调研主题，例如：`/research-mode 调研 2026 年大语言模型的最新发展趋势`，发送。
3. AI 会先弹出提问卡片，询问调研深度（快速概览 / 中等深度 / 深度调研）和输出格式偏好，点选后按「确认选择」（也可以直接输入自定义回答）。
4. AI 随后建立研究计划并在实时 5 阶段研究仪表盘中逐步推进：联网搜索、抓取网页正文、检索本地与多模态知识库、交叉验证并撰写报告。你可以随时查看进度，或点「停止」（或双击 `Esc`）中断。
5. 调研结束后，报告会保存为一篇结构化笔记（涵盖调研概述、主要发现、详细分析、结论与建议、参考来源）。你可以在仪表盘直接「复制报告」「导出计划」「复制为 Markdown」，或在笔记写入块中点「在学习资源中打开」，后续在 [笔记](./07-笔记.md) 中继续编辑。

提示：调研会执行较多次工具调用，如果中途出现「已达工具调用限制」卡片，点「继续执行」即可让 AI 接着做完。

### 跟踪调研进度与核对来源

1. 调研开始后，消息区的任务进度与**实时 5 阶段研究仪表盘**会同步刷新，完整呈现从拆解、检索、验证到成稿的每一步。
2. 输入栏上方的**任务面板**同步汇总「计划」「来源」「产物」和「变更」：
   - 在「计划」区点「DAG 拓扑视图」可直观查看子任务依赖关系与三态进度；
   - 在「产物」区可直接预览生成的报告笔记；
   - 在「变更」区点「Diff 审阅面板」可核对或回滚本轮对笔记的写入修改。
3. 每个检索块都可展开核对出处，来源类型现已扩展至 **6 类**：
   - **网络搜索**
   - **文档知识库**
   - **多模态知识库**
   - **用户记忆**
   - **学术论文**
   - **灵感卡**
   点击「打开来源」即可直达原文、笔记或对应灵感卡。
4. 对调研方向不满意时，随时中断并补充一条新的指示，AI 会自动调整后续研究计划。

### 调研前的准备：配置搜索引擎与网页抓取

深度调研依赖外部联网搜索与网页正文提取。请前往「设置 → 外部搜索」：

1. **选择外部搜索引擎（共支持 9 个）**：
   - **免费开箱即用**：「Bing RSS（免费）」无需任何 Key，默认即可直接使用；
   - **API Key / 自建引擎**：`Google CSE`、`SerpAPI（Google）`、`Tavily`、`Brave`、`智谱 AI（国产）`、`博查 AI（国产）` 填入对应 API Key，`SearXNG` 填入自建实例端点地址；
   - **DeepSeek 官方搜索**：支持返回带相关性评分与权威性分级的结果，原生支持 `site:` / `lang:` / `after:` / `before:` 精确语法；开启**「搜索时返回网页正文」**（官方 `need_content`）后，搜索结果直接附带 Markdown 正文，减少二次抓取且不额外计费；其 API Key **留空时会自动复用模型服务里已配置的 DeepSeek API Key**。
2. **DeepSeek Fetch 网页抓取后端**：在 DeepSeek 能力或搜索相关设置中启用后，抓取网页正文时优先走 DeepSeek Fetch 提取；若抓取失败，会自动无缝回退到本地抓取，兼顾正文质量与稳定性。
3. 用「测试可用性」验证连通性，并设为「默认搜索引擎」。
4. 切记不要在对话输入栏的「＋」菜单里关闭**「联网搜索」**总开关，否则深度调研只会停留在本地资料，无法联网获取新信息。
5. 如果希望调研同时检索个人资料，请确认相关文档已在资源库的「知识库索引」或「多模态知识库」完成索引（见 [资源库](./04-学习资源中心.md)）。

### 开启智能记忆

1. 打开**「设置 → 记忆」**（桌面端与移动端路径一致）。
2. 打开「启用」开关。开启后 AI 会自动提取并调用关于你的信息来个性化对话体验；关闭后不再提取、检索或注入任何用户记忆。
3. 在「存储位置」中选择或新建一个文件夹作为记忆根目录（默认名称「我的记忆」）。记忆以普通笔记形式存放在这个文件夹里。
4. 按需调整：
   - 「自动创建子文件夹」：写入记忆时自动按分类建子文件夹
   - 「默认分类」：未指定分类时记忆存入的子文件夹（通用 / 偏好 / 经历）
   - 「自动提取频率」：对话结束后自动提取记忆的频率，可选「关闭 / 平衡 / 积极」
5. （可选）在「设置 → 模型分配」中指定「记忆决策模型」——用于判断新记忆应当新增、更新还是合并，建议选择快速轻量的模型；不设置时使用功能增强模型。

### 查看、管理与恢复记忆

1. 打开资源库，在左侧点「AI 记忆」进入「记忆管理」页面（首次进入若未设置根文件夹，会引导你「选择记忆根文件夹」或「创建记忆文件夹」）。
2. 顶部搜索框可按关键词「搜索记忆…」。
3. **内联展开与跳转笔记**：记忆列表支持点击条目**内联展开预览**正文，并可**一键跳转到对应的原始笔记**，无需频繁弹窗切换；也可以直接「编辑记忆」或手动「创建新记忆」。
4. **行内二次确认删除**：单条删除改为**行内二次确认**，避免误删也不必经过繁琐的居中弹窗；勾选多条记忆仍支持批量删除。
5. **恢复过期 / 归档记忆**：对于因长期未命中而被归档或标为过期的记忆，可以在列表中查看并一键**恢复**，重新纳入日常检索。
6. 点「导出记忆」可把全部记忆导出保存；页面同时提供「记忆树」视图（按分类的树状结构）和自动汇总生成的用户画像展示。

### 在对话与学习空间中利用记忆

1. 记忆开启后无需额外操作：提问时 AI 会自动检索相关记忆，回答上方出现「用户记忆」块，标注命中条数和类型：
   - **对话记忆**：从近期对话中提取的短期上下文
   - **长期记忆**：稳定的事实与偏好（如「目标院校」「薄弱科目」）
   - **用户画像**：由多条记忆汇总生成的整体描述
2. 展开记忆块可查看具体命中了哪几条，点击可跳转到对应记忆。
3. 你也可以直接让 AI 记住某件事，例如发送「记住：我是高三学生，目标院校是 ××」，AI 会调用记忆工具写入（写入操作受当前会话执行档位约束，见 [AI 对话与会话管理](./02-AI对话与会话管理.md)）。
4. **学习空间级长期记忆范围隔离**：当你在不同学习空间里同时备考多个学科或推进不同项目时，可以在每个学习空间的「编辑学习空间 → 目标与记忆调度 → 长期记忆范围」中单独设定隔离策略：
   - **本空间优先 + 全局画像**（默认）：优先检索本空间积累的长期记忆，同时参考全局用户画像；
   - **仅限本空间隔离**：只在本空间记忆范围内检索和注入，彻底避免跨学科信息串扰；
   - **仅使用全局记忆**：忽略空间隔离，统一使用全局记忆库。

## 进阶用法

- **调研 + 记忆联动**：调研模式可按需加载记忆工具，让 AI 在调研时参考你已有的背景（如研究方向、前置知识），并把重要结论沉淀为长期记忆。
- **在学习空间中固定调研配置**：把调研模式设为某个学习空间的「默认技能」，该空间下每个新会话自动携带调研能力，配合空间 System Prompt 与空间级记忆隔离即可固定报告风格与领域上下文。
- **审阅与回滚调研写入**：若希望写入笔记前逐项把关，可将当前会话执行档位切至「谨慎」；报告写入后，也可随时打开输入栏上方任务面板的「变更 → Diff 审阅面板」逐文件审阅或一键回滚。
- **记忆的自动维护**：新提取的事实会与已有记忆做语义比对，由 AI 判定新增、更新、追加还是删除，避免重复堆积；长期未命中的记忆会逐渐淡出或归档（随时可手动恢复），高频命中的条目会被突出。

## 📱 移动端说明

- **深度调研**：移动端可正常使用。在对话输入框输入 `/` 选择调研模式即可；5 阶段研究进度、任务列表、搜索块、提问卡片均已适配小屏。建议调研期间保持应用在前台，切走后台可能中断长时间生成。
- **记忆管理**：打开资源库，点左上角 ☰ 打开抽屉，选择「AI 记忆」。未设置根文件夹时显示引导页；已设置时支持列表内联展开预览、跳转笔记、行内二次确认删除、恢复过期/归档记忆以及记忆树浏览。
- **记忆设置**：移动端与桌面端路径已统一——从抽屉底部进入「设置」，直接点击**「记忆」**分区即可配置开关、存储位置与提取频率。
- **搜索引擎配置**：同样在移动端设置的「外部搜索」分区中完成，支持全部 9 个引擎（含 DeepSeek 官方搜索）与可用性测试。

## 常见问题

**Q1：发起调研后 AI 说搜索失败 / 没有联网结果？**
先检查两处：① 在对话输入栏的「＋」菜单里确认顶层**「联网搜索」**开关处于开启状态；② 前往「设置 → 外部搜索」从 9 个引擎中选好默认引擎（Bing RSS 免费可用，DeepSeek 官方搜索可留空复用模型服务 Key，其余按需填 Key 或端点），用「测试可用性」验证通过后再重试。

**Q2：调研报告保存在哪里？**
报告以笔记形式保存在你的笔记库中，调研结束时研究仪表盘支持一键复制报告或导出 Markdown，消息里的笔记块也提供一键打开入口，之后随时可在资源库继续编辑（见 [资源库](./04-学习资源中心.md)）。

**Q3：调研做到一半停下来了？**
两种常见情况：一是触发了工具调用上限，消息区会出现「已达工具调用限制」卡片，点「继续执行」或直接发送「继续」即可；二是 AI 的写操作在等你审批，查看消息区是否有未被折叠的工具确认或提问卡片。

**Q4：AI 记住了过时或错误的信息怎么办？**
到资源库「AI 记忆」的「记忆管理」里搜索到对应条目，内联展开核对后直接编辑修正或行内二次确认删除即可；AI 下次对话会使用更新后的记忆。

**Q5：不想让不同科目的记忆互相串扰怎么办？**
为不同科目分别建立学习空间，在空间设置的「目标与记忆调度 → 长期记忆范围」中选择**「仅限本空间隔离」**，即可让该空间的长期记忆保持独立。

**Q6：我不想让 AI 记录我的信息，怎么彻底关掉？**
在「设置 → 记忆」关闭「启用」开关即可，关闭后不再提取、检索或注入用户记忆。已有记忆不会被自动删除，可在「记忆管理」中自行删除；也可以仅把「自动提取频率」设为「关闭」，保留手动记忆但停止对话后自动提取。

**Q7：记忆数据存在哪里？会上传云端吗？**
记忆以普通笔记文件存储在本地指定的记忆根文件夹中，不会单独上传。只有在你主动使用云同步备份时才会随其他数据一起备份，见 [数据管理与云同步](./16-数据管理与云同步.md)。
