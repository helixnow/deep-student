# 深度调研与智能记忆

> 让 AI 像研究助理一样分阶段联网调研并写成报告；同时通过全新的**长期记忆内核**，让你亲手定规矩、看清 AI 记住了什么、随时修改或回滚，越用越懂你的学习节奏。

## 快速上手：你想做什么？

| 你想做什么 | 3 步操作 | 你会看到 |
|---|---|---|
| **让 AI 永远记住一条互动规矩** | 1. 打开资源库左侧「AI 记忆」→ 2. 在顶部「长期记忆内核」输入规则、选作用域（全局 / 数学 / 英语 / 作文批改）并勾选「必遵」→ 3. 点「添加规则」 | 下次新对话第 1 轮 AI 就会 100% 照做，规则字符预算实时可见 |

## 功能概览

- **智能记忆（Memory v2 双区工作台）**：把记忆分为**上半区「长期记忆内核」**（每次新对话第 1 轮必看的高价值规则、薄弱点与学习目标，受字数预算约束、透明可预览、支持 10 版历史回滚与一键梳理）和**下半区「记忆笔记归档库」**（以普通笔记保存在本地文件夹，支持分组、搜索、内联预览与恢复）。你在聊天每条回答下方还能随时点开「记忆内核」胶囊核对并一键「忘掉」。
- **深度调研（调研模式）**：给出研究主题后，AI 先确认深度与格式，再自动拆解计划、跨网络与本地资料库交叉验证，在实时 5 阶段研究仪表盘中透明推进，最终把结构化报告直接写进你的笔记库。

## 入口与界面布局

### 智能记忆工作台分布

1. **资源库 → 左侧「AI 记忆」**（主工作台）：采用上下双区布局——
   - **上半区「长期记忆内核」**：集中管理**互动硬规则**、**活跃薄弱点**、**学习目标**，右上角常驻字符预算条、**「梳理建议」**、**「预览注入内容」**和**「历史 (N)」**。
   - **下半区「记忆笔记归档」**：以普通本地笔记管理长期归档事实，支持「+ 新建分组」、移动到分组、列表 / 树状视图切换、内联展开预览与跳回原笔记。
2. **对话消息下方「记忆内核 · N 规则 / M 薄弱点」胶囊**：在聊天现场直接查看本轮生效的规则与薄弱点，一键「忘掉这条规则」或跳往「管理记忆设置」（详见 [AI 对话与会话管理](./02-AI对话与会话管理.md#查看并修正记忆内核归因胶囊每条回答透明可追溯)）。
3. **设置 → 记忆**：配置记忆总开关、记忆存储文件夹、自动子文件夹、默认分类与自动提取频率（桌面端与移动端路径一致）。
4. **学习空间设置 → 目标与记忆调度**：为单个学习空间单独设置「长期记忆范围」隔离策略。

### 深度调研入口

在对话页有两种方式激活「调研模式」：

- **斜杠命令**：在输入框开头输入 `/`，选择「调研模式」（`/research-mode`）。
- **技能面板**：点输入栏「＋」→「技能」，搜索并「激活」调研模式。

> 提示：发起联网调研前，请确认输入栏「＋」菜单中的顶层 **「联网搜索」** 开关处于开启状态；关闭后深度调研只会检索本地资料。

## 核心操作：智能记忆（Memory v2）

### 1. 开启记忆与配置基础开关

1. 打开 **「设置 → 记忆」**，确认 **「启用」** 开关已打开（关闭后不再提取、检索或注入任何用户记忆）。
2. 在 **「存储位置」** 中选择或新建一个本地文件夹存放记忆笔记（默认「我的记忆」）。即便暂未绑定归档目录，「长期记忆内核」也已就绪可用。
3. 按需调整：
   - **「自动创建子文件夹」** 与 **「默认分类」**（通用 / 偏好 / 经历）；
   - **「自动提取频率」**：可选 **关闭**（仅停止对话后自动提取，已有记忆与画像照常工作）、**平衡**（默认，每轮满 10 字触发）或 **积极**（满 4 字触发，整理更勤）。
4. （可选）在「设置 → 模型分配」指定轻快的 **「记忆决策模型」**，不设时自动使用核心模型。

### 2. 添加「互动硬规则」（首轮 100% 强制遵循）

想让 AI 记住你固定的讲解习惯（例如「先用生活例子讲直觉，再写推导，最后附 1 道变式题先不给答案」），直接加进互动硬规则：

1. 打开资源库左侧 **「AI 记忆」**，在顶部 **「长期记忆内核」** 找到 **「互动硬规则（首轮 100% 强制遵循）」** 区域。
2. 在输入框写下规则，选择它的 **作用域**：
   - **`全局`**（所有对话生效）
   - **`数学`**（数学相关学习生效）
   - **`英语`**（英语学习生效）
   - **`作文批改`**（作文批改模式生效）
3. 勾选 **「必遵」**（置顶优先保留，避免内容多时被裁剪），点 **「添加规则」**。
4. **字符预算控制**：面板右上角会实时显示 `规则` 与 `画像` 的字符用量进度条（规则默认上限 **1500 字符**，避免规则越堆越长拖慢回答或挤占上下文）。
5. **5 秒内联撤销**：点规则右侧的删除图标后，下方立刻弹出提示条，**5 秒内**点 **「撤销」** 即可无损恢复。

> 提示：在对话中途新增或删除规则时，变更会从**下一轮对话**起立刻生效；新开的对话则从第 1 轮就 100% 生效。你也可以直接在聊天里对 AI 说「记住这条规则：……」，AI 会按同样机制写入。

### 3. 管理「活跃薄弱点」与「学习目标」

在「互动硬规则」下方，左右两栏展示了你的长期学习者画像：

- **活跃薄弱点**：系统会自动接收来自**闪卡复习、题库刷题和作文批改**的真实学习信号——例如反复遗忘的知识点，或在作文批改中得分低于 **65%** 的薄弱维度，都会自动沉淀到这里，并标注学科、出现次数与常见错因。你真正掌握某项后，点右侧垃圾桶按钮（**「移出薄弱点」**）即可清掉。
- **学习目标**：在右侧输入框填入阶段目标（如「12 月前拿下雅思写作 7.0」）回车或点 `＋` 保存，不需要时随时移除。

### 4. 用三大透明工具掌控记忆：「梳理建议」「预览注入内容」「历史 (N)」

「长期记忆内核」面板右上角常驻三个实用按钮，让你完全掌控 AI 看到的每一句话：

1. **「梳理建议」**：点击后系统会自动检查反复复发的薄弱点、长期未复发的旧薄弱点、高频习惯是否适合升为硬规则、规则间是否冲突，以及字符预算是否吃紧（超过 80% 时提醒精简）。每条建议都附带一键操作按钮——如 **「升格硬规则」**、冲突规则 **「移除后一条」**、旧薄弱点 **「标记已掌握」**——**系统绝不会背着你静默改写记忆**。
2. **「预览注入内容」**：点击即可展开查看 AI 在新会话第一轮实际读到的完整记忆原文，清楚核对有没有过时或写错的内容。
3. **「历史 (N)」**：按钮始终可见，展开后分为两部分——**记忆变更历史**（记录每次新增、更新、删除）与 **学习者画像历史快照（最近 10 版）**。只要觉得最近几次自动更新不太准确，在任意历史版本（`vN · 薄弱点 X · 目标 Y`）旁点 **「回滚」**，即可一键回到当时的画像状态。

### 5. 整理下半区「记忆笔记归档库」

除了核心规则与画像，你在日常对话中积累的背景经历、长期资料偏好会以普通笔记保存在下半区归档库：

1. **快速定位与预览**：顶部「搜索记忆…」支持关键词检索，也可在列表视图与「记忆树」之间切换；点击任意条目即可**内联展开预览**，并一键跳到原笔记编辑。
2. **页内分组与移动**：直接点 **「新建分组」** 在当前页创建子文件夹；单条记忆或勾选多条后，均可直接 **「移动到分组」** 归类整理。
3. **安全删除与恢复**：单条删除采用行内二次确认，防止手滑误删；因长期未命中而被归档或过期的条目，可随时在列表中一键**恢复**，也能点「导出记忆」统一备份。

### 规则作用域、学习空间隔离与项目目录的区别

很多同学第一次用时会混淆这三个「范围」设置，其实它们各管一摊，互不冲突：

| 层次 | 在哪里设置 | 管什么 | 可选内容 |
|---|---|---|---|
| **互动硬规则作用域** | 资源库 → AI 记忆 → 长期记忆内核（添加规则时） | 控制这条互动习惯在什么科目/模式下生效 | `全局`、`数学`、`英语`、`作文批改` |
| **学习空间长期记忆范围** | 编辑学习空间 → 目标与记忆调度 → 长期记忆范围 | 控制本空间对话能否读取其他空间的记忆笔记，防止多科备考串台 | `本空间优先 + 全局画像`（默认）、`仅限本空间隔离`、`仅使用全局记忆` |
| **项目目录（工作区根目录）** | 编辑学习空间 → 基础与提示词（默认项目目录）或工作区设置 | 绑定本机磁盘文件夹，用于读写本地文档/代码和扫描项目级技能 | 本机任意已授权文件夹（与记忆笔记库相互独立） |

**推荐搭配**：同时备考考研数学与雅思写作时，可以分别建两个学习空间，把空间记忆范围设为 **「仅限本空间隔离」**；同时在记忆内核里给数学加 `数学` 作用域规则、给写作加 `英语` / `作文批改` 作用域规则——既互不串扰，又能精准定制回答风格。

### 隐私模式与关闭记忆

- 开启隐私模式后，记忆内核面板顶部会显示 **「隐私模式暂停注入」**，对话期间不读取、不注入、也不提取记忆。
- 想长期停用，可在「设置 → 记忆」直接关闭 **「启用」** 开关；如果只想保留手动规则、停止对话后自动抓取，把 **「自动提取频率」** 改为 **「关闭」** 即可。

## 核心操作：深度调研

### 调研前的准备：配置搜索引擎

前往 **「设置 → 外部搜索」**，内置 **9 个搜索引擎**：

1. **免费开箱即用**：**Bing RSS（免费）** 无需任何 Key，默认即可直接用。
2. **DeepSeek 官方搜索**：支持 `site:` / `lang:` / `after:` / `before:` 等精确语法；开启 **「搜索时返回网页正文」** 后直接带回正文，减少二次抓取且不额外计费；API Key **留空时会自动复用你在「模型服务」里保存的 DeepSeek 密钥**。配合开启 DeepSeek 网页抓取后，抓取失败会自动回退到本地抓取。
3. **其他引擎**：`Google CSE`、`SerpAPI（Google）`、`Tavily`、`Brave`、`智谱 AI（国产）`、`博查 AI（国产）` 填入对应 API Key；`SearXNG` 填自建地址。
4. 点 **「测试可用性」** 通过后设为默认引擎，并确认对话「＋」菜单里的 **「联网搜索」** 总开关处于开启状态。

### 发起并跟踪一次深度调研

1. 新建一个会话（建议每次调研单独开会话），输入 `/` 选择 **「调研模式」**，写清主题发送，例如：`/research-mode 梳理 2026 年轻量化端侧模型在学习场景的应用`。
2. AI 会先弹出 **提问卡片**，向你确认调研深度（快速概览 / 中等深度 / 深度调研）与输出格式，点选后按 **「确认选择」**（也可输入补充要求）。
3. 随后消息区会出现 **实时 5 阶段研究仪表盘**（制定检索计划 → 文献检索 → 引用筛选 → 子代理调研 → 综合报告），输入栏上方任务面板同步汇总计划、来源、产物与文件变更。
4. **6 类来源交叉核对**：展开每个检索块即可核对出处，覆盖 **网络搜索、文档知识库、多模态知识库、用户记忆、学术论文、灵感卡**，点「打开来源」直达原文。
5. 完成后报告会自动写成一篇结构化笔记，可在仪表盘一键 **「复制报告」**、**「导出计划」**、**「复制为 Markdown」**，或在笔记写入块点 **「在学习资源中打开」** 继续编辑（见 [笔记](./07-笔记.md)）。若中途触发工具调用上限，点 **「继续执行」** 即可接着跑完。

## 进阶用法

- **调研 + 记忆联动**：在某个学习空间把「调研模式」设为默认技能，并配合该空间的「长期记忆范围」与互动硬规则，每次调研都会自动按你的专业背景和固定报告格式输出。
- **审阅调研写入**：希望每一步写入都先过目时，把当前会话执行档位切为「谨慎」；写入后也可随时在输入栏上方任务面板的「变更」里对比修改或一键回滚。

## 📱 移动端说明

- **记忆工作台**：打开资源库，点左上角 ☰ 打开抽屉选择 **「AI 记忆」**，同样可使用顶部的「长期记忆内核」（增删硬规则、查看薄弱点、梳理建议、预览注入内容、历史回滚）和下半区的笔记归档管理。
- **记忆设置与外部搜索**：从抽屉底部进入「设置」，路径与桌面端完全一致（**「记忆」** 与 **「外部搜索」** 分区）。
- **深度调研**：在移动端对话输入 `/` 激活调研模式即可，5 阶段进度与提问卡片均已适配小屏；建议调研期间保持应用在前台。

## 常见问题

**Q1：AI 记住了过时或错误的信息怎么办？**
A：如果在聊天里发现不对，直接点回答下方的 **`记忆内核`** 胶囊点 **「忘掉这条规则」** 或移除薄弱点；如果想彻底检查或恢复旧版，打开资源库 **「AI 记忆」**，可在「长期记忆内核」里直接删改（删错 5 秒内可点「撤销」），或点右上角 **「历史 (N)」** 一键回滚到最近 10 个版本中的任意一版。归档笔记则可在下半区搜索后内联编辑或删除。

**Q2：为什么我加的互动规则提示超出预算了？**
A：互动硬规则默认有 **1500 字符** 的精炼预算，用来保证每轮对话响应迅速、重点不稀释。建议把每条规则写成简短明确的一句话，给最关键的规则勾选 **「必遵」**，并定期点右上角 **「梳理建议」** 合并或清理不再需要的条目。

**Q3：不想让不同科目的记忆互相串扰怎么办？**
A：给规则选对应的作用域（`数学` / `英语` / `作文批改`），同时给不同科目分别建学习空间，并在空间设置的「目标与记忆调度 → 长期记忆范围」选择 **「仅限本空间隔离」**。

**Q4：发起调研后 AI 说搜索失败 / 没有联网结果？**
A：先检查两处：① 对话输入栏「＋」菜单的 **「联网搜索」** 总开关是否开启；② 「设置 → 外部搜索」里默认引擎是否通过「测试可用性」（Bing RSS 免费开箱即用，DeepSeek 官方搜索留空可复用模型服务密钥）。

**Q5：不想让 AI 记录任何个人信息，怎么彻底关掉？**
A：在「设置 → 记忆」关闭 **「启用」** 开关即可，关闭后不再提取、检索或注入任何用户记忆；已有条目可在「AI 记忆」中自行删除。

**Q6：记忆数据存在哪里？会上传云端吗？**
A：全部保存在你本机的数据目录与记忆文件夹里，不会单独上传。只有在你主动开启云同步或云备份时，才会随你的学习数据一起加密备份（详见 [数据管理与云同步](./16-数据管理与云同步.md)）。
