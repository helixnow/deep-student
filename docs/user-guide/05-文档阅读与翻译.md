# 文档阅读与翻译

> 内置 PDF / Word / EPUB 阅读器支持论文精读（AI 论文导读、5 色语义高亮、框选提取 LaTeX/表格与钉住对照、跨应用反链与「边读边问」）；翻译工作台提供全文翻译、逐段双语对照、7 种领域预设与术语表。

## 功能概览

- **PDF 论文精读阅读器**：翻页、缩放、单双页视图、紧凑裁白边与单栏贴合（185%）、暗色阅读、5 标签侧栏（目录 / 缩略图 / 书签 / 批注 / 关联）、边扫边出全文搜索、5 色语义高亮与批注导出、跨页返回栈、文内引用预览定位、扫描页文字识别。
- **AI 论文导读与「边读边问」**：工具栏「AI 论文导读」一键提取大纲与关键页上下文发起深度对读；对话侧支持「文档优先」可调分栏阅读；勾选页面或框选公式/图表即可提问、钉住对照、提取 LaTeX / Markdown 表格或遮挡制卡。
- **跨应用页码与引文反链**：划词、批注、对话回答存为笔记自动带可点击跳回原页的 `pdfref://` 反链，闪卡「查看出处」回跳原页；PDF 页右上角显示页边反链胶囊，一键分栏打开关联的思维导图、闪卡与笔记。
- **Word / EPUB / 其他格式阅读**：Word 文档以「白纸」版式渲染并可调字号；EPUB 电子书支持目录、护眼主题与排版调节；PDF、Word、PPT、EPUB 均支持统一划词闭环。
- **翻译工作台**：面向精读的翻译工具——全文翻译、逐段双语对照、7 种领域预设、术语表、自定义提示词、流式字符进度、单段快捷复制与朗读，翻译记录自动保存为资源库文档。

适合场景：精读英文论文边读边用 5 色高亮批注并生成带反链的文献笔记；把跨页的架构图或公式钉住对照正文推导；外文文献先全文翻译、再逐段对照精读。

## 入口与界面布局

### PDF 阅读器

**打开方式**：在资源库中双击任意教材或 PDF 文档（导入方法见 [资源库](./04-学习资源中心.md)）。学习桌面里会开成一个独立窗口，可与对话窗口并排；在对话侧打开引用 PDF 时，也支持切换到「文档优先」可调分栏（「边读边问」模式）。

界面从上到下：

- **顶部工具栏**：侧栏切换、页码框（「第 x 页 / 共 y 页」）与上一页 / 下一页、缩放与版面适配（适应宽度、适应页面、实际大小、紧凑裁白边、单栏贴合 185%）、**「AI 论文导读」**菜单、「框选」工具、扫描页文字识别；「更多」菜单里有旋转、单页 / 双页视图、封面单独成页、暗色阅读、文本选择开关、全屏和快捷键提示。
- **左侧侧栏（5 标签）**（按需展开）：「目录」「缩略图」「书签」「批注」与新增的「**关联**」五个标签页合并在同一侧栏内，顶部图标切换——「关联」标签集中展示与当前 PDF 相关的笔记和相关对话，点击即可打开。
- **中间阅读区**：支持滚动阅读与文内引用预览定位。每页角落有页面选择框（勾选页面问 AI），右上角会在有跨应用关联时显示**页边反链胶囊**（如 `2 导图 · 1 闪卡`），底部在跨页跳转后浮现「返回第 N 页」返回胶囊。

### 翻译工作台

**打开方式**：在资源库点「新建」→「新建翻译」，或双击已有的翻译资源。

界面分区：

- **顶部工具栏**：布局切换（左右 / 上下分栏）；语言选择（「源语言」「目标语言」，支持「自动检测」与二十多种语言）、交换语言按钮；「自动翻译」「同步滚动」开关与翻译设置入口。
- **主体双栏**：左侧「待翻译文本」输入区（带 `⌘/Ctrl + Enter` 快捷键引导），右侧「翻译结果」（流式生成时显示字符进度，复制后弹出成功胶囊反馈）；分栏比例可拖拽调整并自动记住，语向与语气偏好也会在新建翻译时自动恢复。窗口较窄时自动改为上下排列，「自动翻译」「同步滚动」开关收进设置面板。
- **对照视图**：切换「段落对照」后，原文与译文按段落逐一对齐显示，每段支持快捷复制。
- **翻译选项面板**：语气、翻译领域、自定义提示词、术语表（见下文）。

## 核心操作

### 阅读 PDF：翻页、缩放、版面与扫描页识别

1. **翻页与跳页**：用工具栏的上一页 / 下一页按钮或键盘 `←` `→` 翻页；在页码框直接输入数字回车可跳页。
2. **跨页返回栈**：点击目录、书签、文内引用或页码跳转后，阅读区底部会浮现「返回第 N 页」胶囊，也可以用 `Alt + ←` / `Alt + →` 在跳转历史中前进后退（最多记录 **30 步**），看完图表或参考文献后一键回到正文位置。
3. **缩放与精读版面**：
   - 常规缩放：点放大 / 缩小按钮，或 `Ctrl / ⌘ + ±`；缩放菜单可选「适应宽度」「适应页面」「实际大小」。
   - **紧凑裁白边**：自动裁去页面四周空白边距，提升正文有效显示面积。
   - **单栏贴合（185%）**：阅读双栏英文论文时一键放大至单栏贴宽，免去反复手动缩放。
4. **单双页与护眼**：宽屏可开启「双页视图」与「封面单独成页」（封面独占一行，其余按 `[2,3]` `[4,5]` 对页排布）；夜间可开「暗色阅读」；「旋转」可顺/逆时针转 90°。
5. **识别扫描页文字**：遇到无文字层的扫描版 PDF，可直接点击工具栏的「识别扫描页文字」识别当前页文字层（桌面端支持系统本地 OCR 与云端 OCR；移动端需使用云端 OCR 或多模态模型）。
6. **记忆偏好**：阅读进度、缩放档位、单双页视图和封面偏移均按文档自动保存，下次打开自动恢复。

### 搜索、目录与文内引用预览

1. **边扫边出全文搜索**：点工具栏「搜索」（或按 `Ctrl / ⌘ + F`）输入关键词，找到第一个命中立即跳转高亮，结果计数随后台扫描实时增长，搜索栏显示"已扫描 x/y 页"。
2. **文内引用预览定位**：鼠标悬停或点击正文中的文内引用标记（如 `[12]`、`Fig. 3`、`Eq. (4)` 等），可就地预览对应的参考文献、图表或公式位置，并支持点击直接跳转（跳完可用 `Alt + ←` 返回）。
3. **目录与缩略图**：在左侧侧栏切换「目录」或「缩略图」快速浏览与跳页。

### 5 色语义高亮与批注管理

1. 确认「文本选择」处于开启状态，选中一段文字后即可通过弹出色板或数字快捷键 `1`–`5` 完成语义高亮：

   | 快捷键 | 颜色 | 语义用途 |
   |---|---|---|
   | `1` | 黄色 | 核心结论 |
   | `2` | 绿色 | 研究方法 |
   | `3` | 蓝色 | 背景定义 |
   | `4` | 红色 | 存疑局限 |
   | `5` | 紫色 | 公式数据 |

2. **高亮写批注**：点击已有高亮块，在弹出的批注框中输入笔记并按 `Ctrl + Enter` 保存，也可以在浮层中切换高亮颜色或「删除批注」（触屏设备从底部操作条操作）。
3. **筛选与导出**：打开侧栏「批注」标签页，支持按**颜色**与**关键词**筛选全部批注，并可将批注一键「**导出为笔记**」（每条自动携带 `pdfref://` 页码反链）或「**导出带批注的 PDF**」分享归档。
4. 注意：旋转视图下暂不支持划词高亮，请先恢复原始方向。

### 划词精读闭环与快捷键

选中文字后弹出划词工具条（PDF、Word、PPT、EPUB 均支持），并提供高频快捷键：

| 按钮 / 快捷键 | 作用 |
|---|---|
| 解释（`E`） | 结合上下文提供**四视角精读**讲解（核心释义、背景关联、实例/推导、要点延展），结果可一键**存入批注**或放入对话 |
| 翻译（`T`） | 自动识别语向（可手动切换 / 对调），结合前后文流式译出并消除多义词歧义；支持复制原文 / 译文 |
| 复制学术引文（`C`） | 复制选中文字并自动修复双栏论文常见的断词连字符与多余换行 |
| 保存为笔记 | 以选中内容为引用块新建摘录笔记，附带可点击跳回原文那一页的 `pdfref://` 反链 |
| 制卡 | 将选中内容及上下文送去闪卡后台生成记忆卡片，放进「划词制卡::资料名」牌组（见 [Anki 制卡与模板](./12-Anki制卡与模板.md)） |
| 划选即入图 / 拖入思维导图 | 把选中片段一键送入当前或新建思维导图作为节点，也支持直接将选区拖入思维导图窗口 |
| 添加到聊天 | 把这段文字连同页码作为引用加进对话输入框，接着追问 |

### AI 论文导读与「边读边问」

1. **AI 论文导读**：点击工具栏的「**AI 论文导读**」菜单，系统会自动提取当前 PDF 的目录大纲与关键页上下文，提供 5 项快捷精读动作：
   - **加入当前对话对读**：把整篇文档与大纲上下文接入当前会话开始互动对读；
   - **提炼全文核心贡献与脉络**：梳理研究问题、主要贡献与章节逻辑主线；
   - **精读当前页**：结合上下文逐段拆解正在阅读这一页的重点与公式；
   - **拆解模型架构与复现要点**：梳理方法框架、模块设计、超参数与实验复现细节；
   - **审稿人视角局限与追问**：从审稿人角度审视假设漏洞、消融不足与值得进一步追问的问题。
2. **「文档优先」可调分栏（「边读边问」模式）**：从对话侧打开或联动阅读 PDF 时，可切换为「文档优先」可调分栏布局，左侧大面积留给原文精读、右侧对话随时追问，拖拽中间分隔条自由调整宽度。
3. **选取页面问 AI**：勾选每页角落的选择框（一次最多 10 页），连续页码会自动合并为「1-3页」出现在对话输入框上方，直接输入问题即可让学习 Agent 针对所选页面作答。

### 框选工具：提问、钉住对照、提取公式与表格、遮挡制卡

页面上的公式、架构图、表格或扫描页内容不方便划词时，点工具栏的「框选」工具（窄窗口在「更多」菜单里），拖出一个矩形框即可选择以下动作：

- **框选提问**：将框选区域截成图片附件加入当前对话输入框（需当前模型支持读图），提示「已引用到对话」，点「去对话」即可追问。
- **钉住对照**：把框选的公式、架构图或表格以**悬浮对照窗口**钉在阅读器上层，翻到后面章节读文字分析时随时对照，并可一键将钉住的图块送入对话提问。
- **提取 LaTeX**：把框选的数学公式识别并转换为可复制的 LaTeX 代码。
- **提取表格（Markdown）**：把框选的数据表格解析为规范的 Markdown 表格，方便直接贴进笔记。
- **拖出摘录与遮挡制卡**：将框选图像直接拖出摘录到笔记，或进入图像遮挡制卡流程，圈出要挖空的区域生成复习闪卡。

一次框选对应单个页面（跨页时取覆盖面积更大的那一页），高亮批注不会截入底图；按 `Esc` 或点「取消」随时退出。

### 跨应用 PDF 页码与引文反链

Deep Student 把阅读器、笔记、对话、思维导图和闪卡通过页码反链打通：

- **笔记与对话反链**：划词「保存为笔记」、批注「导出为笔记」、或将对话中带页码引用的回答存为笔记时，都会写入 `pdfref://` 链接；在笔记或对话里点击引用徽章，会直接打开 PDF 并跳到对应页面、高亮原句。
- **闪卡出处回跳**：复习由 PDF 划词或遮挡生成的闪卡时，点击「查看出处」直接跳回原 PDF 的对应页。
- **页边反链胶囊**：当某一页已被思维导图、闪卡或笔记引用时，该页右上角会显示**页边反链胶囊**（例如 `2 导图 · 1 闪卡`），点击胶囊会自动以分栏方式打开对应的导图、闪卡或笔记，双向对照。
- **侧栏「关联」标签**：打开左侧侧栏第 5 个标签「关联」，可一览整份 PDF 关联的所有相关笔记与相关对话。

### 书签

1. 翻到想标记的页面，点工具栏的「添加书签」。
2. 书签默认命名为"书签 - 第 x 页"，会自动打开侧栏「书签」标签页进入标题编辑，可直接改名。
3. 之后点侧栏「书签」图标打开列表，点击任意书签即可跳页；不需要时点「删除书签」。

### 阅读 Word / EPUB / 其他文档

- **Word（DOCX）**：双击打开即渲染为分页的「白纸」版式，工具栏可以「增大字号 / 减小字号 / 重置字号」。正文可以选中并划词，引用会带上「第 N 节」。加密文档无法预览时会有相应提示。
- **PPT（PPTX）**：按幻灯片预览，同样可以划词，引用带「第 N 张幻灯片」。
- **EPUB 电子书**：支持「目录」侧栏、书内搜索、「上一章 / 下一章」；「阅读主题」可选明亮 / 护眼 / 深色 / 跟随应用；「排版设置」可调字号、字体、行距、页边距。选中文字同样有划词工具条，引用带「第 N 章」。阅读进度按章节随资料保存，换设备或清理缓存后重开仍能回到上次读到的地方。
- **Excel / 文本 / 音视频**：见 [资源库](./04-学习资源中心.md) 的格式与预览说明。

### 全文翻译

1. 打开翻译工作台，把原文粘贴进「待翻译文本」，或直接**拖拽文件**（支持图片、PDF、DOCX、TXT、MD）到输入区——图片走 OCR 识别，文档自动解析出文本。
2. 选择源语言（默认「自动检测」）和目标语言。
3. 点「翻译」按钮或按快捷键 `⌘ / Ctrl + Enter`（按钮旁有快捷键引导提示），译文流式出现在右侧「翻译结果」并实时显示**流式字符进度**。
4. 翻译完成后可以：「复制」译文（弹出**复制成功胶囊反馈**）、「导出」为 Markdown / 文本文件、「编辑译文」手动修正、「朗读」听发音，或为本次翻译打星评分。
5. 单次翻译上限 5 万字符，超出会自动截断；拖入的文件最大 50 MB。

> 翻译用的模型在「设置 → 模型分配 → 翻译专用模型」里指定（不设置就用对话模型），见 [模型与供应商配置](./14-模型与供应商配置.md)。

### 逐段双语对照

1. 翻译完成后，打开「段落对照」（对照视图）。
2. 原文与译文按段落一一对应显示，每段均带**单段快捷复制**按钮；若两侧段落数不一致，系统会按句子启发式对齐并提示。
3. 译文结果区和段落对照里的文字都可以选中，选中后弹出和 PDF 一样的划词工具条：「解释」「翻译」「保存为笔记」「制卡」「添加到聊天」——添加到聊天的引用会标明来自这篇翻译，点它能在对话右侧重新打开。

### 领域预设与自定义提示词

打开「翻译选项」面板：

1. **语气**：「自动 / 正式 / 非正式」。
2. **翻译领域**：7 种预设——「通用」「学术论文」「技术文档」「文学作品」「法律文书」「医学文献」「日常对话」，选择后会针对该领域优化术语与行文。
3. **自定义提示词**：在默认规则之外补充要求（如"保留所有专有名词英文原文"），随每次翻译发送给模型；可「恢复默认」，常用组合可「存为模板」复用。切换翻译领域时，未手动改过的默认提示词会自动跟随新领域模板；只有你**显式修改过**的提示词才会固定保留。
4. **术语表**：添加"原文术语 → 目标译法"条目，翻译时严格遵守——适合固定教材与论文术语译法。

### 翻译记录管理

每篇翻译都会自动保存为资源库里的一个翻译资源，并按原文第一句自动命名：在资源列表中可搜索、收藏、重命名、移动到科目文件夹或删除；双击即可回到工作台继续编辑。关闭带有未保存修改的翻译窗口时，会询问「保存并关闭 / 丢弃 / 取消」。

## 进阶用法

- **论文精读一条龙**：先点「AI 论文导读 → 提炼全文核心贡献与脉络」建立框架 → 开启「单栏贴合（185%）」或「紧凑裁白边」精读 → 遇到核心架构图用框选「钉住对照」→ 边读边用 `1`–`5` 做 5 色语义高亮与批注 → 读完在侧栏把批注一键「导出为笔记」，留下完整的 `pdfref://` 双向反链。
- **翻译 + 阅读联动**：单句难懂按 `T` 划词翻译或 `E` 四视角解释；整节需要双语精读时粘贴进翻译工作台选「学术论文」预设并配置术语表，再按段落逐段对照。

## 📱 移动端说明

**PDF 阅读**（移动端断点统一为 `768px`）：

- **手势**：**双指捏合**缩放、**双击**放大/还原、上下滑动翻阅；PDF 区域不会触发应用的左右切屏手势。
- **版面限制**：「双页视图」与「封面单独成页」在窄屏（≤ `768px`）下自动收回为单页模式。
- **扫描页识别**：移动端**不支持系统本地 OCR**，识别扫描版 PDF 需在设置中配置云端 OCR 或使用支持读图的多模态模型。
- **侧栏与反链**：目录 / 缩略图 / 书签 / 批注 / 关联 5 个标签在小屏上以全屏子页面展开（顶部五个分段切换），选择后自动返回阅读；页边反链胶囊和底部返回胶囊同样可用。
- **划词与框选**：长按选中文字后同样支持 5 色高亮与划词工具条；「框选」工具在「更多」菜单里，用手指拖出区域即可；页面勾选照常可用。

**翻译工作台**：

- 原文 / 译文双栏在窄屏自动变为**上下堆叠**布局；领域预设、术语表、段落对照、流式进度与单段快捷复制均与桌面一致。
- 朗读功能依赖系统语音合成，部分设备可能提示"当前浏览器不支持语音合成"。

**DOCX / EPUB**：阅读与排版调节功能与桌面一致，工具栏为紧凑样式。

更多移动端通用操作见 [移动端指南](./17-移动端指南.md)。

## 常见问题

**Q1：打开 PDF 提示"该 PDF 已加密或需要密码"？**
若知道密码，在弹出的密码框输入即可打开；受版权保护无法解密的文件请先在其他工具中解除保护再导入。

**Q2：PDF 很大打不开或加载很慢？**
超过 100 MB 的超大 PDF 预览可能受限，建议改用系统阅读器；较大的文件首次加载偏慢属正常，之后有进度记忆。若原路径失效，系统会优先回退 VFS blob 副本，仍无法打开时可在桌面端或 Android 使用「重新关联文件」指向文件的新位置。

**Q3：为什么选不中 PDF 里的文字、没法高亮？**
两种可能：一是「文本选择」开关未开启；二是这份 PDF 是扫描版（没有文字层）——可以点工具栏的「识别扫描页文字」为页面补全文字层（移动端需配置云端 OCR 或多模态模型），或在资源库「知识库索引」中完成 OCR 索引让学习 Agent 检索。扫描页里的公式与题目也可以直接用「框选」工具提问、提取 LaTeX / 表格或遮挡制卡。

**Q4：高亮和批注会丢吗？导出 PDF 后别人能看到吗？**
不会丢，都会随资源保存并自动恢复。点击侧栏「批注」里的「导出带批注的 PDF」即可把高亮与批注写入导出的 PDF 文件中，在其他 PDF 阅读器里也能查看。

**Q5：翻译结果不满意怎么办？**
依次尝试：选对「翻译领域」预设；在「术语表」固定关键术语译法；用「自定义提示词」描述风格要求；必要时到「设置 → 模型分配」换一个能力更强的翻译模型。也可以点「编辑译文」手动修正，修改会保存进历史。

**Q6：翻译需要联网吗？**
发起新翻译需要。翻译调用你配置的 AI 模型服务，离线时会提示网络错误；使用本地模型服务（如 Ollama）则可离线。已翻译内容的**本地操作不受离线影响**：编辑译文保存、质量评分、关窗时的「保存并关闭」都是本地写入，断网时照常可用。
