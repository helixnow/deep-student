# 文档阅读与翻译

> 内置 PDF / Word / EPUB 阅读器支持论文精读（AI 论文导读、5 色语义高亮、框选提取公式/表格与钉住对照、带批注 PDF 导出、跨应用页码回跳与「边读边问」）；翻译工作台提供全文翻译、逐段双语对照、语向与语气自动记住、版本回退以及 7 种领域预设与术语表。

## 三步上手

**想精读一篇 PDF 并沉淀成带溯源的笔记：**

1. **打开文档**：把 PDF 拖进「资源库」并双击打开；点击顶部工具栏「AI 论文导读 → 提炼全文核心贡献与脉络」快速摸清结构。
2. **精读与标注**：按需开启「单栏贴合（185%）」或「紧凑裁白边」，划选文字按 `1`–`5` 做 5 色语义高亮、用「框选」把图表公式「钉住对照」或提问。
3. **沉淀与分享**：打开左侧「批注」标签，点「导出为笔记（N）」生成带可点击回跳页码的文献笔记，或点「导出带批注的 PDF」直接分享给同伴（支持旋转页面与常见权限加密 PDF）。

**想高质量翻译外文文献并随时对照修改：**

1. **输入原文**：在资源库点「新建 → 新建翻译」，粘贴文本或直接拖入图片 / PDF / Word 文件。
2. **调好风格**：选好「源语言 / 目标语言」（支持「自动检测」），在「翻译选项」中选好「语气」「翻译领域」和「术语表」，按 `Ctrl / ⌘ + Enter` 发起翻译。
3. **对照与留存**：打开「段落对照」逐段核对或单段复制，一键「存为生词闪卡」加入复习；修改原文或设置后，可用「另存新版本」与「恢复上一版」安心迭代不丢旧稿。

## 功能概览

- **PDF 论文精读阅读器**：翻页、缩放、单双页视图、紧凑裁白边与单栏贴合（185%）、暗色阅读、5 标签侧栏（目录 / 缩略图 / 书签 / 批注 / 关联）、边扫边出全文搜索、5 色语义高亮与带批注 PDF 导出（兼容旋转页面与加密 PDF）、跨页返回栈、文内引用预览定位、扫描页文字识别。
- **AI 论文导读与「边读边问」**：工具栏「AI 论文导读」一键提取大纲与关键页上下文发起深度对读；对话侧支持「文档优先」可调分栏阅读；勾选页面或框选公式 / 图表即可提问、钉住对照、提取公式代码 / Markdown 表格或遮挡制卡。
- **跨应用页码回跳与窄分栏联动**：划词、批注、对话回答存为笔记后，自动附带可点击跳回原页与高亮处的引用链接（即便在 460px 窄分栏下与笔记并排阅读也能精准跳转并记住笔记位置）；闪卡「查看出处」回跳原页；PDF 页右上角显示页边反链胶囊，一键分栏打开关联的思维导图、闪卡与笔记。
- **Word / EPUB / 其他格式阅读**：Word 文档以「白纸」版式渲染并可调字号；EPUB 电子书支持目录、护眼主题与排版调节；PDF、Word、PPT、EPUB 均支持统一划词闭环。
- **翻译工作台**：面向精读的翻译工具——全文翻译、逐段双语对照、语向与语气偏好跨会话自动记忆、版本历史回退（「另存新版本」/「恢复上一版」）、源语言错选检测、7 种领域预设、术语表、自定义提示词、流式字符进度、单段快捷复制、朗读与一键「存为生词闪卡」，翻译记录自动保存为资源库文档。

适合场景：精读英文论文边读边用 5 色高亮批注并生成带页码回跳的文献笔记；把跨页的架构图或公式钉住对照正文推导；外文文献先全文翻译、反复调整语气与术语表对比不同版本，再逐段对照精读。

## 入口与界面布局

### PDF 阅读器

**打开方式**：在资源库中双击任意教材或 PDF 文档（导入方法见 [资源库](./04-学习资源中心.md)）。学习桌面里会开成一个独立窗口，可与对话或笔记窗口并排；在对话侧打开引用 PDF 时，也支持切换到「文档优先」可调分栏（「边读边问」模式）。

界面从上到下：

- **顶部工具栏**：侧栏切换、页码框（「第 x 页 / 共 y 页」）与上一页 / 下一页、缩放与版面适配（适应宽度、适应页面、实际大小、紧凑裁白边、单栏贴合 185%）、**「AI 论文导读」**菜单、「框选」工具、扫描页文字识别；「更多」菜单里有旋转、单页 / 双页视图、封面单独成页、暗色阅读、文本选择开关、全屏和快捷键提示。
- **左侧侧栏（5 标签）**（按需展开）：「目录」「缩略图」「书签」「批注」与「**关联**」五个标签页合并在同一侧栏内，顶部图标切换——「关联」标签集中展示与当前 PDF 相关的笔记和相关对话，点击即可打开。
- **中间阅读区**：支持滚动阅读与文内引用预览定位。每页角落有页面选择框（勾选页面问 AI），右上角会在有跨应用关联时显示**页边反链胶囊**（如 `2 导图 · 1 闪卡`），底部在跨页跳转后浮现「返回第 N 页」返回胶囊。

### 翻译工作台

**打开方式**：在资源库点「新建」→「新建翻译」，或双击已有的翻译资源。

界面分区：

- **顶部工具栏**：布局切换（「左右分栏」/「上下分栏」）；语言选择（「源语言」「目标语言」，支持「自动检测」与二十多种语言）、「交换语言」按钮；「自动翻译」「同步滚动」开关与「翻译选项」入口。
- **主体双栏**：左侧「待翻译文本」输入区（带 `Ctrl / ⌘ + Enter` 快捷键引导），右侧「翻译结果」（流式生成时显示实时字符进度，复制后弹出「已复制」胶囊反馈，并配有「恢复上一版」「编辑译文」「朗读」「复制」「存为生词闪卡」「导出」动作组）；分栏比例可拖拽调整并自动记住。窗口较窄时自动改为上下排列，「自动翻译」「同步滚动」开关收进设置面板。
- **对照视图**：切换「段落对照」后，原文与译文按段落逐一对齐显示，每段支持快捷复制。
- **翻译选项面板**：语气、翻译领域、自定义提示词、术语表（见下文）。

## 核心操作

### 阅读 PDF：翻页、缩放、版面与扫描页识别

1. **翻页与跳页**：用工具栏的「上一页」/「下一页」按钮或键盘 `←` `→` 翻页；在页码框直接输入数字回车可跳页。
2. **跨页返回栈**：点击目录、书签、文内引用或页码跳转后，阅读区底部会浮现「返回第 N 页」胶囊，也可以用 `Alt + ←` / `Alt + →` 在跳转历史中前进后退（最多记录 **30 步**），看完图表或参考文献后一键回到正文位置。
3. **缩放与精读版面**：
   - 常规缩放：点「放大」/「缩小」按钮，或 `Ctrl / ⌘ + ±`；缩放菜单可选「适应宽度」「适应页面」「实际大小」。
   - **紧凑裁白边**：自动裁去页面四周空白边距，提升正文有效显示面积。
   - **单栏贴合（185%）**：阅读双栏英文论文时一键放大至单栏贴宽，免去反复手动缩放。
4. **单双页与护眼**：宽屏可开启「双页视图」与「封面单独成页」（封面独占一行，其余按 `[2,3]` `[4,5]` 对页排布）；夜间可开「暗色阅读」；「旋转」可顺 / 逆时针转 90°。
5. **识别扫描页文字**：遇到无文字层的扫描版 PDF，可直接点击工具栏的「识别扫描页文字」识别当前页文字层（桌面端支持系统本地 OCR 与云端 OCR；移动端需使用云端 OCR 或多模态模型）。
6. **记忆偏好**：阅读进度、缩放档位、单双页视图和封面偏移均按文档自动保存，下次打开自动恢复。
7. **导入校验与后台渲染暂停**：一次导入多份 PDF 时会按顺序依次排队处理，并在导入早期校验 PDF 文件尾结构（截断或损坏的 PDF 会被立即清晰拒收）；当 PDF 阅读标签页或窗口退至后台非激活状态时，系统会自动暂停后台页面画布渲染以节省内存与电量，切回前台后即时恢复阅读。

### 搜索、目录与文内引用预览

1. **边扫边出全文搜索**：点工具栏「搜索」（或按 `Ctrl / ⌘ + F`）输入关键词，找到第一个命中立即跳转高亮，结果计数随后台扫描实时增长，搜索栏显示「已扫描 x/y 页…」。
2. **文内引用预览定位**：鼠标悬停或点击正文中的文内引用标记（如 `[12]`、`Fig. 3`、`Eq. (4)` 等），可就地预览对应的参考文献、图表或公式位置，并支持点击直接跳转（跳完可用 `Alt + ←` 返回）。
3. **目录与缩略图**：在左侧侧栏切换「目录」或「缩略图」快速浏览与跳页。

### 5 色语义高亮、批注与带批注 PDF 导出

1. **选中文字并高亮**：确认「文本选择」处于开启状态，选中一段文字后即可通过弹出色板或数字快捷键 `1`–`5` 完成语义高亮（旋转视图下暂不支持新划词高亮，请先恢复原始方向）：

   | 快捷键 | 颜色 | 语义用途 |
   |---|---|---|
   | `1` | 黄色 | 核心结论 |
   | `2` | 绿色 | 研究方法 |
   | `3` | 蓝色 | 背景定义 |
   | `4` | 红色 | 存疑局限 |
   | `5` | 紫色 | 公式数据 |

2. **高亮写批注**：点击已有高亮块，在弹出的批注框中输入笔记并按 `Ctrl + Enter` 保存，也可以在浮层中切换高亮颜色或「删除批注」（触屏设备从底部操作条操作）。
3. **筛选与导出**：打开侧栏「批注」标签页，支持按**颜色**与**关键词**筛选全部批注，并可执行两种导出：
   - **「导出为笔记（N）」**：把当前列表的批注按页汇总为一篇结构化笔记，每条批注都带可点击跳回原页的引用链接。
   - **「导出带批注的 PDF」**：将所有高亮与批注文字写入导出的 PDF 副本，发给同伴或在其他 PDF 阅读器里打开也能查看与点击注释：
     - **旋转页面自动对齐**：原文档本身带有横向或旋转页面（90° / 180° / 270°）时，导出的高亮框会自动换算坐标，精准贴合文字，不会偏移错位。
     - **常见权限加密 PDF 自动适配**：遇到仅带空加密标记的文档会自动清理标记，让导出文件在各类阅读器里顺畅打开；遇到真正带权限加密保护的 PDF 时，系统会自动将其安全重建为清晰可读的带批注 PDF 副本，不再静默损坏文件。
     - **极端受限情况明确引导**：若当前运行环境确实无法重建某个高强度权限加密文件，应用会明确提示原因，并引导你先解除原文件权限保护，或一键改用「导出为笔记（N）」保留全部批注摘要。

<details>
<summary>技术说明：带批注 PDF 导出的旋转与加密处理机制（可选阅读）</summary>

- 导出时系统会依据每一页的 PDF 视口矩阵将高亮坐标映射回标准 PDF 坐标系，确保 90° / 180° / 270° 旋转页的高亮 QuadPoints 准确落在原文字区域。
- 对仅含无效/占位 `/Encrypt` 标记但内容流并未加密的文件，导出时会自动移除残留标记，避免下游阅读器误弹密码框。
- 对包含真实加密流的权限保护 PDF，系统会使用受控分辨率栅格重建页面（单边上限 `2000px`、单页总像素上限 `3.6MP`，多页间自动让出主线程防卡顿），并在重建后的页面上叠加标准可编辑高亮批注。若运行环境缺少画布支持导致无法重建，则会返回明确提示，建议解除权限或导出笔记摘要。

</details>

### 划词精读闭环与快捷键

选中文字后弹出划词工具条（PDF、Word、PPT、EPUB 均支持），并提供高频快捷键：

| 按钮 / 快捷键 | 作用 |
|---|---|
| 解释（`E`） | 结合上下文提供**四视角精读**讲解（核心释义、背景关联、实例 / 推导、要点延展），结果可一键**存入批注**或放入对话 |
| 翻译（`T`） | 自动识别语向（可手动切换 / 对调），结合前后文流式译出并消除多义词歧义；支持复制原文 / 译文 |
| 复制学术引文（`C`） | 复制选中文字并自动修复双栏论文常见的断词连字符与多余换行 |
| 保存为笔记 | 以选中内容为引用块新建摘录笔记，附带可点击跳回原文那一页的页码反链 |
| 制卡 | 将选中内容及上下文送去闪卡后台生成记忆卡片，放进「划词制卡::资料名」牌组（见 [Anki 制卡与模板](./12-Anki制卡与模板.md)） |
| 划选即入图 / 拖入导图 | 把选中片段一键送入当前或新建思维导图作为节点，也支持直接将选区拖入思维导图窗口 |
| 引用到对话 | 把这段文字连同页码作为引用加进对话输入框，接着追问 |

### AI 论文导读与「边读边问」

1. **AI 论文导读**：点击工具栏的「**AI 论文导读**」菜单，系统会自动提取当前 PDF 的目录大纲与关键页上下文，提供 5 项快捷精读动作：
   - **加入当前对话对读**：把整篇文档与大纲上下文接入当前会话开始互动对读；
   - **提炼全文核心贡献与脉络**：梳理研究问题、主要贡献与章节逻辑主线；
   - **精读当前页**：结合上下文逐段拆解正在阅读这一页的重点与公式；
   - **拆解模型架构与复现要点**：梳理方法框架、模块设计、超参数与实验复现细节；
   - **审稿人视角局限与追问**：从审稿人角度审视假设漏洞、消融不足与值得进一步追问的问题。
2. **「文档优先」可调分栏（「边读边问」模式）**：从对话侧打开或联动阅读 PDF 时，可切换为「文档优先」可调分栏布局，左侧大面积留给原文精读、右侧对话随时追问，拖拽中间分隔条自由调整宽度。
3. **选取页面问 AI**：勾选每页角落的选择框（一次最多 10 页），连续页码会自动合并为「1-3页」出现在对话输入框上方，直接输入问题即可让学习 Agent 针对所选页面作答。

### 框选工具：提问、钉住对照、提取公式与表格、遮挡制卡

页面上的公式、架构图、表格或扫描页内容不方便划词时，点工具栏的「框选」工具（窄窗口在「更多」菜单里），拖出一个矩形框即可选择以下动作：

- **框选提问**：将框选区域截成图片附件加入当前对话输入框（需当前模型支持读图），提示「已引用到对话」，点「去对话」即可追问。
- **钉住对照**：把框选的公式、架构图或表格以**悬浮对照窗口**钉在阅读器上层，翻到后面章节读文字分析时随时对照，并可一键将钉住的图块送入对话提问。
- **提取 LaTeX**：把框选的数学公式识别并转换为可复制的 LaTeX 代码。
- **提取表格**：把框选的数据表格解析为规范的 Markdown 表格，方便直接贴进笔记。
- **拖出摘录与遮挡制卡**：将框选图像直接拖出摘录到笔记，或进入图像遮挡制卡流程，圈出要挖空的区域生成复习闪卡。

一次框选对应单个页面（跨页时取覆盖面积更大的那一页），高亮批注不会截入底图；按 `Esc` 或点「取消」随时退出。

### 跨应用 PDF 页码回跳与 460px 窄分栏对照

Deep Student 把阅读器、笔记、对话、思维导图和闪卡通过页码反链打通，尤其适合在学习桌面中**左右并排看 PDF + 写笔记**：

1. **从笔记一键跳回原页与高亮**：无论是划词「保存为笔记」、批注「导出为笔记」还是从对话存为笔记，笔记顶部会显示「**来源 · 来自资料 · 第 N 页**」入口，正文也会写入可点击的页码反链（`pdfref://`）。
2. **460px 窄分栏下照样精准回跳**：即使笔记窗口被缩窄到约 460px 与 PDF 左右并排，点击来源栏或正文里的页码反链，系统都会按从第 1 页起算（1-based）的页码引用路由自动定位到原 PDF 的准确页码与对应高亮处（避免页码偏移跳错页）——即使原 PDF 窗口当时已经关闭需要重新加载，也会稳妥跳到目标页而不是停在首页；切回笔记时还会自动记住你刚才读到的滚动位置（详见 [笔记](./07-笔记.md)）。
3. **闪卡出处回跳与页边反链胶囊**：复习由 PDF 生成的闪卡时，点「查看出处」直接跳回原页；当 PDF 某一页已被导图、闪卡或笔记引用时，该页右上角会显示**页边反链胶囊**（如 `2 导图 · 1 闪卡`），点击即可分栏打开对应产物；左侧侧栏第 5 个标签「关联」可一览整份 PDF 关联的所有相关笔记与相关对话。

### 书签

1. 翻到想标记的页面，点工具栏的「添加书签」。
2. 书签默认命名为「书签 - 第 x 页」，会自动打开侧栏「书签」标签页进入标题编辑，可直接改名。
3. 之后点侧栏「书签」图标打开列表，点击任意书签即可跳页；不需要时点「删除书签」。

### 阅读 Word / EPUB / 其他文档

- **Word（DOCX）**：双击打开即渲染为分页的「白纸」版式，工具栏可以「增大字号 / 减小字号 / 重置字号」。正文可以选中并划词，引用会带上「第 N 节」。加密文档无法预览时会有相应提示。
- **PPT（PPTX）**：按幻灯片预览，同样可以划词，引用带「第 N 张幻灯片」。
- **EPUB 电子书**：支持「目录」侧栏、书内搜索、「上一章 / 下一章」；「阅读主题」可选明亮 / 护眼 / 深色 / 跟随应用；「排版设置」可调字号、字体、行距、页边距。选中文字同样有划词工具条，引用带「第 N 章」。阅读进度按章节随资料保存，换设备或清理缓存后重开仍能回到上次读到的地方。
- **Excel / 文本 / 音视频**：见 [资源库](./04-学习资源中心.md) 的格式与预览说明。

### 全文翻译、语向语气记忆与版本回退

1. **发起翻译**：打开翻译工作台，把原文粘贴进「待翻译文本」，或直接**拖拽文件**（支持图片、PDF、DOCX、TXT、MD）到输入区——图片自动识别文字，文档自动解析出文本。选择「源语言」（默认「自动检测」）和「目标语言」，点「翻译」或按 `Ctrl / ⌘ + Enter`，译文流式出现在右侧「翻译结果」并实时显示字符进度。
2. **多语种与语气跨会话自动记住**：
   - 你在翻译中选定的**源语言、目标语言与语气（「自动 / 正式 / 非正式」）**会自动随每篇翻译文档保存；下次重新打开这篇翻译时原样恢复，不会莫名重置回默认语向。
   - **新建空白翻译**时，会自动继承你最近一次偏好的语向与语气组合，省去每次重新下拉选择的麻烦。
   - 如果手动选定的源语言与你粘贴的原文明显不一致（例如源语言设为英语却粘贴了一段日文或中文），顶部会弹出贴心提示，提供一键「**切换为…**」或「**改为自动检测**」，避免译文原样复读。
3. **版本历史与无损回退（「另存新版本」/「恢复上一版」）**：
   - 翻译完成后，如果你改动了原文、切换了语气或更新了术语表，译文区顶部会出现过期提示条，提供三个不丢稿的选择：
     - **「另存新版本」**：先把当前译文妥善存进历史版本，再按新设置生成新译文；
     - **「重新翻译」**：立即重译（如果你手工修改过译文，系统会先弹出二次确认避免误覆盖）；
     - **「保留当前译文」**：暂不重译，保留眼前这一稿。
   - 生成新译文后，译文区右上角会亮起「**恢复上一版**」按钮（并记录「共 N 个历史版本」），觉得新译文不如上一稿时，一键就能切回上一版译文。
4. **译后快捷动作**：翻译完成后可以「复制」（弹出「已复制」反馈）、「导出」为 Markdown / 文本、「编辑译文」手动润色、「朗读」听发音、打星评分，或点击「**存为生词闪卡**」把当前原文和译文一键存入「翻译生词本」并加入每日闪卡复习队列。
5. **长度限制**：单次翻译上限 5 万字符（超出会自动截断），拖入的文件最大 50 MB。

> 翻译用的模型在「设置 → 模型分配 → 翻译专用模型」里指定（不设置就用对话模型），见 [模型与供应商配置](./14-模型与供应商配置.md)。

### 逐段双语对照

1. 翻译完成后，打开「段落对照」（对照视图）。
2. 原文与译文按段落一一对应显示，每段均带**单段快捷复制**按钮；若两侧段落数不一致，系统会按句子智能对齐并提示。
3. 译文结果区和段落对照里的文字都可以选中，选中后弹出和 PDF 一样的划词工具条：「解释」「翻译」「保存为笔记」「制卡」「添加到聊天」——添加到聊天的引用会标明来自这篇翻译，点它能在对话右侧重新打开。

### 领域预设与自定义提示词

打开「翻译选项」面板：

1. **语气**：「自动 / 正式 / 非正式」（随文档和偏好自动记忆）。
2. **翻译领域**：7 种预设——「通用」「学术论文」「技术文档」「文学作品」「法律文书」「医学文献」「日常对话」，选择后会针对该领域优化术语与行文。
3. **自定义提示词**：在默认规则之外补充要求（如「保留所有专有名词英文原文」），随每次翻译发送给模型；可「恢复默认」，常用组合可「存为模板」复用。切换翻译领域时，未手动改过的默认提示词会自动跟随新领域模板；只有你**显式修改过**的提示词才会固定保留。
4. **术语表**：添加「原文术语 → 目标译法」条目，翻译时严格遵守——适合固定教材与论文术语译法。

### 翻译记录管理

每篇翻译都会自动保存为资源库里的一个翻译资源，并按原文第一句自动命名：在资源列表中可搜索、收藏、重命名、移动到科目文件夹或删除；双击即可回到工作台继续编辑，并自动还原该篇的语向、语气、译文与版本记录。关闭带有未保存修改的翻译窗口时，会询问「保存并关闭 / 丢弃 / 取消」。

## 进阶用法

- **论文精读一条龙**：先点「AI 论文导读 → 提炼全文核心贡献与脉络」建立框架 → 开启「单栏贴合（185%）」或「紧凑裁白边」精读 → 遇到核心架构图用框选「钉住对照」→ 边读边用 `1`–`5` 做 5 色语义高亮与批注 → 读完在侧栏点「导出为笔记（N）」留下双向页码反链，再点「导出带批注的 PDF」分享给导师或同学。
- **多风格对比翻译**：先用「正式 + 学术论文」翻出一稿 → 切换语气为「非正式」或调整术语表后点提示条里的「另存新版本」生成第二稿 → 对比不满意时点「恢复上一版」瞬切回来，两种风格都不会丢失。

## 移动端说明

**PDF 阅读**（移动端断点统一为 `768px`）：

- **手势**：**双指捏合**缩放、**双击**放大 / 还原、上下滑动翻阅；PDF 区域不会触发应用的左右切屏手势。
- **版面限制**：「双页视图」与「封面单独成页」在窄屏（≤ `768px`）下自动收回为单页模式。
- **扫描页识别**：移动端**不支持系统本地 OCR**，识别扫描版 PDF 需在设置中配置云端 OCR 或使用支持读图的多模态模型。
- **侧栏与反链**：目录 / 缩略图 / 书签 / 批注 / 关联 5 个标签在小屏上以全屏子页面展开（顶部五个分段切换），选择后自动返回阅读；页边反链胶囊和底部返回胶囊同样可用。
- **划词与框选**：长按选中文字后同样支持 5 色高亮与划词工具条；「框选」工具在「更多」菜单里，用手指拖出区域即可；页面勾选照常可用。

**翻译工作台**：

- 原文 / 译文双栏在窄屏自动变为**上下分栏**布局；领域预设、术语表、段落对照、语向与语气记忆、「恢复上一版」「另存新版本」「存为生词闪卡」与单段快捷复制均与桌面一致。
- 朗读功能依赖系统语音合成，部分设备可能提示「当前浏览器不支持语音合成」。

**DOCX / EPUB**：阅读与排版调节功能与桌面一致，工具栏为紧凑样式。

更多移动端通用操作见 [移动端指南](./17-移动端指南.md)。

## 常见问题

**Q1：打开 PDF 提示「该 PDF 已加密或需要密码」？**
若知道密码，在弹出的密码框输入即可打开；受版权保护无法解密的文件请先在其他工具中解除保护再导入。

**Q2：PDF 很大打不开或加载很慢？**
超过 100 MB 的超大 PDF 预览可能受限，建议改用系统阅读器；较大的文件首次加载偏慢属正常，之后有进度记忆。如果原文件在电脑里被移动或改名导致路径失效，系统会优先使用应用内保存的副本继续阅读；仍无法打开时，可在桌面端或 Android 使用「重新关联文件」指向文件的新位置。

**Q3：为什么选不中 PDF 里的文字、没法高亮？**
两种可能：一是「文本选择」开关未开启（或当前处于手动旋转视图，恢复原始方向即可高亮）；二是这份 PDF 是扫描版（没有文字层）——可以点工具栏的「识别扫描页文字」为页面补全文字层（移动端需配置云端 OCR 或多模态模型），或在资源库「知识库索引」中完成 OCR 索引让学习 Agent 检索。扫描页里的公式与题目也可以直接用「框选」工具提问、提取 LaTeX / 表格或遮挡制卡。

**Q4：旋转页或加密 PDF 能导出带批注的 PDF 吗？别人看得到吗？**
可以。所有高亮和批注都会随资源自动保存。点击侧栏「批注」里的「导出带批注的 PDF」即可写入导出的 PDF 文件中，在其他 PDF 阅读器里也能查看：带有旋转页面的 PDF 会自动换算高亮位置不错位；常见权限加密 PDF 会自动重建为清晰的带批注副本；若个别强保护文件在当前环境确实无法导出，系统会给出清晰提示，你可以先解除权限或一键「导出为笔记（N）」保存全部批注摘要。

**Q5：重译后觉得还是上一版翻得好，怎么找回？**
点译文区右上角的「恢复上一版」即可一键切回；平时修改原文或语气后，推荐点击提示条里的「另存新版本」，把当前译文存进历史版本后再生成新稿。如果对译文整体质量不满意，也可以依次调整「翻译领域」「术语表」「自定义提示词」，或在「设置 → 模型分配」换一个更强的翻译模型。

**Q6：翻译需要联网吗？**
发起新翻译需要。翻译调用你配置的 AI 模型服务，离线时会提示网络错误；使用本地模型服务（如 Ollama）则可离线。已翻译内容的**本地操作不受离线影响**：编辑译文保存、质量评分、恢复历史版本、关窗时的「保存并关闭」都是本地写入，断网时照常可用。
