# 文档阅读与翻译

> 内置 PDF / DOCX / EPUB 阅读器支持双页阅读、高亮批注、书签和"选页问 AI"；划词可直接生成题目、制作记忆卡片；翻译工作台提供全文翻译、逐段双语对照、7 种领域预设与自定义提示词。

## 功能概览

- **PDF 阅读器**：翻页、缩放、旋转、单页/双页视图（含"封面单独成页"）、暗色阅读、侧栏（目录/缩略图/书签/批注）、全文搜索（边扫边出结果）、四色划词高亮、划词翻译，阅读进度与缩放/视图偏好按文档自动记住。
- **划词学习闭环**：选中一段教材文字，除高亮、翻译外还可一键「生成题目」（送入 AI 出题流，产出题目集）或「制卡」（送入 Anki 制卡流，后台生成记忆卡片）。
- **围绕文档问 AI**：在阅读器里勾选页面，页码会出现在聊天输入栏，输入问题即可让 AI 针对这些页作答；AI 回答中的页码引用可以一键跳回 PDF 对应页。
- **DOCX / EPUB / 其他格式阅读**：DOCX 文档以"白纸"版式渲染并可调字号；EPUB 电子书支持目录、护眼主题与排版调节。
- **翻译工作台**：面向精读的翻译工具——全文翻译、段落对照、术语表、领域预设、译文编辑与朗读，翻译记录自动保存为可管理的资源。

适合场景：精读英文教材边读边高亮；把论文某几页圈出来让 AI 讲解；外文文献先全文翻译、再逐段对照精读。

## 入口与界面布局

### PDF 阅读器

**打开方式**：在「学习资源」中双击任意教材或 PDF 文档（导入方法见 [04-学习资源中心.md](04-学习资源中心.md)）。

界面从上到下：

- **顶部工具栏**：目录、缩略图、书签、批注列表按钮；页码框（"第 x 页 / 共 y 页"）与上一页/下一页；「选择此页」按钮；缩放（放大/缩小/缩放级别菜单：适应宽度、适应页面、实际大小）；「更多」菜单里有旋转、单页/双页视图、封面单独成页、暗色阅读、文本选择开关、全屏和快捷键提示。
- **左侧侧栏**（按需展开）：目录、缩略图、书签、批注合并为同一侧栏的四个标签页，顶部图标切换——「目录」显示文档大纲点击跳转；「缩略图」按页面小图浏览；「书签」「批注」列表也在这里查看、编辑与删除，不再是互相遮挡的浮动面板。
- **中间阅读区**：支持滚动阅读；选中文字会弹出划词工具条（高亮色板 +「翻译选中文字」「生成题目」「制卡」按钮）。

### 翻译工作台

**打开方式**：在「学习资源」点＋ →「新建翻译」，或双击已有的翻译资源。

界面分区：

- **顶部工具栏**：布局切换（左右/上下分栏）；语言选择（「源语言」「目标语言」，支持「自动检测」与二十多种语言）、交换语言按钮；「自动翻译」「同步滚动」开关与翻译设置入口。
- **主体双栏**：左侧「待翻译文本」输入区，右侧「翻译结果」；分栏比例可拖拽调整并自动记住，语向与语气偏好也会在新建翻译时自动恢复。
- **对照视图**：切换「段落对照」后，原文与译文按段落逐一对齐显示。
- **翻译选项面板**：语气、翻译领域、自定义提示词、术语表（见"核心操作"）。

## 核心操作

### 阅读 PDF：翻页、缩放与视图

1. 用工具栏的上一页/下一页按钮或键盘 ← → 翻页；在页码框直接输入数字回车可跳页。
2. 缩放：点放大/缩小按钮，或 Ctrl/Cmd + ±；缩放级别菜单里可选「适应宽度」「适应页面」「实际大小」。
3. 宽屏阅读时点「双页视图」并排显示两页（窄窗口和触屏设备会自动收回「单页视图」）。书籍类 PDF 第 1 页通常是封面，可再点「封面单独成页」让封面独占一行，其余页按 [2,3] [4,5] 的真实对页排布，翻页也按此步进。
4. 夜间阅读点「暗色阅读」，页面反色护眼；「旋转」可顺/逆时针转 90°。
5. 阅读进度自动保存，下次打开同一文档会回到上次的页面；缩放档位（含适应宽度/页面等）、单双页视图和封面偏移也按文档记住，下次打开自动恢复。

### 搜索与目录导航

1. 点工具栏「搜索」（或按 Ctrl/Cmd + F），输入关键词。
2. 搜索是**边扫边出结果**的：找到第一个命中立即跳转并高亮，结果计数随扫描实时增长，搜索栏同时显示"已扫描 x/y 页"——几百页的大书不用等全书扫完。
3. 结果计数显示"当前 / 总数"，用「上一个」「下一个」在命中之间跳转，命中文本会高亮。
4. 点「目录」按钮打开侧栏大纲（部分 PDF 没有内置目录，会提示"此文档没有目录"）；侧栏顶部可切到「缩略图」按页面小图浏览跳转。

### 高亮批注与划词翻译

1. 确认「文本选择」处于开启状态，用鼠标选中一段文字。
2. 在弹出的工具条中选择颜色：「黄色」「绿色」「蓝色」「红色」，即完成一条高亮批注。
3. 颜色之外，划词工具条还提供一组动作：「复制」选中文字；「引用到对话」——把这段文字连同页码作为引用发进 AI 对话；「做笔记」——以选中内容为引用块直接创建一条摘录笔记（带来源信息）；此外还有「生成题目」「制卡」两个学习入口（见下文「划词生成题目 / 制卡」）。
4. 点工具条的「翻译选中文字」按钮，阅读区底部会弹出翻译卡片：自动检测语向（可手动切换/对调）、流式给出译文或短语对照，并利用选区前后的原文上下文消歧多义词；可复制原文/译文，按 Esc 或点关闭收起。
5. **修改已有高亮**：点击页面上的高亮块会弹出操作浮层，可换成另一种颜色（当前色有标记）或「删除」这条高亮；触屏设备从底部操作条完成同样操作。保存失败时会有可见提示，不会静默丢失。
6. 点工具栏「查看批注」打开侧栏「批注」标签页，按页码排列，点击可跳转原文，也可「删除批注」。
7. 注意：旋转视图下暂不支持划词高亮，请先恢复原始方向。

### 划词生成题目 / 制卡

选中教材文字后，划词工具条右侧还有两个学习入口（选区至少 10 个字符）：

1. **生成题目**：点击后自动切到 AI 对话，输入栏已预填好出题指令与你选中的学习材料（含来源"《文件名》第 x 页"）。你可以先调整题量、题型要求再发送；AI 会调用题目集工具建好新题目集并回贴引用，之后可在题库中练习（见 [11-题库与练习.md](11-题库与练习.md)）。
2. **制卡**：点击后直接把选中内容（连同前后文上下文）送入 Anki 制卡流，后台生成记忆卡片，完成后通知可一键打开任务台查看；卡片管理与复习见 [12-Anki制卡与模板.md](12-Anki制卡与模板.md) 与 [13-闪卡复习.md](13-闪卡复习.md)。
3. 划词高亮、翻译、生成题目、制卡共用同一工具条——读到重点先高亮，再顺手出几道题或做几张卡，学习闭环不用离开阅读器。

### 书签

1. 翻到想标记的页面，点工具栏的「添加书签」。
2. 书签默认命名为"书签 - 第 x 页"，会自动打开侧栏「书签」标签页进入标题编辑，可直接改名。
3. 之后点「查看书签」（或侧栏顶部的书签图标）打开列表，点击任意书签即可跳页；不需要时点「删除书签」。

### 选取页面问 AI

这是"边读边问"的核心玩法：

1. 阅读时翻到想提问的页面，点工具栏的「选择此页」（再次点击为「取消选择此页」）；可连续勾选多页，工具栏会显示已选页数与上限，超出上限会提示"最多只能选择 N 页"。
2. 切换到 AI 对话（桌面端可用分屏：左侧对话、右侧阅读），输入栏会出现"第 x 页"的页码标签。
3. 输入你的问题（如"讲讲这两页的推导过程"）并发送，AI 会针对选中页面作答。
4. 发送后可在输入栏移除单个页码标签或清空选择。

### 页码引用跳转

当 AI 的回答基于你的 PDF 资料时，回答中会附带页码引用；点击引用即可让阅读器自动跳到对应页面，方便核对原文。

### 阅读 DOCX / EPUB / 其他文档

- **DOCX**：双击打开即渲染为分页的"白纸"版式，工具栏可调整字号（「增大字号 / 减小字号 / 重置字号」）。加密文档或旧版二进制格式（.doc/.xls/.ppt）无法在线预览，会提示下载后用办公套件打开。
- **EPUB 电子书**：支持「目录」侧栏、书内搜索、「上一章 / 下一章」；「阅读主题」可选明亮/护眼/深色/跟随应用；「排版设置」可调字号、字体、行距、页边距。阅读进度百分比实时显示，且按章节随资源本身保存（不再只存在本机浏览数据里），清理浏览数据后重开仍能回到上次读到的章节。
- **PPTX / Excel / 文本 / 音视频**：见 [04-学习资源中心.md](04-学习资源中心.md) 的预览说明。

### 全文翻译

1. 打开翻译工作台，把原文粘贴进「待翻译文本」，或直接**拖拽文件**（支持图片、PDF、DOCX、TXT、MD）到输入区——图片走 OCR 识别，文档自动解析出文本。
2. 选择源语言（默认「自动检测」）和目标语言。
3. 点「翻译」按钮或按 Ctrl/Cmd + Enter，译文流式出现在右侧「翻译结果」。
4. 翻译完成后可以：「复制」译文、「导出」为 Markdown/文本文件、「编辑译文」手动修正、「朗读」听发音，或为本次翻译打星评分。
5. 单次翻译上限 5 万字符，超出会自动截断；拖入的文件最大 50MB。

> 翻译使用的模型在 设置 → 模型 中指派，见 [14-模型与供应商配置.md](14-模型与供应商配置.md)。

### 逐段双语对照

1. 翻译完成后，打开「段落对照」（对照视图）。
2. 原文与译文按段落一一对应显示，适合精读比对；若两侧段落数不一致，系统会按句子启发式对齐并提示。

### 领域预设与自定义提示词

打开「翻译选项」面板：

1. **语气**：「自动 / 正式 / 非正式」。
2. **翻译领域**：7 种预设——「通用」「学术论文」「技术文档」「文学作品」「法律文书」「医学文献」「日常对话」，选择后会针对该领域优化术语与行文。
3. **自定义提示词**：在默认规则之外补充要求（如"保留所有专有名词英文原文"），随每次翻译发送给模型；可「恢复默认」。常用组合还能「存为模板」复用。切换翻译领域时，提示词的默认文案会自动跟随新领域的模板；只有你**显式修改过**的提示词才会作为覆盖项固定下来、不随领域切换变化。
4. **术语表**：添加"原文术语 → 目标译法"条目，翻译时严格遵守——适合固定教材术语的译法。

### 翻译记录管理

每篇翻译都会自动保存为「学习资源中心」里的一个翻译资源：在资源列表中可搜索、收藏、重命名、移动到科目文件夹或删除；双击即可回到工作台继续编辑。关闭带有未保存修改的翻译窗口时，会询问「保存并关闭 / 丢弃 / 取消」。

## 进阶用法

- **翻译 + 阅读联动**：读到不懂的句子直接划词翻译（见上文），需要整段精读时把该页文字复制进翻译工作台，再用「选择此页」让 AI 讲解原文——阅读、翻译、问答在同一工作台内闭环。
- **教材导学页数上限**：设置 → 系统 中可调整"最大页数"（教科书处理的页数上限），影响一次可发送给 AI 的教材页数。
- **保存即资源**：每篇翻译都是学习资源中心里的一个资源，可收藏、移动到科目文件夹、被 AI 引用检索。

## 📱 移动端说明

**PDF 阅读**：

- 手势：**双指捏合**缩放、**双击**放大/还原、上下滑动翻阅；PDF 区域不会触发应用的左右切屏手势。
- 「双页视图」在手机上不提供（窄屏自动回到单页），「封面单独成页」入口也随之隐藏。
- 划词操作改为**底部工具条**：长按选中文字后，可选高亮颜色，并使用「复制」「引用到对话」「做笔记」「翻译选中文字」「生成题目」「制卡」；未接入对应上层能力的预览场景会自动隐藏「引用到对话」或「做笔记」。
- 目录/缩略图/书签/批注在小屏上以全屏子页面展开（顶部四个分段切换），选择后自动返回阅读。
- 「选择此页」照常可用，选中的页码同样会出现在聊天输入栏。

**翻译工作台**：

- 原文/译文双栏在窄屏自动变为**上下堆叠**布局；其余功能（领域预设、术语表、对照视图）与桌面一致。
- 朗读功能依赖系统语音合成，部分设备可能提示"当前浏览器不支持语音合成"。

**DOCX / EPUB**：阅读与排版调节功能与桌面一致，工具栏为紧凑样式。

更多移动端通用操作见 [17-移动端指南.md](17-移动端指南.md)。

## 常见问题

**Q1：打开 PDF 提示"该 PDF 已加密或需要密码"？**
若知道密码，在弹出的密码框输入即可打开；受版权保护无法解密的文件请先在其他工具中解除保护再导入。

**Q2：PDF 很大打不开或加载很慢？**
超过 100MB 的 PDF 会停止预览并提示改用系统阅读器；较大的文件首次加载偏慢属正常，之后有进度记忆。若提示"文件路径可能已失效"，用「重新关联文件」指向文件的新位置。

**Q3：为什么选不中 PDF 里的文字、没法高亮？**
两种可能：一是「文本选择」开关未开启；二是这份 PDF 是扫描版（没有文字层）——可先在「向量化状态」中完成 OCR 索引让 AI 能读到内容，但阅读器内的划词高亮仍需文字层。

**Q4：高亮和书签会丢吗？**
不会，都会随资源保存，下次打开自动恢复。注意高亮位置依赖页面版式，请在同一文档内查看。

**Q5：翻译结果不满意怎么办？**
依次尝试：选对「翻译领域」预设；在「术语表」固定关键术语译法；用「自定义提示词」描述风格要求；必要时到 设置 → 模型 换一个能力更强的翻译模型。也可以点「编辑译文」手动修正，修改会保存进历史。

**Q6：翻译需要联网吗？**
发起新翻译需要。翻译调用你配置的 AI 模型服务，离线时会提示网络错误；使用本地模型服务（如 Ollama）则可离线。已翻译内容的**本地操作不受离线影响**：编辑译文保存、质量评分、关窗时的「保存并关闭」都是本地写入，断网时照常可用。
