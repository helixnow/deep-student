> 面向最终用户的完整使用手册，覆盖桌面端（Windows / macOS / Linux）与移动端（Android）。

## 新用户从这里开始

**[01 · 快速上手](./01-快速上手.md)** —— 10 分钟跑通"配模型 → 导资料 → 带资料提问 → 生成导图/卡片/题目"的核心闭环。

## 双端阅读说明

- 全书以桌面端界面为基准描述；每章末尾均有「📱 移动端说明」小节，说明该模块在移动端的入口差异、手势操作与功能限制。
- 移动端与桌面端最重要的差异（导航形态、MCP 限制、学习桌面缺席等）汇总在 [17 · 移动端指南](./17-移动端指南.md) 的功能可用性对照表中。

## 约定

- UI 名词均采用应用内简体中文界面的真实文案，如「学习资源」「向量化状态」「问一问 / 想一想 / 做一做」。
- 标注「（实验性）」的功能可能在后续版本中调整。
- 快捷键以 macOS 的 `⌘` 表示法书写时，Windows / Linux 对应 `Ctrl`。
