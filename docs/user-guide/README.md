# Deep Student 用户指南

> 面向学习者的完整使用手册，覆盖桌面端（Windows / macOS / Linux）、移动端（Android）与自托管 WebUI / PWA。
>
> 在线版：https://deepstudent.cn/user-guide/ · **English User Guide**：[docs/user-guide/en/](./en/README.md) · 按 **v0.20.10**（2026 年 11 月）版本编写。

## 新用户从这里开始

- **[01 · 快速上手](./01-快速上手.md)**：零门槛三步起步引导，10 分钟跑通「接好模型 → 导资料 → 边读边问 → 生成导图、卡片和题目」。
- **3 分钟场景速通**（拿来就能照着做）：
  - **[3 分钟考前冲刺](./01-快速上手.md#3-分钟考前冲刺)**：真题制卡 + 设定考期与预算 + 开启「今日冲刺」
  - **[3 分钟精读 40 页论文](./01-快速上手.md#3-分钟精读-40-页论文)**：AI 论文导读 + 五色高亮与钉住对照 + 导出带批注 PDF 与可回跳笔记
  - **[1 分钟安全模式自救](./01-快速上手.md#1-分钟安全模式自救)**：插件报错、界面卡死或配置损坏时零数据损失自救
- **[18 · 学习桌面](./18-学习桌面.md)**：桌面端与宽屏桌面浏览器 WebUI 的默认工作台——多窗口平铺、学习流阶段预设、状态栏与快捷键都在这里。

## 阅读说明

- 全书以桌面端（及宽屏桌面浏览器 WebUI）默认的「**学习桌面**」为基准：应用固定在底部程序坞（Dock）里，以独立窗口运行；在设置里关掉学习桌面后可切回「左侧导航 + 单页」的经典布局。两种布局功能一致，正文中会在必要时注明经典布局入口。
- 每章末尾的「移动端说明」小节介绍该功能在手机端的入口、手势与差异。桌面端与移动端完整对照见 [17 · 移动端指南](./17-移动端指南.md)，浏览器与 PWA 自托管见 [21 · WebUI 与 PWA 自托管](./21-WebUI与PWA自托管.md)。
- 英文读者请查阅 **[English User Guide](./en/README.md)**（含 [英文版快速上手与 3 分钟速通](./en/01-quickstart.md)）。

## 约定

- 界面名称一律使用应用简体中文界面的原文，例如「资源库」「知识库索引」「学习空间」「插件工坊」「长期记忆内核」。
- 标注「（实验性）」或「（预览）」的功能可能在后续版本中调整。
- 快捷键写作 `⌘` 时，Windows / Linux 对应 `Ctrl`；写作 `Ctrl` 时，macOS 对应 `⌘`。学习桌面的窗口快捷键在 macOS 上 `Ctrl+Alt` 对应 `⌘⌥`。
