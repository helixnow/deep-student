# 学习资源中心

> 「学习资源」是 Deep Student 的资料总仓库：把教材、笔记、题目集、翻译、导图、图片和各类文档统一存放、整理，并自动建立可供 AI 检索的向量索引。

## 功能概览

学习资源中心（Learning Hub）像一个内置的"访达 / 文件管理器"，你可以在这里：

- **集中管理所有学习资料**：笔记、教材、题目集（Exam）、作文批改、翻译、知识导图、待办列表、图片和普通文档，全部放在同一套文件夹体系里。
- **导入外部文件**：拖拽或选择文件导入 PDF、DOCX、Excel/CSV、文本、演示文稿、电子书等格式，导入后自动进入向量化索引队列。
- **就地预览**：双击即可在标签页中打开 PDF、DOCX、Excel、PPTX、EPUB、图片、音频、视频和纯文本，无需切换到外部软件。
- **喂给 AI**：任何资源都可以「引用到对话」，成为 AI 问答、生成导图、出题、制卡的上下文来源。
- **管理向量索引**：查看每个资源"是否已被 AI 索引"，一键重建索引、重试失败项。

适合场景：开学时把整学期的电子教材一次性导入；复习时按科目建文件夹整理讲义；写论文时把下载的文献集中管理并交给 AI 检索。

## 入口与界面布局

**打开方式**：点击应用左侧边栏中的「学习资源」。

界面分为三个区域：

1. **左侧快捷导航栏**（可点击底部箭头收起）：
   - 顶部是**搜索框**和**新建（＋）按钮**；
   - 「桌面」「全部文件」「最近」「收藏」——常用位置；
   - **资源类型**分区：「全部笔记」「全部教材」「全部题目集」「全部作文」「全部翻译」「知识导图」；
   - **媒体**分区：「全部图片」「全部文档」；
   - **系统**分区：「回收站」「向量化状态」「记忆管理」；
   - 底部会在有索引任务时出现一个小状态条（见"向量化索引"一节）。
2. **中间文件区**：显示当前文件夹或分类下的内容，顶部工具栏包含后退/前进按钮、路径面包屑、「网格视图 / 列表视图」切换、「排序方式」菜单、「新建文件夹」、「刷新」和「搜索资源...」输入框；底部状态栏显示"N 个项目"。
3. **右侧标签页预览区**：双击打开的资源会以标签页形式在这里展开（详见"标签页与分屏"）。

## 核心操作

### 导入学习资料

方式一：拖拽导入

1. 打开「学习资源」，进入想存放文件的文件夹。
2. 把文件从系统文件管理器直接拖进窗口，出现"拖放文件到此处导入"提示后松手。
3. 等待"正在导入 x / y"完成，成功后提示"已导入 N 个文件"。

方式二：通过「导入教材」按钮

1. 点击左侧导航栏顶部的**＋按钮**（或在文件区空白处右键），选择「导入教材」。
2. 在弹出的文件选择框中选择文件。支持的类型包括：PDF 文档、DOCX 文档、Excel/CSV 表格、文本文件、演示文稿/电子书、数据文件。
3. 导入过程会依次显示"正在校验文件 → 正在复制文件 → 正在渲染预览 → 正在解析文档 → 正在提交索引任务（可在后台继续）→ 正在保存"，最后提示"导入完成（索引可能仍在后台进行）"。

> 提示：Markdown 文件请用「导入 Markdown」入口导入，会自动转换成可编辑的笔记。

### 新建资源

1. 点击左侧导航栏顶部的**＋按钮**，或在文件区空白处**右键**。
2. 从菜单中选择：「新建文件夹」「新建笔记」「导入 Markdown」「新建题目集」「导入教材」「新建翻译」「新建作文」「新建知识导图」（部分视图还提供「新建待办列表」）。
3. 新建的资源会立即在右侧标签页中打开，可直接开始编辑。

注意：「最近」「收藏」「回收站」等聚合视图不支持新建，会提示"当前视图不支持新建资源"，请回到文件夹视图操作。

### 浏览、搜索与排序

1. **切换视图**：用工具栏的「网格视图 / 列表视图」按钮切换；列表视图显示"名称 / 修改日期 / 类型"列。
2. **排序**：点击排序按钮，选择「按名称」「按修改时间」「按创建时间」「按类型」「按大小」，并可切换「升序 / 降序」。
3. **搜索**：在工具栏搜索框输入关键词即可实时过滤。搜索主要匹配标题/文件名，带「[索引]」标记的结果来自内容索引。
4. **空格快速预览（Quick Look）**：选中一个文件后按**空格**，弹出轻量预览浮层——图片直接显示原图、PDF 显示第一页真实预览，其余类型显示大图标、名称、类型 / 大小 / 修改时间 / 所在位置和内容摘要（如有），用来快速确认"是不是这份"。再按空格或 `Esc`（或点浮层外）关闭；点浮层上的「打开」进入完整预览。
5. **记忆徽标**：被 AI 记入长期记忆的资源，会在文件名旁显示记忆徽标——类型（事实 / 学习 / 笔记）加用途（内化 / 补充 / 系统），重要条目还有一颗星标。徽标来自「记忆管理」中的关联记录，详见 [03-深度调研与智能记忆.md](03-深度调研与智能记忆.md)。左侧快捷导航的「收藏」也会显示收藏数量徽标。
6. **键盘操作**：`Ctrl / ⌘ + A` 全选当前视图；多选后按 `Enter` 一次打开全部选中项（数量有上限，超出会提示）；`Esc` 依次执行"关闭快速预览 → 清除选择 → 退出多选 → 清空搜索"。

### 整理：文件夹、移动与重命名

1. **建文件夹**：工具栏「新建文件夹」按钮，输入名称确认。文件夹最多嵌套 10 层、总数上限 500 个。
2. **移动**：右键资源 →「移动到…」，在弹出的文件夹选择框中选择目标位置，点击「移动到此处」。也可以直接把资源拖进文件夹图标。
3. **重命名**：右键 →「重命名」，输入新名称。
4. **撤销移动 / 重命名**：手滑移错了或改错名，按 `Ctrl / ⌘ + Z` 即可撤销最近一次移动或重命名（移动回源文件夹、名称改回旧名）；撤销失败时会提示，可再按一次重试。搜索结果中的操作不记入撤销栈。
5. **复制 / 粘贴 / 制造副本**：右键「复制」再到目标文件夹「粘贴」（或用 `Ctrl / ⌘ + C` / `Ctrl / ⌘ + V`）；「制造副本」（`Ctrl / ⌘ + D`）在当前位置直接生成一份副本，对标访达的 Duplicate。
6. **收藏**：右键 →「收藏」，之后可在左侧「收藏」快速找到；再次右键可「取消收藏」。

### 右键菜单速查

对单个资源右键，常用项包括：

- 「打开」/「预览」——在标签页中打开；
- 「引用到对话」（部分视图显示为「添加到对话」）——把资源注入当前 AI 对话的上下文；
- 「收藏」「重命名」「移动到…」「复制」；
- 「添加到桌面」——在「桌面」视图创建快捷方式；
- 「导出」——把资源导出为文件保存到本地（不同资源支持的格式不同）；
- 「删除」——直接移入回收站（无确认弹窗），随后弹出「已移入回收站」提示，点击提示上的「撤销」按钮可立即恢复；被对话引用的资源会额外提示"被 N 个对话引用"。

### 批量操作

1. 在文件区按住鼠标框选，或按住 Ctrl/Cmd 点选多个资源（触屏设备先点底部工具栏的「多选」开关）。
2. 底部批量工具栏会显示"已选择 N 项"，提供「全选」「添加到对话」「移动」「删除」按钮。
3. 批量删除同样直接软删进回收站（无确认弹窗），完成后提示"已将 N 项移入回收站"并附「撤销」按钮，可一键整批恢复。只有在**回收站内**批量删除（即永久删除）时才会弹确认框。

### 标签页与分屏

- 双击资源在右侧打开标签页，可同时打开多个并点击切换；标签可**拖拽排序**。
- 右键标签页可以：「固定标签页」（固定的标签不会被自动回收或批量关闭）、「关闭其他标签页」「关闭右侧标签页」，以及「在右侧打开」开启**分屏视图**——左右各显示一个资源，方便对照阅读；点「关闭分屏」恢复单栏。

### 桌面快捷方式

「桌面」是学习资源中心的启动页，可以放常用入口：

1. 点击左侧「桌面」进入。
2. 在空白处右键 →「添加快捷方式」，可选择常用动作（如"新建笔记""全部笔记""收藏""最近访问"等预设）或具体资源；也可以对任意资源右键 →「添加到桌面」。
3. 右键快捷方式可「重命名」或「从桌面移除」（移除快捷方式不会删除资源本身）。

### 在学习桌面中使用资源库（Quick Look 式预览）

在学习桌面（Workbench）里，学习资源中心以「资源库」窗口出现（Dock 中的访达式图标），与全屏页共用同一套文件夹体系，另有几处桌面专属体验：

- **双击开窗而非开标签**：在资源库窗口中双击资源，会直接打开对应的应用窗口（笔记、教材、题目集、翻译、导图等各归其位），而不是右侧标签页。
- **悬停快速预览**：鼠标在文件上悬停片刻，会浮出一张玻璃预览卡，显示资源类型、标题和元信息，无需打开即可确认"这是不是我要找的那份"。
- **拖出开窗**：把资源从资源库窗口**拖出窗外**松手，即在桌面上直接为它开一个窗口，适合快速铺开多份资料对照。
- **文件预览窗口（对标 Quick Look）**：图片和普通文档会在轻量的「文件预览」窗口中打开，支持：
  - `Ctrl / ⌘ + F` 全文查找，命中高亮，`Ctrl / ⌘ + G`（`Shift` 反向）在命中间跳转；
  - 「打印」（支持的格式）、「另存为」导出副本；
  - 「用系统应用打开」「在文件夹中显示」；
  - 「引用到对话」——若先选中了预览中的一段文字，引用会带上选区上下文。

### 回收站

1. 删除的资源进入「回收站」，会一直保留，不会自动清除。
2. 在回收站中右键项目可「恢复」或「永久删除」；顶部提供「清空回收站」。
3. 恢复后如提示"内容搜索可能稍晚生效"，表示该资源已重新排队建立索引，稍等即可。

### 向量化索引：让 AI 能"读到"你的资料

资源导入后会自动排队进行向量化：**提取文本（必要时 OCR 识别）→ 分块 → 生成向量（Embedding）→ 写入索引**。索引完成后，AI 对话中的知识库检索才能找到这份资料。

**前提**：需要先配置嵌入模型。如果「向量化状态」页提示"尚未配置嵌入模型"，请先到 设置 → 模型 → RAG 与知识库 配置（参见 [14-模型与供应商配置.md](14-模型与供应商配置.md)）。

**查看索引状态**：

1. 点击左侧「向量化状态」。
2. 页面顶部显示"文本索引进度 / 综合进度"和统计（总向量数、向量维度、索引错误、待更新）。
3. 列表中每个资源标注状态：「已索引」「待索引」「索引中」「失败」或「不适用」，并可按类型筛选。

**常用操作**：

1. **一键索引**：点击「一键索引」，系统自动处理所有待索引资源（含 OCR 与多模态索引）。
2. **重试失败项**：点击「重试全部失败项」，或对单个失败资源点「重试」。
3. **重建单个资源**：对某个资源点「重新索引」；内容更新过的资源会标注"内容已更新"，点「更新」刷新索引。
4. **全部重来**：点击「重置状态」会删除所有向量数据并把全部资源重置为待索引（操作不可撤销，会二次确认），之后再执行一键索引。

**侧栏状态小条**：当有索引任务时，左侧导航栏底部会出现"索引中 x%""N 项待索引"或"N 项索引失败"的小条，点击可直达向量化状态页；全部就绪时小条自动隐藏。

## 进阶用法

- **召回测试**：在「向量化状态」页点击「召回测试」，输入一个问题即可模拟 AI 检索，查看命中了哪些资料片段和相似度得分——用来验证"AI 到底能不能搜到这本教材"。
- **清除 OCR 重新识别**：扫描版 PDF 如果识别效果差，可在资源的索引详情中选择「清除 OCR 数据并重新识别」。
- **多模态索引**：教材、题目集、图片等支持"原生多模态索引"（按页面图像建立索引），适合图表多、排版复杂的资料；在「向量化状态」页随一键索引自动执行。
- **记忆管理**：左侧「记忆管理」入口用于查看/编辑 AI 的长期记忆，详见 [03-深度调研与智能记忆.md](03-深度调研与智能记忆.md)。
- **引用到对话的批量用法**：多选若干讲义 →「添加到对话」，再让 AI"对比这几份讲义的重点"，是跨文档提问的高效路径（参见 [02-AI对话与会话管理.md](02-AI对话与会话管理.md)）。

## 📱 移动端说明

移动端的学习资源采用**三屏结构**：

- **左屏（抽屉）**：从屏幕左缘右滑或点顶栏 ☰ 打开，包含桌面/全部文件/最近/收藏/各资源类型/回收站/向量化状态/记忆管理入口，以及**＋新建按钮**（可直接新建笔记、题目集、翻译、作文、导图，创建后自动打开）。
- **中屏（文件区）**：单击文件夹进入、单击文件打开预览；顶栏面包屑逐级返回。新建文件夹请使用中屏工具栏的＋菜单。
- **右屏（预览）**：打开的资源以标签页展示，关闭最后一个标签自动返回文件区；从屏幕左缘滑动或点顶栏返回键回到中屏。

差异与注意点：

- **多选**需先点底部工具栏的「多选」开关，再逐个点选；批量操作按钮在底部常显。
- **「导出」在移动端不可用**，请在桌面端导出资源。
- 桌面视图的快捷方式**重命名/移除**目前依赖右键菜单，触屏上暂无对应入口；添加快捷方式可用底部按钮完成。
- 拖拽导入不适用于移动端，请使用＋菜单中的「导入教材」「导入 Markdown」。
- Android 返回键遵循"先关浮层、再返回上一屏、最后退应用"的顺序。

更多移动端通用操作见 [17-移动端指南.md](17-移动端指南.md)。

## 常见问题

**Q1：导入了教材，但 AI 说"找不到相关内容"？**
先到「向量化状态」页确认该教材是「已索引」状态。若是「待索引」，点「一键索引」；若「失败」，点「重试」并留意错误提示——常见原因是未配置嵌入模型（去 设置 → 模型 → RAG 与知识库）或网络问题。

**Q2：扫描版 PDF 能被检索吗？**
可以。系统会自动对无文字层的 PDF 做 OCR 识别再建索引，页数多时耗时较长，可在侧栏状态条或「向量化状态」页查看进度。识别效果不佳时可「清除 OCR 数据并重新识别」。

**Q3：删除的文件还能找回吗？**
能。删除默认移入「回收站」并一直保留：刚删完可直接点提示上的「撤销」，之后也随时可进回收站「恢复」。「永久删除」和「清空回收站」不可撤销，操作前会二次确认。

**Q4：为什么某些资源的索引状态是「不适用」？**
表示该资源类型或内容当前无法建立索引（例如空内容、不支持的格式）。详情里会给出"不可索引原因"。

**Q5：文件很大导入很慢/预览不了怎么办？**
超大文件（如超过 100MB 的 PDF）预览可能受限，建议用系统阅读器打开原文件；文本/表格预览过大时只显示开头部分，可用「导出」或「保存到本地」查看完整内容。

**Q6：同一份资料可以同时出现在两个文件夹吗？**
不可以，资源只属于一个文件夹。可以用「收藏」或「添加到桌面」为它建立第二个入口。
