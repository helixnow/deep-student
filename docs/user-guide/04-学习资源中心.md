# 资源库

> 「资源库」是 Deep Student 的资料总仓库：统一存放教材、笔记、题目集、翻译、思维导图、音视频与各类办公文档，支持跨学习空间挂载，并自动建立文本与多模态知识库索引供学习 Agent 检索。

## 功能概览

资源库像一个内置的"访达 / 文件管理器"，你可以在这里：

- **集中管理所有学习资料**：笔记、教材、题目集（Exam）、作文批改、翻译、思维导图、待办列表、图片、音视频与普通文档，全部放在同一套文件夹体系里。
- **广泛的格式解析**：桌面端通过 WASI-WASM 引擎解析 Office 与标记格式、PDFium 解析 PDF，另支持 EPUB、多编码文本/Markdown、CSV/JSON/XML 及 70+ 种代码文件，导入后自动排队建索引。
- **就地预览与跨空间挂载**：双击即可在应用内预览常见文档、图片与音视频；支持将任意资料或文件夹挂载到其他学习空间共享，无需重复复制与重复索引。
- **喂给学习 Agent**：任何资源都可以「引用到对话」，通过统一的 `res_*` 引用机制解析并透传处理状态，成为问答、生成导图、出题、制卡的上下文来源。
- **文本与多模态知识库索引**：查看每个资源的索引状态，一键重建索引、重试失败项，并支持多模态页图检索让模型直接「看图」读 PDF。

适合场景：开学时把整学期的电子教材一次性导入；复习时按科目建文件夹整理讲义；把公共参考书挂载到多个课程空间复用；写论文时把下载的文献集中管理并交给学习 Agent 检索。

## 入口与界面布局

**打开方式**：学习桌面里点 Dock 的「资源库」；经典布局下点左侧导航的「资源库」。两处共用同一套文件夹和资料。

界面分为三个区域：

1. **左侧导航栏**（可点底部箭头收起）：
   - 顶部是**搜索框**；
   - 「学习资料」：「桌面」「全部文件」「最近」「收藏」；
   - 「AI 知识」：「回收站」「知识库索引」「AI 记忆」；
   - 有索引任务时，底部会出现一个小状态条（见「知识库索引」一节）。
   - 想按类型浏览（全部笔记、全部题目集、全部作文、全部翻译、思维导图等），可以在「桌面」上添加对应的快捷方式（见「桌面快捷方式」）。
2. **中间文件区**：显示当前文件夹的内容。顶部工具栏有后退 / 前进、路径、「新建」菜单、「新建文件夹」、「网格视图 / 列表视图」、排序和「搜索资源...」；底部状态栏显示「N 个项目」。
3. **右侧标签页预览区**：经典布局下，双击打开的资源会以标签页形式在这里展开（详见「标签页与分屏」）；学习桌面里则直接开成独立窗口。

## 核心操作

### 导入学习资料

方式一：拖拽导入

1. 打开资源库，进入想存放文件的文件夹。
2. 把文件从系统文件管理器直接拖进窗口，出现「拖放文件到此处导入」提示后松手。一次可以拖多个文件。
3. 等待「正在导入 x / y」完成，成功后提示「已导入 N 个文件」。

方式二：通过「导入资料…」

1. 点工具栏的「新建」（或在文件区空白处右键），选择「导入资料…」。
2. 在文件选择框中选择文件，**文档、图片与音视频**均可直接通过此处导入。
3. 导入过程会依次显示「正在校验文件 → 正在复制文件 → 正在渲染预览 → 正在解析文档 → 正在提交索引任务（可在后台继续）→ 正在保存」，最后提示「导入完成（索引可能仍在后台进行）」。

**支持的格式与解析引擎（桌面端）**：

- **Office 与标记格式（WASI-WASM 引擎）**：`.docx`、`.xlsx`、`.xls`、`.xlsb`、`.ods`、`.pptx`、`.rtf`、`.html`。
- **PDF（PDFium 引擎）**：支持文本提取、页面渲染、加密检测与扫描页 OCR 流程。
- **电子书、文本与代码**：`.epub`、多编码纯文本、Markdown（`.md`）、CSV / JSON / XML 及 **70+ 种代码格式**。
- **压缩包**：`.zip` 会自动生成条目清单供预览与检索；`.rar` / `.7z` 仅存档保存，不解包解析。
- **解析上限与安全防护**：桌面端单文档解析上限 **200 MB**，内置加密检测与 ZIP Bomb 防护；Markdown 单文件导入上限 **10 MB**；音视频单文件最大 **4 GB**。
- **专用格式智能引导**：拖入 `.apkg` / `.colpkg` 会自动引导前往「闪卡」导入；拖入 `.xmind` / `.opml` / `.mm` / `.mmap` 会自动引导前往「思维导图」导入。

**去重、Markdown 转换与原文件失联恢复**：

- **SHA-256 自动去重**：导入相同内容的文件时，系统基于 SHA-256 校验自动去重并弹出提示，避免重复占用空间与重复建索引。
- **Markdown 导入即笔记**：`.md` 文件（≤ 10 MB）无论拖入还是通过「导入资料…」导入，都会直接成为可编辑的笔记。早先作为资料导入的 Markdown，打开后点信息栏的「转为笔记」即可改用笔记应用编辑（原文件移入回收站，可撤销）。
- **PDF 原路径失联与重新关联**：本地关联的 PDF 原路径失效时，系统会优先回退到内部 VFS blob 副本继续阅读；若仍无法定位源文件，可在桌面端与 Android 均使用「重新关联文件」指向文件的新位置。

### 新建资源

1. 点工具栏的「新建」，或在文件区空白处**右键**。
2. 从菜单中选择：「新建文件夹」「新建笔记」「导入 Markdown」「新建题目集」「导入资料…」「新建翻译」「新建作文」「新建思维导图」（部分视图还有「新建待办列表」）。
3. 新建的资源会立即打开（经典布局在右侧标签页，学习桌面里开成窗口），可以直接编辑。

注意：「最近」「收藏」「回收站」等聚合视图不支持新建，会提示"当前视图不支持新建资源"，请回到文件夹视图操作。

### 浏览、搜索与排序

1. **切换视图**：用工具栏的「网格视图 / 列表视图」按钮切换；列表视图显示"名称 / 修改日期 / 类型"列。
2. **排序**：点击排序按钮，选择「按名称」「按修改时间」「按创建时间」「按类型」「按大小」，并可切换「升序 / 降序」。
3. **搜索**：在工具栏搜索框输入关键词即可实时过滤。搜索主要匹配标题/文件名，带「[索引]」标记的结果来自内容索引。
4. **空格快速预览（Quick Look）**：选中一个文件后按**空格**，弹出轻量预览浮层——图片直接显示原图、PDF 显示第一页真实预览，其余类型显示大图标、名称、类型 / 大小 / 修改时间 / 所在位置和内容摘要（如有），用来快速确认"是不是这份"。再按空格或 `Esc`（或点浮层外）关闭；点浮层上的「打开」进入完整预览。
5. **记忆徽标**：被 AI 记入长期记忆的资源，会在文件名旁显示记忆徽标——类型（事实 / 学习 / 笔记）加用途（内化 / 补充 / 系统），重要条目还有一颗星标。徽标来自「AI 记忆」中的关联记录，详见 [深度调研与智能记忆](./03-深度调研与智能记忆.md)。左侧快捷导航的「收藏」也会显示收藏数量徽标。
6. **键盘操作**：`Ctrl / ⌘ + A` 全选当前视图；多选后按 `Enter` 一次打开全部选中项（数量有上限，超出会提示）；`Esc` 依次执行"关闭快速预览 → 清除选择 → 退出多选 → 清空搜索"。

### 整理：文件夹、移动、重命名与跨空间挂载

1. **建文件夹**：工具栏「新建文件夹」按钮，输入名称确认。文件夹最多嵌套 10 层、总数上限 500 个。
2. **移动**：右键资源 →「移动到…」，在弹出的文件夹选择框中选择目标位置，点击「移动到此处」。也可以直接把资源拖进文件夹图标。
3. **重命名**：右键 →「重命名」，输入新名称。
4. **撤销移动 / 重命名**：手滑移错了或改错名，按 `Ctrl / ⌘ + Z` 即可撤销最近一次移动或重命名（移动回源文件夹、名称改回旧名）；撤销失败时会提示，可再按一次重试。搜索结果中的操作不记入撤销栈。
5. **复制 / 粘贴 / 制造副本**：右键「复制」再到目标文件夹「粘贴」（或用 `Ctrl / ⌘ + C` / `Ctrl / ⌘ + V`）；「制造副本」（`Ctrl / ⌘ + D`）在当前位置直接生成一份副本，对标访达的 Duplicate。
6. **收藏**：右键 →「收藏」，之后可在左侧「收藏」快速找到；再次右键可「取消收藏」。
7. **挂载到学习空间**：对任意非回收站的资料或文件夹右键 →「挂载到学习空间...」，即可将其挂载到其他学习空间。挂载**不会复制文件，也不会重复建立向量索引**，各空间共用同一份原文与索引；在目标空间右键已挂载项可选择「解除当前空间挂载」，仅移除当前空间的引用，不影响原空间中的文件。

### 右键菜单速查

对单个资源右键，常用项包括：

- 「打开」/「预览」——打开资源；
- 「引用到对话」（部分视图显示为「添加到对话」）——把资源加入当前对话的上下文；系统通过统一的 `res_*` 标识解析资源，并自动透传当前解析、转写或索引处理状态，确保学习 Agent 准确知晓资料是否就绪；
- 「用这份资料制卡」——新开一个对话，引用这份资料并预填制卡指令，发送后 AI 按资料类型出一组复习闪卡（见 [Anki 制卡与模板](./12-Anki制卡与模板.md)）；
- 「挂载到学习空间...」/「解除当前空间挂载」——跨学习空间共享或解除共享（非回收站资源/文件夹可用）；
- 「收藏」「重命名」「移动到…」「复制」；
- 「添加到桌面」——在「桌面」视图创建快捷方式；
- 「导出」——把资源导出为文件保存到本地（不同资源支持的格式不同）；文件夹可以「导出为 ZIP」；
- 「删除」——直接移入回收站（无确认弹窗），随后弹出「已移入回收站」提示，点击提示上的「撤销」按钮可立即恢复；被对话引用的资源会额外提示"被 N 个对话引用"。

### 批量操作

1. 在文件区按住鼠标框选，或按住 `Ctrl / ⌘` 点选多个资源（触屏设备先点底部工具栏的「多选」开关）。
2. 底部批量工具栏会显示"已选择 N 项"，提供「全选」「添加到对话」「移动」「删除」按钮。
3. 批量删除同样直接软删进回收站（无确认弹窗），完成后提示"已将 N 项移入回收站"并附「撤销」按钮，可一键整批恢复。只有在**回收站内**批量删除（即永久删除）时才会弹确认框。

### 标签页与分屏

- 双击资源在右侧打开标签页，可同时打开多个并点击切换；标签可**拖拽排序**。
- 右键标签页可以：「固定标签页」（固定的标签不会被自动回收或批量关闭）、「关闭其他标签页」「关闭右侧标签页」，以及「在右侧打开」开启**分屏视图**——左右各显示一个资源，方便对照阅读；点「关闭分屏」恢复单栏。

### 桌面快捷方式

「桌面」是资源库的启动页，可以放常用入口：

1. 点击左侧「桌面」进入。
2. 在空白处右键 →「添加快捷方式」，可选择常用动作（如"新建笔记""全部笔记""收藏""最近访问"等预设）或具体资源；也可以对任意资源右键 →「添加到桌面」。
3. 右键快捷方式可「重命名」或「从桌面移除」（移除快捷方式不会删除资源本身）。

### 在学习桌面中使用资源库（Quick Look 式预览）

在学习桌面里，资源库以独立窗口出现（Dock 中的访达式图标），与全屏页共用同一套文件夹体系，另有几处桌面专属体验：

- **双击开窗而非开标签**：在资源库窗口中双击资源，会直接打开对应的应用窗口（笔记、教材、题目集、翻译、思维导图等各归其位），而不是右侧标签页。
- **悬停快速预览**：鼠标在文件上悬停片刻，会浮出一张玻璃预览卡，显示资源类型、标题和元信息，无需打开即可确认"这是不是我要找的那份"。
- **拖出开窗**：把资源从资源库窗口**拖出窗外**松手，即在桌面上直接为它开一个窗口，适合快速铺开多份资料对照。
- **文件预览窗口（对标 Quick Look）**：图片和普通文档会在轻量的「文件预览」窗口中打开，支持：
  - `Ctrl / ⌘ + F` 全文查找，命中高亮，`Ctrl / ⌘ + G`（`Shift` 反向）在命中间跳转；
  - 「打印」（支持的格式）、「另存为」导出副本；
  - 「用系统应用打开」「在文件夹中显示」；
  - 「引用到对话」——若先选中了预览中的一段文字，引用会带上选区上下文。

### 回收站

1. 删除的资源进入「回收站」，会一直保留，不会自动清除。
2. 在回收站中右键项目可「恢复」或「永久删除」；顶部提供「清空回收站」。
3. 恢复后如提示"内容搜索可能稍晚生效"，表示该资源已重新排队建立索引，稍等即可。

### 知识库索引：让学习 Agent「读到」你的资料

资源导入后会自动排队进行向量化：**提取文本（必要时 OCR 识别）→ 分块 → 生成向量（Embedding）→ 写入索引**。索引完成后，对话中的知识库检索才能精准命中这份资料。

**配置嵌入模型与自动重排**：

- 尚未配置嵌入模型时，页面顶部会显示醒目的配置引导横幅；点击可直达「设置 → 模型分配 → 嵌入维度管理」完成配置（参见 [模型与供应商配置](./14-模型与供应商配置.md)）。
- 配好嵌入模型后，先前「待索引」和「失败」的资料会**自动重新排队**开始索引，无需逐一手动点击。
- 在尚未建立向量索引或未配置嵌入模型的环境下，检索会自动**降级为关键词检索**，保证基础查找可用。

**多模态索引与页图直读**：

- 在「设置 → 模型分配 → 嵌入维度管理」中绑定多模态嵌入维度后，系统会**自动启用多模态索引**，对 PDF 页面、题目集、图片等按页面图像建索引，适合公式、图表密集或复杂排版的资料。
- 在使用支持读图的多模态模型对话时，知识库检索若命中带有页图的 PDF 页面，会自动将最多 **4 张**原始页图（单张 ≤ 4 MB）临时注入模型上下文，让模型直接「看图」作答，而不只依赖纯文本提取。

**查看索引状态与常用操作**：

1. 点击左侧「知识库索引」，顶部显示"文本索引进度 / 综合进度"和统计（总向量数、向量维度、索引错误、待更新），列表按「已索引」「待索引」「索引中」「失败」「不适用」标注并支持按类型筛选。
2. **一键索引**：点击「一键索引」，自动处理所有待索引资源（含 OCR 与多模态索引）。
3. **重试失败项 / 重建单个资源**：支持「重试全部失败项」、单项「重试」「重新索引」；内容更新过的资源会标注"内容已更新"，点「更新」刷新索引。
4. **重置状态**：点击「重置状态」会删除所有向量数据并把全部资源重置为待索引（不可撤销，二次确认），之后再执行一键索引。
5. **侧栏状态小条**：有索引任务时，左侧导航栏底部出现"索引中 x%""N 项待索引"或"N 项索引失败"的小条，点击直达知识库索引页；全部就绪时自动隐藏。

### 音视频

网课录像、讲座录音（MP4、MOV、MKV、M4A、MP3、WAV、FLAC 等，单个文件最大 4 GB）和其他资料一样存放在资源库里。在资源库中打开音视频，仍会就地显示学习视图：播放器、带时间戳的字幕、转写与导入字幕都在。想走完整的"转写 → 边看边问 → 讲义 → 制卡出题"流程，点工具栏的「在音视频中学习」进入「音视频」应用，详见 [音视频](./19-音视频.md)。

## 进阶用法

- **召回测试（文本 / 多模态切换）**：在「知识库索引」页点击「召回测试」，输入问题即可模拟检索并查看命中片段与相似度得分；已启用多模态索引时，可在「文本 / 多模态」之间切换，直观对比两种通道的召回效果。
- **清除 OCR 重新识别**：扫描版 PDF 如果识别效果差，可在资源的索引详情中选择「清除 OCR 数据并重新识别」。
- **AI 记忆**：左侧「AI 记忆」入口用于查看 / 编辑 AI 的长期记忆，详见 [深度调研与智能记忆](./03-深度调研与智能记忆.md)。
- **引用到对话的批量用法**：多选若干讲义 →「添加到对话」，再让学习 Agent "对比这几份讲义的重点"，是跨文档提问的高效路径（参见 [AI对话与会话管理](./02-AI对话与会话管理.md)）。

## 📱 移动端说明

移动端的资源库采用**三屏结构**：

- **左屏（抽屉）**：从屏幕左缘右滑或点顶栏 ☰ 打开，包含桌面 / 全部文件 / 最近 / 收藏 / 各资源类型 / 图片与文档 / 回收站 / 知识库索引 / AI 记忆入口，以及**＋新建按钮**（可直接新建笔记、题目集、翻译、作文、思维导图，创建后自动打开）。
- **中屏（文件区）**：单击文件夹进入、单击文件打开预览；顶栏面包屑逐级返回。新建文件夹请使用中屏工具栏的＋菜单。
- **右屏（预览）**：打开的资源以标签页展示，关闭最后一个标签自动返回文件区；从屏幕左缘滑动或点顶栏返回键回到中屏。

差异与注意点：

- **解析与渲染能力**：Android 单文件导入/解析上限为 **50 MB**；PDF 采用 PDF.js 渲染；支持纯文本、代码、PDF、EPUB 与 DOCX 解析，其余 Office 格式（如 `.xlsx` / `.pptx` / `.rtf` 等）以附件方式预览。
- **本地向量检索与重新关联**：Android 端基于 OPFS 提供本地向量存储与检索能力；PDF 原路径失联时，同样可在移动端使用「重新关联文件」恢复访问。
- **多选**需先点底部工具栏的「多选」开关，再逐个点选；批量操作按钮在底部常显。
- **「导出」在移动端不可用**，请在桌面端导出资源。
- 桌面视图的快捷方式**重命名/移除**目前依赖右键菜单，触屏上暂无对应入口；添加快捷方式可用底部按钮完成。
- 拖拽导入不适用于移动端，请使用＋菜单中的「导入资料…」「导入 Markdown」。
- Android 返回键遵循"先关浮层、再返回上一屏、最后退应用"的顺序。

更多移动端通用操作见 [移动端指南](./17-移动端指南.md)。

## 常见问题

**Q1：导入了教材，但学习 Agent 说"找不到相关内容"？**
先到「知识库索引」页确认该教材是「已索引」状态。若是「待索引」，点「一键索引」；若「失败」，点「重试」并留意错误提示——常见原因是未配置嵌入模型（去「设置 → 模型分配 → 嵌入维度管理」，配好后待索引与失败项会自动重排）或网络问题。

**Q2：扫描版 PDF 能被检索吗？**
可以。系统会自动对无文字层的 PDF 做 OCR 识别再建索引，页数多时耗时较长，可在侧栏状态条或「知识库索引」页查看进度。识别效果不佳时可「清除 OCR 数据并重新识别」；也可以绑定多模态嵌入维度，让多模态索引按页图直接召回。

**Q3：删除的文件还能找回吗？**
能。删除默认移入「回收站」并一直保留、不会自动清除：刚删完可直接点提示上的「撤销」，之后也随时可进回收站「恢复」。「永久删除」和「清空回收站」不可撤销，操作前会二次确认。

**Q4：为什么某些资源的索引状态是「不适用」？**
表示该资源类型或内容当前无法建立索引（例如空内容、不支持解析的压缩存档 `.rar` / `.7z` 等）。详情里会给出"不可索引原因"。

**Q5：文件很大导入很慢或预览不了怎么办？**
桌面端单文档解析上限为 **200 MB**（Android 为 **50 MB**，Markdown 单文件上限 **10 MB**，音视频最大 **4 GB**）。超过 100 MB 的超大 PDF 在内置阅读器预览可能受限，建议改用系统阅读器打开原文件；文本/表格过大时预览仅展示开头部分，可「导出」查看完整内容。

**Q6：同一份资料可以同时出现在两个文件夹或两个学习空间吗？**
在**同一个学习空间**内，资源只属于一个文件夹，可用「收藏」或「添加到桌面」为它建第二个快捷入口；如果想在**多个学习空间**共用同一份资料或整个文件夹，右键选择「挂载到学习空间...」即可——不会复制文件也不会重复建索引，不需要时再「解除当前空间挂载」。
