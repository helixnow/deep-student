# Paper Export Fonts

Noto Sans SC is distributed under the SIL Open Font License 1.1 in `OFL.txt`.
Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/Variable/TTF/Subset

The bundled static TTF instances were generated from `NotoSansSC-VF.ttf` using
fontTools 4.67.0 at `wght=400` and `wght=700`. The character coverage is unchanged.
Static weights ensure consistent PDF embedding and browser screenshot metrics.
These fonts are loaded only for paper exports, not for application UI text.
